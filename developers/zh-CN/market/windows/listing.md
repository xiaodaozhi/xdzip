## 说明

```text
打包与解压，都简单一点。

xdzip 是一款开源 Windows 压缩包管理工具。先查看包内内容，找到需要的文件，再选择性解压，不必每次都解开整个压缩包。基础压缩、解压和浏览可离线使用，归档内容在你的电脑上处理，无需注册 xdzip 账户。

浏览 ZIP、7z、RAR、TAR、CAB、ISO、UDF 等格式。通过搜索、排序和目录导航查找文件，排序时文件夹优先。可在多个标签页或独立窗口中打开压缩包，并在解压前预览受支持的文本、图像或静态 SVG。

创建 ZIP、TAR、TAR.GZ、7z 和 LZH 压缩包、ISO9660/Joliet 数据镜像及 Windows x64 ZIP 自解压文件。可使用 ZIP AES-256 加密或受支持的 7z 密码保护。分卷、固实归档和编辑单文件压缩包条目取决于具体格式及配置。

按喜好选择浅色或深色外观，调整字号，选择十种界面语言。任务进度清晰可见，需要时可以请求取消。

不同格式的功能有所区别。RAR、CAB 和 UDF 为只读，已有 ISO 镜像无法修改。使用其他应用打开包内文件时会生成本地临时副本，对副本的编辑不会自动写回压缩包。

面向配备 x64 处理器的 Windows 11 电脑。可通过文件资源管理器的现代右键菜单或“显示更多选项”中的传统菜单创建、解压归档，也可以在 Windows 设置中选择默认打开的文件类型。此版本由 Microsoft Store 管理更新。
```

## 产品功能

逐项填写，每行是一个独立功能，不要复制列表编号。

1. 浏览 ZIP、7z、RAR、TAR、CAB、ISO、UDF 等归档格式。
2. 通过搜索、文件夹优先排序和目录导航查找文件。
3. 按需解压选中的文件或文件夹，无需解开整个压缩包。
4. 创建压缩包、ISO 数据镜像及 Windows x64 ZIP 自解压文件。
5. 使用 ZIP AES-256 加密及受支持的 7z 密码保护。
6. 处理受支持的分卷和固实归档。
7. 向符合条件的普通单文件压缩包添加、替换或移动条目。
8. 按需预览受支持的文本、图像和静态 SVG。
9. 在多个标签页或独立窗口中管理压缩包。
10. 通过文件资源管理器的现代或传统右键菜单创建和解压归档。
