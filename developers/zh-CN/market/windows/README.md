# Microsoft Store 商店材料

[English](../../../market/windows/README.md) | 简体中文

[构建和提交商店包](build.md)。

[可复制的商店文案](listing.md)包含说明、十项产品功能、补充字段、七个关键字、版权、开发者信息、链接和图片说明。`zh-CN` 使用本目录，`en-US` 使用[英文文案](../../../market/windows/listing.md)。十种产品语言均维护在素材配置中，并可导出为各语言的文本文件。

一览面向 [支持政策](../../../../docs/zh-CN/engineering/support-policy.md)所述的 Windows 11 x64。商店版由 Microsoft Store 管理更新，同时声明现代和传统资源管理器菜单。现代命令要求已安装包具有 Microsoft Store 签名。

通过[本地导出与截图指南](capture.md)获取十语言独立文件。例行发包时，若现有素材仍准确，可在合作伙伴中心沿用图片，并按需更新「此版本的新增功能」文案。

## Store 一览语言规则

语言清单以 MSIX 包中声明的区域语言为依据生成。英语始终只使用 `en-US`，即使软件包声明了其他英语地区，也不额外添加对应的一览。繁体中文以 `zh-TW` 作为文案和宣传图来源，合作伙伴中心提供时添加 `zh-HK`、`zh-MO` 等地区；`zh-CN` 保持独立并使用简体中文材料。

对于西班牙语、德语、法语等其他语言族，只要软件包中存在匹配的 `xx-` 语言前缀，就添加合作伙伴中心提供的其他地区条目，并复用软件包中已有语言的文案和宣传图。软件包中没有对应前缀的语言族不添加，合作伙伴中心没有提供的地区代码跳过。每个新增地区都是独立的一览，必须随提交发布后才会显示；未提交的地区继续使用此前已发布的默认或回退一览。

## 文本字段

| 合作伙伴中心字段 | 材料或填写决定 |
| --- | --- |
| 产品名称 | 所有语言均为 `xdzip` |
| 说明 | 使用 [listing.md](listing.md) 中的纯文本块，不超过 10,000 个字符 |
| 此版本的新增功能 | 使用 [listing.md](listing.md#此版本的新增功能) 中的本地化文本 |
| 产品功能 | 十项分别填写，每项不超过 200 个字符，页面自动添加项目符号 |
| 短标题 | `xdzip` |
| 排序标题 | 留空，无需另设字母排序名称 |
| 语音标题 | 留空，本次为桌面应用，不使用 Xbox 语音标题 |
| 简短描述 | 使用本地化文案，控制在建议的 270 个字符以内 |
| 关键字 | 七项分别添加，每项不超过 40 个字符，空格分词总数不超过 21 |
| 版权和商标信息 | 使用不超过 200 个字符的本地化版权说明 |
| 其他许可条款 | 留空，不额外制定商店专用补充条款 |
| 开发者 | `xiaodaozhi` |
| 网站、支持和隐私政策 | 使用 [listing.md](listing.md) 中的专用链接，不把 URL 写进说明正文 |

补充条款留空不会改变应用已有的 Apache-2.0 许可及第三方通知。本材料包不决定商店定价，也不代替法律条款的接受操作。

## 应用截图与融合宣传图

从审核过的截图集导出，或[用已校验 MSIX 采集指定语言](capture.md)。按成品尺寸审阅导出的 PNG。拍摄采用默认窗口尺寸和自有演示文件。导出时裁去顶部的一行像素、清理四角并绘制内侧细边框，再与本地化文案和柔和阴影合成。

按以下顺序，把每种语言 `promotional/` 目录中的四张 **1920 × 1080** 融合宣传图上传到桌面截图栏。

| 顺序 | 场景 | 文件 |
| --- | --- | --- |
| 1 | 应用起始页 | `01-welcome-1920x1080.png` |
| 2 | 创建窗口与 ZIP 设置 | `02-create-1920x1080.png` |
| 3 | 按需图像预览 | `03-preview-1920x1080.png` |
| 4 | 多标签与网格浏览 | `04-workspace-1920x1080.png` |

导出结果还包括 `screenshots/` 下的纯界面图，以及 `feature-illustrations/` 下带用途说明的功能示意图。需要 3840 × 2160 成品时加 `--4k`。[商店一览文案](listing.md)提供各场景的图片说明。

## 图标、头像和商店品牌图

每种语言的 `branding/` 目录包含 71、150、300 像素应用图标，512、1024 像素头像，720 × 1080 与 1440 × 2160 招贴画，1080 与 2160 像素方形品牌图，以及 1920 × 1080 无文字横幅。选择 4K 导出时也会生成 3840 × 2160 横幅。

## 编辑与重新生成

在[营销规格](../../../../specs/marketing/windows-store.json)修改十语言文案，在[宣传图生成脚本](../../../../scripts/build-windows-store-assets.cjs)调整构图。用 `node scripts/build-windows-store-assets.cjs` 刷新 Markdown 一览文案。文案或版式更新后，可[重新导出审核过的截图集](capture.md#从审核过的截图集导出)。截图导出仅为已采集并校验的语言生成融合图。

提交新的图片后，把审核过的导出目录复制到备份位置。保留 `capture-source/`、实际上传的图片和 `manifest.json`，便于重新渲染或还原提交。清单分别记录采集截图的程序包和一览导出版本。根 README 的展示图单独维护。

## 审核字段

[审核说明](reviewer-notes.md)提供英文和简体中文的 `runFullTrust` 用途说明与认证测试说明。十语言导出包包含各语言的审核文案，可复制到相应栏目。本材料包不表示受限功能已经获批或已提交认证。定价、年龄分级和账户级问卷仍属于合作伙伴中心的其他提交栏目。
