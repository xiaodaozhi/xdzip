# xdzip 设计交付目录

[可操作组件页](html/components.html)与[功能覆盖（本地／CI 工件）](../docs/qa/README.md)提供菜单、按钮状态和主窗口行为复核。

**HTML 界面从 [html/index.html](html/index.html) 打开，完整原稿从 [hifi/index.html](hifi/index.html) 查看，素材统一从 [assets/index.html](assets/index.html) 查看。** 三个入口分别负责实现、视觉依据和共用素材；历史迭代由 Git 保存，不再按交付批次拆目录。

原来分散在 `assets` 和 `hifi` 的图标已经合入同一素材库。HTML 载入两种主题的共用 SVG 和三张示例照片，Qt 引用同源透明 PNG；实际资源别名见素材清单。原稿对照切片也完整保留，并与运行图标区分用途。

目录树 B 的多级展开、交互与边界图板已经归档，切图、共享分支圆点与状态图标及[接入规格](../docs/ux/directory-tree.md)同步交付；[专用 HTML](hifi/directory-tree.html)可集中查看。HTML 示例与 Qt 只读树已接入核心交互；专用边界提示和骨架资源仍待接入。

## 图标尺寸

所有界面图标使用 `viewBox="0 0 24 24"`，PNG 导出为 24×24、48×48、72×72。PDF、文本、代码和 Markdown 图标共用中心与 22 像素可见高度，保留各类型的轮廓宽度和内部样式；文件夹采用 22×约18.86 的横向轮廓，在相同画布内居中。HTML 使用统一的 48×48 源空间槽位，Qt 文件列表使用统一的 18×18 逻辑像素槽位，不再逐类型放大或平移图标。系统应用和 ZIP 文档图标另从品牌母版导出 16 至 1024 像素 PNG、ICO 与 ICNS，不能用界面画布限制平台图标分辨率。

原像素对照切片保留各自裁切矩形，因此其物理尺寸不同；其尺寸不用于设置运行时图标大小。调整 SVG 后重新导出 PNG，HTML 与 Qt 才能保持同一图形。

当前应用标记采用四条交错带与 U 形下部，应用品牌、蓝色归档和灰色归档标识共用 `scripts/brand_assets.py` 的几何。它是明确的新品牌设计修订，完整高保真原稿中的旧 ZIP 标志仍作为历史视觉依据保留。平台接入与本轮补图见 [品牌与素材复核（本地／CI 工件）](../docs/qa/README.md)；交付 ZIP 图标不代表已注册系统文件关联。

## 更新顺序

1. 新增完整原稿放入 `hifi/screens/`，更新原稿清单；不能修改原稿来掩盖实现差异。
2. 图标修改统一生成器；品牌修改共用品牌几何并先导出平台图标，再生成浅深色界面 SVG 和 PNG。在素材画廊与对应原稿或新设计依据逐项核对。
3. 运行 `python scripts/build-html-design.py`，同步 HTML 共用素材并生成离线交付。
4. 运行素材、资源集成与 HTML 检查，再查看实际渲染。交互或结构检查通过不等于视觉验收通过。

未采用的品牌母图、早期提案、旧原型与重复素材交付目录已删除。历史 QA 报告保留当时的截图、数值与哈希；旧输入路径通过素材迁移清单或对应 Git 提交追溯。

Qt 实际截图在 `docs/qa/`，HTML 截图在 `html/screenshots/`；两者都不是原稿。
