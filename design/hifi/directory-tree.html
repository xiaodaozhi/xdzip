行为与状态

有无子目录决定箭头；条目数表示全部后代物理记录，包含重复记录，排除该节点自己的目录记录，不受搜索影响。只有文件或为空的叶子都没有箭头，同层级保留空槽。方向键焦点、展开、当前目录及文件复选框状态相互独立。

操作结果
点击箭头只展开 / 收起，不改变列表路径、文件选择或详情。
点击名称 / Enter激活目录；成功替换查询后按既有规则重置分页、选择与详情。
上 / 下移动可见目录行的焦点，不自动进入目录。
右 / 左展开 / 收起；已经展开或无法收起时移到子节点 / 父节点。
收起当前目录的祖先列表保持当前目录；最近可见折叠祖先显示圆点，焦点回到可见行。
深层级 / 长名称层级区横向滚动，数字固定靠右；省略名称可查看完整名称与路径。
200% 字号行高、图标槽与箭头命中区增长，文字和计数不裁切。

读取时未知计数显示“—”，索引完整后发布树。空归档的文件列表为空；只有根文件时列表正常显示。导航索引超限仍可使用全部文件和搜索；读取失败提供重新打开，不假装空目录。
