组件规范

设计参数与大字号规则见 目录树规范；各主题共享形状，颜色遵循主题参数。文件夹保持自然比例，运行控件按统一逻辑槽绘制。

行为与状态

有无子目录决定箭头；运行树不显示计数；原稿中的数字保留其设计参考身份。只有文件或为空的叶子都没有箭头，同层级保留空槽。方向键焦点、展开、当前目录及文件复选框状态相互独立。

操作结果
点击箭头只展开 / 收起，不改变列表路径、文件选择或详情。
点击名称 / Enter激活目录；成功替换查询后重置选择与详情。
上 / 下移动可见目录行的焦点，不自动进入目录。
右 / 左展开 / 收起；已经展开或无法收起时移到子节点 / 父节点。
收起当前目录的祖先列表保持当前目录；最近可见折叠祖先显示圆点，焦点回到可见行。
深层级 / 长名称按已展开节点宽度横向滚动；不显示文件数或悬浮提示，完整路径保留可访问描述。
200% 字号行高、图标槽与箭头命中区增长，文字不裁切。

索引完整后发布目录树。空压缩包的文件列表为空；只有根文件时列表正常显示。导航索引超限仍可使用根目录和搜索；读取失败提供重新打开，不假装空目录。
