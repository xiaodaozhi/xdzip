独立 Windows 自解压

自解压文件不附带 Qt。以下流程仅使用 Windows 系统文件夹选择器和 TaskDialog，系统决定控件比例、字体、密度、DPI 和辅助功能；不将系统截图像素转换成 Qt 逻辑尺寸。桌面创建窗口沿用 C01 格式选择。

1. 选择目标文件夹

系统文件夹选择器，允许键入已存在的目录。取消即退出，不写文件。完成选择后在可取消的进度窗口校验包体，只有校验通过才进入输出。

2. 确认同名处理

主说明为“遇到同名文件时”，正文显示完整目标路径。按钮为跳过、自动改名、覆盖和取消，默认跳过。页脚说明仅解压，绝不运行解压出的文件。

3. 解压与取消

主说明为“正在解压”，正文显示当前文件、已提交文件数和总文件数，系统进度条与取消按钮保持可用。取消发往共享 Rust 任务，等待暂存清理完成后关闭进度框。已提交文件保留。

4. 结果

分别显示解压完成、已取消或未能完成，正文显示已保存和已跳过文件数。仅提供关闭，不打开目标目录，不运行任何载荷。英文环境使用对应英文资源。
