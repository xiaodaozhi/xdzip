# xdzip：软件设计总览

版本：设计基线 0.1；日期：2026-10-11；状态：待实现。产品名称：**xdzip**，统一使用小写拼写。

用户已选择 **Qt Quick**。正式技术方向为 **Qt Quick/QML + 薄 C++ 适配层 + Rust 核心**。本套文档定义产品行为、模块边界、接口契约、扩展、安全、性能和交付流程，供开源维护者分工实施。本仓库是独立的正式产品仓库，当前只包含开发前文档和设计资产，没有产品代码。历史界面选型实验未迁入本仓库。

## 核心决定

1. 双击压缩包先浏览内容；解压、压缩、覆盖及执行外部程序都由明确操作触发。
2. UI 不实现归档业务。Rust 核心不依赖 Qt，预留测试驱动和未来 CLI 接入。
3. 正式 Qt/Rust 边界使用 `cxx` 生成的构建期类型桥接，不承诺跨版本二进制 ABI。原型的 JSON/C ABI 仅用于迁移验证。
4. 格式以能力声明驱动。源码级 Rust 扩展和进程级第三方扩展是不同契约；不加载任意 Rust 动态库。
5. 文件授权、路径校验、输出事务和配额集中在宿主。编解码器不能自行挑选真实输出路径。
6. 先完成 ZIP 和 TAR/GZIP 的真实闭环，再扩大格式范围。7z、RAR、加密、分卷、第三方沙箱均有独立验证门槛。
7. UI、索引、任务、插件均有有界队列和缓存；任务终态不能被进度事件淹没。
8. 把“小、快、低占用”转化为机器配置和工作负载明确的预算，不把原型二进制大小当安装体积。

## 证据与未验证项

现有比较在 Debian 13/x86_64、Xvfb 软件渲染下完成。Qt 6.8.2 原型的重复启动准备标记 P50 约 158ms，峰值全进程树 PSS 中位数约 81.9MiB；Qt 程序与 Rust 动态库合计约 0.80MiB，**未含 Qt/QML 运行库**。这不是最终产品首帧、安装包或真实解压性能。

实验原始报告和数据保存在独立的 archive-ui-lab 工作区，未随本仓库分发；上述数字只是历史背景，不是本仓库可复现实测证据。设计选择遵循用户确定的 Qt Quick 方向；后续 Mac 验证用于修正部署、字体、交互和预算，不重复发起框架选型。macOS、Windows、GPU、中文输入法、系统无障碍、签名安装包、真实格式互操作和外部插件沙箱尚未完成验证。

## 设计成熟度

| 内容 | 当前状态 | 落地要求 |
|---|---|---|
| 产品体验、核心模块、任务状态、中心安全策略 | 设计决定 | 编码前补充具体类型及用例测试 |

| 第三方进程协议 | v1 草案 | 两个独立样例扩展通过兼容性套件后冻结 |
| 平台沙箱、GPU、打包尺寸 | 待验证 | 在目标机器和签名包上验证，缺少沙箱时禁用第三方执行 |
| 性能数值 | 初始工程预算 | 参考机冻结并测量，不作已实现承诺 |
