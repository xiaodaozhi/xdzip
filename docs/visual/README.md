规范入口：[界面设计规范](design-standard.md)、[强制设计流程](design-workflow.md)、[密度与单位契约](layout-scale.json)。主窗口与菜单比例的复验按[通用方法](../qa/README.md)记录。

当前原稿见 [design/hifi](../../design/hifi/README.md)，可操作 HTML 交付见 [design/html](../../design/html/README.md)。未采用的早期提案不作为当前基线；不要依赖已整理的 main 历史查找旧稿，当前原稿以此目录及清单为准。

`tokens.json` 保存主题与通用实现参数。主窗口几何和字号从独立冻结的 [qt-main-reference.json](qt-main-reference.json) 生成，依据高保真原稿及已验收 HTML 的量测，按 1024/1548 等比换算；此前 1280 宽的基准折算为正常密度。取整、实际截图和未实现能力按[验证方法](../qa/README.md)分别记录；实现参数不能反过来充当设计验收基准。

4. [Transmit 官方界面](https://panic.com/transmit/)：借鉴文件管理工具的信息密度、路径导航和克制的分隔方式。
5. [Linear 2026 界面改版说明](https://linear.app/now/behind-the-latest-design-refresh)：参考较安静的侧栏、紧凑导航、柔和边框及中性底色，让中央内容区成为视觉重点。

调研日期为 2026-10-11，基于公开官方截图、演示和文章；不宣称这些画面对应各产品最新安装版。第三方调研素材保留在独立实验工作区，不纳入本仓库。

## 视觉系统

采用暖灰底色、钴蓝主操作和石墨深色主题。避免以大面积渐变或磨砂背景替代信息层级。正常文件列表保持清晰平面结构；阴影只用于浮层。左侧回答“在哪里”，中间回答“有什么”，右侧回答“选中了什么”。

HTML 与 Qt 共用 [Xdzip Design Sans SC 字体](../../design/assets/fonts/README.md)的字形与度量，Qt 使用同源 TTF，超出子集的归档名称使用平台回退。主列表 13、列头与工具栏 12、分栏标题 13 逻辑像素；字体采用 Qt 整数像素取整。文件名保留完整可访问名称；视觉截断显示省略号并提供悬停全文。文件图标共用约 31.75 逻辑像素槽位，不按文件类型分别补偿尺寸。

主窗口初始 1024 × 622、最小 832 × 544 逻辑像素。侧栏与预览栏的源测量约 193.16 / 257.98，Qt 结构边界取整为 193 / 258；目录行约 43，文件行约 44.65。分栏标题高 46，表头高 34，搜索与主按钮约 33.74。目录树 B 独立保持 32 高与 16 图标槽。窄于 928 时预览栏收起，通过按钮打开独立原生窗口。设置提供 100%／125%／150% 字号，旧 200% 配置按 150% 读取；大字号通过真实布局、滚动和独立详情窗口适配，不以整体缩放掩盖溢出。分栏拖拽与宽度记忆尚未实现。

## 主窗口交互

- Qt 支持独立归档会话，按已保存的打开模式创建胶囊标签页或主窗口，重复打开激活已有会话。各页面保留路径、选择、排序和滚动状态，关闭页面后任务继续运行，见[应用会话契约](../engineering/application-sessions.md)。HTML 多标签仍仅用于验证设计。
- 主按钮：没有选择时为“全部解压”，有选择时为“解压所选”；下拉菜单始终提供另一种范围。
- 文件表格支持排序、多选、范围选择和键盘导航。文件夹双击进入；普通文件显示属性，不运行内容。受限内容预览是后续能力，不能把 HTML 示例照片当作已接入的 Qt 解码预览。
- 搜索递归当前目录及其后代，根目录搜索覆盖全部内容；搜索结果显示完整压缩包内路径，普通目录列表显示末级名称。
- 详情栏支持关闭与重新打开。预览需异步读取并限制资源；不支持时显示属性和解压入口。任务取消后丢弃迟到的预览结果。
- 状态栏显示选择数量与原始大小、索引状态和可重开的任务历史数；活动任务数单独用于提示与退出保护。索引尚未结束时明确标记“正在读取”，不展示伪造的完整数量。

## 解压面板交互

面板集中展示归档、目标位置、选择范围、同名策略和完成后行为。示例选中 8.4 + 6.2 + 12.8 = 27.4 MB。文件列表只作摘要，较多时显示“查看全部”。

目标位置默认使用上次目录；“创建同名文件夹”在最终路径预览中即时体现，避免重复嵌套。路径权限、剩余空间和归档读取失败均用文本提示；检查中的状态独立显示，无法确认空间时显示“未知”。

重名默认询问，另外提供跳过、自动重命名和覆盖。用户选择覆盖时清楚标记后果。执行中显示实际阶段、已处理文件数、可计算时的字节进度与速度；未计算出总量时使用不定进度。取消后显示“正在停止”，由后台确认停止后再结束任务。

## 组件状态与可访问性

| 组件 | 必备状态与反馈 |
| --- | --- |
| 主按钮 | 默认、悬停、按下、键盘焦点、禁用、提交中；避免重复启动 |
| 文件行 | 默认、悬停、选中、选中但窗口失焦、键盘焦点；选择态不只改变文字颜色 |
| 搜索 | 空、输入、搜索中、无结果、清除；支持 Esc 退出焦点，保留搜索文字 |
| 预览 | 未选择、加载中、已加载、不支持、错误、已取消 |
| 任务 | 等待、运行、等待密码/重名决策、停止中、完成、部分失败、失败 |
| 模态面板 | 焦点约束、Esc 关闭未提交面板、关闭后焦点回到触发按钮 |

主题颜色在 Qt 实现后验证 WCAG AA 正文对比度，焦点外观与退出行为遵循当前设计规范，不额外绘制焦点环。提供屏幕阅读器名称和状态公告，尊重系统减少动态效果设置。常规过渡建议 120–160ms，不对文件列表持续播放装饰动画。

## Qt Quick 实施约束

建立统一 Theme 与尺寸 token，QML 组件不得散落硬编码主题色。建议组件包括 ArchiveTabs、ArchiveToolbar、ArchiveTree、ArchiveTable、InspectorPanel、ExtractDialog 和 TaskPanel。文件列表使用可虚拟化模型，预览、索引和压缩操作均由后台驱动；QML 负责呈现与用户意图，不承担格式解码。

macOS、Windows、Linux 共用内容布局与交互模型；窗口按钮、菜单与快捷键遵循各平台习惯。这里绘制 macOS 窗口外框，不要求其他平台复制交通灯按钮。大面积实时模糊不作为实现要求；截图中的背景弱化可用静态遮罩实现。

当前完整原稿覆盖浅色归档浏览、解压确认、新建、冲突、任务、结果与设置。深色图标已有适配，完整深色主窗口、插件管理及部分异常页面仍需补齐；完整产品页面尚未全部定稿。

## 原稿与统一素材库

[完整原稿](../../design/hifi/README.md) 集中在 `design/hifi/screens/`，包括主窗口、解压确认与八张操作状态图板。功能及恢复路径见 [状态契约](../ux/hifi-state-spec.md)。原稿保持原始字节，原稿及其切片不能因实现需要而修改。

[统一素材库](../../design/assets/README.md) 集中全部主窗口与操作状态素材，取消按交付批次拆分的目录。SVG 是透明运行图标的唯一图形源，HTML 直接嵌入，Qt 使用同源多倍率 PNG。45 张原像素对照切片保存在 `reference/`，保留精美原图、裁切范围及背景；三张 HTML 示例照片保存在 `demo/`。两者都在同一清单中标明用途，避免把带背景切片当作透明图层。

所有透明图标共用 24×24 画布。PDF、文本、代码和 Markdown 图标统一中心与 22 像素可见高度，保留各类型的轮廓宽度和内部样式；文件夹采用 22×约18.86 的横向可见轮廓并在画布居中。此高度约束用于运行图标，不描述原稿切片的尺寸。1×/2×/3× PNG 分别为 24×24、48×48、72×72；倍率不改变逻辑大小。HTML 文件列表统一使用 48×48 源空间槽位，Qt 文件列表使用同尺度换算后的约 31.75×39.69 逻辑像素槽位，取消逐类型 CSS 放大、平移和描边补偿。

文件列表面包屑与右侧预览／详情标题共用栏高、字号和文字垂直中心。HTML 使用共享标题栏变量，Qt 使用 `PaneHeader` 与 `Theme.mainPaneTitleSize`；标题保持在滚动内容上方，大字号同步增加两栏高度。实际量测按[验证方法](../qa/README.md)保留于执行工件。

HTML 照片预览从分栏标题下边缘直接开始，顶边与文件列表表头一致，不增加额外顶部间距；搜索提示条出现时，按其实际占位同步对齐。图片高度和下方内容间距沿用既有规格。照片对齐复验覆盖两张示例图片、浅深色、三种窗口装饰及搜索变化。

文件列表的原始大小、压缩大小标题与数值靠右对齐，类型标题与内容靠左对齐；每列共用内容边距。HTML 保持原有列宽和行高，大小列右边距分别为 26、22 源空间像素，类型列左边距为 28 源空间像素。复验须记录全部可见行的文字布局边缘。

图标轮廓形状、原像素对照切片尺寸与运行画布尺寸分别记录；文件夹无需被拉长成纸张形状，SVG 也不应为填满槽位而变形。视觉调整集中在图形源完成，在素材画廊复核后再同步两种实现。

## 当前主稿的工具栏修订（2026-10-12）

上述早期通用控件建议不再用于主工具栏。当前控件的原稿量测为 51 源像素高、18 源像素字号、32 源像素图标，按主窗口 1024/1548 换算为约 33.74 高、12 整数字号和 21.17 图标画布；工具栏区域高 53。此前按 1280 宽换算的 42.17/15/26.46 已被正常密度取代；普通操作窗口继续使用各自登记的映射。

工具栏左右普通动作与搜索/主操作分组布局；大字号可增长高度，搜索框可收缩，保证最小窗口下右侧操作完整可见。禁用文字不叠加整组透明度，主按钮使用单独的禁用背景颜色。解压主按钮保留分隔线和下拉箭头的禁用外观，实际解压与范围菜单按运行时能力启用，未选中时禁用所选范围与元数据预检；独立完整性检查仍禁用。复验按[通用验证方法](../qa/README.md)记录。

## 应用品牌与平台图标

应用品牌采用四条交错带与开放的 U 形下部，几何统一维护在 `scripts/brand_assets.py`。独立标记、应用图标与 ZIP 文档母版位于 `design/assets/brand/`；界面的 `app-mark`、`archive`、`archive-grey` 分别用于应用、蓝色归档和灰色归档身份，均从同一品牌几何生成。应用使用蓝色圆角外形，文档使用纸张与折角外形，身份共用而外框各有职责。

当前标记保留修长的 2:3 比例，不横向拉伸为旧标记宽度。底板使用四角旋转对称的连续曲率曲线，曲率从直边的零值平滑增加到对角中点，避免圆角中间出现斜切感。光照与底板使用同一路径；不叠加不同半径的描边或开口高光线。文档徽章沿用同一轮廓定义。

这是明确的新品牌设计修订，不能把它描述为旧高保真原稿中 ZIP 拉链图标的无差别还原。十张完整原稿、45 张原像素图标参考和三张示例照片保持原字节；新生成的 `brand/identity-reference.png` 是当前品牌的视觉方向，用于审阅，不作为运行资源。主素材清单逐项记录参考覆盖，对旧品牌参考明确标注历史设计角色。

界面小图标仍使用 24×24 画布；平台图标分别从母版导出 16/24/32/48/64/128/256/512/1024 像素透明 PNG。16/24/32 像素简化不可读文字及大图光影，保留交错带与 U 形的识别结构；应用和 ZIP 文档各提供含七种尺寸的 ICO、含十一种密度表示的 ICNS。不能把 24 单位界面图标无限放大充当系统图标，也不把大图阴影缩成小尺寸噪点。

系统应用图标接入 Qt 窗口、macOS app bundle、Windows 可执行资源以及 Linux 桌面启动项 / hicolor 图标目录。ZIP 文档平台格式已用于安装器及文件关联，系统打开请求通过统一路由进入真实浏览，详见[安装与关联契约](../engineering/installers-associations.md)。只注册打开候选，不修改用户默认应用。平台验证按[通用方法](../qa/README.md)记录。

主题、成功、取消、冲突及进度缺图从原像素参考补齐为独立语义素材；取消大图使用方形停止符号，系统主题保留完整窗口结构。HTML 使用原生单选输入，Qt 使用 IntentRadioButton 将鼠标、键盘与辅助功能动作路由至同一选择模型；素材只负责外观。此次新增与修订素材的生成检查、目标平台显示和原稿差异分别记录，既有验收不能代替本轮结果。

## 可操作控件规范

[controls.json](controls.json)定义菜单四列、行高、圆角、颜色、焦点和提示时序；[directory-tree.json](directory-tree.json)定义目录层级。两份规格生成 HTML 控件参数和 QML Theme，通过检查避免手工复制尺寸与主题。主稿的逻辑 / 源像素比例从 `display-spec.js` 读取；[组件审阅页](../../design/html/components.html)采用 1:1 逻辑尺寸，主画布仍使用源坐标。功能清单与输入契约在[主窗口组件说明](../ux/main-window-components.md)，真实渲染与行为按[验证方法](../qa/README.md)保存到对应 issue 与工件。
