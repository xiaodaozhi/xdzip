# 界面设计规范

本规范约束界面创作、HTML 设计交付和 Qt 实现。尺寸换算以 [layout-scale.json](layout-scale.json) 为准；颜色、共享控件和目录树分别以 [tokens.json](tokens.json)、[controls.json](controls.json)、[directory-tree.json](directory-tree.json) 为准。原稿量测保存在 [qt-main-reference.json](qt-main-reference.json)，不以实现结果反向改写原图。

## 单位与密度

1. 所有交付值使用逻辑像素：HTML 的 CSS px、Qt 的 device-independent pixel。截图物理像素除以 DPR 后才能和设计值比较。素材的 1×／2×／3×仅决定采样清晰度，不改变图标槽尺寸。
2. 主窗口此前 1280 宽的基准按 125% 处理，折算到 100% 使用 `1 / 1.25 = 0.8`。新默认客户区为 1024×622；最小客户区为 832×544，预览收起阈值为 928。标题区、工具栏、分栏、文件列表、目录树、底栏的空间尺寸和字号都执行这次密度校正。
3. 弹出菜单与提示采用正常密度，不再跟随主窗口密度一起缩小。菜单默认 240 宽、最小 32 行高、13 字号、18 图标槽。主列表目标约 12.57，Qt 取 13；菜单／列表字号比例必须落在 0.95～1.10。不能只检查各自的参数而漏掉相互比例。
4. 主原稿内部客户区 1548×940 是量测坐标。HTML 主画布换算比例为 `1024 / 1548`；菜单的 CSS 源坐标反向换算，最终保持上述逻辑尺寸。普通操作窗口沿用 `1280 / 1548`。解压原稿采用单独的 `819.2 / 1548` 映射，窗口约 491 宽；这是修正独立入口比嵌入入口大 25% 的明确密度调整。各入口必须共用同一最终逻辑尺寸，不能在嵌入和独立展示时分别指定组件字号。
5. 浏览器审阅倍率、浏览器页面缩放、系统缩放和 DPR 都不得写入组件尺寸参数。Qt 不通过 `Item.scale`、窗口截图缩小或额外 1.25 系数实现密度校正；由规范参数生成真实布局与整数 pixelSize。
6. 1 逻辑像素分隔线与焦点描边保留规范值，原生系统窗口装饰由操作系统负责。空间尺寸保留小数；结构边界和窗口尺寸按最近整数取整，Qt 字号在密度换算后、辅助字号放大前取整。

## 标题区修订

主标题栏采用 48 逻辑像素高度；标签采用 32 高、16 圆角的悬浮胶囊，上下各留 8。活动标签使用完整边框，不与工具栏相连。标签关闭、加号、设置按钮与标题栏共享垂直中心。辅助字号放大时先增高胶囊，再保留上下相等留白。此修订替代原图的底部吸附标签，原图保持存档。

## 组件规则

每个组件必须明确尺寸、字号、图标槽、内边距、对齐边、命中区域、状态和数据来源。禁止只交付默认状态。按钮必须覆盖 normal、hover、pressed、focus、disabled、busy；菜单必须覆盖键盘选中、子菜单、checked、disabled、边缘翻转和滚动；目录树必须覆盖子层级、叶节点、折叠当前路径、深层滚动和长名称；文件列表必须覆盖表头／内容同边对齐、排序、多选、空态和未知数据。

数字列同边右对齐，类型列同边左对齐。面包屑与预览标题区高度、字号、文字基线一致；预览顶边与文件表头顶边一致。图标按槽居中，文字按字体度量对齐。所有图标使用统一素材库，不从带底色截图中临时裁切。

主窗口正常密度校正与辅助字号放大是两个独立步骤。200% 字号可以增加高度、滚动或打开独立详情窗口，不能用缩小文字抵消辅助字号选择。任何视觉例外必须记录理由和验证范围。

## 验收门槛

HTML 与 Qt 必须在同一逻辑宽度下对比；原稿只裁去外背景并按明确比例展示。几何误差最多 1 逻辑像素，文字／图标垂直中心误差最多 0.5，要求共线的分栏顶边误差最多 0.01。截图报告必须写明提交、平台、渲染后端、浏览器缩放、审阅倍率、DPR 和逻辑窗口尺寸。

必须验证 100%／125% 浏览器页面缩放及 DPR 1／1.25／2；对应的 Qt 测量验证高 DPR 下窗口、字体、菜单仍使用相同逻辑参数。验证工具不能用 CSS zoom 冒充真实浏览器页面缩放，也不能把离屏截图写成原生桌面窗口验收。检查数不是视觉还原百分比。

变更按 [界面设计流程](design-workflow.md) 执行；规范、生成输出、实际坐标、截图和交互证据缺一项时，不能标记完整验收。

## 主窗口交互修订

主工具栏图文间距固定为 6；图标独占按钮时在内容框居中。列表／网格／排序按钮采用固定 28×28 圆角方形，标题区间距固定为 6.4，面包屑吸收剩余空间。面包屑按钮正常高度为 28，上下留白；菜单与调用按钮间隔 4，底部菜单向上展开。树行不显示文件数，左边选中边平直、指示线全高，子节点不使用四边描边。树宽按已展开节点的真实文字度量计算。完整修订及检查见[主窗口交互验收](../qa/qt-interaction-fixes.md)。

## 操作窗口与任务状态素材

普通独立窗口沿用 1280／1548 源坐标换算，宽度约 612；进度原稿映射为 1024／1548，最终宽度保持 846。操作窗口随当前审阅上下文换回源坐标，不能因从解压窗进入进度窗而再次缩小。解压使用 [extract-reference.json](extract-reference.json) 冻结的原稿哈希、量测和映射，宽度 491、标题 20、正文 13、路径框约 35 高、内嵌更改按钮约 69×24。Qt 直接使用真实布局尺寸，不用 Item.scale 或截图缩小。HTML 将正常尺寸换回当前审阅上下文的源坐标，独立和嵌入入口最终尺寸必须相同。

解压目标与重名卡片为均匀底色，范围卡片为浅色标题带与白色正文；浅色卡片 #F4F6FA、边框 #DFE5EF、路径与下拉框边框 #C9D1E0，深色对应值见 tokens.json。路径图标、可编辑路径和“更改”按钮共享一个边框。复选框使用统一素材库的选中图形。所有操作窗口复用 xdzip 内建下拉组件，覆盖选中、禁用、键盘导航、Escape、焦点返回及边缘翻转。菜单保持与调用控件 4 逻辑像素间距。

所有 footer 的按钮文字为 13、辅助文字为 12、图标槽为 16 逻辑像素，由 layout-scale.json 生成；正文单独滚动，footer 固定可达。字体、颜色与 1 逻辑像素描边不随嵌入／独立入口变化。当前整改与实际对照见[解压窗口复核](../qa/extract-fidelity/README.md)。

解压目标卡片的“创建同名文件夹”和目标检查反馈使用同一 24 图标槽、16 可见标记与 8 图文间距；标记光学中心共线，文字起点相同，各行文字与标记垂直居中。检查中或失败时仍保留图标槽，文字不向左跳动。“更改”按钮右侧留白等于其上下留白，按路径框与实际按钮高度之差的一半计算；辅助字号增大时保持这一关系。

任务结果圆盘采用 [status-icons.json](status-icons.json) 的纯色填充与白色语义标记，24 单位画布、20 可见直径；没有渐变、高光、细边或阴影。浅深色 SVG 和 1×／2×／3× PNG 同步导出。既有原稿与参考切片保留历史像素，不改写为新风格。实际验证见[操作窗口与扁平素材验收](../qa/operation-windows.md)。

## 根目录与文件项交互

目录树顶部“档案文件”与面包屑标题共享垂直中心；普通目录浏览只显示直属文件和目录，树入口为“根目录”。完整归档路径保留在数据中，普通列表显示末级名称，搜索结果显示完整路径。树悬停没有浮动提示；完整路径保留可访问描述。父层竖线中心 X 与父节点展开箭头中心 X 一致。

列表悬停覆盖整行全部列，选中填充优先。网格左右内边距为 16，卡片槽 144×124、槽间留白 12、图标槽 40；复选框位于卡片内部左上 8×8，悬停可见，选中后常驻。辅助字号放大时槽位按真实字体需求增长。预览面板重新打开按钮同样为 28×28。菜单阴影参数半径 12、下移 4，Qt Canvas 使用一次模糊圆角轮廓绘制，兼容软件与 GPU 渲染，不叠加矩形模拟阴影；HTML 使用同源参数的 CSS 模糊阴影。验证实际像素与浅深色状态。深色分裂按钮分隔线使用深色 border 色。
