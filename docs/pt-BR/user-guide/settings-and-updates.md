## Configurar o espaço de trabalho

Abra **Configurações** no menu do aplicativo ou na barra de ferramentas. Escolha o idioma, o tema, o tamanho do texto e a densidade nos ajustes correspondentes. A detecção automática usa o idioma do sistema quando há suporte. Escolha se os arquivos compactados abrem em abas ou janelas. Você também pode configurar o histórico de arquivos recentes e o ícone na área de notificação se a plataforma oferecer essas opções. As mudanças são aplicadas de imediato. Se uma configuração não puder ser salva, veja a mensagem de erro da página. [Comportamento das configurações](../ux/settings-localization.md)

Altere as associações de arquivos no sistema operacional. As ações do menu de contexto têm configurações próprias. No macOS, o sistema controla a ativação da extensão do Finder. Os serviços do Finder ficam disponíveis quando são registrados. [Ações do gerenciador de arquivos](../engineering/shell-actions.md)

## Atualizar o aplicativo

- **Edição da Microsoft Store.** Atualize pela Microsoft Store. Quando o aplicativo usa a identidade de pacote MSIX, a página Sobre não oferece o controle de atualização pelo GitHub.
- **Instalações do GitHub.** Abra **Sobre o xdzip** e verifique se há atualizações. Para instalar pelo aplicativo, é necessária uma instalação compatível por usuário no Windows, uma cópia compatível em Aplicativos no macOS ou uma instalação DEB no Ubuntu. Também é necessário um pacote de versão verificado. O Windows pode pedir confirmação do instalador. O Ubuntu usa a autorização do sistema. Se tarefas ativas atrasarem a instalação, aguarde o término ou cancele a espera.
- **Versões portáteis ou de desenvolvimento.** Baixe o pacote correspondente. No Windows e no Linux, extraia o novo pacote ZIP ou TAR.GZ completo em uma pasta separada. No macOS, encerre o aplicativo anterior antes de substituí-lo na pasta Aplicativos. Veja os [passos de instalação](install.md).

Você inicia a verificação de atualizações do GitHub manualmente. Ela usa a configuração de proxy compatível. Se o aplicativo oferecer apenas a opção manual, acesse a versão pelo link fornecido e verifique o pacote. Após o download, ainda será preciso instalá-lo. Depois de atualizar, abra **Sobre o xdzip** novamente para conferir a versão em execução. A Microsoft Store e o GitHub publicam de forma independente.
