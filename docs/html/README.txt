xdzip HTML 软件设计文档

多页面阅读：解压整个目录后，用浏览器打开 index.html。请保留 assets 目录。
单文件阅读：all.html 包含全部 16 篇、样式、搜索数据和两张 SVG 图，可以单独复制分享。
搜索：点击顶部搜索按钮，或按 Cmd/Ctrl+K；可用空格组合关键词。
显示：顶部按钮切换深浅色；窄屏点击目录按钮切换文档。
打印：使用浏览器打印功能，可另存为 PDF；导航和搜索控件会自动隐藏。
文档无需网络或服务器，搜索需启用 JavaScript。
本包为软件设计文档，不是已经实现的 xdzip 桌面应用。补充工程和视觉文档链接指向 GitHub，访问它们需要网络和仓库权限。
