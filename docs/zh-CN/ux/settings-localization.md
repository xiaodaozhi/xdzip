# 设置窗口与界面语言

[English](../../ux/settings-localization.md) | 简体中文

没有可见主窗口时，从托盘打开的设置和关于窗口没有 owner，按指针所在显示器的可用区域居中。复用 OperationWindow 的屏幕居中路径，在原生窗口创建及高度确定后再次定位，完整原生边框保持在工作区内；高度上限取选定 QScreen 的实际可用高度，保留既有屏幕留白，不使用虚拟桌面合并范围推导位置或高度，不恢复隐藏或最小化的主窗口。已有 owner 的入口继续跟随调用窗口，窗口尺寸和密度不变。


设置使用非模态独立系统窗口，标题栏、应用菜单和托盘复用同一个可见窗口。左侧依次为外观、通用、隐私、文件关联、网络和关于；所有关于入口打开同一设置窗口的关于页。窗口逻辑宽度为 612，客户区高度为 532，屏幕空间不足时限制高度，侧栏和正文分别滚动。侧栏与正文相接，顶部不留额外空隙。窗口没有 footer、保存或取消按钮。设计源和各状态图见[设置设计](../../../design/hifi/sources/settings.html)，尺寸令牌见[布局规范](../../../specs/visual/layout-scale.json)。

主题、字号、列表密度、语言、打开方式、托盘和最近记录开关在操作时写入并生效；关闭窗口不会撤销已成功的更改。语言即时刷新产品文字、应用提供的原生菜单及托盘菜单，运行中的任务不受影响；系统自带菜单项遵循系统语言。打开方式影响后续所有打开入口和标题栏加号，不迁移已打开的会话。清空最近记录立即执行，不删除原文件。清空失败与设置写入失败均在页面显示错误，保留既有数据和实际设置。多选框基于 IntentCheckBox，主题和代理单选基于 IntentRadioButton；鼠标、键盘及原生辅助功能 press/toggle 必须提交同一个选择意图，并核对模型，不得只更改图形。下拉框继续使用 OperationSelect，选择确定后提交一次。

设置持久化使用 schema 1，保留未知键，包含网络代理和镜像地址，不存放密码。保存持有独立配置锁，先在同目录暂存完整 INI，原子更新备份及主文件。读取失败、超过 1 MiB、非法或更高 schema、符号链接、备份或提交失败均拒绝覆盖原文件。设置应用失败时恢复运行中状态。最近路径独立保存在同目录 recent.json，最多 20 条、去重并限制读取为 64 KiB，文件仅用户可读写；关闭记录开关停止新增，清空入口删除已有记录。

暂存阶段将原始字节保存为只读输入快照，复制全部键值到另一份全新的候选 INI，再写入变更，不就地重写刚生成的快照。schema 校验与未知键保留继续执行，备份保留原始字节。

Windows 原子替换若因读句柄未共享删除权限等短暂占用而重命名失败，最多重试四次，退避共 75 ms，不含文件 I/O 时间。重试持续持有配置锁，使用同一份待提交字节和新的暂存文件，不处理 GUI 事件，不回退为原地覆盖；持续占用或其他错误仍保留原文件及已生效设置并报告失败。


文件关联页按生成的格式数据对后缀分组。普通安装版的开关显示查询到的系统默认状态。Windows 转到系统默认应用，macOS 使用 Launch Services，Ubuntu 使用桌面 MIME 默认设置。macOS 或 Ubuntu 取消默认关联时可能需要选择替代应用。多个后缀可共享一个系统类型，Windows 按 `.tar.gz` 的最后一段扩展名处理。MSIX 显示可关联类型和不可操作的开关，并提供“在 Windows 中设置默认应用”。实际默认状态可在系统设置中查看。见[关联契约](../engineering/installers-associations.md)与[包身份设置稿](../../../design/hifi/sources/settings.html?tab=associations&channel=msix)。

Windows 安装版的逐格式文件关联描述跟随应用的中文／English 选择，语言成功更改时同步；安装或升级也读取已保存的语言。应用只更新确认属于当前安装的九个 ProgID 描述，不修改默认处理器；系统或其他应用拥有的类型名称、缓存和其他平台的显示不受此设置直接控制。同步前提及失败边界见[安装与文件关联](../engineering/installers-associations.md)。


网络提供不使用代理、系统代理、自定义 HTTP 或 SOCKS5 代理，及可选 HTTPS GitHub 镜像地址。自定义代理必须包含主机和端口，不接收凭据；地址输入完成并验证后保存。镜像为空时直接访问官方地址；非空时仅改变更新流量的传输地址，校验和签名边界不变。进行中的更新保持原网络配置，下一次更新操作使用新配置。macOS Sparkle 支持系统代理、直连和无凭据的自定义 HTTP CONNECT／SOCKS5 代理；自定义代理失败时不会回退为直连。完整信任和重定向策略见[软件更新](../engineering/software-update.md)。

六个页面的正文不重复侧栏标题。普通构建的“关于”页为更新状态和操作保留稳定的滚动区域。主操作随更新状态切换，包括检查、取消、下载、安装和跳转发布页。键盘焦点可将屏幕外的控件滚动到可见位置。以 MSIX 包身份运行时，“关于”隐藏应用内更新区，保留构建信息和许可声明。商店版由 Microsoft Store 更新。见[包身份关于页原稿](../../../design/hifi/sources/settings.html?tab=about&channel=msix)与[更新契约](../engineering/software-update.md)。

关于页的更新状态文字同时作为原生辅助功能名称，随检查、下载、安装、成功或失败状态及语言变化同步更新；辅助技术读取的文字与界面显示一致。

macOS 手动更新说明显示当前首先未满足的安装条件，并保留发布页和下载位置；多个条件可能同时不满足，安装身份失败不推测具体原因。说明覆盖同版本 DMG 与 app.zip 手动替换，且明确下载不等于安装。

设置正文的竖向滚动条位于视口右侧，轨道覆盖视口高度；滑块随滚动移动，也可拖动控制正文滚动。

关于页版本信息的标签列按实际文案和字号自适应，值列使用剩余宽度并可换行；新增字段应使用相同布局。



所有产品静态文字通过 `resources/i18n/zh-CN.json` 和 `en-US.json` 的稳定 ID 引用；QML 使用 `qsTrId`，C++ 使用 `qtTrId`。协议码、文件名、路径和用户内容不翻译。语言选项依次为“自动识别”、“中文 (简体)”、“English (US)”，默认选中“自动识别”。持久化 `locale/language` 为 `auto`、`zh-CN` 或 `en-US`，实际生效语言独立解析。自动模式读取 `QLocale::system().uiLanguages()` 的首选项，所有中文区域使用简体中文，所有英文区域使用 English (US)，其他语言或空列表以 English (US) 兜底；不受应用通过 `QLocale::setDefault()` 设置的数字区域影响。每次启动重新解析自动模式，切回自动与手动选择均即时生效；保存失败恢复之前的实际语言与选择模式。后续语言在共享支持列表及两种界面选项中扩展，本次不增加历史设置迁移。

字号支持 100%、125%、150%，历史 200% 读取为 150%。系统文件选择器遵循系统语言，独立于应用语言。macOS 包声明 zh-Hans、en 并允许混合本地化，Qt 标准控件按系统 locale 加载可用翻译，不修改用户的 AppleLanguages。


验证六个页签及设置和关于的共用入口、即时保存与失败恢复、两种语言下的主题、语言和字号，以及适用的代理、更新和关联状态。涉及普通 Windows 安装版时，核对九个核心 ProgID 的语言同步。MSIX 要核对禁用的关联开关、系统设置入口，以及应用内更新区的隐藏。使用 `QAccessibleActionInterface` 提交单选与开关操作，核对实际模型状态和事件。原生检查和证据要求见[验证指南](../../../developers/zh-CN/qa/README.md)。
