# 补充交互与文案规范

[English](../../ux/interaction-spec.md) | 简体中文 | [繁體中文（台灣）](../../zh-TW/ux/interaction-spec.md)

主窗口与解压确认的视觉基线由[操作状态规范](hifi-state-spec.md)补充新建、冲突、任务、结果、设置及平台对照。欢迎页和打开进度见[欢迎页契约](welcome-opening.md)，当前原稿与布局依据以[窗口登记](../../../specs/visual/window-registry.json)为准。不因状态规范存在便将全部设计视为已实现或已通过原生视觉验收，具体实现边界见相应工程和交互契约。

| 场景 | 呈现与动作 | 恢复路径 |
| --- | --- | --- |
| 首次启动 | 打开压缩包、创建压缩包；可拖入本地文件 | 不扫描全磁盘，不自动关联全部格式 |
| 正在读目录 | 已读数量和不定进度；总数未知 | 可关闭会话，不能把部分结果称为全部 |
| 空压缩包 | “此压缩包没有内容”，保留文件属性 | 打开另一个；禁用解压并解释 |
| 无搜索结果 | 显示搜索词和范围 | 清空搜索，不误报压缩包为空 |
| 不支持特性 | 显示具体格式/算法/加密原因 | 保留可读元数据，停止不安全的部分输出 |
| 创建压缩包 | 输入清单、格式、目标、级别、预检 | 错误邻近字段；不默认覆盖已有文件 |
| 重名冲突 | 展示两项信息，提供跳过、重命名和覆盖，以及后续决定的适用范围 | 关闭提示后任务继续等待，可从任务窗口重开或取消 |
| 任务完成 | 显示成功、跳过、失败及提交数量 | 解压按显式选择打开目标目录。创建可在应用内打开受支持的单卷结果或首卷，重试需要重新规划 |
| 部分失败 | 保留已经提交的文件，明确失败原因 | 不以全任务回滚删除用户文件 |
| 应用退出 | 活跃任务数量，等待完成或取消后退出 | 核心确认清理结束；不阻塞 GUI 无限 join |
| 设置 | 主题跟随系统/浅/深、密度、字号、语言、最近记录、托盘 | 更改保存成功后立即生效，失败保留原值；额度编辑不属于当前设置能力 |
| 格式扩展 | 产品使用内置格式，[外部 SDK 试验](../engineering/sdk-trial.md)独立验证只读执行 | 到[格式登记](../engineering/format-registry.md)查询可用操作 |

解压主按钮按当前选择切换，菜单按当前能力提供两种范围。搜索只覆盖当前目录和后代。属性面板支持用户主动请求[文本与图片预览](../engineering/content-preview.md)。窗口窄于属性面板的折叠阈值时可用独立窗口打开。大字号下内容按实际尺寸增长，通过滚动保留确认控件的可达性。

错误文案采用“发生什么＋可采取什么动作”，错误码放详情；不向普通用户显示调用栈或 IPC 术语。危险文件名按安全文本呈现，插件消息不解释为 HTML。快捷键、IME、焦点与读屏以 [Qt Quick 界面设计](../design/qt-quick-ui.md)为准。
