# 数据生命周期与诊断

[English](../../engineering/privacy.md) | 简体中文 | [繁體中文](../../zh-TW/engineering/privacy.md) | [日本語](../../ja-JP/engineering/privacy.md) | [한국어](../../ko-KR/engineering/privacy.md) | [Français](../../fr-FR/engineering/privacy.md) | [Deutsch](../../de-DE/engineering/privacy.md) | [Español](../../es-ES/engineering/privacy.md) | [Português (Brasil)](../../pt-BR/engineering/privacy.md) | [Русский](../../ru-RU/engineering/privacy.md)

[隐私政策](../../../PRIVACY.zh-CN.md)说明 xdzip 处理哪些数据，以及用户可以作出哪些选择。下表说明实现将数据存在哪里、何时释放。浏览、压缩与解压可离线使用。xdzip 不会自动向维护者发送遥测或归档内容。

| 数据 | 生命周期 | 存放与清理 |
| --- | --- | --- |
| 设置与主题 | 跨启动，使用版本化结构 | 通过原子替换保存。设置更新失败时保留上一次的设置，界面报告失败。 |
| macOS 原默认应用 | 本地保存，可跨启动 | 将 xdzip 设为默认后，独立的设置文件按内容类型记录原应用的包标识。恢复原应用或改用替代应用后，清除该类型的记录。 |
| 最近文件 | 可关闭，仅在本地保存 | 私有 `recent.json` 文件最多保存 20 条去重记录，读取上限为 64 KiB。关闭后停止新增。清空只删除历史记录，不影响原文件。 |
| 归档索引 | 归档会话打开期间 | 小索引驻留内存。大型 ZIP 用私有磁盘文件保存元数据和查询顺序。正常关闭、替换查询、失败及取消会清理已知文件。后续创建索引时可按身份和租约规则回收未使用的崩溃残留。索引不会跨启动复用。详见[大型归档索引](large-index.md)。 |
| 暂存输出与恢复状态 | 任务执行及恢复期间 | 恢复只处理受控元数据，只清理能够确认归属的项，不执行归档内容或恢复任意路径的写入。 |
| 应用内预览 | 用户触发，有资源上限 | 更换预览目标或结束会话时清除当前结果，迟到的结果不能恢复已经失效的内容。 |
| 密码 | 仅在操作需要期间 | 应用不会将密码保存到设置或日志。操作系统可能持有应用无法控制的额外内存副本。 |
| 独立更新检查与下载 | 适用版本中由用户触发 | 请求访问 GitHub 的公开发行和下载服务。已配置的代理可以转发请求，可选的 HTTPS 镜像会收到原始下载地址。服务端可见连接信息及请求中的应用版本。Windows MSIX 禁用独立更新。 |
| 更新事务回执 | 本地保存，可跨安装重启 | 设置旁的独立 `update-state.ini` 保存事务和目标身份。失败的下载可能留在私有更新缓存中。更新器只读取固定回执文件，不执行回执内容。 |
| 状态与诊断 | 按功能出现在界面、终端或本地记录 | 应用不会自动上传诊断。复制版本或文件信息会写入系统剪贴板。分享错误、日志或截图前，请检查文件名、路径等私人信息。 |

更新网络、签名、安装交接与恢复流程见[主动更新契约](software-update.md)。
