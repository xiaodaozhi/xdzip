# 浏览、选择与预览文件

[English](../../user-guide/browse.md) | 简体中文

1. 打开压缩包。在目录树中选择文件夹，或双击列表中的文件夹进入。用面包屑路径返回上一级。
2. 按名称搜索当前目录及其子目录。提交搜索后查看结果。可以切换列表或网格视图，也可以按列排序。升序和降序都将文件夹排在文件之前。
3. 用复选框或平台支持的选择快捷键勾选条目。“全选”作用于当前查询，包括视图中尚未显示的行。解压前先核对已选项数量。
4. 打开文件属性并主动预览。属性卡支持部分纯文本和静态图片，包括受支持的静态 SVG。HEIC 和 HEIF 需要 macOS。即使文件可以读取，也可能因为超过预览限额或编码不支持而无法预览。归档允许提取时，仍可尝试解压。

双击普通文件时，XDZip 会解压临时副本，再请系统打开。修改副本不会写回压缩包。要长期保留文件，请解压到自己选择的位置。[临时打开说明](../engineering/archive-opening.md)

每个压缩包可按设置在标签页或独立窗口中打开。大型普通 ZIP 按需加载列表行。索引转入磁盘后，部分整包操作不可用。[大归档限制](../engineering/large-index.md)、[预览格式与限制](../engineering/content-preview.md)
