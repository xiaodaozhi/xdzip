# 安装 XDZip 与打开压缩包

[English](../../user-guide/install.md) | 简体中文

在[下载页](../../../README.zh-CN.md#下载安装)选择对应平台。直接下载后，用发布页提供的校验和核对文件。可用系统版本见[支持政策](../engineering/support-policy.md)。

1. **Windows 11 x64。** 在 Microsoft Store 搜索 XDZip，或下载 GitHub 当前用户安装器。使用便携版时，先解压整个 ZIP，再从解压目录运行程序，保留同目录的配套文件。GitHub 安装器默认装到当前用户。
2. **Apple Silicon Mac。** 打开 DMG，将 XDZip 拖入“应用程序”。若下载的是应用 ZIP，先解压，再把应用移动过去。请从“应用程序”启动新的副本。GitHub 包采用 ad-hoc 完整性签名，遇到系统提示时先核对来源和校验和。
3. **Ubuntu 24.04 x64，X11。** 使用包管理器安装 DEB，或完整解开运行目录的 TAR.GZ，再从目录中运行启动器。保留配套运行文件。

在 XDZip 中选择“打开压缩包”，也可以把支持的压缩包拖到窗口。要从文件管理器打开，在系统的“打开方式”中选择 XDZip。要设为默认应用，在操作系统设置中选择。Windows 商店版可从文件关联页面打开系统的默认应用设置。默认应用和右键压缩解压动作分别设置。[安装与文件关联说明](../engineering/installers-associations.md)
