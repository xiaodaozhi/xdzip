## 从归档窗口解压

1. 打开压缩包。已有选择时，工具栏主按钮解压所选条目。没有选择时，主按钮解压整个压缩包。也可用按钮旁的箭头明确选择“全部解压”或“解压所选”。
2. 核对解压范围并选择可写的目标目录。需要以归档名称新建一层目录时，可在提供此选项的界面中勾选。
3. 选择重名策略。“询问”会暂停等待决定，“跳过”保留已有文件，“重命名”另存一份，“覆盖”在校验后替换符合条件的文件。
4. 开始解压并查看任务结果。失败或取消之前已经保存的文件可能保留。重试前根据结果详情确认剩余项。[检查、任务与结果](checks-and-tasks.md)

选中最多 128 个实际归档条目时，解压菜单还提供“解压元数据预检”，可提示危险名称、不支持的方法和声明数据超限等问题。预检请选择归档中有实际记录的条目。仅为导航显示的隐式目录仍可按格式能力参与解压。预检不读取负载，也不授予写入权限。[预检与解压限制](../engineering/extraction-preflight.md)

对使用磁盘索引的大型 ZIP，可以在任务限额内解压所选普通文件。整包超出限额时，请缩小选择范围。如果来源发生变化或被替换，请重新打开并选择所需条目。[大归档限制](../engineering/large-index.md)

## 从文件管理器解压

Windows 11 的经典菜单位于“显示更多选项”，商店版也可在现代菜单显示。Ubuntu 使用 Nautilus 扩展。macOS 需要在系统设置中启用 Finder 扩展，也可通过已登记的 Finder 服务操作。找不到这些入口时，可在 XDZip 中打开压缩包再解压。

文件管理器菜单可解压到各压缩包所在目录、为每个压缩包新建目录、使用智能目录，或让你选择目标位置。校验后的输出恰好有一个顶层目录时，智能解压会省略外层目录。批量操作会逐包显示结果，单包失败后继续处理其余压缩包。取消会停止后续子项，并向正在准备或执行的任务发出取消请求。[文件管理器操作与设置](../engineering/shell-actions.md)
