# 解压全部或所选文件

[English](../../user-guide/extract.md) | 简体中文

1. 打开压缩包。要解压一部分，勾选文件或文件夹后选择“解压所选”。要解压整个包，选择“全部解压”。
2. 在确认窗口核对范围，选择可写的输出位置。界面提供同名文件夹选项时，可以按需启用。
3. 选择重名策略。“询问”会等待你的决定，“跳过”保留原文件，“重命名”将结果另存为新文件，“覆盖”在校验通过后替换符合条件的文件。对不熟悉的压缩包可以先使用新建的目标目录。
4. 开始解压后查看任务结果。写入失败、取消或遇到不支持的条目时，之前已保存的文件可能仍在目标目录。重试前先查看结果详情。

元数据预检可在解压前提示命名、格式能力和限额等问题，实际提取还会执行完整检查。部分链接、特殊条目或不安全的输出位置无法写入。操作期间若源压缩包发生变化，请重新打开当前副本，再选择所需条目。[解压预检规则](../engineering/extraction-preflight.md)

从文件管理器开始时，可使用系统支持的 XDZip 右键入口，在操作窗口内核对目标。压缩包只有一个顶层目录时，智能解压可以省去多余的外层文件夹。批次操作依次处理选择的归档，并列出每个归档的结果。[文件管理器操作](../engineering/shell-actions.md)
