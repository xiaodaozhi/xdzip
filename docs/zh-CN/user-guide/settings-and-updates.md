# 设置与更新

[English](../../user-guide/settings-and-updates.md) | 简体中文

## 调整工作区

从应用菜单或工具栏打开“设置”。在对应设置中选择语言、主题、字号及界面密度。自动语言在支持时跟随系统。还可按平台和版本设置用标签页或窗口打开压缩包、是否记录最近文件，以及托盘行为。设置随选择即时生效，保存失败时请查看对应页面的提示。[设置行为说明](../ux/settings-localization.md)

文件关联由操作系统管理，右键菜单动作单独配置。macOS 的 Finder 扩展由系统管理启用状态，已登记时还可使用 Finder 服务。[文件管理器操作](../engineering/shell-actions.md)

## 更新应用

- **Microsoft Store 版。** 在 Microsoft Store 检查更新。采用 MSIX 包身份时，“关于”页没有 GitHub 更新入口。
- **GitHub 版。** 打开“关于 xdzip”，主动检查更新。符合条件的安装版可以下载并安装校验通过的更新。等待活动任务结束时可保持应用打开，也可取消等待，稍后再更新。
- **便携版或实验性构建。** 下载适合的平台包并手动安装。macOS 应退出旧程序，再替换“应用程序”中的副本。

GitHub 更新会按支持范围使用所设的代理模式。网络检查或校验失败时，请看错误提示和发布页。Microsoft Store 与 GitHub 独立发布。[更新行为与恢复](../engineering/software-update.md)
