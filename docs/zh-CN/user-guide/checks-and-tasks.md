# 检查压缩包与管理任务

[English](../../user-guide/checks-and-tasks.md) | 简体中文

## 测试压缩包

1. 打开压缩包，在工具栏选择“测试压缩包”。
2. 如有密码提示，按需输入后等待结果。检查读取符合条件的内容，不写出解压文件。
3. 若检查失败，查看显示的原因和相关条目。部分格式支持校验和或认证，另一些只检查结构和可读性。通过结果仅覆盖该格式能验证的内容。[完整性检查规则](../engineering/archive-checking.md)

大型 ZIP 转为磁盘索引后，整包测试可能不可用。请查看适用限制，必要时只提取所需普通文件。[大归档限制](../engineering/large-index.md)

## 进度、取消与结果

通过任务菜单可以回到正在执行的操作或查看结果。关闭压缩包标签页不会终止后台任务。出现密码或重名窗口时，操作可能需要你的决定才能继续。

在任务窗口选择“取消”以请求停止，并等待最终状态。已保存文件可能保留。展开结果详情，区分已完成、已跳过和未完成的条目，再结合数量和原因决定重试范围。清除已完成的历史记录只移除对应任务入口，磁盘中的文件会保留。[任务窗口说明](../ux/task-windows.md)
