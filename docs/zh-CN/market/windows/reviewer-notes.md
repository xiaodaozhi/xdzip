# 商店审核说明

简体中文 | [English](../../../market/windows/reviewer-notes.md)

以下文本用于[商店文案](listing.md)所标明 MSIX 候选的受限功能解释和认证备注，不代表该功能已经获批，也不表示已经提交认证。

## runFullTrust 使用说明

```text
xdzip 是采用 Qt Quick 和 Rust 的打包 x64 桌面压缩包管理工具，应用入口为 Windows.FullTrustApplication。runFullTrust 用于运行现有桌面应用，并通过普通桌面文件接口浏览、创建和解压用户选择的压缩包。

应用读取用户选择的压缩包，并向用户选择的目标目录写出文件。应用还会启动随包提供的工作进程，处理受支持的归档格式和受限的内容预览。临时文件用于暂存、安全写出，以及按用户请求通过系统关联应用打开文件。

普通归档操作不要求管理员账户，也不请求权限提升；应用不安装服务或驱动。商店构建声明独立的现代和传统文件资源管理器菜单类。现代菜单仅在已注册包具有微软 Store 签名时启用，未签名或自签名审核副本的现代入口保持隐藏。具有 MSIX 包身份时，独立的应用内更新功能关闭，商店交付版本由 Microsoft Store 管理更新。

基础归档操作在本机进行，无需 xdzip 账户。应用不会将归档内容、路径或密码自动上传给开发者。公开隐私政策已通过商店一览中的链接提供。
```

## 认证备注

```text
基础功能不需要登录 xdzip、订阅、测试凭据或安装外部压缩程序。

浏览与预览：打开包含普通文本和 PNG 图片的 ZIP，选择文件查看属性，点击“预览内容”按需预览。再打开一个压缩包，可检查多标签浏览和列表、网格视图切换。

创建：点击“新建”，添加普通文件并选择 ZIP，再选择测试账户拥有且可写的目录后创建。本候选支持创建 ZIP、TAR、TAR.GZ 和 7z，RAR、CAB、ISO 和 UDF 为只读。加密与分卷支持取决于所支持的格式和配置。

解压：选择包内文件，点击“解压所选”，选择可写目录。应用提供进度和取消入口。通过系统应用打开文件时会生成本地临时副本，对副本的修改不会自动写回压缩包。

商店交付后的系统集成检查：打开“设置”的“文件关联”，点击 Windows 默认应用设置按钮。在文件资源管理器中右键自有测试文件，分别检查现代菜单和“显示更多选项”。菜单开关及语言遵循应用设置，应用不会自动更改默认程序。

商店一览面向 Windows 11 x64。英语（美国）与简体中文截图均使用自有演示内容。商店交付版本由 Microsoft Store 管理更新。
```

受限功能由 [build-windows-msix.py](../../../../scripts/build-windows-msix.py) 声明。上述说明描述候选的桌面行为及通过清单声明的外壳集成，不增加服务或权限提升。定价、年龄分级及其他提交问卷需要在合作伙伴中心各自的栏目中完成。
