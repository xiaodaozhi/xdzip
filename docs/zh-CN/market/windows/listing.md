## 说明

```text
打包与解压，都简单一点。

xdzip 是一款开源 Windows 压缩包管理工具。先查看包内内容，找到需要的文件，再选择性解压，不必每次都解开整个压缩包。基础压缩、解压和浏览可离线使用，归档内容在你的电脑上处理，无需注册 xdzip 账户。

浏览 ZIP、7z、RAR、TAR、TAR.GZ、CAB、ISO 和 UDF 文件。通过搜索、排序和目录导航查找内容，在多个标签页或独立窗口中管理压缩包。需要时，可以先预览受支持的文本、图像和静态 SVG，再决定提取哪些文件。

创建 ZIP、TAR、TAR.GZ 和 7z 压缩包，按格式使用 ZIP AES-256 加密或 7z 密码保护，并处理受支持的分卷与固实归档。符合条件的普通单文件压缩包还支持添加、替换或移动包内条目。

按喜好选择浅色或深色外观，调整字号，在简体中文与英语之间切换。任务进度清晰可见，需要时可以请求取消。

不同格式的功能有所区别。RAR、CAB、ISO 和 UDF 为只读；加密和分卷支持取决于具体格式与配置，并非所有归档都支持修改。使用其他应用打开包内文件时会生成本地临时副本，对副本的修改不会自动写回压缩包。

面向配备 x64 处理器的 Windows 11 电脑。Microsoft Store 版本由商店管理更新，本版本尚未提供 Windows 11 现代文件资源管理器右键菜单。
```
