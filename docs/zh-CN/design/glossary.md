# XDZip 术语与实现限额

[English](../../design/glossary.md) | 简体中文

## 1. 术语

| 术语 | 定义 |
|---|---|
| 归档/Archive | 一个容器或受支持压缩流及其授权源 |
| 编解码器/Codec | 识别、扫描、读取或创建格式的实现 |
| 会话/Session | 打开源、后端、索引和浏览上下文；不是任务 |
| 条目/Entry | 一个实际归档记录；目录可另有合成展示节点 |
| 来源版本/SourceVersion | 对已接收文件或分卷用于尽力检测变化的指纹 |
| 查询快照/QuerySnapshot | 运行时的当前不可变结果顺序，由会话、查询、代数及修订号标识 |
| 代次/Generation | 前端请求替代关系，避免过期结果覆盖 |
| 已准备的作业 | 运行时为执行保留的有界输入，包括本次操作所需的来源、选择和选项 |
| 任务/Task | 作业进入任务队列后的生命周期与执行结果 |
| 授权/Grant | 宿主持有的文件/目录访问权，不是路径字符串 |
| Sink | 受计量、限额和事务控制的写接口 |
| 工作线程与工作进程 | 命令和任务在宿主线程中执行，归档和图片工作进程独立运行。 |
| 提交/Commit | 通过已授权的文件或归档操作发布经过验证的暂存内容 |
| 任务快照 | 最新的任务状态、进度、提示或结果。中间快照可以合并。 |
| 能力/Capabilities | 特定实现、格式特性、平台和政策的具体交集 |
| 固实/Solid | 多文件共享压缩块，选择性读取可能需要解码前置内容 |
| 首帧/First presented frame | 实际渲染呈现，不能以 ui_ready 日志冒充 |

## 2. 单位和数值

内存/文件量使用二进制 KiB/MiB/GiB，1MiB=1024² bytes；传输和计量保留整数 bytes。时间使用毫秒或秒。运行耗时采用单调时钟。文件时间在可用时保留日历表达方式与来源精度。吞吐统一 MiB/s 并说明压缩输入、解码或输出哪一种字节。

单核计 CPU 100% 表示占满一个逻辑核心，进程树可超过 100%。PSS/RSS/USS/physical footprint 不互相等同。下载压缩体积、安装体积、executable 大小分别记录。

## 4. 版本边界

应用版本、内部 CXX 构建接口、外部通信协议和持久化数据格式各自有版本边界。产品版本无法直接推导 SDK 协议版本。见[编解码扩展 SDK 设计](codec-extension-sdk.md)。
