## Arbeitsumgebung einrichten

Öffnen Sie die **Einstellungen** über das App-Menü oder die Symbolleiste. Wählen Sie Sprache, Farbschema, Schriftgröße und Oberflächendichte in den jeweiligen Einstellungen. Die automatische Sprachauswahl verwendet die Systemsprache, sofern sie unterstützt wird. Legen Sie fest, ob Archive in Tabs oder Fenstern geöffnet werden. Wenn die Plattform dies unterstützt, können Sie zuletzt geöffnete Dateien und das Symbol im Infobereich konfigurieren. Änderungen werden sofort angewendet. Kann eine Einstellung nicht gespeichert werden, lesen Sie die Fehlermeldung auf der Seite. [Verhalten der Einstellungen](../ux/settings-localization.md)

Ändern Sie Dateizuordnungen in den Systemeinstellungen. Kontextmenüaktionen werden separat eingerichtet. Unter macOS aktiviert das System die Finder-Erweiterung. Registrierte Finder-Dienste sind ebenfalls verfügbar. [Aktionen des Dateimanagers](../engineering/shell-actions.md)

<a name="xdzip-update-the-app"></a>

## App aktualisieren

- **Version aus dem Microsoft Store.** Aktualisieren Sie die App über den Microsoft Store. Wenn sie als MSIX-Paket ausgeführt wird, bietet der Info-Bereich keine GitHub-Updatefunktion.
- **Installationen von GitHub.** Öffnen Sie **Über xdzip** und suchen Sie nach Updates. Ein Update aus der App setzt eine geeignete Windows-Installation im Benutzerkonto, eine geeignete macOS-Kopie in Programme oder eine DEB-Installation unter Ubuntu voraus. Außerdem wird ein geprüftes Paket benötigt. Windows kann eine Bestätigung des Installationsprogramms anfordern. Ubuntu verwendet die Systemautorisierung. Wenn laufende Aufgaben die Installation verzögern, warten Sie, bis sie abgeschlossen sind, oder brechen Sie das Warten ab.
- **Portable Versionen oder Entwicklungsbuilds.** Laden Sie das passende Paket herunter. Entpacken Sie unter Windows und Linux das vollständige neue ZIP- oder TAR.GZ-Paket in einen eigenen Ordner. Beenden Sie unter macOS die alte App, bevor Sie sie in Programme ersetzen. Siehe [Installationsschritte](install.md).

Sie starten die Suche nach GitHub-Updates selbst. Sie verwendet die unterstützte Proxy-Einstellung. Bietet die App nur den manuellen Download an, folgen Sie dem Link zur Version und prüfen Sie das Paket. Nach dem Herunterladen müssen Sie das Update noch installieren. Öffnen Sie danach **Über xdzip** erneut und prüfen Sie die laufende Version. Microsoft Store und GitHub veröffentlichen unabhängig voneinander.
