# cxx 诊断阶段准入记录

状态：允许进入独立工具链探针；产品发行准入、完整漏洞审查和三平台 Qt 链接仍待完成。

选择 `cxx = 1.0.205` 与 `cxx-build = 1.0.205` 精确同版，配合 Rust 1.99.0。采用声明生成的类型化所有权桥接，避免为原型手工维护 C ABI 的字符串/释放函数；Qt 仍留在 C++。手写 C ABI 是依赖更少但人工不变量更多的替代方案；不引入第三套 Qt/Rust 对象模型。cxx 不是第三方格式扩展 ABI。

## 来源与许可

来源为 crates.io，仓库为 https://github.com/dtolnay/cxx 。本次查询版本未撤回；版本页显示 1.0.205 于 2026-10-11 发布，最低 Rust 1.88。cxx 与 cxx-build 标注 MIT OR Apache-2.0，原包附带两份许可证；发行时按选用许可汇总材料。

[依赖清单](bridge-dependencies.json) 记录 Cargo.lock 闭包的 32 个第三方包、版本、crate SHA-256、来源、声明许可、metadata features 和构建脚本标记。包含目标条件不成立的包，不等同于当前二进制实际链接清单；例如 cxx 的 `cfg(any())` 构建依赖引入 cxxbridge-cmd/clap 的锁定记录，本探针没有编译这些包。该清单不是完整产品 SBOM，不涵盖编译器、Qt 或系统库。

## 特性与构建行为

保留 cxx 的默认 std/alloc，未启用 C++20 等可选能力；本地桥接编译使用 C++17。cxx-build 生成源码/头文件并调用 cc；cxx 的 build.rs 编译包内 cxx.cc、查询 rustc 版本、输出构建配置。link-cplusplus 编译包内 dummy.cc 并选择平台 C++ 标准库。已阅读这些构建入口，未发现入口主动联网下载；这不构成对全部传递依赖源码的安全审计。依赖包获取由 Cargo 执行并校验锁文件哈希。

本次未完成 RustSec 全库扫描、第三方独立审查、供应链签名验证，也不据此声明“无已知漏洞”。产品采用前补充这些结果及实际平台链接矩阵。默认 features 暂按互操作探针所需保留，后续裁剪需复验所有权与错误路径。

## 本次验证范围

可复现构建、Rust 测试、C++ 静态链接、Qt UTF-8 往返、Result 到 C++ 异常、唯一句柄、容量上限和关闭排空，详见 [测试证据（本地／CI 工件）](../qa/README.md)。未验证归档不可信输入、安全文件写入、运行时崩溃恢复或外部插件。
