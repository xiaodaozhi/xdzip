# WP-10 创建 ZIP 实现契约

本工作包实现从明确选择的文件与目录创建新 ZIP；默认 Deflate 均衡级别，支持 Store 与 Deflate 1／6／9。加密、分卷、TAR/GZIP 和就地编辑不属于本工作包。输入授权、暂存、校验、重名决策和最终保存由宿主负责，格式层只接收条目、可读输入与可写输出。

## 输入树与预算

选择项必须为绝对路径的普通文件或目录。去重同一路径，并去除已选择目录内部的重复选择；目录递归保留根目录名称，空目录写入显式记录。拒绝链接、重解析点、设备等特殊对象，拒绝不可移植名称与大小写碰撞。根目录句柄按共同父目录合并，最多 128 个；条目最多 100,000，深度最多 64，名称总量最多 16 MiB，每文件最多 8 GiB，输入总量最多 20 GiB。只持有有限根句柄和当前读取文件，不为每个条目持有一个文件描述符。

输入父目录的系统别名先归一到同一位置，所选叶对象不跟随链接；打开根后绑定并复核目录身份。目录发现使用根句柄下的 no-follow 遍历，保存目录身份与过滤后的子项清单、文件身份／长度／修改时间。编码前后和保存前复核；打开每个文件与读到 EOF 时复核文件版本。新增、删除、改名、链接替换和可观察内容修改失败为来源变化。身份／时间戳复核是尽力检测，不是原子内容快照，不能保证识别同账户刻意恢复元数据的编辑。

输出位于输入目录内时，仅排除明确的输出路径和本次已创建、身份匹配的暂存工作目录；不能按 `.xdzip-*` 通配符忽略其他内容。明确选择输出文件本身时拒绝。排除后没有任何条目则拒绝。归档过程中不重新递归发现新增文件，不把正在增长的输出文件归档进自身。

## 格式接口与校验

编码接口独立于 Qt 和文件路径。宿主提供有序的不可变条目列表及按序号打开的只读流；格式层写入宿主流并报告实际处理字节。ZIP 采用现有 rawzip 写入器及 flate2 Rust 后端，固定 UTF-8 名称、普通文件／目录权限，不保留特权位。大条目和中央目录自动使用 ZIP64。

写完数据、结束压缩流、写完中央目录后，宿主重新扫描暂存 ZIP，并逐条解码检查头、大小、CRC 和流终止。条目名、类型、大小必须与冻结输入树一致。校验与来源复核通过后才允许整体保存；不把仅能列目录视为归档完整性证明。读取、压缩、写出及校验均在后台重任务线程执行，定期检查取消。

## 暂存、冲突与整体保存

使用 M3 已验证的目录授权、同卷私有暂存和整体文件提交原语。默认询问重名，支持使用新名称或替换已确认的普通文件；不覆盖目录、链接、特殊对象或参与输入的文件身份。重名决策绑定任务与提示 ID，提交前再次复核现有目标。文件系统不能提供所需原语时失败，不以复制／删除模拟原子保存。

创建任务只整体保存一个 ZIP。校验或保存前取消，移除本次已知暂存文件，现有归档保持不变；不能把已经写出的输入条目计为已经保存的文件。取消与最终提交共享既有门闩；提交许可获得前取消胜出，许可获得后整体提交结果胜出。成功提交后到达的取消不把成功改成取消。清理失败保留可恢复材料并标记警告，不删除陌生暂存目录。

## 任务与界面

创建与解压共用有界后台任务通道、控制与退出机制。任务快照明确区分创建／解压及总量是否已知；扫描阶段显示未知总量，扫描完成后使用冻结文件数与大小。写入过程中显示实际输入读取量、输出写入量与当前文件；校验阶段单独标明，不能把校验字节再次计为输入读取量。

新建窗口按高保真原稿与 HTML 布局实现，复用路径框、内建下拉、复选框、按钮与 footer。添加文件、添加目录、移除、名称、目标、Store／Deflate、级别、打开完成结果均可操作。不支持的格式、加密、密码、分卷不表现为可执行能力。运行窗口使用修正后的正常密度，关闭窗口后任务继续；任务可在状态栏重新打开，并可取消和处理重名。

## 验收

真实 Store／Deflate、Unicode 名称、空文件与空目录的写入、重新打开和解压互操作；独立 Python zipfile 验证内容、CRC 与目录。验证来源变化、名称碰撞、链接／特殊对象、输出在输入树内、校验失败、重名变化与取消保留旧归档。三平台核心／桥接／Qt 构建与后台生命周期检查，正常密度及高 DPR 实际捕获。性能记录实际输入量、耗时、资源与校验开销，不由压缩级别推定压缩率。
