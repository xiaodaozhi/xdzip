# 发布操作手册

本仓库尚无可发布版本。本手册由发布工作包执行，不能将未勾选项解释为通过。

1. 按[版本机制](versioning.md)更新 VERSION.json 并同步派生版本，确认版本范围与能力矩阵，关闭或标记未达门槛的特性。
2. 从确定提交构建源码、各平台未签名包、调试符号、SBOM、NOTICE 与依赖许可证。
3. 记录工具链、哈希、features、目标和基准环境；验证源码可重建未签名部分。
4. 在独立发布环境签名；macOS 公证/staple，Windows 签名验证；凭据不进入 PR 或仓库。
5. 在干净系统检查安装、首开、文件关联、Unicode、权限、退出、升级/卸载和 Qt 依赖完整性。
6. 核对安全与互操作验收，完成所需独立审查；验证私密漏洞报告入口。
7. 准备发布说明、已知限制、完整安装/下载体积及校验和，经发布负责人确认后上传。
8. 发行后确认下载工件与已验证哈希一致；发生问题撤回问题渠道并说明影响，保留诊断证据。

v0.1 手动下载更新；不在活跃任务中覆盖程序或插件。回退前检查设置 schema 兼容性，保留旧可运行版本，不能强行降级数据。域名、bundle ID、签名身份、证书、渠道和维护周期均在发行前确定，当前不虚构。
