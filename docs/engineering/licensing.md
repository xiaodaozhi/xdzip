Status: Adopted. On 2026-10-11 the project established **Apache-2.0** for original project code, documentation, and other original content except where otherwise declared. The MIT OR Apache-2.0 choice in earlier experimental documents does not apply to this repository.

The root [LICENSE](../../LICENSE) contains the full standard Apache License 2.0 text, SPDX identifier `Apache-2.0`. Contribution guidance and release design were updated. License selection does not change repository visibility; a read-only check on 2026-10-19 confirmed the repository was public. Release admission still requires separate review of actual materials.

Qt dynamic linking requires LGPL/GPL/commercial terms to be checked per module. Backends, icons, fonts, tools, and static Rust dependencies are reviewed separately. License compatibility does not imply code has no security defects. Required notices, source/relinking materials, and installation information accompany release artifacts.

7z, RAR, CAB, and ISO/UDF use [independent Rust implementations](independent-rust-codecs.md); official UnRAR and 7-Zip source does not enter current product builds or deployment. See the [isolated backend contract](native-codecs.md) for fixed routing and controlled I/O. Analysis sources, development reference tools, and historical official-backend deliveries retain their original licenses separately. Independent implementation is not a strict clean-room or zero-legal-risk claim. Historical deliveries containing official 7-Zip or UnRAR continue to meet their original terms, notice, and modification-material obligations; they cannot be relabeled Apache-2.0 because current dependencies were removed. An empty current product-source list does not waive obligations for historical deliveries or independent reference tools. Experimental builds do not replace formal license review.

RAR's finite wire-format mappings and public test fixtures retain their respective provenance, original notices, and licensing records; see [RAR implementation basis](rar-format-sources.md). Removing the production engine does not relicense these materials as original project code.

The finite mappings also retain [pinned original reference text and provenance](../../third_party/rar-wire-mappings/README.md), including the complete original license for upstream internal version UnRAR 7.30 beta1, download archive `unrarsrc-7.3.1.tar.gz`, and original-text SHA-256. The notice collector includes these bounded materials in actual notice hashes, and corresponding-source delivery retains a separate copy. They do not reintroduce the official engine or declare it a runtime dependency, automatically determine applicability of terms, or approve this candidate for release.

The pinned original text matches the SPDX `UnRAR` license text word for word after whitespace normalization. As conservative handling of reference mappings, the RAR crate and its source SBOM declare `Apache-2.0 AND UnRAR`, requiring both rather than offering a dual-license choice. The crate is not published to crates.io. `UnRAR` is a non-OSI-approved identifier in SPDX 3.28 and later; older tools may not recognize it. Retain the original license and restrictions with materials. This declaration does not determine the mappings' copyright status or rewrite the original alpha.8 inventory.

Platform runtime notices, supplier inputs, and license eligibility follow [native runtime provenance and notices](native-runtime-materials.md); a generic license text does not replace supplier copyright notices.
