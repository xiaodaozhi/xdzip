# ZIP 只读浏览首个实现契约

状态：有限开发版本，2026-10-11。补充 design/03、05、06 的分阶段落地说明，不冻结完整桥接协议或格式 SDK。

## 数据与依赖方向

xdzip-codec-api 定义借用只读输入、取消信号、限额、条目和错误。xdzip-codec-zip 实现内置 ZIP 元数据适配，不获取路径或写入能力。xdzip-runtime 打开并持有只读文件，扫描成功后发布不可变快照。xdzip-qt-bridge 通过 cxx 暴露工作线程入口；薄 C++ 控制器将有界页面转换为 Qt 模型，QML 负责显示和操作意图。

已迁移到 [M1 正式命令/事件运行时](m1-runtime.md)：GUI 提交短命令，Rust 工作线程持有归档，独立 Qt 接收线程通过有界 mailbox 投递结果。QtConcurrent 同步桥接已移除。每个浏览控制器最多一个 pending 请求；这仍不是完整多任务调度器、动态插件 ABI 或第三方进程协议。

## 行为与数据

打开 ZIP 后显示中央目录物理记录，不自动解压。重复名称保留独立 EntryId；会话 ID 不复用，UI 以字符串传输 ID 和字节数，避免 JavaScript 数值精度损失。Qt 每页 128 条，Rust 页面上限 256 条。支持名称子串搜索和显式目录范围浏览，仍无排序、隐式目录树或内容预览。

识别普通单卷 ZIP。EOCD 的 ZIP64 哨兵和分卷字段，以及中央目录的非零起始磁盘均拒绝；不宣称完整 ZIP64 支持。中央目录数量必须与 EOCD 一致，错误、取消或超限不发布半成品列表。UTF-8 标志或 ASCII 名称按原文显示；其他原始字节转义，不猜测 CP437。控制字符和双向文本控制符转义；绝对路径、上级路径、特殊文件等标为“需检查”。原始名称始终保留，绝不转成输出路径。

大小、压缩方法、加密位均是归档声明的元数据。未读内容，未验 CRC，未校验本地头；“元数据”状态不表示安全或完整。解压与新建按钮禁用。

## 资源与生命周期

| 项目 | 当前上限 |
| --- | --- |
| 物理记录 | 10,000 |
| 单个原始名称 | 4 KiB |
| 累计原始名称 | 4 MiB |
| 累计读取字节（含重复读取） | 16 MiB |
| 扫描缓冲区 | 256 KiB |
| Qt 页面 | 128 条 |

显示转义和桥接复制另占空间；上述不是进程 RSS 或耗时保证。元数据完整驻留 Rust 内存；不承诺大索引性能。扫描前后检查长度和修改时间，只能尽力检测变动，不能替代原子快照。

取消在读取和遍历边界检查，不能打断操作系统阻塞读取。关闭忙碌主窗口先请求停止，收到完成通知后关闭，不在 GUI 线程 join。控制器意外销毁也不使后台任务引用悬空。正常窗口关闭和应用 Quit 已统一经过 M1 shutdown 屏障；强制终止和磁盘异常恢复仍待后续写入任务运行时落地。

源文件要求普通文件；路径检查与打开之间仍有竞争窗口，不构成沙箱或强制时间限制。桥接源路径暂限可无损表示的 UTF-8。文件选择器采用原生独立对话框，macOS 不绘制交通灯；实际系统焦点、模态归属与窗口装饰须在桌面验收。

## 浏览交互增量

- 归档中的安全显式目录可双击进入，或聚焦复选框按 Enter；“全部文件”返回根范围。范围包含所有后代物理记录，保留完整归档内名称，不合成目录条目；危险名称目录不可进入，但仍可在全部文件中检查。
- 名称搜索回车提交，Unicode 小写后作字面子串匹配，不支持正则或区域排序；搜索框最多 256 个 UTF-16 代码单元，Rust 入口最多 1,024 UTF-8 字节。搜索作用于当前目录范围；返回全部文件保留搜索词，打开新会话清空搜索。
- 过滤只遍历已加载且最多 10,000 条的快照，按物理顺序返回至多 128 条；每条记录检查取消。目录参数传物理 EntryId 字符串，由 Rust 校验目录资格，不接受 GUI 拼接的文件路径。
- 这是串行、有界的即时查询，不新增并发查询或宣称完整查询代际协议已实现。偏移越界返回错误，空结果属于 Ready。目录跳转与搜索从第一页开始。
- 单击行或复选框切换本页多选，以物理 ID 区分同名记录。页切换、查询完成或新会话替换模型后清空选择及详情；不宣称跨页选择或可对选择执行解压。详情显示最近激活条目的元数据，和复选框集合分别表达焦点与选择。
- 列表大小以 B/KiB/MiB/GiB 显示，数值转换仅用于近似显示；模型和 Rust 保留原始整数。文件图标表示类型，详情卡片不是内容预览。

所选条目现可发起 [解压元数据预检](extraction-preflight.md)，使用独立原生结果窗口；该功能不写出文件，不改变只读阶段边界。
