# ZIP 只读浏览首个实现契约

状态：有限开发版本，2026-10-13。补充 design/03、05、06 的分阶段落地说明，不冻结完整桥接协议或格式 SDK。

## 数据与依赖方向

xdzip-codec-api 定义借用只读输入、取消信号、限额、条目和错误。xdzip-codec-zip 实现内置 ZIP 元数据适配，不获取路径或写入能力。xdzip-runtime 打开并持有只读文件，扫描成功后发布不可变快照。xdzip-qt-bridge 通过 cxx 暴露工作线程入口；薄 C++ 控制器将有界页面转换为 Qt 模型，QML 负责显示和操作意图。

已迁移到 [M1 正式命令/事件运行时](m1-runtime.md)：GUI 提交短命令，Rust 工作线程持有归档，独立 Qt 接收线程通过有界 mailbox 投递结果。QtConcurrent 同步桥接已移除。每个浏览控制器最多一个 pending 请求；这仍不是完整多任务调度器、动态插件 ABI 或第三方进程协议。

## 行为与数据

打开 ZIP 后显示根目录的直属文件与目录，不自动解压；搜索可覆盖后代物理记录。重复名称保留独立 EntryId；会话 ID 不复用，UI 以字符串传输 ID 和字节数，避免 JavaScript 数值精度损失。单次桥接批次 128 条，Rust 页面上限 256 条；产品传输另限单批名称 64 KiB；Qt 自动收集完整查询后原子更新最多 100,000 行，不显示分页，视图委托按可见区域复用。支持名称子串搜索、显式和隐式目录树，以及全查询结果排序；内容预览尚未实现。

识别单卷 ZIP／ZIP64，校验 ZIP64 locator、尾记录及中央目录起始磁盘；分卷保持拒绝。ZIP64 的大小与偏移保持 64 位，不根据声明大小分配内容缓冲。中央目录数量必须与 EOCD 一致，错误、取消或超限不发布半成品列表。UTF-8 标志或 ASCII 名称按原文显示；其他原始字节转义，不猜测 CP437。控制字符和双向文本控制符转义；绝对路径、上级路径、特殊文件等标为“需检查”。原始名称始终保留，绝不转成输出路径。

大小、压缩方法、加密位均是归档声明的元数据。未读内容，未验 CRC，未校验本地头；“元数据”状态不表示安全或完整。本契约描述只读浏览，显式解压见 [M3](m3-extraction.md)，实际创建及写后校验见 [WP-10](m4-creation.md)；独立完整性测试尚未接入。打开归档仍不写出文件内容。

## 资源与生命周期

主窗口校准后显示名称、原始大小、压缩后、类型、修改日期五列。类型仅由显示名称后缀推断，JPG 统一为 JPEG。修改日期来自 ZIP 中央目录的有效 DOS 本地日期／时间，不推断时区，无效值显示 `—`。五列均支持排序；日期按完整 DOS 时间排序，表格显示日期。压缩方法仍在详情中可用，桥接保留方法排序代码。加密／需检查状态保留于行提示、可访问描述和详情；需注意条目在名称旁显示标记，不能被视觉精简隐藏。

标签关闭提交已有 `CloseSession` 命令，成功后清空会话、列表、选择和详情，窗口与运行时继续存活；忙碌时禁用。加号调用原生打开选择器，当前仍是单归档会话，打开新归档会替换当前会话。标题栏全选复选框为三态；状态栏大小只汇总当前查询已选元数据，不冒充归档总量。完整验收证据见 [Qt 校准（本地／CI 工件）](../qa/README.md)。

| 项目 | 当前上限 |
| --- | --- |
| 物理记录 | 100,000 |
| 单个原始名称 | 4 KiB |
| 累计原始名称 | 16 MiB |
| 转义显示名 | 16 MiB |
| 累计读取字节（含重复读取） | 64 MiB |

| 桥接传输批次 | 128 条 |

| 目录名称与完整前缀合计 | 4 MiB |

显示转义和桥接复制另占空间；上述不是进程 RSS 或耗时保证。元数据完整驻留 Rust 内存；直属索引保留行身份，查询结果缓存只存排序后的索引。实际十万条测量见 [M2 验收（本地／CI 工件）](../qa/README.md)，不宣称百万条能力。扫描前后检查长度和修改时间，只能尽力检测变动，不能替代原子快照。

取消在读取和遍历边界检查，不能打断操作系统阻塞读取。关闭忙碌主窗口先请求停止，收到完成通知后关闭，不在 GUI 线程 join。控制器意外销毁也不使后台任务引用悬空。正常窗口关闭和应用 Quit 已统一经过 M1 shutdown 屏障；强制终止和磁盘异常恢复仍待后续写入任务运行时落地。

源文件要求普通文件；路径检查与打开之间仍有竞争窗口，不构成沙箱或强制时间限制。桥接源路径暂限可无损表示的 UTF-8。文件选择器采用原生独立对话框，macOS 不绘制交通灯；实际系统焦点、模态归属与窗口装饰须在桌面验收。

## 浏览交互增量

- 归档中的安全显式目录可双击进入，或聚焦复选框按 Enter；“根目录”返回根范围。普通目录只显示直属文件与目录，不递归列出后代；搜索递归当前范围并显示完整归档路径。列表的普通名称只显示末级名称，不影响内部完整路径、复制与导航。危险名称不可成为导航节点，仍保留在归档快照中供搜索和元数据检查。
- 名称搜索回车提交，Unicode 小写后作字面子串匹配，不支持正则或区域排序；搜索框最多 256 个 UTF-16 代码单元，Rust 入口最多 1,024 UTF-8 字节。搜索作用于当前目录范围；返回根目录保留搜索词，打开新会话清空搜索。
- 过滤遍历已加载且最多 100,000 条的快照，再按指定顺序排序并返回至多 128 条；过滤每条记录、排序前后检查取消。目录参数传物理 EntryId 或 `d` 前缀的虚拟目录 ID，由 Rust 校验当前会话资格，不接受 GUI 拼接的文件路径。
- 这是单工作线程、有界的版本化查询。页面携带完整 QueryKey，Qt 合并最新意图并取消旧工作；过期请求或不匹配的会话、查询、代际、修订和偏移均不能替换当前视图。偏移越界返回错误，空结果属于 Ready。目录跳转与搜索从第一页开始。
- 单击行或复选框切换当前查询多选，以物理 ID 区分同名记录，隐式目录使用独立的 dN 行键。查询成功或新会话替换模型后清空选择及详情；内部传输批次不影响已合成列表，界面不分页。详情显示最近激活条目的元数据，和复选框集合分别表达焦点与选择。全选以当前完整列表最后一行作为详情焦点，与逐项选中到最后一行的行为一致；取消全部选择清空详情。没有选择时隐藏原始大小、压缩后、修改日期、压缩方法与解压焦点条目的动作，不展示误导的空属性。
- 列表大小以 B/KiB/MiB/GiB 显示，数值转换仅用于近似显示；模型和 Rust 保留原始整数。文件图标表示类型，详情卡片不是内容预览。

所选条目现可发起 [解压元数据预检](extraction-preflight.md)，使用独立原生结果窗口；该功能不写出文件，不改变只读阶段边界。

## 完整目录索引与排序

- Rust 从完整不可变快照建立显式/隐式目录，Qt 不从当前页推断树。每个虚拟节点有当前会话内唯一的 `dN` ID、父节点 ID、显示名称、归档内完整前缀及后代物理记录数。没有显式记录的直属目录以导航行显示，物理 id 为 0，桥接额外携带 navigation_id、physical=false，Qt 使用 dN 展示键；它不能作为物理解压选择，也不会增加物理记录数。显式重复记录不去重；导航行只补没有显式记录的目录。导航行可选中、复制路径和进入目录，但大小、方法、日期显示 —；预检只允许实际物理记录，含导航行的选择集合禁用预检。
- 目录先于子节点发布，按归档中首次出现的顺序排列。同名物理条目保持独立；节点计数包含该前缀下全部后代（包括待检查条目），不包含与目录前缀完全相同的记录。计数不随名称搜索改变。
- 带警告、非可信 UTF-8、反斜杠、空组件、`.` 或 `..` 的记录不用于生成节点；它们仍留在物理快照和递归搜索中供检查。索引是导航能力，不是路径安全或解压授权。
- 超出任何目录预算时丢弃整个目录索引，界面明确提示，继续提供根目录、搜索及符合条件的显式目录浏览；未获得索引的隐式目录不能推测生成，根目录可能为空，搜索仍覆盖完整物理快照。绝不展示看似完整的截断树。目录空间另受名称预算限制，不改变原有 100,000 条扫描上限。
- 点击“名称、原始大小、压缩后、类型、修改日期”列头切换升/降序；Enter/Space 可激活。更多菜单可恢复归档物理顺序。先过滤和排序整个结果，再分页，因此跨页顺序一致。名称使用 Unicode 标量字典序、区分大小写，不宣称自然排序或区域规则；数值按 Rust 原始整数比较。所有相等值以行类型（物理先于导航）及对应身份升序决定先后，不因降序翻转同名记录。类型排序先依据记录的 directory 标记分组，显式与隐式目录都先于文件；类型升序／降序只改变文件类别顺序。文件类别由规范化扩展名确定，JPG 与 JPEG 属同组，无后缀文件保留独立的文件组，不用本地化显示文案作为目录身份。
- 浏览命令排序码：0 为物理顺序（补充的隐式目录随后按索引顺序），1/2 名称升/降序，3/4 原始大小，5/6 压缩大小，7/8 ZIP 方法编号，9/10 类型，11/12 修改时间；其余拒绝。切换列、目录或搜索回到第一页，成功替换页面时清空当前查询选择和详情。未获准入的操作恢复上一次已显示的查询参数。
- 树支持展开/收起、键盘导航及 Enter 进入目录；深层级通过横向滚动访问。基础行高 32、层级缩进 12.8、文件夹槽 16、图文间距 6.4，文字和图标与行中心对齐。大字号可增长行高与列宽。

本次验收见[目录导航与排序（本地／CI 工件）](../qa/README.md)。完整 M2 查询身份、来源版本检查与十万条验证见 [M2 契约](m2-readonly.md)；界面选择覆盖完整当前查询，内部批次不清空选择。

## 共享控件与上下文命令

菜单、按钮和快捷键复用只读控制器动作。右击已选条目保留当前查询多选，右击未选条目先单选；Shift 范围使用稳定条目 ID 作为锚点，查询或排序成功替换时清空。全选覆盖当前已收集完整目录查询，最多 100,000 行（含导航行）；预检独立限制为至多 128 个真实物理记录，含导航行或超限的集合禁用预检。名称 / 归档内路径复制到系统剪贴板，目录名称去掉末尾分隔符，路径保留原始展示形式。

列表与网格共享同一个受限模型与选中 ID；不为网格创建第二份索引。目录指南、末尾兄弟标记、祖先链和面包屑由已发布的完整目录模型派生，不新增格式查询。归档摘要缓存 Open 的物理总数，不随当前目录或搜索变化；面包屑右侧计数显示当前列表行数（含必要导航行）。

菜单在读取、查询或会话变化时失效关闭，执行前再次判断能力。Qt 当前维持单个真实归档会话；HTML 双标签属于独立示例会话。真实解压在 M3 中单独获得显式输出意图与目标授权；创建和独立归档完整性测试仍禁用，预检项明确只分析元数据。共享控件不直接获得文件写入能力。

## M2 查询与资源增量

同一查询先生成一次完整排序，再从缓存的行索引切取传输批次。每批最多 128 行、名称合计 64 KiB，控制／数据队列仍维持 8 MiB 背压。搜索或目录意图改变时，只保留最新待执行意图；旧响应不写入新查询。普通查询取消或超限保留最近成功列表；源版本变化清空失效数据并要求重新打开。

扫描前后、查询与预检边界检查来源句柄及当前路径的长度、修改时间和可用创建时间；Unix 另检查设备／inode，Windows 通过已锁定 winapi-util 的安全封装检查卷号／文件索引，以检测保留时间戳的路径替换。检查不是文件系统原子快照。选择汇总按模型选择修订缓存，使用 Rust u128 精确求和，避免重复遍历及 64 位溢出。
