# M3 安全 ZIP 解压实现

状态：2026-10-13 开发与三平台自动化验收完成。macOS ARM64、Windows X64、Linux X64 的核心、真实解压／冲突／取消／退出、尺寸检查与部署通过；完整提交、工件身份和测量见 [M3 验收（本地／CI 工件）](../qa/README.md)。该开发状态不替代最新 macOS 桌面人工验收或正式发行的独立安全审查。

格式插件只获得借用输入、不可变条目快照和宿主 `DecodedSink`。ZIP 元数据扫描与负载解码分离。Store、Deflate、单卷 ZIP64 的本地头、中央目录、数据描述符、声明大小、实际大小、CRC 和 Deflate StreamEnd 必须一致；不支持加密、分卷、其他压缩方法、非 UTF-8 名称和链接／特殊对象。原始 ZIP64 本地数据描述符可与普通中央目录组合，按本地头的大小宽度验证。流结束后剩余的压缩字节及输出正确但缺少终止块的流都失败。

所有输出先通过共享 portable 名称解析器，拒绝路径穿越、绝对路径、保留设备名、非法字符和歧义组件。任务准备阶段冻结选择：根目录全量解压包括全部物理记录；所选目录展开全部后代；所选文件去除当前目录前缀。浏览器根目录列表仍仅显示直属文件和文件夹。常见 Unicode NFD／小写等价名称按首个拼写映射，普通文件别名进入冲突流程；文件与目录冲突、父目录歧义在创建目标对象前拒绝。该比较不是所有文件系统名称规则的完整模拟，最终排他创建仍由原生文件系统裁决。

用户选择的目标目录通过 `xdzip-io::Grant` 转为持有目录句柄的能力。子目录逐组件 no-follow 打开，保留并复核父链身份。POSIX 目标须属于当前有效用户且不能向组或其他用户开放写权限；Windows 检查重解析点、所有者和 DACL，内容与修改权限只允许当前用户、SYSTEM、Administrators 和继承用途的 Creator Owner。其他 SID 仅可有 FILE_READ_ATTRIBUTES／READ_CONTROL／SYNCHRONIZE 元数据权限，兼容 Qt 私有目录；目录枚举、内容读取、写入、删除、改 ACL、泛型与未知位仍拒绝，继承 ACE 同样检查。共享、外部账户可写、链接或特殊目标拒绝；这是初版明确的目标限制，不通过放宽写入校验兼容共享盘。

私有工作目录以系统随机 128-bit 名字排他创建，POSIX 目录 0700、文件 0600。阶段文件使用宿主生成的顺序号，不使用归档提供的临时路径。真实解码字节逐块计量：单文件 8 GiB、单任务 20 GiB；声明压缩比高于 1000:1 且输出大于 1 MiB 时须显式允许，硬字节限额保持不变。每个解码器使用固定缓冲区，解压数据不整体积累到内存。

完整校验与数据同步后才提交。默认不覆盖：同卷硬链接的排他创建成功后移除私有链接；允许覆盖：复核已有普通文件的身份、大小和修改时间，使用同卷重命名替换，绝不先删除或截断旧文件。拒绝硬链接叶子和源归档本身。文件系统不支持提交原语时失败，没有复制／删除退路。身份校验是 best effort，不是同账户并发编辑的内容 CAS，也不承诺断电后的目录元数据持久化。目录已创建、文件已提交的效果分别计数，不虚构任务整体回滚。

私有 journal 记录准备与提交的相对路径和任务身份。清理只删除身份匹配的已知对象；发现未知文件、目标被替换或删除失败时保留恢复材料并报告清理警告。崩溃后的随机工作目录只统计提示，不自动解析、执行或递归删除。恢复策略与完整独立审查仍属于正式发行前的门禁。

任务和元数据各用一个工作线程。最多 32 个任务，等待终态消费的任务也占槽；队列保守计入不可变快照和计划，累计不超过 64 MiB。普通命令累计拥有数据不超过 8 MiB。每个任务只保留最新显示快照，输出进度最多 10 Hz，终态在清理后发布；GUI 接收线程和其邮箱继续有界，不能因 GUI 暂停无限增长。冲突提示具有任务内单次使用的 prompt ID，取消和退出会唤醒等待，不依赖数据队列有空间。

关闭准入以同一状态锁下发布的单调原子标记供非阻塞 submit 查询；shutdown 返回后，即使退出工作线程正持有锁，合法命令仍稳定返回 Closed，不会误报可重试的 Busy。该标记只决定拒绝，不绕过锁下的任务与请求状态检查。

取消通过原子提交许可线性化：开始提交前取消不写目标；提交已经开始时允许完成整文件原子发布，并在最终结果中计入已提交文件；最后任务完成后取消不能改变成功结果。关闭进度窗口只隐藏窗口，任务继续；退出程序须取消并等待工作线程与源句柄退出，不在 GUI 线程 join。

Windows ACL 是新增隔离 unsafe 边界，每个调用解释句柄、指针及缓冲区前提。当前是单维护者开发验证，不能将这些自检称为独立安全评审。依赖准入与公告查询见 [ZIP 解压依赖](zip-extraction-admission.md)，验收证据将在 [M3 验收（本地／CI 工件）](../qa/README.md)登记。

OWNER RIGHTS（S-1-3-4）表示对象所有者的动态权限，只在所有者已通过当前用户／SYSTEM／Administrators 检查后接受；不能使外部所有者或其他 SID 变为受信账户。原生回归同时验证继承到阶段文件与新建输出父目录，以及存在 OWNER RIGHTS 时仍拒绝 Everyone 的内容读取和修改权限。

Windows cap 目录句柄不允许 FILE_SHARE_DELETE，父目录改名攻击会在系统层被拒绝；验收同时证明外部目录未改变及安全目标发布仍在授权目录内。空私有工作目录清理在身份复核后使用 cap 的 consuming remove_open_dir，先关闭句柄再删除；只删除已验证的空目录，不放宽 nofollow、ACL 或链接拒绝规则。

Qt 桥接只传不含输出能力的目标／任务 DTO，ID 以不透明字符串进入 QML。菜单、解压选项、冲突、进度／结果和退出均接入真实任务；系统 Quit 同窗口关闭先经过任务决策，再进入异步关闭屏障。持续进度最多 10 Hz；提示、取消、清理及终态立即发布。运行时异常不猜测已提交总量，保留最近状态并明确标记计数不完整。

界面以 [逻辑尺寸规范](../visual/layout-scale.json)及 [操作图稿实测（本地／CI 工件）](../qa/README.md)为准，解压宽 614、任务宽 846、冲突宽 612；footer 操作字 15、提示 13。固定底部操作区与可滚动正文保证小屏和大字号可操作。大图使用同一 SVG 的 216 像素透明导出，不放大 72 像素小图；[素材规范](../visual/operation-assets.json)保留同源关系。原生系统标题栏与稿中的系统外观示意分开验收。

当前输出归属当前账户，使用受限权限（POSIX 目录 0700、文件 0600）；不还原可执行位、扩展属性或文件原始修改时间。程序包、链接条目和依赖这些元数据的内容不应按完整安装包解压能力验收。损坏、特殊项和源／目标变化默认停止当前任务；保留早前已提交文件，没有静默继续、整任务回滚或自动重试。

提交任务时，Qt 控制器继续使用 busy 串行准入并拒绝重复请求；taskStarting 区分解压／创建任务提交与目录读取。主窗口加载遮罩和普通控件外观使用 browsingBusy，不能把任务提交误画为目录重新读取。browserQueryAvailable 保持提交期间的查询入口外观，实际命令仍经过原有串行请求防护。解压确认仅“开始解压”动作随请求占用禁用，其他控件不出现临时禁用再恢复的闪烁。任务受理后才切换到真实任务窗口，拒绝或失败保留确认窗口和错误说明；不乐观清空目录或提前伪造任务成功。

链接诊断修订：格式层在只读 Entry 中单独保留 link 元数据，ZIP 从 Unix 创建者的原始类型位识别符号链接，TAR 从链接类型识别符号／硬链接。任务准备在输出授权和任何目录创建前返回 unsupported_link；Qt 使用双语专用说明，明确应用包依赖链接和可执行权限时不能完整还原。本次未新增链接写入、权限还原、自动跳过或普通文件替代链接的能力。现有 ZIP 中 Store／Deflate 方法受支持不代表其链接条目可提取。
