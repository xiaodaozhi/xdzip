# M2 完整 ZIP 只读浏览验收

状态：本地实现与自动化验收通过；本提交三平台 CI 和 Apple Silicon 工件待登记。日期：2026-10-13。

## 已实现

单卷 ZIP／ZIP64 最多 100,000 条真实物理元数据；重复记录与精确 64 位声明大小保留。根目录和普通子目录仅显示直属文件／文件夹，搜索递归当前范围。类型排序依据目录标记，两个方向都保持目录在前。

直属目录索引只保存身份，完整查询只过滤和排序一次。产品页面携带会话、查询 ID、GUI 代际、快照修订及偏移；批次最多 128 行、名称 64 KiB。Qt 合并最新搜索／目录／排序意图并取消旧工作，内部批次不构成界面分页。源句柄与当前路径变化使旧结果失效，普通查询取消保留最近成功的列表。

选择覆盖完整当前查询，汇总按选择修订缓存，用 Rust u128 精确求和；包含隐式目录或超过 128 个物理记录的选择仍不能发起元数据预检。列表／网格只实例化可见委托。

## 本地证据

自建数据集是十万条零字节文件组成的有效 ZIP64，另有分层与固定种子乱序样本；它们用于真实元数据扫描与查询，不替代内容解码或压缩／解压基准。生成方式见 [脚本](../../scripts/generate-m2-fixture.py)，核心探针见 [使用说明](../../tools/m2-probe/README.md)。大样本只生成在 build 或临时目录，不进入源码仓库。

Linux x86_64、本地 release 核心的乱序数据测量：读取与索引约 67ms、名称排序约 25ms、后续 781 批次约 0.8ms、检索约 8ms，峰值 RSS 约 19MiB。Qt 6.8.2 offscreen / software、当前本地 debug 开发构建：完整加载约 878ms，全结果排序并展示约 648ms，可见文件行委托 55 个，完整场景峰值约 213MiB。详细数据见 [核心 JSON](m2/local-core-performance.json)、[Qt JSON](m2/local-qt-performance.json)、[Qt 测量日志](m2/local-qt-performance.log)；数值不是跨机器性能保证。

Rust 工作区、Clippy、QML 检查及本地 5 组 CTest 已通过。新增回归覆盖十万条 ZIP64、普通 ZIP 恰好 65,535 条的边界、超过 2^53 的大小、ZIP64 扩展磁盘、损坏尾记录／locator、转义名称字节预算、跨批次共享身份、四维过期键、最新意图、源修改／替换、完整选择及虚拟化委托数量。实际 Qt 截图见 [HTML 证据页](m2/index.html)，5 组 CTest 见 [日志](m2/local-tests.log)，独立布局检查 729 项通过，见 [JSON](m2/local-fidelity.json)。截图来自 Linux 离屏软件渲染，并非 macOS 原生窗口截图。内存和传输约束见 [M2 契约](../engineering/m2-readonly.md)。

## 开发包与人工操作

本阶段工件由 Qt components 工作流生成，名称为 `xdzip-m2-macOS-ARM64`、`xdzip-m2-Windows-X64`、`xdzip-m2-Linux-X64`，最终以 Actions 实际平台标识为准。包内 `build.json`、同提交源代码、许可、测试和测量必须一起核对。macOS 包是 Apple Silicon 开发 app，采用 ad-hoc 签名，不是公证发行。

人工验收：打开普通 ZIP 和十万条样本；连续搜索／切换目录；五列表头排序；跨可见区选择及全选；确认根目录直属项、搜索完整路径、类型目录优先；修改来源后查询必须要求重新打开；退出与 Cmd+Q 等待异步关闭。核对浅深色、200% 字号及系统 DPI。

内容预览、CRC／本地头验证、真实解压、创建、分卷、猜测编码、第三方插件和发行签名尚未实现。目录导航另有 32,768 节点／64 层／4 MiB 限额，超限整体降级，不能把“已读取十万条物理记录”描述成没有这些边界。
