## 实际验证

- `check-html-controls.py`：22 组实际指针、键盘和触摸检查，覆盖三平台示意、浅深主题及 320／390 宽度；任务重新打开通过新的菜单入口。
- `check-html-density.py`：原有密度检查加上 `html_interaction_contract.py` 的组合交互检查。私有 Xvfb 与 XTest 驱动真实 Chromium 100%／125% 页面缩放，DPR 1／1.25／2；438 项通过，无页面异常或外部请求。未用 CSS zoom 或图片缩小代替页面缩放。
- `check-html-header.py`：21 项原稿锚点与实际图标墨迹检查通过。
- `check-html-body.py`：67 项内容区域检查通过。新方形按钮及图标中心采用逻辑规范；原稿对应量测仍以明确的历史修订记录保留，没有覆盖原图或放宽误差。
