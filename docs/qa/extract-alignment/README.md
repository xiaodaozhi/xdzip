# 解压目标区域对齐复核

2026-10-14。[当前 HTML／Qt 截图](index.html)、[实际坐标](measurements.json)。这是[正常密度修订](../extract-fidelity/README.md)之后的对齐追加修订；原稿与上一轮截图、回执保持原始字节。

“创建同名文件夹”与目标检查反馈共用 24 逻辑像素图标槽、16 可见标记、8 图文间距。复选框和状态圆盘在槽内居中；两行文字采用同一起点，并在各自行中垂直居中。Qt 检查中或失败时仍保留槽位，文字位置稳定。

路径框中的“更改”按钮以真实高度计算右留白，保持与上下留白相等；默认均为 6。这个关系随按钮实际字体和高度变化，不用固定右边距近似。路径输入的上下空间保持可用，不挤压编辑文字。

[HTML 验证](html-validation.json)通过 221 项，包含浅深主题、嵌入／独立入口与 DPR 1／1.25／2 的两列对齐和各行垂直中心；操作窗检查 648 项通过。Qt 在 [DPR 1](qt-validation-dpr1.json)、[DPR 1.25](qt-validation-dpr1.25.json)、[DPR 2](qt-validation-dpr2.json)各通过 64 项，六组本地 CTest 通过。新增检查比较实际坐标间的关系，不把布局参数本身当作验收结果。

截图为 Linux x86_64、Qt 6.8.2、offscreen software 的真实客户区捕获；HTML 的窗口装饰仅作示意。原生 macOS 桌面装饰和输入体验不由离屏截图证明。当前 HTML 和 Qt 使用不同的示例／自有 ZIP 内容，文件名与目标目录不是视觉差异项。不生成 Apple Silicon 开发应用包，build/ 和 dist/ 不入库。
