# 解压窗口与菜单复核

2026-10-14。实现顺序为原稿量测、HTML 参数与真实交互、Qt 同参数实现和实际捕获。[图片对照](index.html)包含正常密度的 HTML、实际 Qt、原稿与下拉菜单；当前可操作入口为 [HTML 解压窗口](../../../design/html/index.html?view=extract&zoom=1)。

## 根因与尺寸契约

修订前，同一 HTML 解压窗在主窗口中约 491 宽，独立入口约 614 宽，Qt 使用了后者；614／491 约为 1.25。此前只检查独立入口的期望值，漏掉了两个入口的组合关系。当前固定正常宽度为 491，标题 20、正文 13、footer 操作 13、辅助文字 12。DPR 只影响截图像素，不改变逻辑尺寸。

[原稿依据](../../visual/extract-reference.json)保留原图 SHA-256、源坐标、颜色取样和换算比例。原图不修改；解压采用独立映射 819.2／1548。HTML 按当前审阅上下文换算源坐标，Qt 使用真实布局；两个 HTML 入口最终宽度与控件字号一致。

## 修订与交互

- 解压目标与重名卡片使用均匀 #F4F6FA 底色、#DFE5EF 边框；范围标题为同色带，正文为白色。深色值来自同一 token 源。
- 文件夹、路径与内嵌“更改”按钮共享输入框；框高约 35，按钮约 69×24，描边保持 1 逻辑像素。Qt 未聚焦时显示实际同名目录预览，聚焦时编辑基础目录。
- 复选框共用已交付的透明选中素材；不采用浏览器蓝色方块和 Qt 默认对勾拼装。
- 操作窗复用 xdzip 下拉组件，保留选中状态、禁用、键盘导航、Home／End、Enter、Escape 与焦点返回。HTML 用 top layer 避免被滚动正文裁切；Qt 根据可用空间翻转，菜单与控件保持 4 间距。
- 解压正文单独滚动，footer 固定可达；Qt 键盘聚焦可滚动区域内的控件时自动使它进入视口。
- Qt 菜单用 Canvas 一次绘制模糊轮廓，替换 12 层扩张矩形；浅深主题重新绘制，软件渲染也显示柔和阴影。

## 证据与限制

[HTML 记录](html-validation.json)对照未修改的原稿，并覆盖嵌入／独立入口、浅深色、DPR 1／1.25／2、键盘选择和完整 footer。普通操作窗检查、浏览器真实 100%／125% 页面缩放和高 DPR 检查继续保留；[HTML 几何契约](html-operation-metrics.json)供 Qt 独立比较。

[Qt 记录](qt-validation.json)来自实际场景树和未处理截图；主机为 Linux x86_64、Qt 6.8.2、offscreen software。截图使用自有 ZIP 样本，照片示例属于 HTML，真实任务不会伪造预览内容。系统装饰不包含在 Qt grabWindow 中，HTML 的装饰是外观示意。较矮的屏幕会限制窗口高度并滚动正文，不能只比较整张图片高度。

历史 M3 回执与图片保留原始验证值，本次修订不覆盖过去的记录。最新版 macOS 原生装饰、输入法与辅助功能仍需真实桌面体验；离屏捕获不替代这项验收。没有生成 Apple Silicon 开发包，build/ 和 dist/ 产物不提交到 Git。
