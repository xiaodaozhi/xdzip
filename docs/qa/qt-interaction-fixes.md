# 主窗口交互与布局修正

日期：2026-10-13。依据：[界面设计规范](../visual/design-standard.md)。主窗口继续使用 1024×622 逻辑尺寸、48 高标题栏及 32 高胶囊。下列修订覆盖正常、悬停、键盘焦点、列表／网格、长路径与真实归档。

| 编号与项目 | 修订与核验方式 |
| --- | --- |
| 1 · macOS 红绿灯 | 将 QML 标题中心转换到 AppKit 按钮容器坐标；保留原生按钮，响应尺寸与全屏状态变化。Cocoa 启动检查实际按钮中心及容器裁切。 |
| 2 · 加号、齿轮居中 | 图标槽在按钮内容区域精确居中；不再参与弹性 RowLayout 分配。 |
| 3 · 工具栏图文间距 | 图标与文字使用固定 6 逻辑像素间距，剩余按钮宽度不分配给间距。 |
| 4 · 全部解压颜色 | 主操作背景保留标准强调蓝；未实现动作继续禁用并提供说明，不伪装已支持写出。 |
| 5 · 面包屑 hover | 按钮正常高度 28，垂直居中；标题区域上下留白，辅助字号增大时随文字增高。 |
| 6 · 类型、日期排序 | 五个表头均支持点击及键盘升降序；类型按扩展名类别排序，JPG 归 JPEG。日期来自 ZIP 中央目录 DOS 本地时间，不推断时区；无效值显示“—”。同值保留物理条目顺序。 |
| 7 · 全量目录列表 | 取消 UI 分页；自动读取 128 条传输批次后原子更新最多 10,000 条结果，TableView/GridView 继续复用可见委托。取消、失败和旧事件身份检查继续有效。 |
| 8、9 · 查看按钮形状与位置 | 列表、网格、排序按钮固定 28×28；右侧布局宽度固定，面包屑仅使用剩余宽度。 |
| 10 · 网格表头 | 网格隐藏列表表头，内容区域随之上移；切回列表恢复。 |
| 11 · 排序菜单 | 从按钮右下角向下定位，保留 4 像素间隔。 |
| 12 · 预览关闭按钮 | 固定方形命中框及共享圆角背景，检查 hover 和图标中心。 |
| 13、16 · 树选中样式 | 左侧两个圆角归零；选中竖线覆盖整行高度。子节点取消四边描边，焦点仍由竖线与键盘状态表达。 |
| 14 · 树文件数 | 移除行末计数及其覆盖层；完整路径保留在 tooltip，无文字／数字重叠。 |
| 15 · 树滚动范围 | 仅按当前展开的可见节点、实际字体宽度与缩进计算列宽；折叠后重算，避免最深隐藏节点留下空白。 |
| 17 · 菜单分隔线 | 共享分隔项具有明确宽度，“在此目录中搜索”上方显示横线。 |
| 18 · 任务菜单 | 从任务按钮上方向上展开，保留 4 像素间隔。 |

## 自动化证据

`reviewedMainControlsAndMenus` 实际点击切换、排序与菜单，检查按钮中心、固定间距、目录切换后的锚点、网格表头及弹出边界；`realPagesAndFailure` 与 `completeNavigationAndGlobalSort` 使用 270 条样本验证完整列表及跨传输批次排序。Rust 覆盖类型／日期双向排序与同值身份稳定性。原生红绿灯检查由 macOS Cocoa smoke 执行，Linux offscreen 图不作为该项证据。

独立的操作窗口、任务写入和图片内容解码不属于本轮新增能力。

本地验证：5 组 CTest、Rust workspace 测试、Clippy、729 项独立主界面检查及 72 项共享组件检查通过；DPR 1.25／2 同时检查主界面和此次交互修订。截图位于[交互验收图](qt-interaction-fixes/index.html)。

macOS ARM64 原生验证：[构建 38371795584](https://github.com/xiaodaozhi/xdzip/actions/runs/38371795584)，三个 AppKit 按钮中心均为 `24.00`，与 48 高标题栏中心一致；按钮及祖先容器裁切检查通过。该证据来自 macOS 14 CI，未代替最新版 macOS 真机验收。

HTML 设计稿的对应修订、截图及真实浏览器缩放检查见[HTML／Qt 同步验收](html-qt-interaction-sync.md)。
