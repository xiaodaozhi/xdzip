## 仍缺什么，以及原因

1. **Qt/Rust 桥接验证**：当前尚未选择和准入具体 cxx 版本，缺少同版本生成器、Unicode 往返、所有权与线程关闭证据。不能把 Qt 单独运行成功当作桥接成功。
2. **平台与依赖冻结**：缺少 macOS arm64 和 Windows MSVC 实际构建/运行；当前 Linux glibc 2.41 也不能证明候选 glibc 2.35 基线兼容。需要对应原生或 CI 环境，并核对 Qt 安全维护渠道、依赖来源和许可。
3. **生命周期和安全 I/O**：命令/事件队列、终态、取消竞争、文件授权与暂存提交仍未实现。这些是后端进入真实文件操作前的工作包，不由素材交付解决。
4. **界面落地契约**：新的高保真稿覆盖主窗口和解压确认；冲突、创建、任务结果、设置及三平台全部状态尚未完成同标准高保真细化。素材中的矢量和透明品牌图是重建候选，未完成与稿件的一致性验收。

以上不阻止 WP-01 基础验证继续推进；会阻止将整个 WP-01 或 WP-04 标记完成。签名、公证、发行身份和独立安全审查属于后续发行门槛，不提前拿来阻塞本阶段探针。
