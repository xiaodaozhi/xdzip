# 解压预检验证

2026-10-11，Linux x86_64，Rust 1.99.0、Qt 6.8.2，软件离屏渲染。不是三平台安全文件层验收。

![实际独立预检窗口](screenshots/zip-preflight.png)

实际读取仓库 ZIP 样本、选中中文文件后得到的报告。截图为窗口内容，不包含系统标题栏。macOS M1 原生装饰、焦点与辅助功能尚待实机验证。

- Rust 工作区 22 个单元测试和 1 个编译失败文档测试通过；新增 5 个预检测试覆盖逃逸、保留名、控制字符、非 UTF-8、重名/大小写父目录别名、文件目录冲突、选择展开、外来 ID、取消、声明量溢出、深度/长度与索引预算、64 条报告上限。
- 运行时只读样本字节在预检后保持一致；预检模块没有文件系统 API 或目标参数。
- CTest 6/6 通过，Qt 用例验证两个同名记录产生冲突、目录展开得到正确计数、报告保留选择、选择变化清空报告，以及结果窗口的 transient owner、非模态和关闭行为。
- Rust/C++ 格式、Clippy、QML 静态检查、文档链接和主题同步检查通过。

这不是解压成功或安全写入证明。尚无解码与输出操作，不能执行链接竞争、磁盘满和提交故障等验收；报告零问题不代表归档内容通过 CRC，也不代表目标文件系统允许这些名称。详见 [阶段契约](../engineering/extraction-preflight.md)。
