はじめて使う場合は、[XDZip をダウンロードしてインストール](user-guide/install.md)し、[アーカイブを開いて内容を閲覧](user-guide/browse.md)してください。[対応形式の一覧](../../README.ja-JP.md#xdzip-format-support)では、開く、作成する、編集する操作に対応した形式を確認できます。インストール済みバージョンの機能については、対応する[リリースノート](https://github.com/xiaodaozhi/xdzip/releases)をご覧ください。

| ドキュメント | 内容 |
| --- | --- |
| [ユーザーマニュアル](user-guide/README.md) | アーカイブの閲覧、プレビュー、展開、作成、編集、検証を行います。パスワード、分割アーカイブ、バックグラウンドタスク、更新の使い方も説明します。 |
| [コマンドラインとの連携](integration/README.md) | 単体のコマンドラインツールを使い、JSON の結果と終了コードを利用してアーカイブ操作を自動化します。 |
| [製品設計と技術リファレンス](reference/README.md) | XDZip の形式検出、ファイル処理、タスク管理、各システムとの連携の仕組みを説明します。 |
| [ビルドと開発への参加](contributing/README.md) | ツールを準備し、コードをビルドして実行した上で、変更に適した確認方法を選びます。 |

問題が発生した場合は[トラブルシューティング](user-guide/troubleshooting.md)をご覧ください。開発やリリースの運用については[メンテナー向けハンドブック](../../developers/README.md)を参照してください。
