# 内容のプレビュー

[English](../../engineering/content-preview.md) | [简体中文](../../zh-CN/engineering/content-preview.md) | [繁體中文（台灣）](../../zh-TW/engineering/content-preview.md) | 日本語 | [한국어](../../ko-KR/engineering/content-preview.md) | [Français](../../fr-FR/engineering/content-preview.md) | [Deutsch](../../de-DE/engineering/content-preview.md) | [Español](../../es-ES/engineering/content-preview.md) | [Português (Brasil)](../../pt-BR/engineering/content-preview.md) | [Русский](../../ru-RU/engineering/content-preview.md)

プロパティカードが表示されているとき、対応するファイルを一つ選択すると、選択が安定した後にプレビューが始まります。ポインターがプレビュー上にあるかボタンがキーボードフォーカスを受けると、右上に更新アイコンが表示され、選択ファイルを再読み込みできます。カードは読み取りやデコードの失敗を報告し、複数選択時は選択を促すメッセージを表示します。メインウィンドウと独立したプロパティビューアーはこれらの動作と既存のパスワードウィンドウを共有します。ファイルのメタデータは別途利用できます。

<a name="xdzip-capabilities-and-budgets"></a>

## 機能と予算

読み取り可能でサイズが既知、危険な名前のない通常ファイルだけをサポートします。許可されるテキスト拡張子は txt、md、log、json、csv、tsv、toml、yaml、yml、ini、xml、rs、c、cpp、h、py です。厳格な UTF-8 または BOM 付き UTF-16 だけを受け入れます。入力と変換後 UTF-8 はそれぞれ 256 KiB 以下で、NUL などのバイナリー制御バイトは禁止です。内容は PlainText コントロールに表示し、タグ、URL、プログラムテキスト、マクロは実行しません。

| 画像形式 | 三つのプラットフォームでの範囲と実際の動作 |
| --- | --- |
| PNG、JPEG（jpg、jpeg、jfif、jpe） | 一つの静止画像を完全に読み、向きに利用可能な変換メタデータを適用する |
| GIF、WebP | 静止画像またはアニメーションの最初のフレーム。アニメーションは再生しない |
| BMP、ICO/CUR | 通常の画像またはデコーダーの既定画像。CUR はシステムカーソルを有効にしない |
| ICNS | 利用可能なシステムデコーダーがサポートする埋め込み PNG または JPEG2000、最大 256 ブロック。未知の埋め込み形式と古い生ビットマップ/RLE アイコンは明示的に拒否する |
| TGA | カラーマップと画像 ID がなく左側を原点とする非圧縮 16/24/32 ビットのトゥルーカラー画像。同じレイアウトで古いフッターが欠けていれば補う。RLE とインデックスカラーは非対応 |
| TIFF（tif、tiff） | 最初のページだけ。ページを自動的に巡回しない |
| SVG | 制限付き解析後にラスタライズする UTF-8 の静的ベクター。以下のサブセットを参照 |
| HEIC/HEIF | システム ImageIO を使う公式 Qt プラグインによる macOS のみ。他では明示的に拒否 |

AVIF、RAW、PSD、EXR、PDF、Office、独立した第三者デコーダーライブラリーは追加しません。拡張子、Rust による形式シグネチャーの検査、固定された Qt デコーダーで受理を共同決定します。システムに追加インストールされたプラグインは製品の機能にならず、他のデコーダーも自動的に調査しません。

エンコードされた画像内容は最大 16 MiB です。Rust のイベントキューと Qt のメールボックスはそれぞれ 32 MiB 以下、コマンド予算は引き続き 8 MiB です。元画像の幅と高さはそれぞれ最大 16,384、総ピクセル数は最大 33,554,432 です。ソースの受理と出力サムネイルは別々に計上します。最終出力の幅と高さはそれぞれ最大 512、縦横比を保持し、RGBA8 は最大 1 MiB です。12 MP などの写真も予算内でサムネイルとして読めます。一部のデコーダーは縮小前に元画像を読むため、サムネイルのサイズだけで内部使用量が 1 MiB 以下と証明することはできません。利用可能なカラープロファイルは sRGB に変換し、不明なプロファイルはデコーダーの結果を保持します。専門的な色校正は保証しません。

Qt の非同期画像プロバイダーはランダムなトークンだけを受け取り、システムパスやネットワーク URL は受け取りません。エンコード内容は全体で最大 32 MiB 保持し、並列デコードは最大二タスクです。キャンセル済みで回収中のタスクも、それぞれ最大一つの 16 MiB 入力を保持できます。各タスクは固定された隣接の非公開ワーカー `xdzip-image-preview` を起動し、アーカイブパス、パスワード、出力先ハンドル、アプリの認証情報を渡しません。ワーカーの出力は固定サイズのヘッダーと、幅、高さ、長さが厳密に一致する RGBA8 のみを許可し、余分な出力を認めません。失敗、クラッシュ、無効なフレーム、タイムアウト、遅れて届いた結果は表示できません。

ホストは起動から合計五秒の期限を設け、50 ms ごとに要求の有効性を確認します。閉じる、キャンセル、項目変更時にはワーカーを終了して回収します。ワーカーは QImage の割り当てを 128 MiB に制限します。Windows はプロセスのコミットメモリー 512 MiB とユーザー CPU 三秒の Job を使います。Unix は CPU 三秒、コアダンプ無効、ファイル記述子の上限を使います。Linux はアドレス空間を 512 MiB、通常ファイルサイズをゼロに制限します。macOS は既存の dyld 仮想予約に加えて 512 MiB のアドレス空間を許可し、これは RSS の厳格な上限ではありません。システム ImageIO はファイルに裏付けられたランタイム資源を使う場合があるため、通常ファイルをそれぞれ 16 MiB 以下に制限し、超過時はデコードを終了します。アプリはアーカイブ項目のコピーをエクスポートせず、システムのランタイム資源と項目出力は別々に管理します。これは非公開デコーダーのクラッシュとリソースの隔離であり、任意の第三者プログラム用のカーネル権限サンドボックスではありません。

アーカイブ内容の各読み取りは累積ソース読み取り 256 MiB、デコードとスキップの作業 64 MiB、補助アルゴリズムの作業 256 MiB に制限されます。形式辞書、ワーカー、方式グラフは引き続き[形式バックエンド契約](native-codecs.md)の別予算に従います。ソリッドアーカイブや順次圧縮ストリームでは、先行デコードが作業予算を超えると小さなファイルのプレビューも拒否される場合があります。

<a name="xdzip-static-svg-subset"></a>

## 静的 SVG サブセット

SVG は三つのデスクトッププラットフォームですべて同じ Qt Svg 描画経路を使います。描画前にストリーミング XML パーサーが、対応する静的図形、テキスト、スタイル、内部定義、グラデーション、クリッピング、マスク、制限されたフィルターを再構成します。上限は 8,192 要素、64 階層、要素ごとに 64 属性、属性ごとに 1 MiB、出力合計 16 MiB です。メタデータは描画に参加しません。スタイル要素はテキストだけを受け付け、XML テキストの断片と CDATA を結合して CSS 全体を確認し、分割による外部参照制限の回避を防ぎます。

DTD、エンティティ、処理命令、スクリプト、イベント、アニメーション、foreignObject、image 要素、フォントファイル、外部スタイル、外部リソース参照は拒否します。href と CSS url は現在の文書内の単純なフラグメント識別子だけを受け入れます。xml:base、src、CSS import、エスケープ形式は禁止です。埋め込みビットマップと SVGZ はサブセット外です。未知の描画要素や禁止された内容は黙って捨てて完全に表示したように見せるのではなく、プレビュー全体を失敗させます。通常の静的 SVG をサポートしますが、SVG やブラウザーのすべての機能を主張しません。

<a name="xdzip-integrity-passwords-and-lifecycle"></a>

## 整合性、パスワード、ライフサイクル

プレビューは固定された物理識別情報、ソースバージョン、ペイロード位置、既存デコーダーを再利用します。テキストやエンコード画像をプレビューに渡す前に、内容を EOF まで完全にデコードし、その形式で利用可能な整合性と認証の検査を完了しなければなりません。ファイルごとの内容チェックサムがない TAR などは、既存の構造と読み取り可能性の保証だけを維持します。ディスク上の大規模索引は、すべてのメタデータを Qt に読み込まず、選択されたペイロードを上限付きで読み取ります。

パスワードは現在の要求にだけ結び付け、既存のゼロ化するコンテナーを使います。エラー、認証の曖昧さ、キャンセルは既存の分類に従い、試行は最大十回です。パスワードウィンドウを閉じるとプレビューだけをキャンセルし、利用可能なディレクトリーを維持します。オープン、移動、その他の前面読み取りコマンドは保留中のプレビュー読み取りより優先します。プレビューを閉じる、項目を変更する、アーカイブページを隠す、セッションを閉じると内容を消去し、無効になった要求やデコード結果が古い内容を復元することはありません。失敗とキャンセルは未検証の部分内容を破棄し、項目のコピーを書き出さず、システムアプリを起動しません。ダブルクリックによる一時オープンは[別の手順](archive-opening.md)に従います。

<a name="xdzip-toolchain-and-acceptance"></a>

## ツールチェーンと受け入れ

`desktop.py prepare --install-qt` は新規または既存の SDK に固定された Qt 6.8.2 の qtimageformats を追加し、doctor はビルド前に Svg と必要なプラグインを検査します。公式ソース、ダイジェスト、通知、SDK の対応関係は共通設定に含めます。Qt 同梱の libwebp/libtiff と別途追加した形式ライブラリーは独立して管理します。`check-image-preview.py` は既定テスト、Windows/Linux の配置検証、許可された Mac パッケージ化で実際のワーカー、プラグイン、最小限のデコードを検証します。Mac は offscreen を明示的に含め、自己検査前に SDK の検索上書きを消去します。開発 SDK のプラグインディレクトリーは実際のランタイムパッケージのテストを代替できません。

回帰ではプロジェクト所有の画像を使い、各形式、アニメーションの最初のフレーム、TIFF の最初のページ、透明度、12 MP の写真、macOS の HEIC と他プラットフォームでの拒否、SVG の内部定義と外部リソース拒否、破損入力、ピクセル超過、無効なフレーム、タイムアウト、キャンセルを網羅します。実際のアーカイブ経路では引き続きパスワード、整合性、ソースの識別、UI 無効化時のクリーンアップを確認します。レイアウトは[視覚標準](../visual/design-standard.md#xdzip-content-preview)に従い、[検証](../../../developers/qa/README.md)に基づいて変更のないレイアウト証拠を再利用し、新たに追加した画像の実表示を観察します。
