# データのライフサイクルと診断

[English](../../engineering/privacy.md) | [简体中文](../../zh-CN/engineering/privacy.md) | [繁體中文](../../zh-TW/engineering/privacy.md) | 日本語 | [한국어](../../ko-KR/engineering/privacy.md) | [Français](../../fr-FR/engineering/privacy.md) | [Deutsch](../../de-DE/engineering/privacy.md) | [Español](../../es-ES/engineering/privacy.md) | [Português (Brasil)](../../pt-BR/engineering/privacy.md) | [Русский](../../ru-RU/engineering/privacy.md)

[プライバシーポリシー](../../../PRIVACY.md)では、xdzip が扱うデータとユーザーが選べる設定を説明します。次の表はデータを保持する場所と削除する時期を示します。閲覧、圧縮、展開はオフラインで動作します。xdzip はテレメトリやアーカイブの内容をメンテナーに自動送信しません。

| データ | 保持期間 | 保存と削除 |
| --- | --- | --- |
| 設定とテーマ | バージョン付きスキーマで起動間に保持 | 変更はアトミックな置き換えで保存します。失敗した場合は従来の設定を保持し、画面にエラーを表示します。 |
| macOS で以前に使っていた既定のアプリ | ローカルで起動間に保持 | xdzip を既定にすると、別の設定ファイルにそのコンテンツタイプの以前のアプリのバンドル ID を記録します。元に戻すか別のアプリを選ぶと、そのタイプの記録を削除します。 |
| 最近のファイル | 任意でローカルのみ | 非公開の `recent.json` は重複しないパスを新しい順に記録し、ファイルの上限は 64 KiB です。無効化すると新しい記録を追加しません。履歴を消しても元のファイルは変更しません。 |
| アーカイブの索引 | 開いているセッションの間 | 小さな索引はメモリー上に保持します。大規模 ZIP の索引ではメタデータとクエリ順を非公開のディスクファイルに保存します。正常終了、クエリの置き換え、失敗、キャンセルでは把握しているファイルを片付けます。後の作成処理では、識別情報とリースの規則に従ってクラッシュ後の未使用ファイルを回収できます。起動をまたいで索引を再利用することはありません。[大規模アーカイブの索引](large-index.md)を参照してください。 |
| 一時出力と復旧状態 | タスクと復旧の実行中 | 復旧は管理されたメタデータのみを使用し、所有権を確認できる項目だけを削除します。アーカイブの内容を実行したり、任意のパスへの書き込みを復元したりしません。 |
| アプリ内プレビュー | ユーザーが開始し、上限あり | プレビューの対象が変わるかセッションが終わると結果を消去します。遅れて届いた結果で無効にした内容を復元することはありません。 |
| パスワード | 必要な操作の間 | アプリはパスワードを設定やログに保存しません。OS がアプリの制御外でメモリー上に別のコピーを保持する場合があります。 |
| 独立した更新確認とダウンロード | 対応版でユーザーが開始 | GitHub の公開リリースとダウンロードサービスを使います。設定したプロキシがリクエストを処理でき、任意で利用する HTTPS ミラーには元のダウンロード URL が渡ります。サービス提供者は接続情報とリクエストに含まれるアプリのバージョンを確認できます。Windows MSIX では独立したアップデーターを無効にします。 |
| 更新トランザクションの記録 | ローカルで、インストール中の再起動をまたいで保持 | 設定と同じディレクトリにある別ファイル `update-state.ini` がトランザクションと対象の識別情報を保持します。失敗したダウンロードは非公開の更新キャッシュに残る場合があります。アップデーターは定められた記録ファイルだけを読み、内容を実行しません。 |
| ステータスと診断 | 機能に応じて画面、ターミナル、またはローカル記録に表示 | アプリが診断情報を自動アップロードすることはありません。バージョンやファイル情報のコピーはシステムのクリップボードに書き込みます。エラー、ログ、スクリーンショットを共有する前に、ファイル名、パス、その他の個人情報を確認してください。 |

ネットワーク通信、署名、インストーラーへの引き継ぎ、復旧は[ソフトウェア更新の仕様](software-update.md)を参照してください。
