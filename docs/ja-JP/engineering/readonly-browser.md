この文書は閲覧データ、リソース、操作の境界を定義し、[ドメインとデータ](../design/domain-data.md)、[Qt/Rust ブリッジ](../design/qt-rust-bridge.md)、[フォーマット拡張設計](../design/codec-extension-sdk.md)を補足します。第三者プロトコルや完全なフォーマット SDK を固定するものではありません。以下に ZIP 固有のメタデータ規則を示します。TAR/TAR.GZ は閲覧とクエリーのモデルを再利用します。フォーマットの違いは [TAR/GZIP 契約](tar-gzip.md)を参照してください。

通常の単一ファイル ZIP/ZIP64 に対する 100 万エントリーのストリーミングインデックス、ディスク退避の制限、オンデマンドモデル、タスクの上限は[大規模アーカイブのインデックス](large-index.md)を参照してください。以下のメモリー内スナップショット 100,000 エントリーの制限は通常フォーマットと初期の ZIP サポートの基準であり、新しいストリーミング ZIP の受付条件を上書きしません。

## データと依存関係の方向

xdzip-codec-api は借用した読み取り専用入力、キャンセル、上限、エントリー、エラーを定義します。xdzip-codec-zip はパスや書き込み権限を持たず、組み込み ZIP メタデータの適応を実装します。xdzip-runtime は読み取り専用ファイルを開いて保持し、スキャン成功後に不変スナップショットを公開します。xdzip-qt-bridge は cxx を通じてワーカースレッドの入口を公開し、薄い C++ コントローラーが制限付きページを Qt モデルに変換し、QML が表示と操作意図を扱います。

製品は[コマンド／イベントのランタイム](product-runtime.md)に移行しています。GUI は短いコマンドを送信し、Rust ワーカーがアーカイブを保持し、別の Qt 受信側が制限付きメールボックスを通じて結果を届けます。QtConcurrent の同期ブリッジは削除されました。各閲覧コントローラーの保留リクエストは最大一つです。これは完全なマルチタスクスケジューラー、動的プラグイン ABI、第三者プロセスのプロトコルではありません。

## 動作とデータ

アーカイブを開くとルート直下の子を一覧表示します。検索には子孫の物理レコードを含めることができます。同名エントリーは別々の `EntryId` を保持し、セッション ID は再利用しません。UI は精度を保つため ID とバイト数を文字列で転送します。ドメインの `PageRequest` は最大 256 行を表現できます。製品ランタイムは一ページにつき最大 128 行、名前合計 64 KiB を送り、一つの順序付きクエリー結果からページを切り出します。Qt は最大 1,024 行の結果を原子的に公開します。より大きな結果では論理行数を保持し、必要時に行を取得し、最大 1,024 行をキャッシュします。ページ送りコントロールはありません。ユーザーが要求するプレビューは[埋め込みプレビュー](content-preview.md)、システムの関連付けでメンバーを開く動作は[アーカイブを開く契約](archive-opening.md)を参照してください。

ZIP/ZIP64 を認識し、ZIP64 ロケーター、終端レコード、中央ディレクトリの開始ディスクを検証します。[分割ボリュームホスト](archive-opening.md)は統合された論理入力を提供し、コーデックは変換されていない複数ディスクメタデータを引き続き拒否します。ZIP64 のサイズとオフセットは 64 ビットのままとし、宣言サイズから内容バッファーを確保しません。中央ディレクトリの件数は EOCD と一致しなければなりません。エラー、キャンセル、上限超過では部分的な一覧を公開しません。名前は[エンコーディング契約](filename-encoding.md)に従い、Unicode 宣言を優先した後、未宣言の旧エンコーディングを検出し、解決できないバイトをエスケープします。制御文字と双方向テキスト制御文字もエスケープします。絶対パス、親へのパス、特殊ファイルなどのレコードには「要確認」を付けます。生の名前バイトは常に保持し、出力には独立してパス検証と認可を受けた有効名だけを使います。

ブラウザーに表示するサイズ、圧縮方式と暗号化フラグはアーカイブのメタデータに由来します。ZIP 閲覧は中央ディレクトリを読み取り、すべてのローカルヘッダーやペイロードを検査しません。圧縮 TAR など一部の他フォーマットは、レコードの発見時に外側のストリームをデコードします。オープン時にメンバーファイルを展開しません。大きな通常 ZIP ではランタイムが非公開の[ディスク上メタデータインデックス](large-index.md)を作成できます。内容を検証するには別の[整合性検査](archive-checking.md)または[安全な展開](zip-safe-extraction.md)を要求してください。

## プラットフォームをまたぐファイル名エンコーディングの境界

フォーマット層は生の名前バイトと物理識別情報を保持し、ZIP UTF-8 フラグと CRC 検証済み Unicode Path を優先し、次にグループ全体の UTF-8 チェックと未宣言名に対するアーカイブ単位の制限付き統計検出を使います。旧来の GBK/GB18030、Big5、Shift-JIS などの名前は、閲覧、移動、展開、一時オープン、エクスポート、通常の変更に直接使用できます。パスを使うすべての処理は固定されたデコード結果を共有し、パス、Unicode と大文字小文字、名前競合の検査を繰り返します。

検出はシステムのコードページや UI 言語に依存せず、任意の短い名前、未宣言の複数エンコーディング、すでに Unicode として保存された文字化けの復元は保証できません。現在、手動のエンコーディング選択はありません。壊れた宣言、厳密なデコード失敗、異常なパスは要確認のままとし、出力を拒否します。優先順位、TAR/PAX、制限、ペイロードとの結び付け、保存は[適応的ファイル名エンコーディング契約](filename-encoding.md)を参照してください。新規または追加される名前は UTF-8 のままで、変更時には解決済みの旧来の名前に明示的な UTF-8 宣言を追加します。

## リソースとライフサイクル

調整済みメインウィンドウは名前、元のサイズ、圧縮後サイズ、種類、更新日の 5 列を表示します。種類は表示名の拡張子からのみ推定し、JPG を JPEG にまとめます。更新日は ZIP 中央ディレクトリの有効な DOS ローカル日時から取得し、タイムゾーンは推測しません。不正な値は空欄です。5 列すべてを並べ替えできます。表は日付を表示しますが、並べ替えには完全な DOS 時刻を使います。プロパティパネルと独立したプロパティウィンドウは秒を含む 24 時間表記を表示します。例えば簡体字中国語では `2026/10/15 12:34:56` です。圧縮方式は詳細に残り、ブリッジは方式別の並べ替えコードを保持します。暗号化または要確認の状態は行のヒント、アクセシビリティの説明と詳細に残ります。注意が必要なエントリーには名前の横にマーカーを付け、視覚上の簡略化で隠してはなりません。

通常の製品はタブを閉じるときアプリケーションセッションマネージャーを使い、バックグラウンドタスクと結果を保持します。タスクのないページは非同期接続終了後に回収します。プラスボタンは保存済みのオープンモードに従って空のタブまたはメインウィンドウを作ります。ファイルのオープンは常にウェルカムページの再利用と重複排除を優先します。[アプリケーションセッション契約](application-sessions.md)を参照してください。独立コントローラーと診断テストは、一つの接続のアーカイブ状態を消去する `CloseSession` コマンドを維持します。タイトルバーのすべて選択チェックボックスは三状態です。ステータスバーのサイズは現在のクエリーで選択したメタデータの合計のみで、アーカイブ全体ではありません。動作と実際のジオメトリーの証拠は[検証](../../../developers/qa/README.md)に従って保存します。

| 項目 | 現在の上限 |
| --- | --- |
| 物理レコード | 100,000 |
| 一つの生の名前 | 4 KiB |
| 生の名前の合計 | 16 MiB |
| エスケープ済み表示名 | 16 MiB |
| 再読み取りを含む読み取りバイト合計 | 64 MiB |
| スキャンバッファー | 256 KiB |
| ブリッジの転送バッチ | 128 エントリー |
| Qt の現在のクエリーモデル | 論理行数はインデックスの受付条件に従い、常駐は最大 1,024 行、デリゲートは仮想化 |
| 独立したディレクトリインデックス | 32,768 ノード、64 階層 |
| ディレクトリ名と完全接頭辞の合計 | 4 MiB |

表示エスケープとブリッジのコピーは追加の領域を使います。これらの値はプロセス RSS や実行時間の保証ではありません。通常のメモリー内スナップショットのメタデータは Rust のメモリーにあり、直下の子インデックスは行の識別情報を保持し、クエリー結果キャッシュは並べ替え済みインデックスだけを保持します。100,000 エントリーの測定は[検証](../../../developers/qa/README.md)に従ってコミット、プラットフォーム、ワークロードに結び付け、その測定だけで 100 万エントリーの結果を示すことはできません。スキャン前後の長さと更新時刻の確認は最善努力の変更検出であり、原子的なスナップショットではありません。

読み取りと走査の境界でキャンセルを確認します。OS にブロックされた読み取りは中断できません。処理中のメインウィンドウを閉じると、まず停止を要求し、完了通知後に閉じます。GUI スレッド上で join しません。予期しないコントローラーの破棄でも、無効なバックグラウンド参照を残しません。通常のウィンドウクローズとアプリケーション終了は、作成と展開で共通の M1 終了バリアを使います。書き込み失敗と準備領域のクリーンアップは、それぞれの書き込み契約に従います。強制終了後は疑わしい準備領域を報告するだけで、未知の内容を自動的に復旧、上書き、削除しません。ディレクトリ全体のトランザクションや装置の電源喪失に対する安全性は約束しません。

ソースは通常ファイルでなければなりません。最初のオープン、ソースの再検証、タスク用ソースのコピーはいずれも `xdzip_io::open_regular_readonly` を使い、同じ開いたハンドルで種類を確認します。Unix では、パスが FIFO などの特殊オブジェクトに置換された場合に I/O を待たないよう、分類前に非ブロッキングで開きます。通常ファイルと通常ファイルを指すソースのシンボリックリンクは引き続き使用でき、ソースバージョンは実際のファイル識別情報に結び付きます。初回オープンや種類確認の失敗は `Io`、後のソース再検証やコピー用オープンの失敗は `SourceChanged` を返します。これは原子的な内容スナップショット、サンドボックス、強制的な通常ファイル I/O 時間制限ではありません。

ブリッジのソースパスは現在、損失なく表現できる UTF-8 に限られます。ファイル選択は独立したネイティブダイアログを使い、macOS の信号ボタンはアプリケーションが描画しません。実際のシステムフォーカス、モーダルの所有関係、ウィンドウ装飾にはデスクトップでの受け入れが必要です。

## 受け入れとフォローアップ

実際のテストとスクリーンショットは[検証](../../../developers/qa/README.md)に従い issue とアーティファクトに記録します。閲覧には実際のオープン、一覧、内部のバッチクエリー、ディレクトリツリー、現在のクエリーの選択、コマンド／イベントのライフサイクルが含まれ、3 プラットフォームの開発ビルドで確認します。100,000 エントリーの ZIP64 インデックスとクエリー世代は [ZIP 閲覧契約](zip-readonly-browsing.md)で検証し、書き込みは[安全な展開](zip-safe-extraction.md)で独立して規定します。内容プレビューには別の内容／デコード上限があります。正式リリースには引き続き[リリースのライセンスレビュー](../../../developers/qa/release-review.md)が必要です。このページは段階的な受け入れの結論を記録しません。

## 閲覧操作の追加事項

- 安全で明示的なアーカイブ内ディレクトリは、ダブルクリックまたはチェックボックスにフォーカスして Enter を押すことで入れます。「ルートフォルダー」でルートの範囲に戻ります。通常のディレクトリには直下のファイルとディレクトリだけを表示し、子孫を再帰表示しません。検索は現在の範囲を再帰的に対象にしてアーカイブ内の完全パスを表示します。通常一覧の名前はベース名のみを表示し、内部の完全パス、コピーやナビゲーションを変更しません。危険な名前はナビゲーションノードにできませんが、検索とメタデータ確認のためアーカイブスナップショットに残ります。
- Enter で名前検索を送信し、Unicode 小文字化後のリテラル部分文字列に一致させます。正規表現やロケール順の並べ替えは使いません。検索入力は最大 256 UTF-16 単位、Rust 入口は最大 1,024 UTF-8 バイトです。検索は現在のディレクトリ範囲を対象とします。ルートへ戻っても検索語は保持し、新しいセッションでは消去します。
- 通常のメモリー内クエリーは最大 100,000 エントリーのロード済みスナップショットを絞り込み、要求に従って並べ替えて最大 128 行を返します。絞り込み中の各レコードと並べ替えの前後でキャンセルを確認します。ディレクトリパラメーターは物理 EntryId または `d` 接頭辞付きの仮想ディレクトリ ID で、Rust が現在のセッションでの適格性を検証します。GUI が連結したファイルパスではありません。
- クエリーは単一ワーカー、制限付き、バージョン管理付きです。ページは完全な QueryKey を持ちます。Qt は最新の意図をまとめ、古い処理をキャンセルします。古いリクエストや、セッション／クエリー／世代／リビジョン／オフセットが一致しない応答は現在の表示を置き換えられません。範囲外オフセットはエラー、空の結果は Ready です。ディレクトリ移動と検索は最初のページから始まります。
- 既存スナップショットがある場合、ディレクトリ、並べ替え、検索のクエリー中も新しい結果がコミットされるまで一覧・グリッドまたは空状態を保持し、busy によって領域全体を一時的にオーバーレイに置き換えません。未準備アーカイブの初回オープンでは引き続き読み込みを表示し、コントローラーの直列受付、キャンセル、ソース変更の検査は維持します。
- 行またはチェックボックスのクリックで現在のクエリー内の複数選択を切り替え、同名エントリーを物理 ID で区別します。暗黙ディレクトリは別の dN 行キーを使います。クエリーまたは新セッションがモデルを正常に置き換えた後に選択と詳細を消去します。内部転送バッチは合成された一覧に影響せず、UI はページ分割しません。詳細は最後にアクティブ化されたエントリーのメタデータを示し、フォーカスとチェックボックスの集合はそれぞれフォーカスと選択を表します。すべて選択は現在の完全な一覧の最後の行を詳細のフォーカスとし、最後の行まで個別に選んだ場合と一致します。すべて解除は詳細を消去します。選択がない場合は、誤解を招く空のプロパティを示す代わりに、元のサイズ、圧縮後サイズ、更新日、圧縮方式、フォーカス項目を展開する操作を隠します。
- 一覧サイズは B/KiB/MiB/GiB で表示します。変換は表示上の概算にすぎず、モデルと Rust は元の整数を保持します。ファイルアイコンは種類を表し、詳細カードはプロパティを示し、対応する単一ファイルではカードが見えている間に[プレビュー](content-preview.md)を自動的にロードします。
- 非圧縮サイズが不明な項目は別の `size_known=false` を持ち、元サイズ列を空欄にしてサイズ不明を示します。サイズが既知の空ファイルは引き続き 0 を表示します。選択合計が不明ならステータスバーは区切りやプレースホルダーなしで選択数だけを示し、コントローラーは不明状態を保持します。合計が既知ならサイズを表示します。昇順・降順のどちらでも不明サイズを既知サイズの後ろに置き、各グループ内の識別順を維持します。物理的な不明サイズ項目は拒否理由を調べるためメタデータ事前検査を要求できますが、仮想ディレクトリを含む選択では引き続きできません。サイズ不明は出力認可やデコード予算を与えません。

選択したエントリーは、独立したネイティブ結果ウィンドウで[展開メタデータの事前検査](extraction-preflight.md)を要求できます。ファイルを書き込まず、読み取り専用フェーズの境界を変えません。

## 完全なディレクトリインデックスと並べ替え

- Rust は完全な不変スナップショットから明示的・暗黙的なディレクトリを構築し、Qt は現在のページからツリーを推測しません。各仮想ノードはセッション内で一意な `dN` ID、親 ID、表示名、完全なアーカイブ接頭辞、子孫の物理レコード数を持ちます。明示的レコードのない直下のディレクトリは、物理 id 0、ブリッジ navigation_id、physical=false のナビゲーション行として現れ、Qt は dN 表示キーを使います。物理的な展開選択にはできず、物理レコード数を増やしません。明示的な重複レコードは重複排除せず、明示レコードのないディレクトリだけをナビゲーション行で補います。ナビゲーション行は選択、パスコピー、移動できますが、サイズ、方式、日付は空欄です。事前検査は実際の物理レコードのみを受け付け、ナビゲーション行を含む選択では無効です。
- 最初に現れたアーカイブ順で、子より先に親を公開します。同名の物理エントリーは独立したままです。ノードの件数は要確認のエントリーを含む接頭辞下のすべての子孫を数えますが、ディレクトリ接頭辞と完全に等しいレコードは除きます。件数は名前検索で変わりません。
- 警告のあるレコード、解決できない名前、バックスラッシュ、空の構成要素、`.`、`..` を含むレコードからノードを作りません。それらは確認のため物理スナップショットと再帰検索に残ります。インデックスはナビゲーションを提供するものであり、パスの安全性や展開認可ではありません。
- ディレクトリ予算を超えた場合はインデックス全体を破棄し、UI に明確に通知します。ルート、検索、適格な明示ディレクトリの閲覧は続行します。インデックスなしで暗黙ディレクトリを推測しません。ルートが空でも検索は完全な物理スナップショットを対象にできます。切り詰めたツリーを完全なものとして表示してはなりません。ディレクトリ領域は独自の名前予算を持ち、フォーマット別のスキャン受付条件を変更しません。
- 名前、元のサイズ、圧縮後サイズ、種類、更新日の見出しをクリックして昇順／降順を切り替え、Enter/Space で操作します。右上の並べ替えメニューはディレクトリとファイルの各グループ内をアーカイブ順に戻せます。ページを切り出す前に結果全体を絞り込み・並べ替えし、ページ間で一貫した順序にします。名前は自然順やロケール順ではなく、大文字小文字を区別する Unicode スカラー値の辞書順を使います。数値は Rust の元の整数を比較します。同値の場合は行の種類（物理がナビゲーションより先）と対応する識別情報の昇順を使い、降順でも同名レコードの順序を反転しません。すべての並べ替えはまずディレクトリフラグでグループ化し、明示・暗黙ディレクトリをファイルより前に置きます。昇順／降順は各グループ内で適用し、元サイズ不明はそのグループ内で既知の後ろに残します。種類の昇順／降順はファイルカテゴリの順序のみを変更します。ファイルカテゴリは正規化した拡張子を使い、JPG と JPEG をまとめ、拡張子のないファイルは別のファイルグループとします。ローカライズされた表示テキストはディレクトリ識別情報ではありません。
- 閲覧の並べ替えコードは、0 が各グループ内のアーカイブ順（物理ディレクトリが先、その後にインデックス順の暗黙ディレクトリ）、1/2 が名前の昇順／降順、3/4 が元のサイズ、5/6 が圧縮後サイズ、7/8 が ZIP 方式番号、9/10 が種類、11/12 が更新時刻です。その他は拒否します。列、ディレクトリ、検索を切り替えると最初のページに戻り、ページの置換が成功したときに現在のクエリー選択と詳細を消去します。受付されなかった操作では最後に表示したクエリーパラメーターを復元します。
- ツリーは展開／折りたたみ、キーボードナビゲーション、Enter によるディレクトリへの移動をサポートし、水平スクロールで深い階層に到達します。基本の行高は 32、階層インデントは 12.8、フォルダー枠は 16、アイコンとテキストの間隔は 6.4 で、テキストとアイコンを行の垂直中心に配置します。大きい文字では行高や列幅が増えることがあります。

ディレクトリ移動と並べ替えは[一般的な方法](../../../developers/qa/README.md)で再検証します。完全なクエリー識別情報、ソース検査、100,000 エントリーの検証は [ZIP 閲覧契約](zip-readonly-browsing.md)を参照してください。UI の選択は現在のクエリー全体を対象とし、内部バッチやキャッシュの回収では消去しません。大きなクエリーの範囲選択は確認前に安定した識別情報に固定します。

## 共有コントロールとコンテキストコマンド

メニュー、ボタンとショートカットは読み取り専用コントローラーの操作を再利用します。選択済みエントリーを右クリックした場合は現在のクエリーの複数選択を維持し、未選択のエントリーを右クリックした場合は先にそれだけを選択します。Shift 範囲は安定したエントリー ID をアンカーとして使い、クエリーや並べ替えが結果を正常に置き換えると消去します。すべて選択はフォーマットとインデックスの受付条件に従い、ナビゲーション行を含む現在のディレクトリの完全なクエリーを対象とします。事前検査は別途、選択を実際の物理レコード 128 件までに制限し、ナビゲーション行を含む集合や上限超過では無効にします。名前やアーカイブ内パスをシステムクリップボードにコピーします。ディレクトリ名は末尾の区切りを除き、パスは元の表示形式を保持します。

一覧とグリッドは一つの制限付きモデルと選択 ID を共有し、グリッド専用の第二インデックスはありません。ディレクトリのガイド、最後の兄弟マーカー、祖先チェーン、パンくずは、追加のフォーマットクエリーなしに公開済みの完全なディレクトリモデルから導出します。アーカイブ概要は現在のディレクトリや検索と独立して、Open の物理合計をキャッシュします。パンくずの右側の件数は必要なナビゲーション行を含む現在の一覧行数です。

メニューは読み取り、クエリーまたはセッションの変更時に閉じます。コントローラーは実行時に操作の適格性を再確認します。各 `BrowserController` は一つのアーカイブセッションを管理し、アプリケーションは複数のアーカイブタブやウィンドウを収容できます。[展開](zip-safe-extraction.md)は明示的な出力意図と出力先権限を取得します。[作成](zip-creation.md)は自身の入力ツリーと出力先を固定します。[整合性検査](archive-checking.md)は独立した読み取り専用タスクとして実行します。[事前検査](extraction-preflight.md)は現在のソースのメタデータを分析します。

## クエリー識別情報とリソース上限

クエリーは完全な順序を一つ生成し、キャッシュされた行インデックスから転送バッチを切り出します。バッチは最大 128 行、名前合計 64 KiB です。コマンドキューは引き続き 8 MiB、Rust のデータイベントと Qt メールボックスは、制限付き画像全体を収容するためそれぞれ 32 MiB の内容バックプレッシャーを持ちます。検索やディレクトリの意図が変わると、保留中の意図は最新のものだけを保持し、古い応答は新しいクエリーに入りません。通常のキャンセルや上限超過では最後に成功した一覧を保持し、ソースバージョンの変更では無効なデータを消去して再オープンを要求します。

スキャン前後とクエリー／事前検査の境界で、ソースハンドルと現在のパスの長さ、更新時刻、取得可能な作成時刻を確認します。Unix ではデバイス／inode も検査します。Windows は固定された winapi-util の安全なラッパーでボリューム／ファイルインデックスを使い、タイムスタンプを維持したパス置換を検出します。これらはファイルシステムの原子的スナップショットではありません。選択要約はモデルの選択リビジョンでキャッシュし、正確な合計に Rust u128 を使って繰り返しの走査と 64 ビットオーバーフローを避けます。

Qt の設定アダプターは UI 言語をロードします。種類、状態、エラー、ユーザー向けの日付には翻訳カタログとロケールを使います。バイト数、エントリーの識別情報、パス、生の時刻、並べ替えパラメーターのブリッジ値は言語によって変わりません。翻訳済みテキストからフォーマット能力、識別情報、セキュリティ判断を推測してはいけません。言語変更の成功は実行中タスクを変更せず、UI テキストに直ちに反映されます。[設定とローカライズ](../ux/settings-localization.md)を参照してください。

アーカイブのオープン成功後、ブリッジはローカル UI 設定アダプターへ archiveOpened(path) のみを送出します。最近使ったパスは別に保存され、ドメインのクエリー、並べ替え、タスク認可には関与しません。失敗したパスは最近使った項目に書き込みません。
