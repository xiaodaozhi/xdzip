# 簡体字中国語の UI 用語

[English](../../ux/chinese-terminology.md) | [简体中文](../../zh-CN/ux/chinese-terminology.md) | [繁體中文](../../zh-TW/ux/chinese-terminology.md) | 日本語 | [한국어](../../ko-KR/ux/chinese-terminology.md) | [Français](../../fr-FR/ux/chinese-terminology.md) | [Deutsch](../../de-DE/ux/chinese-terminology.md) | [Español](../../es-ES/ux/chinese-terminology.md) | [Português (Brasil)](../../pt-BR/ux/chinese-terminology.md) | [Русский](../../ru-RU/ux/chinese-terminology.md)

ユーザー向けの簡体字中国語は[用語設定](../../../specs/ux/chinese-terminology.json)に従います。Qt の静的文言は resources/i18n/zh-CN.json にある安定 ID を維持します。HTML、現在の高忠実度デザイン、ユーザー向け文書は表の用語を使います。技術文書と形式の仕様では専門用語も使用できます。コンポーネント寸法、メインウィンドウ 0.8／メニュー 1 の密度、DPR、拡大縮小の設定は従来どおりです。

| 意味 | 簡体字中国語の標準表記 | 使用例 |
| --- | --- | --- |
| ZIP や TAR などのコンテナーファイル | 压缩包 | 压缩包名称、空压缩包、压缩包信息 |
| 操作の正式名 | 打开压缩包、创建压缩包、解压 | ツールバーで意味が明らかな場合は「打开」「新建」と略せます |
| アーカイブ内の項目 | 文件、文件夹、内容 | 所选文件和文件夹、全部内容 |
| ファイルのプロパティ | 原始大小、压缩大小 | 列見出し、プレビューのプロパティ、並べ替えメニューで同じ名前を使います |
| エントリーの物理的な順序を復元 | 按原始顺序排列 | 名前やサイズによる並べ替えと区別します |

「档案文件」は製品用語から外しています。「归档」「归档文件」「归档格式」は技術仕様、形式の説明、公開 API に限ります。TAR がファイルをまとめるだけの場合も、UI は「压缩包」を使います。実際の圧縮の可否は形式と圧縮レベルで示します。

「压缩文件」は「正在压缩文件」のように、操作を表す場合だけに使います。プロパティ名は「压缩大小」です。旧名の「压缩后」は廃止しました。作成ウィンドウは既定名「新建压缩包.zip」を提案し、既存のファイル名は保持します。

ユーザー指定の名前やパス、アーカイブ内のファイル名、プロトコルのフィールド、コード識別子、過去の高忠実度デザインの画像は原文を保持します。英語では通常の「archive」を英語の文法に従って使い、「全部内容」は「All contents」とします。幅の狭い列見出しでは「Compressed」で「compressed size」を表します。英語のコード識別子はそのまま使います。

現在の用語の状態デザインを参照してください。元の画像、ハッシュ、文字の描画範囲の計測値は過去の記録です。本文計測スクリプトは以前のラベルとの明示的な対応に基づいて新しい文言を検査し、目標寸法と許容差を維持します。長いラベルがメインウィンドウ、列見出し、プレビュー、メニューで収まり、全文が表示されることを確認してください。

`python3 scripts/check-ui-i18n.py` で全言語リソースと簡体字中国語の用語を検査します。用語検査の対象は製品の静的文言です。「压缩文件」の明示的に許可された動詞用法を許容し、ユーザーのデータや専門用語には適用しません。

ファイルマネージャーでは、[課題 #270](https://github.com/xiaodaozhi/xdzip/issues/270)で確認された「添加到压缩文件...」「解压每个压缩文件到单独的文件夹」を維持します。この例外は二つの安定 ID の文言全体に限ります。その他の場所では規定のコンテナー名を使用します。
