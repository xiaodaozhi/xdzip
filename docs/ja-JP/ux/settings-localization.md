# 設定ウィンドウと表示言語

[English](../../ux/settings-localization.md) | [简体中文](../../zh-CN/ux/settings-localization.md) | [繁體中文](../../zh-TW/ux/settings-localization.md) | 日本語 | [한국어](../../ko-KR/ux/settings-localization.md) | [Français](../../fr-FR/ux/settings-localization.md) | [Deutsch](../../de-DE/ux/settings-localization.md) | [Español](../../es-ES/ux/settings-localization.md) | [Português (Brasil)](../../pt-BR/ux/settings-localization.md) | [Русский](../../ru-RU/ux/settings-localization.md)

メインウィンドウが表示されていないとき、通知領域から親なしで開いた設定および「xdzip について」は、ポインターがある画面の作業領域にネイティブ枠全体を中央配置します。OperationWindow の画面配置を再利用し、ネイティブウィンドウを作成して高さが決まった後に再配置します。高さの上限は選択した QScreen の利用可能な高さと既存の余白に基づきます。仮想デスクトップ全体の高さは使わず、非表示または最小化されたメインウィンドウは復元しません。親のある入口では、呼び出し元の配置、寸法、密度を維持します。

設定は独立した非モーダルのシステムウィンドウです。タイトルバー、アプリメニュー、通知領域で同じ表示中のウィンドウを使います。サイドバーは外観、一般、プライバシー、ファイルの関連付け、ネットワーク、xdzip についての順です。各「xdzip について」から同じ設定ウィンドウの該当ページを開きます。論理幅は 612、クライアント高は 532 で、画面が狭ければ制限します。サイドバーと本文は個別にスクロールし、上端に余分な空白を設けません。フッターや保存ボタン、キャンセルボタンはありません。[設定デザイン](../../../design/hifi/sources/settings.html)と[レイアウト値](../../../specs/visual/layout-scale.json)を参照してください。

テーマ、文字サイズ、一覧の表示間隔、言語、アーカイブの開き方、通知領域、閲覧履歴の設定は操作時に保存し適用します。ウィンドウを閉じても保存済みの変更は取り消されません。言語を変えると、進行中のタスクに影響せず、製品の文言とアプリが所有するネイティブメニューおよび通知領域のメニューが即座に更新されます。システムの項目はシステムの言語に従います。開き方は次回以降の操作とタイトルバーのプラスボタンに適用し、既存セッションは移動しません。履歴の消去は即時で、元のファイルは保持されます。履歴の消去や設定の書き込みに失敗するとページに表示し、既存データと適用済みの設定を保持します。チェックボックスは IntentCheckBox、テーマとプロキシのラジオボタンは IntentRadioButton を使います。マウス、キーボード、ネイティブアクセシビリティの press/toggle から同じ選択を実行し、モデルを確認します。ドロップダウンの OperationSelect は選択の確定後に一度だけ送信します。

設定画面の選択欄は、各文字サイズで登録済み UI フォントの最大行高を収める共通の高さを使います。言語を切り替えても選択言語のフォントを保ち、文字の切れや欄の高さの変動を防ぎます。

設定のスキーマは 1 です。不明なキーを保持し、プロキシとミラーのアドレスは保存しますが、パスワードは保存しません。保存時は別の設定ロックを保持し、同じディレクトリーに完全な INI を準備してバックアップと本体をアトミックに更新します。読み取り失敗、1 MiB 超、無効または新しいスキーマ、シンボリックリンク、バックアップや確定の失敗があれば、元のファイルを上書きしません。設定適用に失敗したらランタイムの状態を復元します。最近のパスは同じディレクトリーの recent.json に別途保存します。重複を取り除き、最大 20 件、読み取りの上限は 64 KiB で、ユーザーだけが読み書きできます。履歴を無効にすると追加を停止し、消去操作では既存の記録を取り除きます。

準備時には元のバイト列を不変のスナップショットとして保持し、すべてのキーを別の新しい INI にコピーして変更を適用します。作成したスナップショット自体は書き換えません。スキーマの検証と不明なキーの保持は続行し、バックアップには元のバイト列を残します。

Windows では、削除共有を許可しない読み取りハンドルなどの一時的な競合でアトミック置換の名前変更に失敗した場合、最大四回再試行します。待機時間の合計は I/O を除いて 75 ms です。設定ロックを維持し、各試行で同じバイト列を新しい一時ファイルに準備します。GUI イベントを処理したり、直接上書きしたりしません。競合が続く場合や別のエラーでは、元のファイルと適用済みの設定を保持して失敗を報告します。

ファイルの関連付けページは、生成された形式データに従って登録拡張子を分類します。通常のインストールでは、スイッチがシステムに問い合わせた既定値を示します。Windows では「既定のアプリ」を開きます。macOS は Launch Services、Ubuntu はデスクトップの MIME 既定値を使います。macOS または Ubuntu で既定値を解除するときは、別のアプリを選ぶ場合があります。複数の拡張子が同一のシステム形式を共有できます。Windows は `.tar.gz` の最後の拡張子で扱います。MSIX は関連付け可能な種類を無効なスイッチで表示します。**Windows の既定のアプリを開く**から実際の既定値を確認できます。[関連付けの仕様](../../engineering/installers-associations.md)と[MSIX 版の設定デザイン](../../../design/hifi/sources/settings.html?tab=associations&channel=msix)を参照してください。

Windows にインストールした形式別の説明は、言語の切り替えに成功した後で選択言語に従います。セットアップはインストールまたはアップグレード時に保存された言語を読み取ります。現在のインストールに属することを確認した九つの ProgID 説明だけを書き換え、既定のアプリを維持します。システムや他のアプリの形式説明、キャッシュ、他のプラットフォームの表示はそれぞれ管理されます。前提と失敗時の扱いは[インストールと関連付け](../../engineering/installers-associations.md)を参照してください。

ネットワークでは直接接続、システムプロキシ、カスタム HTTP または SOCKS5 プロキシ、任意の HTTPS GitHub ミラーを選べます。カスタムプロキシにはホストとポートが必要で、資格情報は受け付けません。入力したアドレスは検証後に保存します。ミラーが空なら公式アドレスを使います。ミラーの指定は更新の通信先だけに適用します。チェックサムと署名の確認条件は同じです。進行中の更新は既存のネットワーク設定を使い、次の操作から新しい設定になります。macOS の Sparkle はシステム設定、直接接続、資格情報なしの HTTP CONNECT または SOCKS5 に対応します。カスタムプロキシで失敗しても直接接続に切り替えません。信頼性とリダイレクトについては[ソフトウェアの更新](../engineering/software-update.md)を参照してください。

六つのページではサイドバーの見出しを繰り返しません。通常ビルドの「xdzip について」は更新状態と操作のためのスクロール領域を確保します。主操作は状態に応じて確認、キャンセル、ダウンロード、インストール、公開ページへのリンクになります。キーボードフォーカスは画面外の操作までスクロールできます。MSIX のパッケージ識別情報がある場合はビルド情報と通知を残し、アプリ内更新を表示しません。Microsoft Store 版はストアが更新を管理します。[MSIX 版のデザイン](../../../design/hifi/sources/settings.html?tab=about&channel=msix)と[更新仕様](../engineering/software-update.md)を参照してください。

「xdzip について」の更新状態テキストはネイティブのアクセシブル名でも利用できます。確認中、ダウンロード中、インストール中、成功または失敗の表示と使用言語に同期します。

macOS の手動更新案内は、満たされていない最初のインストール条件を表示し、公開ページとダウンロード先を開けるようにします。満たされない条件が複数ある場合があります。識別情報の検査に失敗しても、個別原因までは分かりません。案内には対応する DMG と app.zip での手動置換が含まれ、ダウンロードではインストールされないことを示します。

本文の縦スクロールバーは表示領域の右端全体に沿います。つまみはスクロールに追従し、ドラッグで移動できます。バージョン情報のラベル列は実際の文言と文字サイズに合わせます。値には残りの幅を使い、折り返しも可能です。新しい項目も同じ配置を使います。

製品の文言には `resources/i18n/` の安定 ID を使います。QML は `qsTrId`、C++ は `qtTrId` を使います。プロトコルコード、ファイル名、パス、ユーザーの内容はそのまま扱います。言語メニューには最初に自動検出、続いて同梱する言語をそれぞれの言語名で表示します。自動検出は起動のたびに、数値形式とは独立してシステムの最優先の表示言語を読み取ります。中国語では明示的な字体指定が地域指定より優先されます。繁体字と zh-TW、zh-HK、zh-MO 地域は繁体字中国語を選びます。ほかの言語は同じ言語の同梱版があれば使用します。設定が空か非対応なら英語（米国）を使います。言語タグの国（地域）コードは言語の地域別変種を区別するために使い、言語の数は国（地域）の数を示しません。

言語の変更は即時に反映します。保存に失敗した場合は直前の選択と言語を復元します。英語と簡体字中国語の後に追加した言語を手動で選ぶと、`locale/extendedLanguage` に選んだ言語、`locale/language` に旧版で読める値を保存します。旧版では繁体字中国語は簡体字、それ以外の追加言語は英語で表示し、ほかの設定を引き続き読み取ります。現行版は互換値が一致する場合に拡張値を使います。自動検出、簡体字中国語、英語を選ぶと拡張値を消去します。

文字サイズは 100%、125%、150% です。旧設定の 200% は 150% として読み取ります。システムのファイル選択と Qt の標準コントロールはシステム言語に従います。macOS のバンドルには同梱する言語を宣言し、混在するローカライズを許可します。

六つのタブと共通の設定・情報の入口、即時保存と失敗時の復元、各言語のテーマと文字サイズ、該当するプロキシ、更新、関連付け状態を確認します。通常の Windows インストールでは、必要に応じて主要な九つの ProgID の即時同期を確認します。MSIX では関連付けスイッチが無効であること、システムへのリンク、組み込み更新の非表示を確認します。ラジオボタンとスイッチを `QAccessibleActionInterface` で操作し、モデルとイベントを確認します。実機テストと記録については[検証ガイド](../../../developers/qa/README.md)を参照してください。
