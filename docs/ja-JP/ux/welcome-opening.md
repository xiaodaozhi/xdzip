# ホーム画面の読み込み表示とアーカイブ作成の完了

[English](../../ux/welcome-opening.md) | [简体中文](../../zh-CN/ux/welcome-opening.md) | [繁體中文（台灣）](../../zh-TW/ux/welcome-opening.md) | 日本語 | [한국어](../../ko-KR/ux/welcome-opening.md) | [Français](../../fr-FR/ux/welcome-opening.md) | [Deutsch](../../de-DE/ux/welcome-opening.md) | [Español](../../es-ES/ux/welcome-opening.md) | [Português (Brasil)](../../pt-BR/ux/welcome-opening.md) | [Русский](../../ru-RU/ux/welcome-opening.md)

2026-10-16 改訂。各パラメーターは [welcome-reference.json](../../../specs/visual/welcome-reference.json) を参照します。動的な高忠実度デザインは[ホーム画面の読み込み状態](../../../design/hifi/sources/welcome.html?opening=1)です。メインウィンドウ、メニュー、ホーム画面の論理単位とタイトルバーを維持します。

ホーム画面から実際のアーカイブを開くと、本文の中央にフローティングカードと半透明のオーバーレイが表示されます。論理単位で、カードの通常幅は 360、内側余白は 24、間隔は 12、角の半径は 8、タイトルのサイズは 16 です。ウィンドウが狭いときは利用可能な幅に収めます。ファイル名は中央を省略し、状態表示は折り返せます。キャンセルボタンには引き続きアクセスできます。ライトテーマとダークテーマは共通の設計値を使い、アクセシビリティ用の文字サイズは全体設定に従います。

開いているアーカイブへの追加と内部での項目移動では、BrowserBusyOverlay のカードと寸法を使います。背景は完全に透明なので既存のファイル一覧が見え、背後の操作はブロックされます。タイトル、説明、進行状況のアクセシブル名、キャンセルボタンは実際の操作を示します。その操作名はタスクの後処理とディレクトリーの更新中も維持します。初回の読み込みには半透明のオーバーレイを使います。

現在のメタデータ読み取りには合計バイト数やパーセント値がありません。「アーカイブの内容を読み取っています」と進行量未確定の進行バーを表示し、タイマーで架空の割合を表示することはありません。キャンセルは既存のキャンセル要求を呼び出し、展開タスクの作成やファイルの書き込みは行いません。キャンセルが確認されたとき、失敗したとき、または成功したときに表示を閉じます。失敗時はホーム画面に結果を残し、成功時はファイル一覧へ進みます。読み取り中は、本文からの再度の開く操作、作成、ドロップをブロックします。タイトルバーは配置とホストのコマンド規則を維持します。

HTML プロトタイプはキャンセル可能な待機の例を表示し、ドロップされたファイルの内容は読みません。キャンセル時はタイマーのコールバックを解除し、あとから例の画面に遷移しないようにします。高忠実度デザインの `opening=1` は固定の待機表示です。元の PNG とハッシュを維持します。

作成ウィンドウから「完了後に出力先フォルダーを開く」を取り除きます。自動完了時に Finder や Explorer は開きません。作成したアーカイブがアプリ内で自動的に開く動作は続けます。対応する暗号化アーカイブや番号付き分割アーカイブも含みます。展開の同名設定とユーザーが明示的にフォルダーを開く操作はそのままです。確定済みの結果を先に処理する場合も終了通知を先に受け取る場合も、作成時の旧フォルダー自動表示引数は無視します。

作成結果の件数では、中国語の「已保存」と英語の「Saved」を使い、数値の意味を維持します。共通操作欄のプレースホルダーは明示的に textSecondary を参照します。ダークテーマのパスワード欄にプラットフォーム既定の明るい文字色が入るのを防ぎ、無効時は共通コントロールの方針に従います。

受け入れでは実際のキャンセル、読み取り失敗後の復帰、タイトルバー寸法、ライトとダークのテーマ、アクセシビリティ用の文字サイズを確認します。作成成功時にシステムのフォルダーを開かず、アプリ内でアーカイブが開くことも確認します。テスト画像と計測値は build/ または CI の成果物にのみ保存します。

コマンドライン、Windows の「プログラムから開く」、Linux のデスクトップエントリー、macOS のファイルを開くイベントで起動した場合、メインウィンドウの初回表示前に実際の読み取り要求を出します。完了を待たずにキャンセル可能なカードをすぐ表示し、ホームのロゴ、開くカードと作成カード、ドロップ領域を隠します。成功するとファイル一覧を表示します。失敗時やキャンセル時はホーム画面に戻り、実際の結果を表示します。ファイルを指定しない通常起動はホーム画面を表示し、そこから開く場合は従来の表示を使います。タイトルバー、メインウィンドウ、メニューの比率は変えず、人工的な遅延や進捗は設けません。

外部起動の高忠実度デザインは [external=1](../../../design/hifi/sources/welcome.html?external=1) です。HTML は同じ状態を表示しますが、システムの関連付けは模擬しません。回帰検査は初回表示前の読み取り要求、初回表示でのホーム画面要素の非表示、失敗後の復帰、各プラットフォームでの実際のシステム起動を検証します。関連付けの検査では実際の frameSwapped 回数とホーム内容が見えた回数を記録します。読み取り成功だけでは起動時の表示を検証できません。
