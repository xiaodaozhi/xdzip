# メインウィンドウの機能、コンポーネントと操作契約

[English](../../ux/main-window-components.md) | [简体中文](../../zh-CN/ux/main-window-components.md) | [繁體中文](../../zh-TW/ux/main-window-components.md) | 日本語 | [한국어](../../ko-KR/ux/main-window-components.md) | [Français](../../fr-FR/ux/main-window-components.md) | [Español](../../es-ES/ux/main-window-components.md) | [Português (Brasil)](../../pt-BR/ux/main-window-components.md)

メインウィンドウのコントロールは外観と動作の両方を提供し、通常、ホバー、押下、キーボードフォーカス、無効、選択、処理中、エラーの状態を明示します。HTML はサンプルアーカイブで操作を確認し、Qt は実際の閲覧、作成、展開、[整合性検査](../engineering/archive-checking.md)、[自動コンテンツプレビュー](../engineering/content-preview.md)の機能に応じて操作を有効にします。HTML の例は実際のバックグラウンド処理結果ではありません。

ファイル名、ディレクトリ名、アーカイブ名、パスは起動時のシステム既定フォントを優先し、文字が不足する場合はプラットフォームのフォールバックを使います。固定の UI 文言は引き続き同梱サブセットを使用します。ディレクトリツリーとドラッグプレビューはそれぞれのテキストフォントで測定します。[視覚標準](../../visual/design-standard.md#界面字体与用户数据)を参照してください。

## 機能とコンポーネント

| 領域 | 共有／合成コンポーネント | 操作と機能 |
| --- | --- | --- |
| システムタイトルバー | `Browser`、`ArchiveTabs`、プラットフォーム枠 | macOS はネイティブの信号ボタンを使用。Windows は統合ボタン、ネイティブのサイズ変更と DWM 装飾を使用。Ubuntu X11 では統合ボタンと通常状態の丸い角が X11 デザインに従う。[プラットフォームウィンドウ](platform-windows.md)を参照 |
| アーカイブタブ | ArchiveTabs、ArchiveTab、アイコンボタン | 既定は新規タブ、任意で新規ウィンドウ。非アクティブタブは通常の太さで、縮小後に水平スクロールし、スクロールとタブ一覧の入口を備える。ウィンドウ内ドラッグと Ctrl+Shift+Page Up/Down で並べ替え。閉じてもバックグラウンドタスクは保持 |
| ツールバー | `ArchiveToolbar`、`ArchiveAction`、`CommandMenu` | 開く、新規作成、検査、その他、分割型の展開ボタンはメニューやキーボードと同じコマンドを実行。条件を満たす選択では展開メニューから事前検査を利用可能 |
| 検索 | SearchField、クリア操作、範囲ヒント | IME 変換中は送信しない。現在のディレクトリ範囲を検索し、クリアしてもディレクトリは変わらない。ショートカットでフォーカス |
| アーカイブ概要 | ArchiveSummary、形式バッジ、統計バー | 準備完了、読み込み中、空、読み込み失敗を区別。未知の値をゼロとしない |
| ディレクトリナビゲーション | DirectoryTree、DirectoryRow、Disclosure、接続線 | 多階層展開、リーフの空矢印枠、独立した現在位置とフォーカス、アクセシブルな完全パス、折りたたんだ祖先のマーカー、ディレクトリのコンテキスト操作 |
| ファイル領域ヘッダー | PaneHeader、Breadcrumb、ViewToggle | 階層パスの移動、リスト／グリッド切り替え、ソートメニュー。高さと縦中心を共有 |
| リストとグリッド | EntryView、SelectableEntry、チェックボックス、SortHeader | 単一／複数／範囲選択、すべて選択、解除、反転、矢印キー。ダブルクリック／Enter はディレクトリへ移動するか、通常ファイルを一時展開してシステムの関連付けで開く。プロパティはコンテキストメニューまたは詳細から利用可能 |
| ファイルのコンテキストメニュー | ContextMenu、CommandMenuItem、Submenu | 開くはダブルクリック同様に右クリックした項目だけに適用し、既存の複数選択を保持。未選択項目を右クリックすると先にその項目だけを選択。選択に応じて展開、プロパティ、名前／パスのコピー、ディレクトリ移動を有効化 |
| 空白領域のコンテキストメニュー | ContextMenu、RadioMenuItem、CheckboxMenuItem | 現在のリストの選択、表示、ソート、詳細ペイン。選択を勝手に解除しない |
| ヘッダーのコンテキストメニュー | ソートメニュー | ソート項目、方向、アーカイブ順序の復元。見えている項目だけでなく問い合わせ結果全体をソート |
| プロパティ／プレビュー | ページ内の `InspectorPanel` または独立した詳細ウィンドウ | ファイル、選択またはアーカイブの状態を表示。コンテンツは要求時に読み取る。論理幅 928 未満では内蔵パネルを閉じ、詳細操作で別ウィンドウを開く |
| 状態とタスク | ステータスバー、タスクボタン、`CommandMenu` | 選択数と判明しているサイズを表示。タスクメニューはアプリ全体の履歴を使用。実行中タスクは別の件数を持ち、進行ウィンドウを閉じても継続 |
| ヒントと操作ウィンドウ | Tooltip、Notice、Toast、独立したプラットフォームウィンドウ | 完全な名前と無効理由を提供。Escape、フォーカス復帰、キャンセル、閉じる操作は各操作の意味に従う |

リストとグリッドは空状態を共有します。確定した検索に結果がない場合は別の語を提案します。検索していないとき、レコードのないアーカイブは空として示し、それ以外は現在のフォルダーで見える内容だけを説明し、制限されたディレクトリインデックスが完全だと推測しません。読み込みとエラーは実際の状態を保持し、未送信の検索文字列は現在の結果メッセージを変更しません。ファイルを開く前の案内では古い形式一覧を列挙しません。

## 統一されたコマンドとメニュー

ボタン、ショートカット、コンテキストメニュー、ドロップダウンは同じコマンドを呼び出し、実行前に現在の機能を再確認します。メニューを開いた時点で対象と選択範囲を固定し、アーカイブまたは問い合わせが変わった場合や対象が消えた場合は閉じます。これにより古い項目のコマンドが新しいアーカイブに適用されることを防ぎます。

メニューはアイコン／チェック枠、名前、ショートカット、サブメニュー矢印の四つの列を共有し、操作グループ間に区切り線を置きます。文脈に関係する操作だけを含めます。ディレクトリには移動と展開を提供し、ファイルには詳細を提供し、複数選択では一括範囲を保持します。現在実行できない操作は無効のままにし、理由はアクセシビリティ説明からのみ利用可能にします。説明の副行やツールチップを表示せず、無効化の代わりにクリック時の「近日公開」を使いません。

文字サイズの変更時、メニューラベルの高さは実際のフォントメトリクスに従い、行の縦中心を保ちます。初回表示から論理 0.5 ピクセル以内の中心誤差を満たし、後のレイアウト処理で古いテキスト枠が修正されることに依存しません。

通常、チェック、ラジオ、サブメニューの行と区切り線は共有コンポーネントです。ソートと表示は現在状態にラジオ項目、詳細パネルはチェック項目を使います。危険な操作が既定で自動実行されることはありません。右クリックやメニューを開くだけでは何も実行しません。

## メニュー入力とライフサイクル

- 下／上で利用可能な項目間を移動し、Home／End で最初／最後に移動します。Enter／Space で実行し、右でサブメニューへ、左で親へ戻ります。
- Escape は一階層ずつ閉じます。ルートを閉じると起点のコントロールまたは元の項目にフォーカスを戻します。Tab はメニューを閉じて通常のページのフォーカス順を続けます。名前の先頭文字検索をサポートし、IME 変換中はメニューの文字検索を起動しません。
- ホバーは実行せず強調表示します。サブメニューは遅延後に開き、入る間は親項目を保持します。マウスとキーボードを続けて使っても複数の強調表示やルートメニューが残りません。
- 外側のクリックはその対象のフォーカスを奪わずメニューを閉じます。メイン領域のスクロール、ウィンドウのサイズ変更、操作ウィンドウへの移動、アーカイブの切り替えでメニューを閉じますが、メニュー自体のスクロールでは閉じません。HTML の共有コントロールは開いた時点の既存コンテナーの実際のスクロール位置を記録します。開く前に完了して遅れて配信されたイベントでは閉じず、その後の位置変更では閉じます。
- 表示領域の下端と右端を避け、必要に応じて左または上へ開きます。ホスト座標で配置しつつ、論理寸法、原稿のピクセル、DPR、レビュー倍率を区別します。
- Shift+F10／Menu キーは現在の項目のコンテキストメニューを開きます。タッチの長押しとマウスの右クリックは文脈を共有し、単一クリックのように複数選択を壊しません。

## コントロール状態とアクセシビリティ

| 状態 | 外観 | 動作 |
| --- | --- | --- |
| 通常 | 承認済み原稿の境界線、角丸、アイコン、基準線を保持 | 状態変更でコントロールの寸法を変えない |
| ホバー | 淡い塗り。主要ボタンは濃い主要色 | 遅延ヒントが対象を覆わない。タッチでホバーが残留しない |
| 押下 | ホバーより明確な塗り | 文字やアイコンを移動しない。キャンセルされた押下は実行しない |
| フォーカス | 追加の輪郭、太い境界線、光彩なし | Tab 順とキーボード実行を保持。外側のクリック、Escape、Enter でコントロールのフォーカスを離れる |
| 無効 | 輪郭を保持しつつ無効用の文字／図形色を明示 | クリックやショートカットに応答せず、アクセシビリティ説明で理由を示す |
| 選択 | 背景またはチェックマークで状態を明示 | `aria-selected` / `aria-checked` / Qt Accessible を同期 |
| 処理中 | 状態と無効範囲はタスクに従う | 二重送信を防ぎ、バックグラウンド処理中も閲覧を許可 |
| エラー | 隣接する文言で問題と復旧方法を説明 | 色だけに頼らず、成功を捏造しない |

共有アイコンは `design/assets` から取得します。コントロールはテキスト、チェック、背景、接続線、メニュー配置を実装し、原稿ピクセルの切り出しは比較用です。HTML はメインデザインの原稿座標を保持し、新しいコントロールパラメーターはまず論理ピクセルから変換します。Qt は同じ論理仕様を使用します。

## 受け入れ

ファイル領域右側の件数と操作ボタンは固定幅のグループを構成します。リスト、グリッド、ソート、表示中の詳細入口は論理 28×28 ピクセル、間隔 6.4 を維持し、ウィンドウを広げるとパンくずにのみ余裕を与えます。ツールバーの「その他」メニューには設定だけを含め、元の順序、展開メタデータの事前検査、すべて選択、詳細は既存の専用入口を使います。

開始ページとアーカイブページは、layout-scale.json の statusbarHeight による最低 32 論理ピクセルのステータスバーを共有します。アクセシビリティ文字の拡大には実際のタスクボタンの高さと等しい上下余白を使い、ページ切り替えで高さを変えません。両方のタスクボタンは main.interaction.taskIconSize による中央配置の論理 16×16 アイコン枠で task-list を使い、ページや文字倍率によって変更しません。

アーカイブのステータスバーは選択数を示し、選択が空でない場合に合計サイズが判明しているときだけ区切りとサイズを追加します。仮想ディレクトリやサイズ不明のファイルにより合計が不明なら、余分な区切りや `—` を付けず件数だけを表示します。既知の 0 バイトも表示し、開始ページの文言は変更しません。

ファイルリストのチェックボックス右端はファイルアイコン枠から論理 12 ピクセルを保ち、アイコン、ファイル名、「名前」ヘッダーを揃えます。アクセシビリティ文字サイズは実際の文字メトリクスを変えますが、この間隔は広げません。行のチェックボックスとヘッダーのすべて選択は既存の選択モデルを維持します。

五つの列はすべて右境界をドラッグして幅を変えられ、操作領域は論理 8 ピクセルです。ダブルクリックでその列の既定幅に戻します。既定では名前列が残りの幅を埋め、他の列は元のデザイン値から始まります。両サイズ列はラベルとソート矢印の測定値が切れずに収まるよう既定で拡張します。ユーザーが指定した幅は実行中のタブとウィンドウ間で共有し、終了時にリセットします。論理幅はメモリに保持し、設定や DPR には保存しません。名前列の最小幅は 160、他の列は 64 で、アクセシビリティ文字では比例して増やし、はみ出しは水平スクロールします。ヘッダーと内容は幅の出所を共有し、ドラッグでソートを起動しません。昇順／降順マーカーは右揃えの「元のサイズ」と「圧縮サイズ」ラベルの前、他のラベルの後に置き、表示テキストから常に論理 6 ピクセル離します。アクティブなソート列は適切な側に矢印の領域を確保します。手動で狭くすると先にラベルを省略し、矢印は文字や隣の列に重なりません。数値ヘッダーは内容と同じく右揃えです。

ファイル種類のアイコンは[拡張子ヒント表](../../../specs/visual/file-types.json)から Qt と HTML の選択器向けに生成し、オフィス文書、表計算、プレゼンテーション、音声、動画、アーカイブ、インストーラー、フォント、ディスクイメージをカバーします。拡張子は大文字小文字を区別せず、不明な種類には汎用文書アイコンを使います。これは外観のみを示し、信頼できる内容やアーカイブ形式の閲覧、作成、展開の対応を示すものではありません。

実際のマウスとキーボードで項目、メニューの端回避、サブメニューの往復、選択の保持、フォーカス復帰、無効操作の保護、タブの分離、表示切り替え、ディレクトリ階層を確認します。ライト／ダークテーマ、三つのプラットフォーム装飾、通常／大きい文字と倍率で実際のコントロールを撮影します。メニューの変更によって既存のメインウィンドウのタイトル、ツールバー、ファイルリスト、プレビューの初期配置を退行させません。

[一般的な検証方法](../../../developers/qa/README.md)に従い、機能範囲、実際のスクリーンショット、未統合の機能を記録し、結論は対応する issue、証拠は build/ または CI の成果物に保存します。静的ボード、ブラウザーの動作、Qt 実行時の検証は別々に説明し、互いに代替できません。

Qt メニューは `Popup.Item` と共有デリゲートを明示的に使用し、AppKit がカスタムスタイルを無視しないようにします。操作ウィンドウは独立したトップレベルウィンドウのままです。`CommandTooltip` は共有ヒントパラメーターとプレーンテキストを使い、アーカイブ名をリッチテキストとして解釈させません。メニューがフォーカスを得たらヒントを隠します。共有 JSON の 8 桁色は CSS RGBA であり、QML ジェネレーターが QColor ARGB に変換します。色と不透明度を一緒に検証します。

ディレクトリツリーとメインツールバーの開く、新規作成、検査、その他、展開のホバー状態にはフローティングツールチップがありません。無効なメニュー操作にも画面上のヒントやツールチップはなく、他のボタンは共有の遅延ヒントを使います。ルートと通常のサブディレクトリは直下のファイルとフォルダーだけを列挙し、検索は現在の範囲を再帰的に対象とします。通常の名前は最後の構成要素、検索では完全なパスを表示します。リストのホバーは行全体を覆い、グリッドは固定の水平余白とホバー／選択時のチェックボックスを保持します。メニューは全方向に柔らかな影を使い、起点ボタンから論理 4 ピクセル離します。操作と倍率の証拠は[一般的な方法](../../../developers/qa/README.md)に従って別々に保持します。

すべてのソートモードでディレクトリをファイルより前に置きます。昇順と降順は各グループ内で適用します。ファイル種類のソートは拡張子のないファイルをディレクトリと別にまとめ、同じ種類では安定した識別順を維持します。内部の転送バッチに分割する前に問い合わせ全体をソートします。HTML では folder が未設定のファイルを false とし、比較のために undefined を NaN に変換しません。

## 選択、タスクとヒント

すべて選択は現在のリストの最後の項目を詳細フォーカスにし、メタデータを個別選択時と一致させます。選択を解除すると四つのプロパティと「このファイルを展開」を隠し、ボタンは共有のホバー／押下／フォーカス状態を使います。すべて選択はディレクトリや物理的な識別契約を変更せず、現在の問い合わせ全体に適用します。

下部の「タスク N」は保持された履歴件数を表示し、実行中件数はヒントと終了ロジックにだけ使用します。各タスクメニュー項目は左に作成／展開と番号、右に状態色を表示し、マウスやキーボードで実行すると同じタスクを開き直します。タスクメニューは他のメニューと密度、文字サイズ、スクロール境界を共有します。未選択時は展開範囲メニューの選択範囲と事前検査を無効にし、追加のヒント行を表示しません。

フローティングヒントはポインターが同じコントロール内で 1200 ms 継続して静止した後にのみ表示します。移動、離脱、押下、メニューを開く操作は表示と古いタイマーをキャンセルします。別のコントロールに移った場合は前のヒントからすぐに再表示せず、再度全時間待ちます。コントロール上方を優先し、上に十分な空間がない場合は下に表示して、端の制約でツールチップがコントロール上に押し戻されホバーが振動するのを防ぎます。Qt の共有 CommandTooltip は明示的な静止タイマーを使用し、HTML の data-tooltip と同期します。リストの完全名はこの方針を回避するネイティブのブラウザー title を使いません。システムのネイティブメニューとトレイのヒント時間はシステムが制御し、QML で制御できると主張しません。時間は文字サイズ、DPR、密度で倍率を変えず、視覚的な形状も変えません。

アーカイブタブも共有の静止遅延ツールチップに完全なファイル名をプレーンテキストで表示します。押下、並べ替え、タブメニューまたはタブ一覧を開くと隠します。全体のタスク項目は最初にメニューを閉じ、タスクウィンドウだけを開きます。アーカイブタブの切り替えや閉じたアーカイブページの再表示は行いません。

開始ページは上部固定で水平方向に中央揃えのスクロール可能な本文を使います。エラーと警告は形式ヒントの下に赤い文字と意味を持つアイコンで表示し、上の内容を押し上げません。トレイ常駐中のメインウィンドウを閉じるとタブを消去し、通常の復元では開始ページだけを表示します。最小化ではタブを保持し、バックグラウンドタスクは全体から引き続き利用できます。

ファイルリストの双方向ドロップ、現在のディレクトリへの追加確認、三つのプラットフォームでの外部コピーについては[ファイルのドラッグ＆ドロップと変更](../../engineering/archive-transfers.md)を参照してください。

アーカイブ内の移動は内部ドラッグを使います。リスト／グリッドとディレクトリツリーのフォルダー対象は既存の選択背景を使い、即時フィードバックはツールチップの形状を再利用して最大四行とし、現在のクライアント領域内に収めます。選択したディレクトリ、その子孫、元の位置、検索、暗号化／分割対象については、新しい確認ウィンドウを作らず明確な拒否理由を示します。名前の衝突にはファイル競合ウィンドウを使い、移動タスクには固有の名前を付けます。トランザクションと境界は[アーカイブ内移動のデザイン](../../../design/hifi/sources/archive-move.html)と[ドラッグ＆ドロップ契約](../../engineering/archive-transfers.md)を参照してください。
