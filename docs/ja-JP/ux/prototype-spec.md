状態：インタラクティブなデザイン検証用ドラフト。ソースは [design/html](../../../design/html/README.md)、入口は [index.html](../../../design/html/index.html) です。Figma のドラフトは過去の検討として残し、現在の機能と状態の詳細化はリポジトリ内で続けています。

<a name="xdzip-interaction-decisions"></a>

## インタラクションの決定

<a name="xdzip-selection-and-search"></a>

### 選択と検索

- 各選択はソート後の行番号ではなく、安定した項目 ID に対応します。隠れた選択による誤解を避けるため、クエリーやディレクトリを変更すると選択を消去します。
- 現在の一覧の全選択とアーカイブ全体の展開は別の概念です。フォルダーをチェックすると重複を除いた子孫ファイルに展開します。
- IME 変換中はクエリーを送信せず、compositionend の後に更新します。ブラウザーの模擬イベント検査は macOS/Windows/Linux のネイティブ IME 受け入れに代わりません。
- 通常ファイルで Enter またはダブルクリックすると一時コピーを展開してシステムの関連付けで開き、ディレクトリでは中に入ります。プロパティの入口は残ります。HTML は進捗と自動非表示のみを示し、ファイルを書き込まずシステムを呼び出しません。Qt の自動内容プレビューは[プレビュー契約](../engineering/content-preview.md)を参照してください。

<a name="xdzip-extraction-and-conflicts"></a>

### 展開と競合

- 最終パスを随時表示し、同名ディレクトリは一度だけ追加します。空または書き込み不可と明確なサンプルパスでは開始を阻止し、出力先変更後は事前確認をやり直します。
- 競合は既定で確認し、スキップ、自動改名、上書きを選べます。隣接する説明に上書きの影響を示します。
- 競合パネルの初期フォーカスはスキップで、上書きは既定の Enter 操作ではありません。以降の競合への適用はこのタスクに限られ、サンプルデータは一つの競合のみを作ります。
- 改名は完了サマリーとファイル詳細に表示します。スキップは失敗ではなく、サンプルの既存ファイルを完了済み書き込みに数えません。

<a name="xdzip-tasks-and-results"></a>

### タスクと結果

- 閲覧に戻ってもタスクはキャンセルされず、ステータスバーから再表示できます。
- キャンセル要求 → 停止中、再度のキャンセルは無効 → キャンセル結果。展開では公開済み項目を保持し、アーカイブ作成では途中結果を公開しません。
- ディスク容量不足ではタスクを停止して成功分を保持します。再試行は失敗・未完了範囲だけを選び、計画の確認に戻ります。
- ソース変更時は古いインデックスを黙って再利用せず、アーカイブを開き直す必要があります。
- 作成タスクは最終アーカイブ一つを数え、キャンセル時は作成数ゼロと表示して古いアーカイブを明確に保持します。

<a name="xdzip-archive-creation-and-capabilities"></a>

### アーカイブ作成と対応範囲

試作は ZIP レベル、TAR パック、GZIP 圧縮オプションを示します。基本的な入力、ファイル名、出力先の項目を検査し、形式に応じて拡張子を変更します。現在の製品の選択肢は[組み込み形式レジストリ](../engineering/format-registry.md)を使い、[ISO](../engineering/iso-creation.md) と [Windows SFX](../engineering/sfx-creation.md) の作成プロファイルも含みます。受け入れられる選択肢は[パスワード操作](password-extraction.md)と[分割ボリューム契約](../engineering/archive-opening.md)を参照してください。

<a name="xdzip-visuals-and-adaptation"></a>

### 見た目と適応

暖かいグレー、コバルトブルー、グラファイトのテーマを維持します。標準の行高は 40、コンパクトは 32 です。ダークテーマの文字アクセントはボタンの塗りと独立し、小さい文字の可読性を保ちます。デスクトップの幅が狭い場合、詳細は閉じられるオーバーレイになります。モバイルレビューではサイドバーと表の補助列を折りたたみ、操作パネルは狭い画面に適応してスクロールします。

操作画面は[プラットフォームウィンドウ仕様](platform-windows.md)に従う独立ウィンドウです。HTML は dialog で模擬し、決定ウィンドウはフォーカスを制限し、進捗、結果、設定はモードレスで、閉じるとフォーカスの復帰を試みます。競合ウィンドウを閉じると黙ってスキップせずタスクをキャンセルし、進捗を閉じると詳細を隠すだけです。Qt は実際の独立したトップレベルウィンドウを使います。

<a name="xdzip-theme-selection"></a>

### テーマ選択

設定ページは `fieldset#setting-theme` と「Appearance theme」凡例を使い、システム、ライト、ダークの三つのネイティブラジオ入力を配置します。各テーマカードは共有素材 `theme-system`、`theme-light`、`theme-dark` のいずれかを使い、テキストラベルと入力を関連付けます。実際のラジオコントロールがカードクリック、キーボード切り替え、フォーカスに参加します。選択は共有ラジオマークを使い、カード枠とプレビューの見た目を同期し、操作できないスクリーンショットで代用しません。

これは HTML デザイン検証の動作を説明します。現在の設定はメモリー内にあり、システム追従は選択時だけ解決します。実行中のシステムテーマ変更、起動をまたぐ保存、製品 Qt 設定の即時保存と失敗処理は別途検証が必要です。

<a name="xdzip-verification-and-remaining-boundaries"></a>

## 検証と残る範囲

ブラウザー検証スクリプトは scripts/check-html-design.py です。実際のクリックフロー、統計、無効条件、形式連動、復旧、モバイルのあふれ、オフライン単一ファイル動作を検査します。レポートは書き出された試作パッケージに添付し、ブラウザー検査は Chromium のみを使います。

現在のメインウィンドウ納品には、独立した二つのサンプルアーカイブセッション、一覧・グリッド、項目別ソート、再帰ディレクトリツリー、階層パンくず、コンテキスト・ドロップダウン・サブメニュー、ボタン状態が含まれます。[コンポーネントと操作の契約](main-window-components.md)および[検証方法](../../../developers/qa/README.md)を参照してください。`scripts/check-html-controls.py` は実際のブラウザー入力で検査し、[コンポーネントレビューページ](../../../design/html/components.html)はメイン UI と同じ実装を使います。

HTML が検証するのはサンプル状態だけで、実際のタスクスケジューリング、認可、パス競合、CRC、プラットフォームのアクセシビリティを証明しません。Qt は実際の作成・展開、ドラッグ＆ドロップ、システム選択画面、永続設定、任意のタブまたは複数ウィンドウ内の独立アーカイブセッションを統合します。複数形式、通常の単一ファイル ZIP の百万項目インデックス、限定プレビューの実際の範囲はそれぞれ[形式バックエンド](../engineering/native-codecs.md)、[大規模インデックス](../engineering/large-index.md)、[内容プレビュー](../engineering/content-preview.md)にあり、受け入れは対応 issue に記録します。HTML 設定のデモ状態はページ内だけで起動をまたがず、ネイティブのシステムテーマ追従やアクセシビリティ受け入れを証明しません。

これらの制限はソフトウェア設計の目標機能を変更しません。試作の「完了」はデモタスクの状態だけを意味し、実際の圧縮や展開の納品を証明しません。

<a name="xdzip-current-directory-queries-and-card-revisions"></a>

## 現在のディレクトリクエリーとカード改訂

ルート項目は「Root」で、直下のファイルとフォルダーだけを一覧します。検索は現在の範囲の子孫に一致し、アーカイブ内の完全パスを示します。通常の一覧・グリッドは末尾名だけを表示し、コピーとナビゲーションは完全パスを保持します。パンくず右側は現在の一覧行数を示します。ディレクトリツリーのタイトルは「Archive」でパンくずと垂直に中央揃えし、ツリーのホバー時に浮動ツールチップを表示しません。

一覧のホバーは行全体を覆います。グリッドの横方向の内側余白は約 16 論理ピクセルで、左上の 8 ピクセルのチェックボックスはホバーで現れ、選択中は表示を維持します。ボタンから開くメニューはボタンから 4 単位離れ、柔らかい影を使います。プレビュー再表示ボタンは一辺 28 に固定します。パラメーターは layout-scale.json、directory-tree.json、controls.json にあり、実際の検証は[共通方法](../../../developers/qa/README.md)に従います。

<a name="xdzip-settings-window"></a>

## 設定ウィンドウ

設定は元画像のアイコン見出し、テーマプレビューカード、密度、最近の履歴、プライバシー説明を保持し、文字サイズと UI 言語を追加します。テーマとフォントのプレビューはキャンセル可能で、保存と既定値の復元はドラフトを使います。HTML は現在のページ内だけにデモ状態を保持します。HTML デモの言語選択は次回 Qt 起動時に有効になる設定を示し、デザインレビューページやサンプルアーカイブの内容は製品翻訳範囲の証拠にはなりません。現在の Qt の言語切り替え、同梱リソース、永続化は[設定と言語](settings-localization.md)を参照してください。
