# システムメニューとトレイ

[English](../../ux/desktop-integration.md) | [简体中文](../../zh-CN/ux/desktop-integration.md) | [繁體中文（台灣）](../../zh-TW/ux/desktop-integration.md) | 日本語 | [한국어](../../ko-KR/ux/desktop-integration.md) | [Français](../../fr-FR/ux/desktop-integration.md) | [Deutsch](../../de-DE/ux/desktop-integration.md) | [Español](../../es-ES/ux/desktop-integration.md) | [Português (Brasil)](../../pt-BR/ux/desktop-integration.md) | [Русский](../../ru-RU/ux/desktop-integration.md)

複数セッション、単一インスタンス、ウィンドウ状態、全体終了は[アプリケーションセッション契約](../engineering/application-sessions.md)に従います。最後以外のメインウィンドウを閉じてもタスクは保持され、最後のウィンドウはトレイ設定に従います。終了確認はすべてのセッションを対象とします。

タスクのパスワードまたは競合確認が表示されていても、システム、メニュー、トレイから明示的な終了を選ぶと全体の確認を開けます。macOS のアプリケーションメニューの終了と Command-Q は引き続き使えます。戻るを選ぶとタスクと確認画面を保持します。ネイティブファイル選択画面やその他のブロックするモーダル画面は先に完了または閉じる必要があります。その画面に阻止された終了要求は破棄します。

macOS のメニューバーと三つのプラットフォームのトレイには OS のネイティブメニューを使い、既存のメインウィンドウのタイトルバーを維持します。[デスクトップ統合パラメーター](../../../specs/visual/desktop-integration.json)、[操作デザイン](../../../design/html/desktop-integration.html)、[高忠実度デザイン](../../../design/hifi/sources/desktop-integration.html)を参照してください。ネイティブのフォント、行高、メニュー幅、システムの強調表示にはアプリ内 CommandMenu の密度パラメーターを使いません。HTML は操作の説明であり、ネイティブのピクセル単位の受け入れではありません。

macOS のメニューは xdzip、ファイル、編集、表示、操作、ウィンドウ、ヘルプです。ヘルプの「ユーザーガイド」と「問題を報告」は既定ブラウザーでプロジェクトの README と Issues を開き、フィードバックを自動送信しません。区切り線の後の「xdzip について」はアプリとトレイのメニューと同じ設定ウィンドウの情報ページを開きます。ヘルプの情報項目は NoRole を使いその位置に残ります。アプリケーションメニューは AboutRole、PreferencesRole、QuitRole を使い、サービス、隠す、すべて表示はシステムが提供します。ファイルには開く、新規、最近使用、アーカイブを閉じる、ウィンドウを閉じるがあります。編集にはテキストのフォーカスに応じて取り消し、やり直し、切り取り、コピー、貼り付け、すべて選択、検索があります。表示には一覧、グリッド、プレビュー、操作にはすべて展開、選択項目の展開、メタデータの事前確認、ウィンドウには最小化、ズーム、メインウィンドウ、タスク、表示中の製品ウィンドウがあります。

メニューと既存 UI は共通のコマンド入口を使い、開くときと有効化する前に機能を再確認します。⌘W は現在のウィンドウ、⇧⌘W はアーカイブを閉じます。テキスト編集でファイル選択を誤って変更してはいけません。モーダルウィンドウはメインウィンドウのコマンドをブロックし、無効項目に説明行を追加しません。最近使ったファイルは記録が許可されている場合だけ表示し、パスを別途コピーまたはアップロードしません。アプリが所有する文言は有効な言語カタログを使い、システム項目はシステム言語に従います。

言語の保存が成功すると既存メニューバー、アプリ所有の情報、設定、終了項目、トレイメニュー、タスクサブメニュー、トレイのツールチップが即座に切り替わります。保存失敗時は以前の言語を維持します。コマンド、ショートカット、タスクの同一性、実行中のタスクは変わりません。macOS のサービスや隠すなどのシステム項目とネイティブファイル選択画面は引き続きシステム言語に従います。

トレイ常駐は既定で有効で、保存成功後に適用されます。メニューにはメインウィンドウの表示、開く、新規、タスク、設定、情報、終了があります。macOS ではトレイアイコンでメニューを開きます。Windows と Linux ではトレイの有効化またはダブルクリックでウィンドウを復元し、システムのコンテキスト操作でメニューを開きます。Windows はトレイ再有効化時にネイティブメニューを再バインドします。タスク完了時はフォーカスを奪わずタスク項目を更新します。

トレイが利用できるときに最後のメインウィンドウを閉じると、そのウィンドウの参照タブと下書きを消去してから非表示にします。復元時はようこそページに戻ります。最小化ではタブを保持します。実行中のタスクと元の識別情報には全体のタスク項目からアクセスできます。管理対象セッションがトレイを失い、表示可能なタスク項目もない場合は、各操作ウィンドウから実行中タスクにアクセスできます。トレイ、表示中のウィンドウ、実行中のタスクがいずれもなければアプリは終了します。明示的な終了と再起動は引き続きタスク確認と非同期シャットダウンに従います。macOS の Dock とシステムによるファイルのオープンからもアプリを復元できます。

macOS は既存ブランドマークから作成したテンプレート形式のトレイアイコンを使います。Windows と Linux を含むその他のプラットフォームはアプリアイコンを再利用し、表示サイズはシステムが選びます。アイコンはアプリやシステムのテーマによって変わらず、レジストリーのテーマ読み取りにも依存しません。アイコンを点滅または連続アニメーションさせません。

表示メニューは「ファイルのプレビューとプロパティ」の後に折りたたまれない区切り線を置き、AppKit が自動追加する全画面コマンドを分離します。これによりシステムの全画面アイコンがプレビュー用の余分なアイコン列を予約するのを防ぎます。プレビューの文字は一覧とグリッドに揃え、チェックマークはシステムが描画します。空白、固定幅、独自メニューで補正しません。HTML と高忠実度デザインはアプリのコマンドだけを表し、システム追加項目はネイティブデスクトップで検証します。

## 検証

アプリ所有の Qt Quick ウィンドウを非表示または最小化したとき、ポインターのホバーを同期的に終了し、ボタン、MouseArea、HoverHandler、ツールチップの古い位置を消去します。復元後の最初のフレームの同期前に、古いホバー色や座標を再利用せず、実際のシステムポインター位置と照合します。遅れて届くネイティブの進入イベントも実際の位置に合わせ、実際のマウス移動または押下が現在の座標を与えるまで正規化します。メインと操作の両ウィンドウに適用し、フォーカス、ボタンのバインド、ネイティブファイル選択画面は変更しません。

Windows ではトレイへの非表示後もネイティブウィンドウ、状態、QML オブジェクト、コントローラー、バックグラウンドタスクを保持します。非表示中は不透明度をマスクし、復元後に新しく送信した最初のフレームまで維持して DWM が古いフレームを一瞬表示するのを防ぎます。hovered の消去だけでは防げません。新たな非表示は古いフレームのコールバックを無効にします。この方針はトレイへの非表示だけに適用し、最小化や表示中のウィンドウには適用せず、スクリーンショットの読み戻し、固定遅延、システムアニメーションの変更を使いません。

グローバルなシステムポインターがないバックエンドでは、物理カーソルを問い合わせて上書きせず、注入されたイベントを正とします。offscreen/minimal のコンポーネント検査は、DWM、Cocoa、X11 の実際のネイティブウィンドウ受け入れとは別です。

自動化はメニューの構造とロール、状態同期、コマンドと編集のルーティング、設定の互換性とキャンセル、常駐と終了の方針、トレイなしの代替、タスクメニュー、モーダルのブロック、再起動を対象とします。ネイティブデスクトップでは macOS メニューバーと Dock からの復元、Windows 通知領域、Linux StatusNotifier/XEmbed、明暗表示、高 DPR、キーボード、スクリーンリーダーを別途確認します。画面外検証はネイティブデスクトップの受け入れではなく、スクリーンショットと報告は build/ または dist/ にのみ保存します。

ネイティブ編集ロールがアプリの言語カタログを使うのは `QCocoaMenuItem` の Cut、Copy、Paste、Select All 翻訳コンテキストだけです。`QCocoaMenuBar/Edit` も同じタイトルを使い、Qt のテキストロール検出と編集メニューの認識がシステム言語に依存しないようにします。システムファイル選択画面とその他の Qt コントロールは引き続きシステムロケールの qtbase 翻訳を使います。ユーザーのグローバル AppleLanguages を変更せず、中国語のアプリと英語システム、英語のアプリと中国語システムの両方を検証します。

日本語のトレイツールチップは `xdzip（実行中のタスク: %1）`、タスクメニューは `タスク（実行中: %1）` です。英語ではそれぞれ `xdzip (Active tasks: %1)`、`Tasks (Active tasks: %1)` です。数はアプリ全体で実際に実行中のタスクから取得し、参照ページを閉じた後も実行中のタスクを含みます。完了した結果は実行中に数えません。
