# 操作と文言の補足仕様

[English](../../ux/interaction-spec.md) | [简体中文](../../zh-CN/ux/interaction-spec.md) | [繁體中文](../../zh-TW/ux/interaction-spec.md) | 日本語 | [한국어](../../ko-KR/ux/interaction-spec.md) | [Français](../../fr-FR/ux/interaction-spec.md) | [Deutsch](../../de-DE/ux/interaction-spec.md) | [Español](../../es-ES/ux/interaction-spec.md) | [Português (Brasil)](../../pt-BR/ux/interaction-spec.md) | [Русский](../../ru-RU/ux/interaction-spec.md)

メインウィンドウと展開確認のビジュアル基準に加え、作成、名前の競合、タスク、結果、設定、プラットフォーム別の比較は[操作状態の仕様](hifi-state-spec.md)にあります。ようこそ画面と読み込み時の進行状況は[ようこそ画面の仕様](welcome-opening.md)を参照してください。現行の原稿とレイアウトは[ウィンドウ登録表](../../../specs/visual/window-registry.json)に従います。実装済みの範囲とネイティブ表示の検証結果は、対応する技術・操作仕様に記載します。

| 場面 | 表示と操作 | 次の操作 |
| --- | --- | --- |
| 初回起動 | アーカイブを開くか作成できます。ローカルファイルをドロップできます。 | ディスク全体の走査や、全形式の自動関連付けは行いません。 |
| ディレクトリーの読み取り | 読み取った件数と不定の進行状況を表示します。総数は不明です。 | セッションを閉じられます。部分結果は読み取り完了と表示しません。 |
| 空のアーカイブ | 「このアーカイブは空です」と表示し、ファイルのプロパティを保持します。 | 別のアーカイブを開けます。展開を無効にし、理由を表示します。 |
| 検索結果なし | 検索語と範囲を表示します。 | 検索を解除できます。アーカイブが空であるとは表示しません。 |
| 非対応機能 | 形式、方式、暗号化の具体的な理由を表示します。 | 読めるメタデータを保持して、安全に書き出せない部分出力を止めます。 |
| アーカイブの作成 | 入力一覧、形式、保存先、レベル、事前確認を表示します。 | エラーはフィールドの近くに表示します。既定では既存ファイルを保持します。 |
| 名前の競合 | 両方の項目を表示します。スキップ、名前の変更、上書きと、その後の適用範囲を選択できます。 | 確認を閉じるとタスクは待機します。タスクから確認を開き直すか、キャンセルできます。 |
| タスク完了 | 成功、スキップ、失敗、確定した出力の件数を表示します。 | 展開先はユーザーの操作で開きます。作成では対応する単一アーカイブまたは先頭の分割ボリュームをアプリ内で開けます。再試行には計画のやり直しが必要です。 |
| 一部失敗 | 確定済みファイルを保持し、失敗内容を表示します。 | 保存済みのユーザーファイルは元の出力場所に残します。 |
| アプリの終了 | 実行中のタスク数を示し、完了を待つか、キャンセルして終了できます。 | コアが後処理の完了を確認します。GUI を無期限に待たせません。 |
| 設定 | システム設定、ライト、ダークのテーマ、密度、文字サイズ、言語、履歴、通知領域があります。 | 保存に成功したら即座に適用し、失敗したら従来の値を保持します。上限は現在の設定から編集できません。 |
| 形式拡張 | 製品は組み込み形式を使います。読み取り専用の実行は[外部 SDK 試験](../engineering/sdk-trial.md)で別に検証します。 | 対応する操作は[形式レジストリー](../engineering/format-registry.md)を参照してください。 |

展開ボタンは選択内容に従います。メニューには現在実行できる両方の範囲を表示します。検索は現在のディレクトリーとその配下を対象にします。対応するファイルを一つ選ぶと、表示中のプロパティパネルに[テキストまたは画像のプレビュー](../engineering/content-preview.md)が自動で表示されます。パネルを置く幅が足りなければ別ウィンドウで開けます。大きな文字ではコンテンツの寸法を広げ、スクロールして確認ボタンに到達できるようにします。

エラーは起きたことと次の操作を説明し、コードは詳細に表示します。一般ユーザーにコールスタックや IPC 用語を表示しません。危険なファイル名は安全なテキストとして表示し、プラグインの文言を HTML として解釈しません。ショートカット、IME、フォーカス、スクリーンリーダーは[Qt Quick の設計](../design/qt-quick-ui.md)に従います。
