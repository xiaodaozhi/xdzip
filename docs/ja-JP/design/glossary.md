# XDZip の用語と実装上の制限

## 1. 用語

| 用語 | 定義 |
| --- | --- |
| アーカイブ | コンテナーまたは対応する圧縮ストリームと、その許可済みソース。 |
| コーデック | 形式を検出、スキャン、読み取り、作成する実装。 |
| セッション | 開いたソース、バックエンド、索引、閲覧の文脈。タスクには別のライフサイクルがあります。 |
| 項目 | アーカイブに実在するレコード。フォルダーには表示用の合成ノードがある場合もあります。 |
| SourceVersion | 許可された単一ソースファイルまたはボリュームから可能な範囲で得る指紋。 |
| QuerySnapshot | セッション、クエリー、世代、リビジョンで識別する、現在の不変の結果順序。 |
| 世代 | 古い結果で新しい結果を上書きしないためのフロントエンド要求の置き換え関係。 |
| 準備済みジョブ | 操作に必要なソース、選択、オプションを含む、上限付きのランタイム入力。 |
| タスク | キューに受理されたジョブのライフサイクルと結果。 |
| 許可 | ホストが保持するファイルやディレクトリーのアクセス権。パス文字列とは異なります。 |
| 出力先 | 計量、上限、トランザクションで制御する書き込みインターフェース。 |
| ワーカー | コマンドとタスクはホストのスレッドで動作します。アーカイブワーカーと画像ワーカーは別プロセスです。 |
| 確定 | 許可されたファイルまたはアーカイブ操作で、検証済みの一時出力を公開すること。 |
| タスクのスナップショット | 状態、進行状況、確認、結果の最新報告。途中の報告はまとめられる場合があります。 |
| 機能 | 実装、形式の機能、プラットフォーム、方針がそろって有効になる処理。 |
| ソリッド | 複数のファイルが圧縮ブロックを共有する方式。選択読み取り時に先行データのデコードが必要な場合があります。 |
| 最初に表示されたフレーム | 実際に描画して表示したフレーム。ui_ready のログだけでは確認できません。 |

<a name="xdzip-2-units-and-values"></a>

## 2. 単位と値

メモリーとファイルの単位は二進の KiB/MiB/GiB で、1 MiB = 1024² バイトです。転送と計上では整数のバイト数を保持します。時間は ms または s で表し、経過時間の測定には単調時計を使います。ファイルの時刻は、取得できる場合に暦の表現とソースの精度を保持します。処理速度は MiB/s で統一し、圧縮入力、デコード済みデータ、出力のどのバイトを数えたかを明記します。

CPU 使用率 100% は論理コア一つを完全に使用する状態です。プロセスツリーでは 100% を超える場合があります。PSS、RSS、USS、物理メモリー使用量は別の指標です。圧縮ダウンロードサイズ、インストール後のサイズ、実行ファイルサイズは別々に記録します。

## 4. バージョン管理

アプリ、内部の CXX ビルドインターフェース、外部の通信プロトコル、永続データのスキーマには別々のバージョン境界があります。製品のバージョンだけから SDK プロトコルのバージョンは分かりません。[コーデック拡張 SDK の設計](codec-extension-sdk.md)を参照してください。
