<a name="xdzip-create-an-archive"></a>

## アーカイブを作成する

1. 初期画面または **作成** から作成ウィンドウを開きます。ファイルやフォルダーを追加し、入力一覧を確認します。
2. 出力名と保存先を指定します。形式と、利用可能な圧縮設定を選びます。共有には ZIP がよく使われます。作成できる形式は[対応形式表](../../../README.ja-JP.md#xdzip-format-support)を参照してください。GZIP のような単一ファイルのストリーム形式は通常ファイル 1 個を受け取ります。
3. ZIP と 7z は、設定によって暗号化と分割ボリュームを利用できます。データディスクイメージには ISO、自己展開 ZIP には Windows x64 用の SFX プロファイルを選びます。処理を開始し、タスクの結果で実際に保存されたファイルを確認します。[パスワードと分割ボリューム](passwords-and-volumes.md)
4. キャンセルや再試行が必要なら、先に結果を確認します。アーカイブは一時的な場所に書き込まれ、完了した結果が確定してから公開されます。

<a name="xdzip-add-replace-or-move-files"></a>

## ファイルを追加、置換、移動する

対応する ZIP/ZIPX、7z、LHA/LZH、TAR、または外側を圧縮した TAR アーカイブを開き、アーカイブ内の対象フォルダーに移動します。ローカルのファイルやフォルダーを一覧またはグリッドにドロップし、追加内容を確認して承認します。名前が重複した場合、置き換え可能な通常ファイルを上書きできます。既存の項目は同じアーカイブ内の別のフォルダーにドラッグし、確認して移動します。ウィンドウの外へのドラッグはコピーを出力します。[プラットフォーム別のドラッグ＆ドロップ](../engineering/archive-transfers.md)

作成時と追加時は、`.DS_Store` ファイルと `__MACOSX` および `_MACOSX` ディレクトリを除外します。変更の可否は形式、内容、元のファイルによって異なります。暗号化済み、分割済み、またはインデックスをディスクに置くアーカイブは通常の手順では編集できません。編集できない場合は、新しいフォルダーに展開して新規アーカイブを作成します。[変更とドラッグ＆ドロップの規則](../engineering/archive-transfers.md)

<a name="xdzip-rename-or-delete-entries"></a>

## 項目名の変更と項目の削除

編集できるアーカイブの通常のフォルダーで、リストまたはグリッド内のファイルやフォルダーを右クリックします。選択済みの項目を右クリックすると選択を維持し、未選択の項目を右クリックするとその項目だけを選択します。

- **名前を変更**できるのは 1 項目だけです。同じフォルダー内で新しい名前を入力します。フォルダーの名前を変更すると、配下の項目のパスもすべて変わります。同じ名前がすでに使われている場合は、別の名前を指定してください。
- **削除**は 1 件以上の選択項目に対して実行できます。確定前に項目名または選択数を確認してください。フォルダーを削除すると、その中身もすべて削除されます。ルートの項目をすべて削除すると、空のアーカイブが残ります。空にしたときに単独の圧縮ストリームとして開かれる場合は、`.tar.xz` などの TAR の複合拡張子を使ってください。

検索結果の項目を編集するには、先にその項目が入っているフォルダーを開いてください。[アーカイブの変更に関する規則](../engineering/archive-transfers.md)
