## アーカイブのウィンドウから

1. アーカイブを開きます。ツールバーのメインボタンを押すと、選択中の項目を展開します。未選択の場合はアーカイブ全体を展開します。ボタンの横にある矢印から **すべて展開** または **選択項目を展開** を選ぶこともできます。
2. 展開する範囲を確認し、書き込み可能な展開先を選びます。利用できる場合は、アーカイブと同じ名前のフォルダーを作るオプションを選べます。
3. ファイル名が重複したときの動作を選びます。**確認する** は判断を待つために処理を一時停止し、**スキップ** は既存のファイルをそのまま残します。**名前を変更** は別のファイルとして保存し、**上書き** は検証後に置き換え可能なファイルを上書きします。
4. 展開を開始し、タスクの結果を確認します。失敗やキャンセルの前に展開されたファイルは残ることがあります。再試行の前に、結果の詳細で残りの項目を確認してください。[検証、タスク、結果](checks-and-tasks.md)

展開メニューには **展開前にメタデータを確認** もあります。実際にアーカイブに記録された項目を明示的に 128 件以内で選ぶと、安全でない名前、未対応の方式、宣言された上限などを報告します。移動用にだけ表示される論理上のフォルダーも、対応形式であれば展開できます。事前確認ではファイル本体を読み込まず、書き込み権限も付与しません。[事前確認と展開の上限](../engineering/extraction-preflight.md)

インデックスをディスクに置く大きな ZIP アーカイブでは、タスクの上限内で選択した通常ファイルを展開できます。アーカイブ全体が上限を超える場合は、選ぶ項目を減らしてください。元のファイルが変更または置換された場合は、開き直して選択し直してください。[大きなアーカイブの上限](../engineering/large-index.md)

## ファイルマネージャーから

Windows 11 のクラシックメニューは **その他のオプションを確認** から開きます。Microsoft Store 版では新しいメニューにも操作が表示される場合があります。Ubuntu では Nautilus 拡張機能を使います。macOS ではシステム設定で Finder 拡張機能を有効にするか、登録済みの Finder サービスを使います。メニューが表示されない場合は、xdzip でアーカイブを開いて展開してください。

ファイルマネージャーのメニューでは、元の各アーカイブがあるディレクトリに展開する、アーカイブごとにフォルダーを作る、自動で展開する、展開先を指定する、といった操作を選べます。自動展開では、検証済みの出力の最上位にフォルダーがちょうど 1 個だけある場合に限り、外側のフォルダーを作りません。一括処理ではアーカイブごとに結果が表示され、個別の失敗があっても次に進みます。キャンセルすると後続項目の処理を止め、現在の処理の中止を要求します。[ファイルマネージャーの操作と設定](../engineering/shell-actions.md)
