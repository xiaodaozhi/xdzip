# ファイルを閲覧、選択、プレビューする

[English](../../user-guide/browse.md) | [简体中文](../../zh-CN/user-guide/browse.md) | [繁體中文](../../zh-TW/user-guide/browse.md) | 日本語 | [한국어](../../ko-KR/user-guide/browse.md) | [Français](../../fr-FR/user-guide/browse.md) | [Deutsch](../../de-DE/user-guide/browse.md) | [Español](../../es-ES/user-guide/browse.md) | [Português (Brasil)](../../pt-BR/user-guide/browse.md) | [Русский](../../ru-RU/user-guide/browse.md)

1. アーカイブを開きます。ディレクトリツリーでフォルダーを選ぶか、該当する行をダブルクリックします。パスバーから親フォルダーに戻れます。
2. ファイル名の一部を入力して Enter キーを押します。現在のフォルダーとその下のフォルダーを検索します。リスト表示またはグリッド表示と、並べ替え順を選べます。昇順と降順のどちらでも、フォルダーはファイルより先に表示されます。
3. チェックボックスまたはシステムの選択用キーで項目を選びます。**すべて選択** は現在の検索結果に適用され、表示領域外の行も含みます。展開の前に選択件数を確認してください。
4. ファイルのプロパティが表示されている状態でファイルを 1 つ選択すると、プレビューが表示されます。プレビューにポインターを合わせ、右上の再読み込みアイコンをクリックすると更新できます。複数の項目を選択した場合は、プロパティカードにその旨が表示されます。テキストは UTF-8 または BOM 付き UTF-16 で、256 KiB 以内です。画像のサイズ制限は別にあります。静的 SVG は対応する機能に限られます。HEIC/HEIF は macOS で使えます。プレビューできない場合も、その項目が対応していれば展開できます。[プレビュー形式と制限](../engineering/content-preview.md)

通常ファイルをダブルクリックすると、一時コピーを展開して OS に開くよう依頼します。そのコピーを編集してもアーカイブには反映されません。残しておくコピーが必要なら、指定した場所に展開してください。[一時的に開く操作](../engineering/archive-opening.md)

アーカイブは既定でタブに開きます。設定で別々のウィンドウに開くように変更できます。通常の単一ファイル ZIP/ZIP64 は最大 100 万件の実レコードを索引化できます。大きなインデックスは表示に必要な行を読み込みます。ディスクにインデックスを置く ZIP でも選択ファイルを展開できる場合があります。アーカイブ全体の検証と更新は無効です。[大きなアーカイブの上限](../engineering/large-index.md)

## アーカイブのコメントを表示する

ZIP または RAR を開き、ツールバーの **その他 → アーカイブのコメント** を選択します。テキストの選択とコピーができます。通常の書き込み可能な ZIP、ZIP64、ZIPX では、編集後に **保存** を選択します。空にして保存するとコメントが削除されます。UTF-8 で 65,535 バイトまでです。分割、自己解凍、暗号化、ディスク索引を使う大規模 ZIP、署名付きまたは派生 ZIP パッケージ、RAR のコメントは読み取り専用です。
