# 領域模型與歸檔資料

[English](../../design/domain-data.md) | [简体中文](../../zh-CN/design/domain-data.md) | 繁體中文（台灣）

歸檔會話、已完成的索引和會話內最新查詢由執行時持有。Qt 儲存結果的檢視，CLI 透過獨立的清單命令讀取物理記錄。兩者都把操作交給同一個 Rust 服務實現。[系統架構](system-architecture.md)、[Qt/Rust 橋接](qt-rust-bridge.md)

<a name="xdzip-身份与来源版本"></a>

## 身份與來源版本

| 身份或資料 | 目前表示與作用範圍 |
| --- | --- |
| `SessionId` | 開啟歸檔後產生的非零執行時身份。每次成功開啟新的歸檔時建立新會話。檔案路徑用於輸入和介面路由。 |
| `SourceVersion` | 執行時記錄各個已接收部分對應的普通檔案的身份、長度和可用時間資訊，在相關讀寫邊界複核已開啟物件及對應路徑。這是一種盡力檢測。 |
| `EntryId` | 標識會話內的一條物理歸檔記錄。同名記錄各有獨立身份。 |
| 導航身份 | 表示已索引的目錄。透過後代記錄合成的虛擬目錄可顯示在目錄樹或列表中，無需對應物理條目編號。 |
| `QueryKey` | 由會話、查詢編號、代數和快照修訂號組成。偏移表示該結果中的位置。 |
| 請求、任務與提示身份 | 服務在連線內分配請求和任務編號。提示歸屬某個具體任務。桌面共享任務入口使用控制器的會話身份及任務編號。 |

領域型別保證歸檔和查詢身份非零。原生橋接透過生成的 CXX 資料傳遞型別化 Rust 值。需要完整保留 64 位的編號以不透明字串交給 QML。行號只表示某個查詢中的位置。[領域身份原始碼](../../../crates/xdzip-domain/src/identity.rs)、[來源實現](../../../crates/xdzip-runtime/src/source.rs)、[應用會話](../engineering/application-sessions.md)

<a name="xdzip-物理条目与输出名称"></a>

## 物理條目與輸出名稱

`xdzip-codec-api::Entry` 儲存格式、物理身份、名稱的不同表示、大小資訊、條目型別標誌、修改資訊以及格式專用的方法和加密欄位。原始名稱位元組、可選的 UTF-8 解碼名、編碼判定及轉義後的顯示文字分別儲存。寫出時，執行時對有效名稱執行可移植路徑校驗，並核對目標授權。未解析的名稱仍可顯示，但解壓該記錄或目錄時會遭拒。

原始大小帶有獨立的 `size_known` 標誌，用於區分已知的零位元組檔案與大小未知。有些壓縮容器沒有逐條目的壓縮後大小。方法值按格式解釋。時間保留各格式的約定，例如 ZIP 的本地 DOS 時間，缺失時仍顯示未知。`payload_supported()` 判斷目前記錄能否解碼，實際寫出還取決於所選操作、來源狀態、名稱與檔案系統規則。[條目欄位](../../../crates/xdzip-codec-api/src/lib.rs)、[檔名處理](../engineering/filename-encoding.md)、[檔案授權](file-security.md)

<a name="xdzip-索引查询与分页生命周期"></a>

## 索引、查詢與分頁生命週期

執行時開啟來源並完成有界掃描後，才釋出歸檔及第一頁。掃描可以取消。尾部損壞、缺少密碼或來源變化時，不會發布部分索引。目錄導航有獨立預算，超出目錄樹限額時仍可支援根目錄瀏覽及物理條目搜尋。普通單檔案 ZIP/ZIP64 的私有磁碟路徑最多可儲存一百萬條記錄。其他格式和分卷路徑遵循各自限額。

`Archive::query_page` 接收目錄、文字、排序方式、偏移和預期查詢身份。新查詢從偏移零開始，使用新的代數。執行時建立完整的結果順序，每個歸檔保留一個目前不可變查詢。分頁從這個順序取出行身份。搜尋和排序保留歸檔記錄原有身份。各排序方式都將目錄排在檔案前，以確定性的身份順序處理並列值，並在同組內將大小未知項排在已知項之後。

通用的領域型別 `PageRequest` 最多接受 256 行。桌面執行時每批最多請求 128 行，名稱資料預算為 64 KiB。Qt 完整提交小結果，大結果最多常駐 1,024 行。會話、查詢、代數、修訂號或偏移不匹配的響應不能替換目前資料。[查詢實現](../../../crates/xdzip-runtime/src/query.rs)、[列表與排序](../../../crates/xdzip-runtime/src/listing.rs)、[大型歸檔索引](../engineering/large-index.md)

<a name="xdzip-选区与操作输入"></a>

## 選區與操作輸入

Qt 模型對已載入的結果按身份記錄選區，對大結果則記錄目前結果內的有界區間。全選覆蓋目前結果。任務能區分整包操作與明確選中的搜尋結果。進入解壓確認前，Rust 透過 `FreezeSelection` 按完整查詢鍵解析跨頁選區。展開目錄會解析實際後代，並按物理條目編號去重。超過操作限額會返回錯誤。CLI 透過 `SelectMembers` 解析成員路徑和物理條目編號。

解壓、檢查和修改分別準備自身的作業，持有操作所需的來源及後設資料。建立接收選項，再掃描和驗證獨立的 `InputTree`。後設資料預檢可說明潛在問題，但不會給任務輸出許可權。寫出前，執行時複核輸入並取得相應授權。作業一旦持有自己的選區，後續介面操作便不會改變其範圍。[桌面模型](../../../apps/desktop/BrowserController.cpp)、[執行時命令](../../../crates/xdzip-runtime/src/service.rs)、[任務排程](task-scheduling.md)

<a name="xdzip-结果与数据生命周期"></a>

## 結果與資料生命週期

| 資料 | 生命週期 |
| --- | --- |
| 目前歸檔、查詢和磁碟索引 | 歸屬目前服務會話。更換查詢或關閉會話會釋放相應私有資料，作業獨立持有的資源可繼續使用。重新開啟歸檔時重建磁碟後設資料索引。 |
| 任務快照 | 執行時釋出受限的快照，記錄實際狀態、位元組數、項目數、清理狀態和有限明細。桌面透過所屬控制器在本次應用會話內保留任務結果。 |
| 使用者設定 | 與歸檔索引和任務結果分別管理。資料保留和隱私見設定與隱私契約。 |
| 工作區與日誌 | 私有輸出暫存及相對路徑釋出記錄用於清理和檢查。重啟不會重放未完成的歸檔寫入。 |

<a name="xdzip-尚未实现的设计选项"></a>

## 尚未實現的設計選項

增量釋出可搜尋索引、帶獨立修訂號和啟動令牌的可複用計劃，以及持久化的分頁任務歷史，屬於設計選項。目前命令分別準備有界作業併入隊，只保留目前查詢和有界任務快照。持久化恢復還需要單獨設計來源及輸出的驗證流程。
