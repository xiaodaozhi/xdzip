# XDZip 產品要求

[English](../../design/product-requirements.md) | [简体中文](../../zh-CN/design/product-requirements.md) | 繁體中文（台灣） | [日本語](../../ja-JP/design/product-requirements.md) | [한국어](../../ko-KR/design/product-requirements.md) | [Français](../../fr-FR/design/product-requirements.md) | [Deutsch](../../de-DE/design/product-requirements.md) | [Español](../../es-ES/design/product-requirements.md) | [Português (Brasil)](../../pt-BR/design/product-requirements.md) | [Русский](../../ru-RU/design/product-requirements.md)

XDZip 支援像瀏覽資料夾一樣檢視壓縮檔、處理選取的內容，並在格式允許時建立或修改壓縮檔。桌面應用程式與[獨立 CLI](../engineering/command-line.md)共用壓縮檔執行環境。[專案首頁](../../../README.zh-TW.md)說明目前的功能與散布方式。下列需求說明需要保留和驗證的行為。

<a name="xdzip-要求与实现"></a>
<a name="要求與實現"></a>

## 需求與實作

| 編號 | 需求 | 目前行為或範圍 |
| --- | --- | --- |
| P01 | 瀏覽時不自動解壓縮 | 開啟時探測來源，完成受限制的掃描後才發布第一頁。解碼項目內容需要另外操作。 |
| P02 | 瀏覽、搜尋、排序和選取 | 已實作穩定的實體編號、獨立瀏覽識別碼、分頁查詢與受限的選取範圍。一般單檔 ZIP/ZIP64 可使用較大的中繼資料索引，工作另有限額。 |
| P03 | 解壓縮選取內容或整個壓縮檔 | 執行環境會固定操作範圍、驗證名稱並授權目標位置，處理名稱衝突的決定，並回報實際提交、略過、失敗與取消的結果。 |
| P04 | 從檔案與資料夾建立壓縮檔 | 依建立登錄表驗證參數，將編碼結果暫存並驗證後再發布。支援的格式和建立選項由登錄表提供。 |
| P05 | 依支援能力提供操作 | 介面結合格式描述和目前工作階段狀態顯示操作。執行環境仍會驗證每個請求。讀取、預覽、檢查、建立、密碼和分割檔案各有適用限制。 |
| P06 | 在限制內執行背景工作並支援取消 | 中繼資料與耗時工作使用獨立執行路徑。桌面應用程式依序接納耗時操作，已接受的工作可在分頁關閉後繼續。 |
| P07 | 在已驗證的授權與限額內安全寫入 | 主程式規則涵蓋名稱、連結、檔案識別、暫存、實際輸出和提交。格式層檢查相關結構與完整性。 |
| P08 | 提供一致且可存取的桌面控制項 | QML 和 C++ 提供共用控制項、鍵盤導覽、焦點和無障礙功能。原生輸入法、螢幕閱讀器和顯示行為需要在相應平台驗證。 |
| P09 | 資源耗用可測量且受限制 | 程式碼套用各自的資源限額。效能目標與實測結果分別記錄。 |
| P10 | 讓格式實作獨立於 Qt | Rust trait、明確的登錄表路由和專用工作程序介面支援內建實作。桌面應用程式和 CLI 共用核心。 |
| P11 | 保護密碼與使用者資料 | 壓縮檔操作可離線使用。密碼儲存在使用範圍受限且可清零的容器中。隱私、診斷輸出及主動更新連線各有契約。 |
| P12 | 發行內容和來源可供稽核 | 使用規定的打包管道、鎖定的輸入、資訊清單、檢查碼、授權資料和平台檢查。驗證結果適用於實際檢查的建置和發行版本。 |
| P13 | 第三方擴充功能須通過信任和權限驗證 | XDP1 唯讀試驗已獨立實作。產品內安裝與啟用仍處於設計階段。 |
| P14 | 提供受限制的預覽與暫時開啟功能 | 屬性面板可見時，選取一個支援的檔案會自動開始受限制的文字或圖片預覽。明確開啟符合條件的一般檔案項目時，使用已驗證的私人副本並交給系統關聯的應用程式。 |
| P15 | 準確回報失敗與不確定結果 | 穩定的錯誤與受限的結果涵蓋來源變更、磁碟故障、略過的項目與清理。重新啟動後自動復原仍是設計選項。 |

<a name="xdzip-工作流程与操作范围"></a>

## 工作流程與操作範圍

- **開啟和檢視。** 開啟請求會交給桌面工作階段協調器。掃描成功後建立工作階段，搜尋和排序會產生新查詢。按兩下可進入目錄，或透過暫存副本開啟符合條件的檔案。屬性面板可見時，選取一個支援的檔案會自動開始預覽。[瀏覽與預覽](../user-guide/browse.md)、[暫時開啟](../engineering/archive-opening.md)
- **解壓縮。**「全部解壓縮」指整個壓縮檔。若只要解壓縮符合搜尋條件的項目，請在查詢結果中選取並檢查實際範圍。中繼資料預檢會在取得寫入授權前回報發現的問題。逐檔提交可在後續失敗或取消時保留已完成的檔案。[解壓縮](../engineering/zip-safe-extraction.md)、[工作排程](task-scheduling.md)
- **建立、修改或檢查。** 建立與符合條件的編輯會在發布前驗證暫存輸出。檢查操作會依格式驗證符合條件的壓縮檔，不取得輸出授權。可用操作取決於格式、項目及來源設定。[格式登錄表](../engineering/format-registry.md)、[壓縮檔傳輸](../engineering/archive-transfers.md)、[壓縮檔檢查](../engineering/archive-checking.md)

<a name="xdzip-规划范围与验证"></a>

## 規劃範圍與驗證

外部擴充功能管理、持續性工作復原和更多格式設定需要各自設計、實作與驗證。版本號本身無法證明支援哪些格式或平台。雲端壓縮檔同步、掛載磁碟映像檔及惡意軟體掃描服務不在產品範圍內。[追蹤矩陣](requirements-traceability.md)將各項需求連結至對應驗證。[支援政策](../engineering/support-policy.md)和版本資訊說明實際散布的版本。
