# XDZip 產品要求

[English](../../design/product-requirements.md) | [简体中文](../../zh-CN/design/product-requirements.md) | 繁體中文（台灣）

XDZip 支援像瀏覽資料夾一樣檢視歸檔、處理選定的內容，並在格式允許時建立或修改歸檔。桌面與[獨立 CLI](../engineering/command-line.md)共用歸檔執行時。[專案首頁](../../../README.zh-TW.md)說明目前能力與分發方式。下列要求說明需要保留和驗證的行為。

<a name="xdzip-要求与实现"></a>

## 要求與實現

| 編號 | 要求 | 目前行為或範圍 |
| --- | --- | --- |
| P01 | 瀏覽時不自動解壓 | 開啟時探測來源，完成有界掃描後再發布第一頁。解碼條目內容需要單獨操作。 |
| P02 | 導航、搜尋、排序和選擇 | 已實現穩定的物理編號、獨立導航身份、分頁查詢與有界選區。普通單檔案 ZIP/ZIP64 支援更大的後設資料索引，任務另有限額。 |
| P03 | 解壓選中內容或整包 | 執行時凍結操作範圍、校驗名稱並授權目標，支援重名決定，報告實際提交、跳過、失敗與取消。 |
| P04 | 用檔案與目錄建立歸檔 | 按建立登錄檔校驗引數，編碼到暫存後驗證再發布。格式和建立選項按登錄檔提供。 |
| P05 | 按能力提供操作 | 介面結合格式描述和目前會話狀態顯示操作。執行時仍校驗每個請求。讀取、預覽、檢查、建立、密碼和分卷配置各有限制。 |
| P06 | 有界執行背景任務並支援取消 | 後設資料和重任務使用獨立執行路徑。桌面序列准入重操作，已接收的任務可在標籤頁關閉後繼續。 |
| P07 | 在授權和限額內安全寫出 | 宿主規則覆蓋名稱、連結、檔案身份、暫存、實際輸出和提交。格式層檢查相應結構和完整性。 |
| P08 | 提供一致且可訪問的桌面控制元件 | QML 和 C++ 提供共享控制元件、鍵盤導航、焦點和輔助功能行為。原生輸入法、螢幕閱讀器和顯示行為需要對應平臺驗證。 |
| P09 | 資源開銷可測量並受約束 | 程式碼執行獨立預算。參考效能目標與實測結果分別記錄。 |
| P10 | 讓格式實現獨立於 Qt | Rust trait、顯式登錄檔路由和專用工作程序介面承載內建實現。桌面和 CLI 共用核心。 |
| P11 | 保護密碼與使用者資料 | 歸檔操作可離線使用。密碼儲存在限定作用域的可清零容器中。隱私、診斷輸出及主動更新訪問各有契約。 |
| P12 | 發行內容和來源可審計 | 使用規定的打包渠道、鎖定輸入、清單、校驗和、許可材料和平臺檢查。驗證結論對應實際檢查的構建與發行渠道。 |
| P13 | 第三方擴充套件須透過信任和許可權校驗 | XDP1 只讀試驗已獨立實現。產品內安裝與啟用仍屬於設計工作。 |
| P14 | 按明確操作預覽或臨時開啟 | 屬性面板可請求有界文字或圖片預覽。開啟普通條目使用已驗證的私有副本，並交給系統關聯應用。 |
| P15 | 準確報告失敗與不確定結果 | 穩定的錯誤碼和有界結果涵蓋來源變化、磁碟失敗、跳過與清理。重啟後自動恢復仍為設計選項。 |

<a name="xdzip-工作流程与操作范围"></a>

## 工作流程與操作範圍

- **開啟和檢視。** 開啟意圖進入桌面會話協調器。掃描成功後釋出會話，搜尋和排序生成新查詢。雙擊進入目錄，或透過臨時副本開啟符合條件的檔案。預覽在屬性面板單獨發起。[瀏覽與預覽](../user-guide/browse.md)、[臨時開啟](../engineering/archive-opening.md)
- **解壓。** “解壓全部”指整個歸檔。只解壓匹配項時，在查詢中選擇並檢查實際範圍。後設資料預檢在取得寫許可權前報告發現。逐檔案提交使已完成檔案在後續失敗或取消時仍能保留。[解壓](../engineering/zip-safe-extraction.md)、[任務排程](task-scheduling.md)
- **建立、修改或檢查。** 建立與符合條件的編輯在釋出前驗證暫存輸出。整包檢查按對應格式核驗符合條件的歸檔，不取得輸出授權。支援的操作取決於格式、條目及來源配置。[格式登錄檔](../engineering/format-registry.md)、[歸檔傳輸](../engineering/archive-transfers.md)、[歸檔檢查](../engineering/archive-checking.md)

<a name="xdzip-规划范围与验证"></a>

## 規劃範圍與驗證

擴充套件管理、任務持久化恢復和更多格式配置需要各自的設計、實現與驗證。版本號本身無法說明格式或平臺覆蓋範圍。雲端歸檔同步、掛載磁碟映象和惡意軟體掃描服務不在產品範圍內。[追蹤矩陣](requirements-traceability.md)把每項要求關聯到對應驗證。[支援政策](../engineering/support-policy.md)和發行說明描述實際分發的版本。
