## 從歸檔視窗解壓

1. 開啟壓縮檔。選取項目後，工具列的主要按鈕會解壓所選項目；若未選取，則會解壓整個壓縮檔。也可以按按鈕旁的箭頭，明確選擇「全部解壓」或「解壓所選」。
2. 確認解壓範圍，選擇有寫入權限的目的地。若介面提供選項，也可以建立以壓縮檔命名的資料夾。
3. 選擇名稱衝突時的處理方式。「詢問我如何處理」會暫停並等待決定，「跳過已有檔案」會保留現有檔案，「自動改名，保留兩個版本」會另存一份，「覆蓋已有檔案」則會在驗證後取代符合條件的檔案。
4. 開始解壓並查看任務結果。失敗或取消時，先前已儲存的檔案可能會保留。重試前，請查看結果詳情，確認還有哪些項目未處理。[檢查、任務與結果](checks-and-tasks.md)

解壓選單也提供「解壓後設資料預檢」。明確選取最多 128 個壓縮檔中的實際記錄後，預檢會報告不安全的名稱、不支援的方式及宣告資料超出限制等問題。僅供瀏覽的隱含資料夾仍可在格式支援時解壓。預檢不讀取檔案內容，也不授予寫入權限。[預檢與解壓限制](../engineering/extraction-preflight.md)

使用磁碟索引的大型 ZIP 可在任務限制內解壓所選的一般檔案。如果整個壓縮檔超出解壓限制，請縮小選取範圍。若來源已變更或被取代，請重新開啟並再次選取所需項目。[大歸檔限制](../engineering/large-index.md)

## 從檔案管理器解壓

在 Windows 11 中，選擇「顯示更多選項」可開啟傳統選單；Microsoft Store 版本也可能在現代選單顯示操作。Ubuntu 使用 Nautilus 擴充功能。macOS 可在系統設定中啟用 Finder 擴充功能，也可使用已註冊的 Finder 服務。找不到選單時，請在 XDZip 中開啟壓縮檔，再從視窗中解壓。

檔案管理器選單可以將檔案解壓到各壓縮檔所在的資料夾、為每個壓縮檔建立個別資料夾、使用智慧資料夾，或讓你選擇目的地。驗證後的輸出恰好包含一個最上層資料夾時，智慧解壓才會省略外層資料夾。批次操作會顯示每個壓縮檔的結果，單一壓縮檔失敗後仍繼續處理其餘檔案。取消會停止後續項目，並請求停止目前的工作。[檔案管理器操作與設定](../engineering/shell-actions.md)
