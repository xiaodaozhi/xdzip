# 高保真狀態與實現契約

本文介紹建立、解壓及任務視窗在不同狀態下的行為、焦點和關閉方式，並關聯[操作狀態原稿](../../../design/hifi/README.md)與[統一素材庫](../../../design/assets/README.md)。下表的編號用於對應設計圖板，不改變實際任務協議。

<a name="xdzip-画面与任务语义"></a>

## 畫面與任務語義

| 狀態 / 圖板 | 進入條件 | 預設焦點與操作 | 關閉與恢復 |
| --- | --- | --- | --- |
| C01 / 01 | 新建，尚無執行任務 | 首個輸入按鈕或檔名；建立前校驗輸入、名稱、目標、能力 | 放棄本視窗草稿；不產生寫入 |
| E02 / 02 | 任務快照帶有仍有效的重名提示 | 跳過、重新命名和覆蓋均由使用者決定，重新命名為主按鈕，“應用後續”預設不選 | 關閉提示後任務繼續等待。可從任務入口重新開啟提示，也可在任務視窗取消 |
| T01 / 03、08 | 已接受計劃並收到執行事件 | 返回瀏覽與取消均為普通按鈕；沒有虛構的暫停能力 | 僅隱藏檢視；任務入口可重開；背景完成不搶焦點 |
| T01 / 完整性檢查 | 與任務進度同一元件，唯讀壓縮檔與驗證階段 | 返回瀏覽、取消檢查與真實任務結果；Qt 元件預覽繼續標記 | 關閉不取消任務，真實檢查經工具欄接入背景佇列 |
| R01 / 04 | 本次任務有已釋出項和未完成項 | 重試僅選未完成項，重新進入計劃確認 | 關閉檢視不刪除已提交檔案 |
| S01 / 05 | 開啟設定，選擇六個標籤之一 | 所有編輯可用鍵盤訪問；修改成功後即時生效，地址須透過校驗 | 關閉保留已生效的設定，失敗保留原值 |
| R02 / 06 上 | 收到唯一成功終態 | 解壓可按顯式選項開啟目標資料夾；建立僅在應用內開啟受支援結果，不自動開啟系統目錄；零失敗計數用中性狀態 | 關閉詳情，不重複通知完成 |
| T02 / 06 中 | 已接受取消，清理尚未完成 | 重複取消停用；仍可返回瀏覽 | 可隱藏；不能提前顯示“已取消” |
| R03 / 06 下 | 收到取消終態 | 保留已釋出項；若允許重試，重新規劃未完成範圍 | 關閉不回滾已釋出項 |
| C02 / 07 | 該原稿展示輸出歸檔已存在的場景 | 實際建立衝突使用目前任務的安全命名與提交規則 | 關閉提示後任務繼續等待。明確選擇重新命名、替換或取消後檢視任務結果 |

“使用新名稱”只提出建議名，真正開始時仍驗證目標是否已存在；不能把檔名檢查當作最終寫入授權。替換建立必須先完整生成並驗證臨時壓縮檔，釋出前再檢查目標條件。取消要求在線性化提交點之後到達時按核心結果顯示已完成，不把成功改寫為取消。

<a name="xdzip-新建能力与字段错误"></a>

## 新建能力與欄位錯誤

- ZIP 的四檔級別對映 Store／Deflate 1／6／9，預設 2-正常壓縮。TAR／TAR.GZ 可建立，格式切換同步副檔名並清空密碼與分卷；TAR 停用級別，TAR.GZ 級別 0／1／2／3 對映 GZIP 0／1／6／9。修改格式同步副檔名，但不能靜默覆蓋既有目標。
- 無輸入、空名稱、目標無效或無許可權時，建立按鈕停用，原因顯示在相鄰欄位。錯誤文字參與螢幕報讀，不只改變邊框顏色。
- 同一輸入去重與目錄展開由核心處理；UI 只展示選擇摘要。建立頁的影像圖示是型別標誌，不進行圖片預覽。
- ZIP 與 7z 提供各自支援的密碼與分卷設定，7z 還可以加密檔名。實際寫入能力以格式登錄檔為準。[ZIP 建立](../engineering/zip-creation.md)、[格式登錄檔](../engineering/format-registry.md)

<a name="xdzip-任务数据与异常"></a>

## 任務資料與異常

樣例 A 為 3 個檔案：8.4 + 6.2 + 12.8 = 27.4 MB。成功 2 個時已儲存 14.6 MB，剩餘 PDF 為 12.8 MB；成功、跳過、未完成的計數不可混淆。樣例 B 為整個壓縮檔：30 個檔案、77.5 MB；46.5 MB 對應 60%，不是樣例 A 的同一個時刻。

百分比來源於已知總位元組與真實計量；未知總量顯示不定進度、不編造剩餘時間。階段變化後重新估算速率；圖中 6.2 MB/s、約 5 秒僅為穩定階段示例。檔案計數標明已完成還是正在處理，不以目前條目序號當成功數。

磁碟滿：停止並保留已釋出項，釋放空間或修改目標後重新規劃。源變化：重試入口改為重新開啟壓縮檔，不能沿用舊索引。單純取消：未完成用琥珀/中性色，不顯示壓縮檔損壞。錯誤碼位於詳情，普通畫面不出現呼叫堆疊或內部橋接術語。

<a name="xdzip-设置即时生效契约"></a>

## 設定即時生效契約

主題、字號、密度、語言、開啟方式和隱私開關操作成功後立即持久化並生效；清空最近記錄立即執行，不刪除原檔案。失敗保留原設定並提示。關於與更新位於設定的關於頁；檔案關聯由作業系統確認並反映真實結果，網路頁儲存經校驗的代理伺服器與鏡像網址。詳細行為見[設定契約](settings-localization.md)。

單檔案 8 GiB、任務 20 GiB 為現有宿主的預設輸出預算，目前設定視窗不提供額度編輯。未來若增加限額設定，須檢查正整數與溢位、單檔案不大於任務上限，並只應用於新計劃；不得更改執行中任務的不可變授權或繞過空間檢查。

<a name="xdzip-窗口布局与素材映射"></a>

## 視窗、佈局與素材對映

全部操作窗遵循 [平台視窗規範](platform-windows.md)。macOS 原生標題欄不採用切圖交通燈；Windows/Linux 標題欄按鈕位置、停用、系統選單和移動行為由平台層驗證。平台對照圖中的 Linux 右側控制元件不是對所有桌面環境的硬編碼承諾。

目前尺寸以[佈局規範](../../../specs/visual/layout-scale.json)、[視窗登記](../../../specs/visual/window-registry.json)及[設計規範](../visual/design-standard.md)為準，替代早期大尺寸建議。建立、解壓、衝突、進度與結果統一寬 491；設定寬 612，屬於已登記的用途差異。標題 20、正文 13，頁尾按鈕 13、說明文字 12。高度按各視窗內容和上限約束，正文可滾動；有頁尾的操作視窗保持頁尾固定且可操作，設定視窗沒有頁尾。設定提供 100%／125%／150% 字號，不以整體縮放或截圖物理畫素推導元件尺寸。

| 使用位置 | 新增素材 | 共享 / 動態部分 |
| --- | --- | --- |
| 新建標題、新增輸入 | archive-add、image-file、remove | folder、file-pdf、new |
| 衝突、部分失敗 | document-warning、status-warning、info | file-pdf；比較卡與文字由 QML 繪製 |
| 執行進度 | document-download、image-file、info | 進度條與數字動態繪製 |
| 成功、跳過、取消、停止 | status-success、status-skipped、status-stopped、spinner、clock | spinner 旋轉由 Qt 控制元件處理 |
| 設定 | settings-tile、theme-system | 主題預覽、開關、數字輸入為元件；settings 用於小圖示 |

素材統一位於 `design/assets/`。`reference/` 保留原畫素切片，用於外觀對照；`svg/` 和 `png/` 為透明執行素材，不能混稱原稿圖層。全部 SVG 使用 24×24 畫布，PNG 匯出 24×24、48×48、72×72；各倍率保持相同邏輯顯示尺寸。Qt 檔案列表採用約 31.75×39.69 邏輯畫素槽位。PDF、文字、程式碼與 Markdown 圖示共用中心與 22 畫素可見高度，保留不同的輪廓寬度；資料夾在相同畫布內居中。深色 SVG 是素材適配，完整深色行為仍需 Qt 實機與對比度檢查。

<a name="xdzip-目录树组件补充"></a>

## 目錄樹元件補充

B01 瀏覽新增[目錄樹 B 規格](directory-tree.md)，配套三張正式圖板與 26 張統一切片。節點箭頭由子目錄決定；展開、目前目錄和鍵盤焦點獨立。讀取、空壓縮檔、根檔案、導航超限、失敗與隱藏目前路徑分別規定，既有隻讀領域契約不變。Qt 已接入核心導航、連線線和隱藏目前分支標記；骨架與專用邊界圖示仍為設計資源，接入範圍見目錄樹規格。

<a name="xdzip-变更与复验"></a>

## 變更與複驗

主要狀態已用於 Qt 實現。後續變更仍須核對原稿及修訂引數、控制項功能對映、共享元件與視窗契約，並執行受影響平台驗證；不能僅憑稿件或靜態檢查確認原生功能和可訪問性。實際結論在對應 issue 登記，歷史驗收不因本頁清單重置。
