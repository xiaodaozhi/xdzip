# v0.1 互動原型與功能對映

[English](../../ux/prototype-spec.md) | [简体中文](../../zh-CN/ux/prototype-spec.md) | 繁體中文（台灣）

狀態：可互動設計驗證稿。原始檔在 [design/html](../../../design/html/README.md)，入口為 [index.html](../../../design/html/index.html)。Figma 工作稿保留為歷史探索；目前功能與狀態細化在倉庫內繼續。

<a name="xdzip-交互决定"></a>

## 互動決定

<a name="xdzip-选择与搜索"></a>

### 選擇與搜尋

- 每項選擇對應穩定條目 ID，不依賴排序後的行號。切換查詢/目錄清空選擇，避免隱藏選擇誤解。
- 目前列表全選與整個壓縮檔解壓是兩個獨立概念。資料夾勾選展開為去重後代檔案。
- 輸入法組合期間不提交查詢，compositionend 後更新。瀏覽器模擬事件檢查不替代 macOS/Windows/Linux 原生 IME 驗收。
- 普通檔案 Enter／雙擊臨時解壓並由系統關聯開啟，目錄 Enter／雙擊進入；屬性入口保留。HTML 僅演示進度和自動隱藏，不真正寫檔案或呼叫系統。Qt 的內容預覽另見[預覽契約](../engineering/content-preview.md)。

<a name="xdzip-解压与冲突"></a>

### 解壓與衝突

- 最終路徑實時顯示，同名目錄只追加一次。空路徑或演示不可寫路徑阻止啟動，更改目標後重新預檢。
- 預設詢問重名；可選擇跳過、自動改名或覆蓋。覆蓋後果用鄰近文案解釋。
- 衝突面板初始焦點是“跳過”，覆蓋不是預設 Enter。應用到後續衝突的選項限定本次任務；演示資料僅產生一個衝突。
- 改名同時體現在完成摘要和檔案明細中。跳過不計為失敗；示例已有檔案不在完成寫入計數內。

<a name="xdzip-任务与结果"></a>

### 任務與結果

- 返回瀏覽不取消任務；狀態列可以再次開啟任務。
- 請求取消 → 正在停止（重複取消禁用）→ 已取消摘要。解壓保留已釋出項；建立壓縮檔沒有中間釋出。
- 磁碟滿停止任務並保留成功項。重試只取失敗/未完成範圍，重新進入計劃確認。
- 源變化要求重新開啟壓縮檔，不靜默複用舊索引。
- 建立任務以一個最終壓縮檔計數；取消時“已建立壓縮檔”為 0，明確舊壓縮檔不變。

<a name="xdzip-创建压缩包与能力"></a>

### 建立壓縮檔與能力

原型展示 ZIP 壓縮級別、TAR 打包和 GZIP 壓縮選項，檢查輸入、名稱和目標欄位，並隨格式更新副檔名。目前產品的選項由[內建格式登記](../engineering/format-registry.md)提供，包括 [ISO](../engineering/iso-creation.md) 與 [Windows 自解壓包](../engineering/sfx-creation.md)建立配置。可用的密碼和分卷選項見[密碼互動](password-extraction.md)與[分卷契約](../engineering/archive-opening.md)。

<a name="xdzip-视觉与适配"></a>

### 視覺與適配

沿用暖灰、鈷藍和石墨主題。標準行高 40、緊湊 32；深色文字強調色獨立於按鈕填色，以提高小字辨識度。桌面寬度不足時詳情作為可關閉浮層。手機審閱佈局收起側欄和次要表格列，操作面板適配窄屏並可滾動。

操作介面按[平臺視窗規範](platform-windows.md)設計為獨立視窗。HTML 使用 dialog 模擬：決策窗限制焦點，進度、結果與設定為非模態；關閉後盡力恢復焦點。關閉衝突窗會取消任務而非靜默跳過；關閉進度窗僅隱藏詳情。正式 Qt 使用獨立頂層視窗。

<a name="xdzip-主题选择控件"></a>

### 主題選擇控制元件

設定頁以 `fieldset#setting-theme` 和“外觀主題”圖例組織三個原生單選輸入：跟隨系統、淺色、深色。每張主題卡片使用共用的 `theme-system`、`theme-light` 或 `theme-dark` 素材，文字標籤和輸入關聯；點選卡片、鍵盤切換和焦點均由實際單選控制元件參與。選中狀態採用共用單選標誌，切換時同步卡片邊框與預覽外觀，不用不可互動的整塊截圖代替控制元件。

此說明記錄 HTML 設計驗證行為。目前設定仍為記憶體狀態；跟隨系統只在選擇時解析，執行中的系統主題變化、跨啟動持久化以及 Qt 正式設定的即時持久化和失敗處理仍分別驗證。

<a name="xdzip-验证与剩余边界"></a>

## 驗證與剩餘邊界

瀏覽器驗證指令碼為 scripts/check-html-design.py，檢查實際點選流程、統計、禁用條件、格式聯動、異常恢復、手機溢位以及單檔案離線執行。報告隨匯出的原型包提供；瀏覽器驗證僅使用 Chromium。

主視窗目前交付兩個獨立示例壓縮檔會話、列表 / 網格、欄位排序、遞迴目錄樹、分級麵包屑、右鍵 / 下拉 / 子選單以及按鈕狀態，詳見[元件與互動契約](main-window-components.md)及[驗證方法](../../../developers/qa/README.md)。`scripts/check-html-controls.py` 使用真實瀏覽器輸入檢查這些行為；[元件審閱頁](../../../design/html/components.html)使用與主介面相同的實現。

HTML 僅驗證示例狀態，不證明真實任務排程、授權、路徑競態、CRC 或平臺輔助功能。Qt 已接入真實建立／解壓、拖放、系統選擇器、持久設定及可選標籤頁或多視窗的獨立歸檔會話。多格式、普通單檔案 ZIP 百萬條索引和受限預覽的實際範圍分別見[格式後端](../engineering/native-codecs.md)、[大索引](../engineering/large-index.md)和[內容預覽](../engineering/content-preview.md)；驗收在對應 issue 登記。HTML 設定只在頁面內儲存演示狀態，不跨啟動持久化，不作為原生系統主題跟隨或輔助功能的透過依據。

這些限制不改變軟體設計中的目標能力。原型中的“已完成”僅描述演示任務狀態，不代表真實壓縮解壓功能已交付。

<a name="xdzip-当前目录查询与卡片修订"></a>

## 目前目錄查詢與卡片修訂

根入口為“根目錄”，只列直屬檔案和資料夾；搜尋匹配目前範圍的後代，並顯示完整壓縮檔內路徑。普通列表／網格只顯示末級名稱，複製與導航保留完整路徑。麵包屑右側顯示目前列表行數。目錄樹標題為“壓縮檔”，與麵包屑垂直中心一致；樹懸停不彈出浮動提示。

列表懸停覆蓋整行；網格有 16 邏輯畫素左右內邊距，左上 8 畫素的核取方塊懸停可見、選中常駐。所有按鈕呼叫選單與按鈕間隔 4，選單使用柔和陰影。預覽重新開啟按鈕固定為 28 方形。對應引數位於 layout-scale.json、directory-tree.json 和 controls.json，實際驗證按[通用方法](../../../developers/qa/README.md)登記。

<a name="xdzip-设置窗口"></a>

## 設定視窗

設定保留原稿的圖示標題、主題預覽卡片、密度、最近記錄和隱私說明，增加文字大小與介面語言。主題和字號預覽可取消；儲存與恢復預設均使用草稿。HTML 只在目前頁面內儲存演示狀態，語言選擇展示 Qt 下次啟動生效的配置，不將設計審閱頁或示例壓縮檔內容作為產品翻譯覆蓋證據。Qt 使用完整中英文資源與跨程序持久化驗證，詳見[設定與語言](settings-localization.md)。
