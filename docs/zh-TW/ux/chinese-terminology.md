# 簡體中文介面術語

[English](../../ux/chinese-terminology.md) | [简体中文](../../zh-CN/ux/chinese-terminology.md) | 繁體中文 | [日本語](../../ja-JP/ux/chinese-terminology.md) | [한국어](../../ko-KR/ux/chinese-terminology.md) | [Français](../../fr-FR/ux/chinese-terminology.md) | [Deutsch](../../de-DE/ux/chinese-terminology.md) | [Español](../../es-ES/ux/chinese-terminology.md) | [Português (Brasil)](../../pt-BR/ux/chinese-terminology.md) | [Русский](../../ru-RU/ux/chinese-terminology.md)

面向使用者的簡體中文文案遵循[術語設定](../../../specs/ux/chinese-terminology.json)。Qt 靜態文案保留 resources/i18n/zh-CN.json 中的穩定 ID。HTML、目前的高擬真設計和使用說明採用下表的簡體中文原文。工程和格式文件可使用技術術語。元件尺寸、主視窗 0.8／選單 1 的密度、DPR 和縮放參數沿用既有設定。

| 語義 | 統一用語 | 使用示例 |
| --- | --- | --- |
| ZIP、TAR 等容器檔案 | 压缩包 | 压缩包名称、空压缩包、压缩包信息 |
| 完整動作名稱 | 打开压缩包、创建压缩包、解压 | 工具列已有明確情境時，可簡寫為「打开」、「新建」 |
| 壓縮檔內的項目 | 文件、文件夹、内容 | 所选文件和文件夹、全部内容 |
| 檔案屬性 | 原始大小、压缩大小 | 欄位標題、預覽屬性和排序選單使用相同名稱 |
| 還原項目的實體順序 | 按原始顺序排列 | 有別於依名稱或大小排序 |

「档案文件」不屬於產品術語。「归档」、「归档文件」和「归档格式」僅用於工程規範、格式說明或公開 API。TAR 即使只打包而未壓縮，介面也會使用「压缩包」。實際的壓縮能力由格式和壓縮等級表示。

「压缩文件」只能表示動作，例如「正在压缩文件」，不能用作容器名稱。屬性名稱使用「压缩大小」，停用「压缩后」。建立視窗預設使用「新建压缩包.zip」，不會改動現有檔名。

保留使用者提供的名稱和路徑、壓縮檔內的檔名、通訊協定欄位、程式碼識別碼和歷史高擬真圖片。英文依英文語法使用通用名稱 archive，「全部内容」對應 All contents。窄欄位標題使用 Compressed 表示 compressed size。不得依中文術語替換英文程式碼識別碼。

目前的高擬真文案請參閱術語狀態設計。原始圖片、雜湊和文字墨跡量測作為歷史依據。正文量測指令碼會依明確的歷史標籤對應關係檢查新文案，沿用原本的尺寸目標和容許差。文案加長後仍須確認主視窗、欄位標題、預覽和選單皆能完整顯示。

執行 `python3 scripts/check-ui-i18n.py` 檢查所有產品語言資源和簡體中文術語。術語檢查僅適用於產品的靜態文案，允許明確核准的「压缩文件」動作用法，不限制使用者內容或工程術語。

依據專案負責人在 [#270](https://github.com/xiaodaozhi/xdzip/issues/270) 確認的名稱，系統檔案管理員保留「添加到压缩文件...」和「解压每个压缩文件到单独的文件夹」。設定僅對這兩個穩定 ID 的完整文字登記例外，其他位置仍使用既定的容器名稱。
