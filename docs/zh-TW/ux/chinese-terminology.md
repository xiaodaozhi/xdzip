# 簡體中文介面術語

[English](../../ux/chinese-terminology.md) | [简体中文](../../zh-CN/ux/chinese-terminology.md) | 繁體中文（台灣）

面向使用者的中文文案以[術語配置](../../../specs/ux/chinese-terminology.json)為準。Qt 靜態文案繼續使用 resources/i18n/zh-CN.json 的穩定 ID，HTML、目前高保真設計與使用者說明同步採用下表；工程和格式文件可以使用技術術語。此次不改變元件尺寸、主視窗 0.8／選單 1 的密度、DPR 或縮放引數。

| 語義 | 統一用語 | 使用示例 |
| --- | --- | --- |
| ZIP、TAR 等容器檔案 | 壓縮檔 | 壓縮檔名稱、空壓縮檔、壓縮檔資訊 |
| 完整動作名稱 | 開啟壓縮檔、建立壓縮檔、解壓 | 工具欄已有明確上下文時可簡寫“開啟”“新建” |
| 包內物件 | 檔案、資料夾、內容 | 所選檔案和資料夾、全部內容 |
| 檔案屬性 | 原始大小、壓縮大小 | 表頭、預覽屬性、排序選單使用同一名稱 |
| 按物理條目順序恢復排序 | 按原始順序排列 | 與按名稱、大小排序區分 |

“檔案檔案”不作為產品術語。“歸檔”“歸檔檔案”“歸檔格式”僅用於工程規範、格式說明或公共 API 語境，不混入普通中文介面。TAR 即使只打包不壓縮，介面仍使用“壓縮檔”，其具體壓縮能力透過格式和壓縮級別表達。

“壓縮檔案”僅可作為動作，例如“正在壓縮檔案”，不作為容器名稱。“壓縮後”不再作為屬性名稱，統一為“壓縮大小”。建立視窗預設名稱為“新建壓縮檔.zip”，這不意味著修改已有檔名。

使用者提供的名稱、路徑、壓縮檔內部檔名、協議欄位、程式碼標識和歷史高保真影象不做術語替換。英文保留標準的 archive，按自身語法表達；“全部內容”為 All contents；英文大小屬性保留適合窄表頭的 Compressed 簡寫，表示 compressed size。不得按中文詞彙替換英文程式碼標識。

目前高保真文案修訂見[術語狀態稿](../../../design/hifi/terminology.html)。原圖、雜湊及文字墨跡測量保持歷史依據；[正文量測指令碼](../../../scripts/check-html-body.py)僅透過顯式的歷史標籤對映核驗新文案，不修改幾何目標或容差。標籤變長後仍需驗證主視窗、表頭、預覽與選單均完整顯示。

執行 `python3 scripts/check-ui-i18n.py` 同時檢查兩份語言資源及中文術語。檢查只針對產品靜態文案，允許明確的“壓縮檔案”動詞用法，不限制使用者內容或工程術語。

系統檔案管理器入口按所有者在 [#270](https://github.com/xiaodaozhi/xdzip/issues/270) 確認的選單名稱，保留“新增到壓縮檔案...”及“解壓每個壓縮檔案到單獨的資料夾”。配置只對這兩個穩定 ID 的完整文字登記例外，不擴大其他中文容器名稱的允許範圍。
