# 目錄樹 B：設計、素材與接入規格

[English](../../ux/directory-tree.md) | [简体中文](../../zh-CN/ux/directory-tree.md) | 繁體中文 | [日本語](../../ja-JP/ux/directory-tree.md) | [한국어](../../ko-KR/ux/directory-tree.md)

狀態：**核心目錄互動已接入 HTML 示例和 Qt 只讀瀏覽，邊界狀態資源仍待接入**。互動遵循[只讀瀏覽契約](../engineering/readonly-browser.md)，普通目錄瀏覽採用直屬子項，搜尋遞迴目前範圍，輸出授權保持只讀。

三張目前圖板位於 [多級展開](../../../design/hifi/screens/directory-tree-capsule.png)、[節點與互動狀態](../../../design/hifi/screens/directory-tree-states.png)、[空態與導航邊界](../../../design/hifi/screens/directory-tree-boundaries.png)。[統一畫廊](../../../design/hifi/index.html#components)展示整幅圖板，[素材庫](../../../design/assets/index.html#directory-tree)提供逐項切圖。多級展開圖從[可編輯設計源](../../../design/hifi/sources/main.html?tree=expanded)匯出，標題欄同步目前膠囊標籤；圖板中的頂部和中央列表僅提供上下文，不重新定義標題欄、工具欄或檔案表格。[歷史多級展開原圖](../../../design/hifi/screens/directory-tree.png)保持原樣，繼續作為 26 張切片的來源及獨立量測依據。

圖板採用放大展示，每張卡片的區域性比例不完全相同。圖片中的文字、圓角和畫素尺寸不能直接當作控制元件尺寸；[元件引數](../../../specs/visual/directory-tree.json)明確記錄落地的邏輯尺寸，資產清單單獨記錄原圖裁剪的物理座標。實現採用 1024 邏輯寬度及統一源畫布變換，不能把這一組新元件再整體放大。

Qt 直接使用下表的邏輯值。現有 HTML 主稿採用 1548 源畫素視窗對映到 1024 邏輯畫素，轉換遵循 [display-spec.js](../../../design/html/display-spec.js)：`source CSS = logical / (1024/1548)`。因此 32 行高對應 48.375 源 CSS 畫素，11.2 字號對應 16.93125，16 圖示槽對應 24.1875，12.8 縮排對應 19.35。預覽縮放在換算之後統一作用於整個視窗；DPR 只決定取樣密度和線條對齊，不參與邏輯尺寸換算。

<a name="xdzip-树结构与计数"></a>

## 樹結構與計數

完整索引同時提供顯式和隱式目錄。葉子僅表示**沒有子目錄**，不表示沒有檔案；冰川湖若含子目錄，就有自己的展開箭頭，與其父目錄的箭頭互不替代。

```text
根目錄                             ← 目前目錄
▼ 01 照片                       12
  ▼ 冰川湖                       6
    ▸ 湖岸步道                   3  ← 有更深目錄，尚未展開
      雪山远景                   3  ← 只有檔案，保留空箭頭位置
  ▸ 山间日出                     4
    其他照片                     2  ← 沒有子目錄
▸ 02 文件                        8
  03 地圖                        4  ← 沒有子目錄
```

壓縮檔示例包含照片 12、文件 8、地圖 4 和根目錄檔案 6；根目錄列表顯示三個直屬目錄及六個直屬檔案，不展開後代。未展開分支的後代也完整列入引數檔案，避免用假箭頭裝飾葉子節點。另一張圖板中的顯式空目錄是獨立狀態樣例，不追加到這個 30 條樣例中。

目錄數字表示該字首下全部後代**物理壓縮檔記錄數**，包含重複名稱，不包含與該目錄字首完全相同的目錄記錄；它不是子目錄數量，也不隨名稱搜尋變化。樹行不顯示計數。壓縮檔摘要保留完整物理記錄數，列表標題右側只顯示目前目錄的行數；二者口徑不同。普通檔案列表顯示末級名稱，搜尋結果顯示完整壓縮檔內路徑。

箭頭只由已知子目錄決定：有子目錄且摺疊時向右，展開時向下；只有檔案或為空時不顯示，但同層級的箭頭槽、圖示槽和文字起點保持相同。讀取完整索引期間不猜測逐節點箭頭、計數或結構，也不增加逐節點非同步載入狀態。

<a name="xdzip-布局字体与动态几何"></a>

## 佈局、字型與動態幾何

| 專案 | 正常邏輯尺寸 / 行為 |
| --- | --- |
| 側欄預設寬度 | 193.16；主視窗結構邊界取整為 193 |
| 行高 | 最小 32；字型放大時按引數檔案公式增高 |
| 每層縮排 | 12.8；不隨節點型別變化 |
| 箭頭命中區 / 圖形槽 | 至少 19.2×19.2 / 14.4×14.4；葉子保留相同槽位 |
| 資料夾圖示槽 | 16×16；共享 24 單位 SVG 等比顯示，替代目前樹的 18 槽位 |
| 圖示到文字 / 行末留白 | 6.4 / 16；不顯示計數 |
| 正文 | 11.2；Qt 取 11，使用同源字型 |
| 記錄數 | 保留在資料與可訪問語義中；行內不顯示，不保留數字列 |
| 目前目錄 | 淡藍背景、右側 6.4 圓角、左側直邊與全高 2.4 寬標記 |
| 鍵盤焦點 | 不增加描邊或焦點豎線，不改變行佔位；目前目錄標記保留 |
| 層級連線線 | 1 寬；顏色與背景保持克制的層級關係 |
| 隱藏目前目錄標記 | 19.2 單位透明槽中的 4.8 單位圓點，與名稱共享行中心 |

連線線根據可見祖先鏈與最後同級節點標誌動態繪製。父層豎線經過已展開子樹，直至最後兄弟節點中心；該層的最後連線以 L 形終止，不向下一組頂層目錄延伸。每段豎線的中心 X 與父節點向下展開箭頭的尖端 X 一致，包含輔助字號放大；內層線獨立終止，不能把一張通用直線圖片貫穿全部行。線段按目標 DPR 對齊；文字、箭頭和資料夾共用行垂直中心。

層級區可橫向滾動；寬度只按目前展開可見節點的實際名稱、縮排與 16 行末留白計算。名稱完整顯示，不用數字覆蓋層。摺疊後重新計算寬度，不讓隱藏深層節點留下空白；左側指示線固定在視口邊。樹行懸停不顯示浮動 tooltip；完整路徑透過可訪問描述和詳情提供。垂直滾動只發生在目錄視口，捲軸不包住主視窗邊框。

所有目錄使用同一個資料夾資源。分支圓點、實心資訊 / 警告、分段轉輪有淺深色 SVG 和 1×/2×/3× PNG；連線線、焦點框、背景、骨架、文字與提示屬於動態元件。深色引數沿用全域性主題並補充線條和標記顏色；**完整深色目錄樹原稿仍待補齊**，不能以深色圖示匯出代替完整圖板。現有渲染與桌面驗收結論另由對應 issue 和工件記錄。

HTML／Qt 互動一致性按[驗證方法](../../../developers/qa/README.md)記錄。圖板和切圖保留原始設計歷史；目前行內計數、焦點與邊角以本文及邏輯規範為準。

<a name="xdzip-交互与独立状态"></a>

## 互動與獨立狀態

展開、目前目錄、懸停和鍵盤焦點分別儲存，可以同時發生。目錄目前態與右側檔案核取方塊的選擇狀態也是兩回事。

根目錄是始終展開的獨立導航入口，不參與普通目錄節點的展開／收起。右擊、選單鍵和 Shift+F10 開啟根目錄選單時，“收起子目錄”保持禁用，選單不顯示禁用原因副行或 tooltip。輔助功能描述使用“根目錄始終展開”，不能因根入口沒有普通樹行而解釋為沒有子目錄。普通父目錄仍按真實子目錄啟用展開／收起，普通葉子的輔助功能描述保留“該節點沒有子目錄”。這些原因只供輔助功能讀取，不渲染為可見 hint。開啟選單或點選禁用項不得改變目錄、檔案選擇或樹的展開狀態。

| 操作 | 結果 |
| --- | --- |
| 點選箭頭 | 僅展開 / 收起該節點，目錄查詢、檔案選擇和詳情保持原狀 |
| 點選名稱區或 Enter | 透過目前會話的目錄 ID 進入目錄；成功替換查詢後按既有契約重置目前目錄查詢、檔案選擇和詳情 |
| 上 / 下 | 在可見目錄行中移動焦點，不自動切換檔案列表 |
| 右 | 摺疊父節點先展開；已展開則移到首個子目錄；葉子保持原位 |
| 左 | 展開父節點先收起；其餘節點移到父目錄；頂層保持原位 |
| 收起目前目錄的祖先 | 保持目前目錄和檔案列表；隱藏焦點回到最近可見祖先 |
| 新壓縮檔會話 | 清除舊節點 ID、展開、焦點與分支圓點，不串用另一壓縮檔狀態 |

例如目前路徑為 `01 照片 / 冰川湖`，收起 `01 照片` 後，右側仍顯示冰川湖。照片行只顯示行末的藍點，不獲得冰川湖的目前目錄填充；根目錄也不能變為目前態。藍點落在**最近的可見摺疊祖先**，一個隱藏目前目錄只有一個分支標記；展開恢復後，冰川湖重新顯示目前背景。

樹本身為一個鍵盤導航入口，節點保留穩定 ID、名稱、層級、展開狀態、位置和記錄數的可訪問語義。葉子不宣告可展開；裝飾性資料夾、連線線和圓點不重複讀出。隱藏目前路徑透過可訪問描述提供，不能只依賴藍色。方向鍵和箭頭點選均不得穿透到行啟用。

<a name="xdzip-状态覆盖与恢复"></a>

## 狀態覆蓋與恢復

| 狀態 | 目錄樹 | 檔案列表 / 恢復 |
| --- | --- | --- |
| 正在讀取 | 讀取提示，記錄數未知；骨架為後續設計資源；導航禁用 | 遵循全域性讀取狀態；完整索引發布後一次替換樹 |
| 空壓縮檔 | 根目錄行不顯示數字，“此壓縮檔沒有內容” | 空列表；仍可開啟另一個壓縮檔 |
| 只有根檔案 | 根目錄行不顯示數字，“沒有子目錄” | 正常顯示六條檔案，不能把整頁改成空態 |
| 目錄索引超限 | 不釋出半棵樹；顯示“目錄超過顯示限額” | 根目錄、搜尋及合格顯式目錄瀏覽繼續按現有能力工作 |
| 讀取失敗 | 灰化導航，明確錯誤 | 重新開啟壓縮檔；不能把失敗解釋為 0 或空目錄 |
| 有子目錄的節點 | 每一級都有獨立箭頭 | 展開並不等於進入該目錄 |
| 非空 / 空葉子 | 記錄數保留在資料中；行內都不顯示計數、都沒有箭頭 | 名稱仍可啟用，空目錄可瀏覽 |
| 長名稱 / 深層級 | 全文名稱、可訪問路徑、橫向滾動與可見節點寬度 | 路徑篩選保持一致 |
| 字號 150%（200% 僅作歷史壓力場景） | 槽位和行高增長，線條重新取行中心 | 名稱、箭頭和焦點不裁切 |
| 隱藏目前目錄 | 最近可見祖先顯示分支圓點 | 列表保持目前路徑；重新展開恢復目前行 |

導航超限與全域性讀取失敗是不同狀態，原因、可用操作和計數來源不能共用一個“空目錄”模板。現有 32,768 節點、64 層和 4 MiB 目錄名稱預算來自只讀契約；設計不提升或繞過這些資源預算。

## 素材交付與實際接入

26 張原畫素切片集中在 `design/assets/reference/tree-*.png`，每張均有源圖、SHA-256、`x,y,width,height` 與用途。`component_reference_coverage` 逐項指向共享向量或動態元件；不把整行靜態圖片稱為可操作控制元件，也不對帶背景切片執行去白或偽造透明層。

| 部分 | 資源 / 繪製方式 | 目前接入情況 |
| --- | --- | --- |
| 資料夾、左右 / 向下箭頭 | `folder`、`chevron-right`、`chevron-down`，複用統一素材庫 | 既有共享資源可用；B 共享圖示與 B 尺寸已用於遞迴 HTML 行和 Qt 委託 |
| 讀取、資訊、警告 | 新增 `tree-spinner`、`tree-info`、`tree-warning` | 八張淺深色 SVG 與 24 張透明 PNG 的一部分；保留圖板實心與分段造型，未用既有輪廓圖示代替 |
| 隱藏目前分支 | 新增 `tree-active-branch` | 兩主題六張透明 PNG 已交付；HTML 與 Qt 均消費該資源，標記最近的可見摺疊祖先 |
| 連線線、目前背景、焦點、骨架、提示 | 動態繪製，引數檔案定義尺寸和主題 | 樣式與邏輯已規定，未交付第二套點陣圖控制元件 |
| 正式圖板 | `hifi/screens/directory-tree*.png` | 保留確認稿原始位元組，用於設計核對 |

HTML 與 Qt 已接入連線線、分支圓點、16 資料夾槽和目錄右鍵；HTML 示例採用完整遞迴層級，Qt 使用真實受限索引。收起目前祖先不提交查詢。載入骨架、專用資訊／錯誤圖示仍為設計資源，深色完整圖板仍待補齊；圖示接入不證明逐平臺讀屏或 HiDPI 驗收，既有人工專項結論以 [WP-12 #5](https://github.com/xiaodaozhi/xdzip/issues/5)為準。

<a name="xdzip-接入后的验收标准"></a>

## 接入後的驗收標準

1. 在同一 1024 邏輯寬度、字型配置、DPR 和狀態資料下擷取實際目錄區域，與已確認圖板的對應區域及規格對照；記錄兩者縮放關係。視覺判斷與結構斷言分別保留。
2. 同層箭頭、圖示、名稱起點一致；行內沒有數字列；圖示、文字、圓點、箭頭共用行中心。目標幾何偏差不超過 1 個物理畫素，字型差異註明平臺和實際回退。
3. 至少三層展開，含一個更深但摺疊的分支和非空葉子；驗收連線線在最後兄弟與展開子樹中的連續 / 終止規則。
4. 單獨及組合檢查目前、懸停、焦點；箭頭點選不提交目錄查詢、不清除檔案選擇，Enter 啟用遵循成功查詢重置規則。
5. 冰川湖為目前目錄時收起照片：列表路徑不變、根目錄不選中、照片只顯示分支圓點；展開後恢復目前行。焦點隱藏後始終可繼續鍵盤導航。
6. 從真實受限索引核對空壓縮檔、根檔案、顯式空目錄、讀取失敗與目錄超限；分別檢查計數、禁用和恢復操作。
7. 長名稱、100%／125%／150% 字號及歷史 200% 壓力場景、最小視窗和索引最大允許深度下，名稱完整可見、橫向滾動只作用於層級區，完整路徑可訪問；樹滾動不移動壓縮檔摘要和底部統計。
8. 完成淺深色實際渲染、正常 / Retina / Windows 高 DPI、鍵盤與讀屏驗收。圖片檢查或素材生成透過不能代替這些執行驗證。

按[驗證方法](../../../developers/qa/README.md)分別核對原稿、切片、資源及實際滑鼠、鍵盤、選單和樹行為，未測的輔助功能與平臺差異保持明確標記。
