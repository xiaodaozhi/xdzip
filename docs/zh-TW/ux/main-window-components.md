# 主視窗功能、元件與互動契約

[English](../../ux/main-window-components.md) | [简体中文](../../zh-CN/ux/main-window-components.md) | 繁體中文 | [日本語](../../ja-JP/ux/main-window-components.md) | [한국어](../../ko-KR/ux/main-window-components.md) | [Français](../../fr-FR/ux/main-window-components.md) | [Deutsch](../../de-DE/ux/main-window-components.md) | [Español](../../es-ES/ux/main-window-components.md) | [Português (Brasil)](../../pt-BR/ux/main-window-components.md)

主視窗的控制元件同時交付外觀和行為：普通、懸停、按下、鍵盤焦點、禁用、選中、忙碌與錯誤均有明確狀態。HTML 使用示例壓縮檔驗證互動；Qt 根據真實瀏覽、建立、解壓、[完整性檢查](../engineering/archive-checking.md)和[內容預覽](../engineering/content-preview.md)的能力啟用動作，HTML 示例不代表真實背景結果。

檔名、目錄名、歸檔名和路徑優先使用啟動時的系統預設字型，缺字由平臺回退；固定介面文案繼續使用內建子集。目錄樹與拖動預覽按對應文字字型量測，詳見[視覺規範](../visual/design-standard.md#xdzip-%E7%95%8C%E9%9D%A2%E5%AD%97%E4%BD%93%E4%B8%8E%E7%94%A8%E6%88%B7%E6%95%B0%E6%8D%AE)。

<a name="xdzip-统一命令与菜单"></a>

## 統一命令與選單

按鈕、快捷鍵、右鍵與下拉呼叫同一個命令，動作執行前重新檢查目前能力。選單開啟時固定物件和選擇範圍；壓縮檔切換、查詢變化或物件消失時關閉，不能把舊條目的命令應用到新壓縮檔。

選單統一使用圖示 / 勾選槽、名稱、快捷鍵、子選單箭頭四列；分隔線按動作組劃分。只包含目前上下文相關動作：目錄提供進入與展開，檔案提供詳情，多選保留批次範圍。尚不可執行的動作保留禁用狀態，原因僅供輔助功能描述讀取，不顯示說明副行或 tooltip，不使用“點選後提示待開發”代替禁用。

字號變化時，選單名稱的高度直接跟隨目前字型度量，並與所在行保持垂直居中；首次呈現即滿足半邏輯畫素的中心誤差限制，不依賴下一輪佈局修正舊文字槽。

普通選單行、複選項、單選項、子選單入口與分隔線是共享元件。排序和檢視以單選項標明目前狀態；詳情面板以複選項表示開關。危險動作沒有預設自動啟用行為，右鍵和開啟選單均不執行動作。

<a name="xdzip-菜单输入与生命周期"></a>

## 選單輸入與生命週期

- 向下 / 向上在可用項間移動，Home / End 到首尾；Enter / Space 啟用，右鍵盤箭頭進入子選單，左箭頭返回父選單。
- Esc 逐級關閉，根選單關閉後退出觸發控制元件或原條目的焦點；Tab 關閉選單並繼續頁面正常焦點順序。支援按名稱首字元定位，輸入法組合不觸發選單型別搜尋。
- 滑鼠懸停高亮但不執行；子選單延遲展開，移動到子選單時保持父項。滑鼠與鍵盤操作可以互相接續，不殘留多個高亮或多個根選單。
- 點選外部關閉，不搶走外部目標焦點。滾動主區域、視窗尺寸變化、進入操作窗或切換壓縮檔關閉選單；選單自身滾動不關閉。HTML 共享控制元件記錄開啟時各現有容器的實際滾動位置，開啟前已完成、僅延遲送達的滾動事件不關閉選單；開啟後位置變化仍關閉。
- 根據實際視口避讓底邊與右邊，必要時向左或向上展開。定位使用宿主座標，邏輯尺寸、原稿源畫素、DPR 和審閱縮放分別處理。
- 鍵盤透過 Shift+F10 / 選單鍵開啟目前條目選單；長按觸屏與滑鼠右擊使用相同上下文，不以單擊方式破壞多選。

<a name="xdzip-控件状态与可访问性"></a>

## 控制元件狀態與可訪問性

| 狀態 | 表現 | 行為 |
| --- | --- | --- |
| 普通 | 保留已確認原稿的邊框、圓角、圖示和基線 | 不因狀態變化改變控制元件尺寸 |
| 懸停 | 淡色填充；主按鈕使用加深主色 | 提示延遲出現，不遮擋目標；觸屏不保留粘滯懸停 |
| 按下 | 比懸停更明確的填充 | 不透過位移造成文字 / 圖示跳動；取消按下不執行動作 |
| 焦點 | 不額外繪製 outline、加粗邊框或光暈 | 保留 Tab 順序及鍵盤啟用，外部點選、Escape、Enter 退出控制元件焦點 |
| 禁用 | 文字與圖形採用明確禁用色，保留輪廓 | 不響應點選或快捷鍵；可訪問描述說明原因 |
| 選中 | 背景或勾選標誌明確目前狀態 | `aria-selected` / `aria-checked` / Qt Accessible 同步 |
| 忙碌 | 狀態與禁用範圍按任務確定 | 阻止重複提交；背景任務允許繼續瀏覽 |
| 錯誤 | 鄰近文案說明問題與恢復動作 | 不用顏色作為唯一資訊，不報告假成功 |

共享圖示來自 `design/assets`。文字、勾選、背景、連線線與選單定位由控制元件實現，原畫素切片用於對照。HTML 沿用主稿源座標，新增控制元件引數先從邏輯畫素換算；Qt 使用相同邏輯規範。

<a name="xdzip-验收"></a>

## 驗收

檔案區域右側的計數和操作按鈕組成固定寬度組。列表、網格、排序和可見的詳情入口保持 28×28 邏輯畫素，按鈕間距為 6.4，視窗變寬只增加麵包屑可用空間。工具欄更多選單僅保留設定，原始順序、解壓後設資料預檢、全選和詳情使用已有專用入口。

起始頁和壓縮檔案頁使用同一底欄高度，正常高度下限為32邏輯畫素，來自 layout-scale.json 的 statusbarHeight。輔助字號按任務按鈕的真實高度與相同上下留白共同增高，切換頁面不改變底欄高度。兩頁任務按鈕使用同一 task-list 素材及 main.interaction.taskIconSize 定義的 16×16 邏輯畫素圖示槽，居中對齊，不隨頁面或輔助字號改變尺寸。

壓縮檔案頁底欄顯示選中數量；有選擇且總大小已知時，在數量後顯示分隔符和大小。選中項包含虛擬目錄或未知大小檔案等導致總大小未知時，只顯示數量，不顯示多餘的分隔符和 `—`。已知的零位元組大小仍正常顯示，歡迎頁文案不變。


檔案列表選框右邊緣到檔案圖示槽固定留 12 邏輯畫素，圖示、檔名和“名稱”表頭同步定位。輔助字號只改變真實文字度量，不擴大這段空白；選框仍與每行選擇狀態及表頭全選狀態共用原有選擇模型。

五列均可拖動右邊界調整寬度，命中區為 8 邏輯畫素，雙擊邊界恢復該列預設寬度。名稱列預設填滿餘量，其餘列以原設計值為基準，兩個大小列的預設寬度按實際標題和排序箭頭度量適當增大，避免預設標題被截斷；使用者列寬在本次執行的標籤頁和視窗間共享，退出後恢復預設，寬度以邏輯尺寸儲存於記憶體，不寫設定或 DPR。名稱列最小 160，其餘列最小 64，輔助字號按同一比例增加，超出視口時橫向滾動。表頭和內容使用同一個寬度來源，拖動不觸發排序；原始大小、壓縮大小的升序和降序標記位於右對齊標題文字左側，其餘列的標記位於標題右側，均與實際顯示文字留 6 邏輯畫素。活動排序列在相應一側為箭頭預留空間，手動縮窄時標題先省略，箭頭不得覆蓋文字或相鄰列；數值列標題繼續與內容右對齊。

檔案類別圖示按 [副檔名提示表](../../../specs/visual/file-types.json)生成 Qt 和 HTML 選擇器，覆蓋辦公文件、表格、演示、音訊、影片、壓縮檔、安裝包、字型與磁碟映象。字尾不區分大小寫，未知類別使用通用文件圖示。這隻說明外觀，不表示檔案內容可信或該歸檔格式已經獲得瀏覽、建立或解壓支援。

實際滑鼠與鍵盤驅動檢查各入口、選單避讓、子選單往返、選擇保持、焦點恢復、禁用保護、標籤隔離、檢視切換與目錄層級。淺深色、三種平臺裝飾、正常 / 大字號和縮放下擷取真實控制元件畫面；初始主視窗的標題欄、工具欄、檔案列表與預覽既有對齊不以選單改造為由回退。

按[通用驗證方法](../../../developers/qa/README.md)記錄功能覆蓋、實際截圖和未接入能力，結論放對應 issue，執行證據放 build/ 或 CI 工件。靜態圖板、瀏覽器行為驗證、Qt 執行驗證分別說明，不能相互替代。

Qt 選單明確使用 `Popup.Item` 消費共享委託，保證 AppKit 不忽略自定義樣式；操作視窗繼續採用獨立頂層視窗。`CommandTooltip` 使用同一提示引數與純文字，避免把壓縮檔名稱解釋為富文字；選單獲得焦點時隱藏提示。共享 JSON 的八位顏色採用 CSS RGBA，QML 生成器轉換為 QColor ARGB，顏色與透明度一起驗證。

目錄樹及主工具欄開啟、新建、測試、更多、解壓的懸停沒有浮動 tooltip；選單中的禁用操作也不顯示可見 hint 或 tooltip，其他按鈕按共享延時提供提示。根目錄和普通子目錄只列直屬檔案與資料夾，搜尋遞迴目前範圍；普通名稱顯示末級名稱，搜尋顯示完整路徑。列表懸停覆蓋整行，網格有固定左右留白及懸停／選中核取方塊，選單使用四周柔和陰影並與呼叫按鈕留 4 邏輯畫素。互動及縮放複驗按[通用方法](../../../developers/qa/README.md)保留獨立證據。

所有排序方式都將目錄排在檔案之前，升序和降序分別在組內生效。按型別排序時，無字尾檔案單獨分組，相同型別保留穩定身份順序。排序作用於完整查詢後再拆分內部傳輸批次。HTML 中未設定 folder 的檔案按 false 處理，不能將 undefined 轉成 NaN 參與比較。

<a name="xdzip-选择任务与提示"></a>

## 選擇、任務與提示

全選保留目前列表末項的詳情焦點，後設資料與逐項選擇一致；取消選擇後隱藏四項屬性及“解壓此檔案”。該按鈕使用共享 hover／pressed／focus 狀態。全選仍作用於完整目前查詢，不改變目錄和物理身份的契約。

底欄“任務 N”顯示保留歷史數，活動數只用於提示和退出邏輯。每個任務選單項左側顯示建立／解壓與編號，右側顯示狀態色標，點選或鍵盤啟用重開同一任務。任務選單與其他選單共用密度、字號和滾動邊界。未選中時解壓範圍選單中所選及預檢動作禁用，不增加提示副行。

浮動提示統一在同一控制元件內指標連續靜止 1200 ms 後顯示；移動、離開、按下按鈕或開啟選單時取消顯示及舊計時，跨控制元件重新完整等待，不沿用上一提示的快速喚醒。提示優先在呼叫控制元件上方顯示，頂部空間不足時改在下方，避免邊界約束將提示壓到控制元件上造成 hover 反覆切換。Qt 共享 CommandTooltip 使用顯式靜止計時，HTML data-tooltip 同步；列表完整名稱不使用瀏覽器原生 title 繞過該策略。系統原生選單和托盤的提示時序由系統管理，不宣稱可由 QML 引數控制。時間不隨字號、DPR 或密度縮放，視覺幾何保持不變。

歸檔標籤的完整檔名同樣使用共享靜止延時提示，按純文字顯示，標籤排序拖動、按下、標籤選單或標籤列表開啟時隱藏。全域性任務列表先關閉選單再顯示任務視窗，不切換歸檔標籤，不重新開啟已關閉的歸檔頁面。

起始頁採用頂部固定、水平居中的可滾動正文，錯誤和警告追加於格式提示下方，以紅色文字和語義圖示顯示，不推動上方內容。關閉托盤駐留的主視窗清空該視窗標籤，普通喚出僅顯示起始頁；最小化保留標籤，背景任務仍從全域性入口訪問。

檔案列表正文的雙向拖放、目前目錄新增確認及三平臺外部複製流程見[檔案拖放與修改](../engineering/archive-transfers.md)。

包內移動採用內部拖動，目標列表/網格資料夾和目錄樹使用既有選擇底色，即時意見回饋複用提示幾何，最多四行並約束於目前客戶區。選中目錄、自身後代、原位置、搜尋及加密/分卷目標有明確拒絕說明，不新增確認視窗。重名使用檔案衝突視窗，移動任務有獨立名稱。狀態原稿見 [包內移動](../../../design/hifi/sources/archive-move.html)，事務與邊界見[拖放契約](../engineering/archive-transfers.md)。
