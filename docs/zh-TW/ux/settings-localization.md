# 設定視窗與介面語言

[English](../../ux/settings-localization.md) | [简体中文](../../zh-CN/ux/settings-localization.md) | 繁體中文 | [日本語](../../ja-JP/ux/settings-localization.md) | [한국어](../../ko-KR/ux/settings-localization.md) | [Français](../../fr-FR/ux/settings-localization.md) | [Deutsch](../../de-DE/ux/settings-localization.md) | [Español](../../es-ES/ux/settings-localization.md) | [Português (Brasil)](../../pt-BR/ux/settings-localization.md) | [Русский](../../ru-RU/ux/settings-localization.md)

沒有可見主視窗時，從托盤開啟的設定和關於視窗沒有 owner，按指標所在顯示器的可用區域居中。複用 OperationWindow 的螢幕居中路徑，在原生視窗建立及高度確定後再次定位，完整原生邊框保持在工作區內；高度上限取選定 QScreen 的實際可用高度，保留既有螢幕留白，不使用虛擬桌面合併範圍推導位置或高度，不恢復隱藏或最小化的主視窗。已有 owner 的入口繼續跟隨呼叫視窗，視窗尺寸和密度不變。


設定使用非模態獨立系統視窗，標題欄、應用選單和托盤複用同一個可見視窗。左側依次為外觀、通用、隱私、檔案關聯、網路和關於；所有關於入口開啟同一設定視窗的關於頁。視窗邏輯寬度為 612，客戶區高度為 532，螢幕空間不足時限制高度，側欄和正文分別滾動。側欄與正文相接，頂部不留額外空隙。視窗沒有 footer、儲存或取消按鈕。設計源和各狀態圖見[設定設計](../../../design/hifi/sources/settings.html)，尺寸令牌見[佈局規範](../../../specs/visual/layout-scale.json)。

主題、字號、列表密度、語言、開啟方式、托盤和最近記錄開關在操作時寫入並生效；關閉視窗不會撤銷已成功的更改。語言即時重新整理產品文字、應用提供的原生選單及托盤選單，執行中的任務不受影響；系統自帶選單項遵循系統語言。開啟方式影響後續所有開啟入口和標題欄加號，不遷移已開啟的會話。清空最近記錄立即執行，不刪除原檔案。清空失敗與設定寫入失敗均在頁面顯示錯誤，保留既有資料和實際設定。多選框基於 IntentCheckBox，主題和代理單選基於 IntentRadioButton；滑鼠、鍵盤及原生輔助功能 press/toggle 必須提交同一個選擇意圖，並核對模型，不得只更改圖形。下拉框繼續使用 OperationSelect，選擇確定後提交一次。

設定頁的選擇框在每個字號下統一依已註冊介面字型的最大行高計算高度。切換語言時保留所選語言的字型，避免文字裁切或選擇框高度跳動。

設定持久化使用 schema 1，保留未知鍵，包含網路代理和映象地址，不存放密碼。儲存持有獨立配置鎖，先在同目錄暫存完整 INI，原子更新備份及主檔案。讀取失敗、超過 1 MiB、非法或更高 schema、符號連結、備份或提交失敗均拒絕覆蓋原檔案。設定應用失敗時恢復執行中狀態。最近路徑獨立儲存在同目錄 recent.json，最多 20 條、去重並限制讀取為 64 KiB，檔案僅使用者可讀寫；關閉記錄開關停止新增，清空入口刪除已有記錄。

暫存階段將原始位元組儲存為只讀輸入快照，複製全部鍵值到另一份全新的候選 INI，再寫入變更，不就地重寫剛生成的快照。schema 校驗與未知鍵保留繼續執行，備份保留原始位元組。

Windows 原子替換若因讀控制代碼未共享刪除許可權等短暫佔用而重新命名失敗，最多重試四次，退避共 75 ms，不含檔案 I/O 時間。重試持續持有配置鎖，使用同一份待提交位元組和新的暫存檔案，不處理 GUI 事件，不回退為原地覆蓋；持續佔用或其他錯誤仍保留原檔案及已生效設定並報告失敗。


檔案關聯頁按生成的格式資料對字尾分組。普通安裝版的開關顯示查詢到的系統預設狀態。Windows 轉到系統預設應用，macOS 使用 Launch Services，Ubuntu 使用桌面 MIME 預設設定。macOS 或 Ubuntu 取消預設關聯時可能需要選擇替代應用。多個字尾可共享一個系統型別，Windows 按 `.tar.gz` 的最後一段副檔名處理。MSIX 顯示可關聯型別和不可操作的開關，並提供“在 Windows 中設定預設應用”。實際預設狀態可在系統設定中檢視。見[關聯契約](../engineering/installers-associations.md)與[包身份設定稿](../../../design/hifi/sources/settings.html?tab=associations&channel=msix)。

Windows 安裝版的各種檔案格式關聯描述使用應用程式選定的語言。變更語言成功後會同步，安裝或升級時也會讀取已儲存的語言。應用程式只更新確認屬於目前安裝的九個 ProgID 描述，不變更預設處理程式。系統或其他應用程式擁有的類型名稱、快取及其他平台的顯示不受此設定直接控制。同步前提及失敗時的行為見[安裝與檔案關聯](../engineering/installers-associations.md)。


網路提供不使用代理、系統代理、自定義 HTTP 或 SOCKS5 代理，及可選 HTTPS GitHub 映象地址。自定義代理必須包含主機和埠，不接收憑據；地址輸入完成並驗證後儲存。映象為空時直接訪問官方地址；非空時僅改變更新流量的傳輸地址，校驗和簽名邊界不變。進行中的更新保持原網路配置，下一次更新操作使用新配置。macOS Sparkle 支援系統代理、直連和無憑據的自定義 HTTP CONNECT／SOCKS5 代理；自定義代理失敗時不會回退為直連。完整信任和重定向策略見[軟體更新](../engineering/software-update.md)。

六個頁面的正文不重複側欄標題。普通構建的“關於”頁為更新狀態和操作保留穩定的滾動區域。主操作隨更新狀態切換，包括檢查、取消、下載、安裝和跳轉發布頁。鍵盤焦點可將螢幕外的控制元件滾動到可見位置。以 MSIX 包身份執行時，“關於”隱藏應用內更新區，保留構建資訊和許可宣告。商店版由 Microsoft Store 更新。見[包身份關於頁原稿](../../../design/hifi/sources/settings.html?tab=about&channel=msix)與[更新契約](../engineering/software-update.md)。

關於頁的更新狀態文字同時作為原生輔助功能名稱，隨檢查、下載、安裝、成功或失敗狀態及語言變化同步更新；輔助技術讀取的文字與介面顯示一致。

macOS 手動更新說明顯示目前首先未滿足的安裝條件，並保留髮布頁和下載位置；多個條件可能同時不滿足，安裝身份失敗不推測具體原因。說明覆蓋同版本 DMG 與 app.zip 手動替換，且明確下載不等於安裝。

設定正文的豎向捲軸位於視口右側，軌道覆蓋視口高度；滑塊隨滾動移動，也可拖動控制正文滾動。

關於頁版本資訊的標籤列按實際文案和字號自適應，值列使用剩餘寬度並可換行；新增欄位應使用相同佈局。



產品文案透過 `resources/i18n/` 中的穩定 ID 引用，QML 使用 `qsTrId`，C++ 使用 `qtTrId`。協議碼、檔名、路徑和使用者內容保留原值。語言選單首先顯示“自動識別”，其餘選項顯示隨包語言的自稱。每次啟動時，自動模式獨立於應用數字區域設定讀取系統首選介面語言。中文顯式簡繁標記優先於地區。繁體中文顯式標記及 zh-TW、zh-HK、zh-MO 地區使用繁體中文譯文。其他語言在有對應譯文時使用該語言的受支援版本。首選系統語言不受支援或為空時使用美式英語。語言標識中的國家（地區）代碼用於區分語言的地區變體，語言數量不代表國家（地區）的數量。

切換語言立即生效，儲存失敗時恢復原選擇和顯示語言。手動選擇中英文之外的新增語言時，設定檔案在 `locale/extendedLanguage` 記錄所選語言，並在 `locale/language` 儲存舊版可讀取的回退值。舊版將繁體中文顯示為簡體中文，其餘新增語言顯示為英語，並繼續讀取其他設定。新版在擴充套件值與已儲存的回退值匹配時使用擴充套件值。選擇自動識別、簡體中文或美式英語時清除擴充套件值。

字號支援 100%、125%、150%，歷史 200% 讀取為 150%。系統檔案選擇器和 Qt 自有控制元件使用系統語言。macOS 包宣告隨包語言並允許混合本地化。


驗證六個頁籤及設定和關於的共用入口、即時儲存與失敗恢復、每種受支援語言的佈景主題和文字大小，以及適用的代理伺服器、更新和關聯狀態。涉及一般 Windows 安裝版時，核對九個核心 ProgID 的語言同步。MSIX 要核對停用的關聯開關、系統設定入口，以及應用程式內更新區是否隱藏。使用 `QAccessibleActionInterface` 執行單選與開關操作，核對實際模型狀態和事件。原生檢查和證據要求見[驗證指南](../../../developers/qa/README.md)。
