# 歡迎頁讀取遮罩與建立完成行為

[English](../../ux/welcome-opening.md) | [简体中文](../../zh-CN/ux/welcome-opening.md) | 繁體中文（台灣） | [日本語](../../ja-JP/ux/welcome-opening.md) | [한국어](../../ko-KR/ux/welcome-opening.md) | [Français](../../fr-FR/ux/welcome-opening.md) | [Deutsch](../../de-DE/ux/welcome-opening.md) | [Español](../../es-ES/ux/welcome-opening.md) | [Português (Brasil)](../../pt-BR/ux/welcome-opening.md) | [Русский](../../ru-RU/ux/welcome-opening.md)

2026-10-16 修訂，引數源為 [welcome-reference.json](../../../specs/visual/welcome-reference.json)，動態高保真入口為 [歡迎頁讀取狀態](../../../design/hifi/sources/welcome.html?opening=1)。沿用主視窗、選單和歡迎頁的邏輯單位，標題欄不變。

歡迎頁開啟真實壓縮檔時，在正文上方居中顯示浮動卡片及半透明遮罩。卡片正常寬 360、內距 24、間距 12、圓角 8、標題 16，窄視窗按可用寬度約束；檔名中間省略，狀態說明可換行，取消按鈕始終可達。淺深色均複用共享主題，輔助字號沿用全域性設定。

已開啟壓縮檔的新增與包內移動複用 BrowserBusyOverlay 卡片及尺寸，背景完全透明，保留原檔案頁並阻止底層操作。標題、說明、進度輔助名稱及取消按鈕使用實際操作名稱；操作身份持續到任務清理和目錄重新整理結束，不借用“開啟”或“載入”。首次開啟的讀取遮罩仍遵循上面的半透明政策。

目前後設資料讀取介面沒有總位元組和百分比進度，顯示持續活動的進度條與“正在讀取壓縮檔目錄”狀態，不使用計時模擬百分比。取消呼叫既有請求取消，不建立解壓任務，不寫出檔案。取消確認、失敗或成功結束後自動移除遮罩；失敗資訊仍顯示於歡迎頁，成功進入檔案列表。讀取期間阻止正文重複開啟、新建與拖入，標題欄保持既有佈局與宿主命令規則。

HTML 設計原型用可取消的示例等待展示該狀態，不讀取拖入檔案內容。取消後清除定時回撥，不能稍後跳入示例；高保真 `opening=1` 固定展示等待狀態，原始 PNG 和雜湊保持不變。

建立視窗移除“完成後開啟目標資料夾”。自動完成路徑不呼叫 Finder／Explorer，既有建立結果仍在本應用中自動開啟；受支援的加密與編號分卷也可瀏覽。解壓的“完成後開啟目標資料夾”及使用者主動點選開啟目錄的動作保持各自語義。舊建立呼叫中的目錄自動開啟引數忽略，以覆蓋已提交和終態先到的兩條路徑。

建立結果計數統一顯示“已儲存”，英文為 Saved，保留現有數值含義。所有共享操作輸入框的 placeholder 顯式繫結 textSecondary，避免深色密碼框沿用平臺淺色預設值；禁用狀態仍遵循共享控制元件策略。

驗收覆蓋真實取消、讀取失敗恢復、標題欄幾何不變、淺深色與輔助字號、建立成功應用內開啟且無系統目錄開啟。測試截圖和量測只寫入 build/ 或 CI 工件。

外部檔案啟動修訂：透過命令列、Windows 開啟方式、Linux 桌面入口或 macOS 檔案開啟事件進入時，在首次顯示主視窗前接收已知開啟意圖並提交真實讀取。視窗不等待讀取完成，直接顯示現有可取消進度卡片，隱藏歡迎頁的品牌說明、開啟／新建卡片與拖入區域；成功後顯示檔案列表，失敗或取消後恢復歡迎頁及真實意見回饋。正常空啟動仍顯示歡迎頁，歡迎頁內主動開啟仍保留原遮罩效果。標題欄、主視窗與選單的尺寸比例不變，不增加延時閾值或偽造進度。

高保真外部啟動入口為 [external=1](../../../design/hifi/sources/welcome.html?external=1)，HTML 僅展示相同狀態，不模擬系統檔案關聯。迴歸覆蓋隱藏視窗預提交、首次呈現時歡迎內容不可見、失敗恢復和各平臺真實系統開啟；關聯探針記錄實際 frameSwapped 次數及歡迎內容可見次數，不以單純成功讀取替代啟動顯示檢查。
