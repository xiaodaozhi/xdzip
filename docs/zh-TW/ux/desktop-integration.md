# 系統選單與托盤

[English](../../ux/desktop-integration.md) | [简体中文](../../zh-CN/ux/desktop-integration.md) | 繁體中文 | [日本語](../../ja-JP/ux/desktop-integration.md) | [한국어](../../ko-KR/ux/desktop-integration.md) | [Français](../../fr-FR/ux/desktop-integration.md) | [Deutsch](../../de-DE/ux/desktop-integration.md) | [Español](../../es-ES/ux/desktop-integration.md) | [Português (Brasil)](../../pt-BR/ux/desktop-integration.md) | [Русский](../../ru-RU/ux/desktop-integration.md)

多工作階段、單一執行個體、視窗狀態及全域退出以[應用會話契約](../engineering/application-sessions.md)為準。關閉非最後主視窗保留任務，最後視窗遵循托盤設定；退出確認覆蓋所有會話。

任務密碼或衝突提示存在時，仍可以從系統、選單或托盤明確進入全域退出確認。macOS 應用選單的退出項及 Command-Q 仍可使用。選擇返回會保留任務和提示。原生檔案選擇器及其他阻塞模態視窗須先完成或關閉，應用會丟棄在這些視窗阻擋時發出的退出請求。

macOS 頂部選單和三平臺托盤使用作業系統原生選單，保留已有主視窗標題欄。引數見 [桌面整合引數](../../../specs/visual/desktop-integration.json)，互動稿，高保真入口。原生字型、行高、選單寬度與系統高亮不套用應用內 CommandMenu 的密度引數；HTML 為互動說明，不作為原生畫素驗收。

macOS 選單依序為 xdzip、檔案、編輯、顯示、操作、視窗、幫助。「幫助」提供「使用說明」和「反饋問題」，透過預設瀏覽器開啟專案 README 與 Issues 頁面，不會自動送出回報。分隔線後的「關於 xdzip」會開啟與應用程式選單、系統匣相同設定視窗的關於頁。幫助選單的關於項目使用 NoRole，保留在原位置。應用程式選單使用 AboutRole、PreferencesRole、QuitRole，系統提供服務、隱藏及顯示全部。檔案選單包含開啟、新建、最近開啟、關閉壓縮檔和關閉視窗。編輯選單依目前的文字焦點提供復原、重做、剪下、複製、貼上、全選和尋找。顯示選單包含清單、網格與預覽。操作選單包含全部解壓縮、解壓縮所選項目和中繼資料預檢。視窗選單包含最小化、縮放、主視窗、任務及可見的產品視窗。

選單和既有介面透過統一命令入口執行，開啟時及觸發前重新檢查能力。⌘W 關閉目前視窗，⇧⌘W 關閉壓縮檔。文字編輯不會誤操作檔案選取，強制回應視窗會阻止主視窗命令，停用的項目不附加說明。最近使用的檔案僅在允許記錄時顯示，不會額外複製或上傳路徑。應用程式自有文案使用目前的介面語言資源，系統提供的項目遵循系統語言。

語言設定儲存成功後，原有選單欄、應用選單的關於／設定／退出、托盤選單、任務子選單和托盤提示立即切換語言；切換失敗時保持原語言。選單命令和快捷鍵的行為、任務身份及正在執行的任務均保持不變。macOS 服務、隱藏等系統提供的項目與原生檔案選擇器繼續遵循系統語言。

托盤駐留預設開啟，設定成功儲存後生效。選單提供顯示主視窗、開啟、新建、任務、設定、關於和退出。macOS 點選托盤圖示展開選單。Windows 和 Linux 的托盤啟用或雙擊恢復視窗，系統叫用快顯選單時開啟選單。Windows 重新開啟托盤時會重新繫結原生選單。任務完成會更新任務入口，無需搶佔焦點。

托盤可用時關閉最後一個主視窗，會清除該視窗的瀏覽標籤和草稿，再隱藏視窗。恢復主視窗時回到歡迎頁。最小化時保留標籤。活動任務及其原有身份仍可從全域任務入口訪問。桌面會話失去托盤且沒有可見任務入口時，透過操作視窗讓活動任務繼續可達。沒有托盤、可見視窗和活動任務時，應用退出。明確退出和重啟仍走任務確認及非同步關閉流程。macOS 也可透過 Dock 或系統檔案開啟恢復應用。

macOS 托盤沿用從現有品牌標誌提取字形的模板圖示。Windows、Linux 及其他非 macOS 平臺統一複用應用圖示，由系統選擇顯示尺寸；應用圖示不隨應用或系統主題改變，也不依賴登錄檔主題讀數。圖示不做閃爍或持續動畫。

“顯示”選單在“檔案預覽與屬性”之後保留不可摺疊的分隔線，將 AppKit 自動追加的全屏命令獨立分組，避免系統全屏圖示使預覽項額外預留圖示列。預覽項與列表、網格的文字起點對齊，勾選標記仍由系統繪製；不靠空格、固定寬度或自繪選單補償。HTML／高保真互動稿只表達應用命令，系統追加項由原生桌面驗證。

<a name="xdzip-验证"></a>

## 驗證

應用自己的 Qt Quick 視窗隱藏或最小化時，同步結束原視窗的指標懸停，清除按鈕、MouseArea、HoverHandler 及 tooltip 的舊位置記錄。恢復首幀同步前按系統實際指標位置重新核對，不能沿用關閉前的 hover 底色或舊座標；晚到的原生進入事件也按實際位置處理，直至真實滑鼠移動或按下同步座標。此規則適用於主視窗與操作視窗，不改變焦點、按鈕繫結或原生檔案選擇器行為。

Windows 托盤隱藏後保留原生視窗、狀態、QML 物件、控制器與背景任務，在隱藏狀態下暫時遮蔽視窗透明度，恢復後首個新幀完成提交才恢復原透明度。僅清理 hovered 屬性不能防止 DWM 在新幀提交前短暫顯示視窗的最後一幀。新一輪隱藏使舊幀回撥失效；此策略只適用於托盤隱藏，不用於最小化或仍可見的視窗，不透過截圖讀回、固定延時或禁用系統動畫實現。

沒有系統全域指標的後端以注入事件為準，不查詢物理滑鼠覆蓋其狀態。offscreen／minimal 的元件檢查與原生桌面恢復檢查分開，不能用離屏檢查替代 DWM、Cocoa 或 X11 的實際視窗驗收。


自動化覆蓋選單結構和角色、狀態同步、命令與編輯路由、配置相容與取消、駐留及退出策略、無托盤回退、任務選單、模態阻塞與重啟。原生桌面另核驗 macOS 頂部選單、Dock 恢復，Windows 通知區與 Linux StatusNotifier/XEmbed，深淺外觀、高 DPR、鍵盤與螢幕閱讀。離屏驗證不等於原生桌面驗收；截圖與報告僅輸出 build/ 或 dist/。

原生編輯角色僅在 `QCocoaMenuItem` 的 Cut、Copy、Paste、Select All 翻譯上下文中使用應用語言目錄，`QCocoaMenuBar/Edit` 也使用同源標題，使 Qt 的文字角色檢測與編輯選單識別不依賴系統語言。系統檔案選擇器及其他 Qt 控制元件繼續使用系統 locale 的 qtbase 翻譯。須同時驗證中文應用與英文系統，以及英文應用與中文系統，不透過修改使用者全域性 AppleLanguages 來測試。

繁體中文的托盤提示使用 `xdzip (活動中的任務: %1)`，任務選單使用 `任務 (活動中的任務: %1)`，英文分別為 `xdzip (Active tasks: %1)` 與 `Tasks (Active tasks: %1)`。計數來自應用級真實活動任務總數，包含被關閉瀏覽頁面仍在執行的任務；完成結果不計為活動任務。
