# 補充互動與文案規範

[English](../../ux/interaction-spec.md) | [简体中文](../../zh-CN/ux/interaction-spec.md) | 繁體中文（台灣） | [日本語](../../ja-JP/ux/interaction-spec.md) | [한국어](../../ko-KR/ux/interaction-spec.md) | [Français](../../fr-FR/ux/interaction-spec.md) | [Deutsch](../../de-DE/ux/interaction-spec.md) | [Español](../../es-ES/ux/interaction-spec.md) | [Português (Brasil)](../../pt-BR/ux/interaction-spec.md) | [Русский](../../ru-RU/ux/interaction-spec.md)

主視窗與解壓確認的視覺基線由[操作狀態規範](hifi-state-spec.md)補充新建、衝突、任務、結果、設定及平臺對照。歡迎頁和開啟進度見[歡迎頁契約](welcome-opening.md)，目前原稿與佈局依據以[視窗登記](../../../specs/visual/window-registry.json)為準。不因狀態規範存在便將全部設計視為已實現或已透過原生視覺驗收，具體實現邊界見相應工程和互動契約。

| 場景 | 呈現與動作 | 恢復路徑 |
| --- | --- | --- |
| 首次啟動 | 開啟壓縮檔、建立壓縮檔；可拖入本地檔案 | 不掃描全磁碟，不自動關聯全部格式 |
| 正在讀目錄 | 已讀數量和不定進度；總數未知 | 可關閉會話，不能把部分結果稱為全部 |
| 空壓縮檔 | “此壓縮檔沒有內容”，保留檔案屬性 | 開啟另一個；禁用解壓並解釋 |
| 無搜尋結果 | 顯示搜尋詞和範圍 | 清空搜尋，不誤報壓縮檔為空 |
| 不支援特性 | 顯示具體格式/演算法/加密原因 | 保留可讀後設資料，停止不安全的部分輸出 |
| 建立壓縮檔 | 輸入清單、格式、目標、級別、預檢 | 錯誤鄰近欄位；不預設覆蓋已有檔案 |
| 重名衝突 | 展示兩項資訊，提供跳過、重新命名和覆蓋，以及後續決定的適用範圍 | 關閉提示後任務繼續等待，可從任務視窗重開或取消 |
| 任務完成 | 顯示成功、跳過、失敗及提交數量 | 解壓按顯式選擇開啟目標目錄。建立可在應用內開啟受支援的單卷結果或首卷，重試需要重新規劃 |
| 部分失敗 | 保留已經提交的檔案，明確失敗原因 | 不以全任務回滾刪除使用者檔案 |
| 應用退出 | 活躍任務數量，等待完成或取消後退出 | 核心確認清理結束；不阻塞 GUI 無限 join |
| 設定 | 主題跟隨系統/淺/深、密度、字號、語言、最近記錄、托盤 | 更改儲存成功後立即生效，失敗保留原值；額度編輯不屬於目前設定能力 |
| 格式擴充套件 | 產品使用內建格式，[外部 SDK 試驗](../engineering/sdk-trial.md)獨立驗證只讀執行 | 到[格式登記](../engineering/format-registry.md)查詢可用操作 |

解壓主按鈕按目前選擇切換，選單按目前能力提供兩種範圍。搜尋只覆蓋目前目錄和後代。屬性面板可見時，選取單一支援的檔案就會自動顯示[文字或圖片預覽](../engineering/content-preview.md)。視窗窄於屬性面板的摺疊閾值時可用獨立視窗開啟。大字號下內容按實際尺寸增長，透過滾動保留確認控制元件的可達性。

錯誤文案採用“發生什麼＋可採取什麼動作”，錯誤碼放詳情；不向普通使用者顯示呼叫棧或 IPC 術語。危險檔名按安全文字呈現，外掛訊息不解釋為 HTML。快捷鍵、IME、焦點與讀屏以 [Qt Quick 介面設計](../design/qt-quick-ui.md)為準。
