屬性卡可見時，選取單一支援的檔案，待選取項目穩定後就會自動開始預覽。將滑鼠移到預覽區，或用鍵盤將焦點移到重新載入按鈕，即可使用右上角的圖示重新載入所選檔案。讀取或解碼失敗時，屬性卡會顯示原因。選取多個項目時會顯示多選提示。主視窗和獨立屬性檢視器共用上述操作和現有的密碼視窗。檔案屬性可以獨立查看。

<a name="xdzip-能力与预算"></a>

## 能力與預算

僅支援可讀取、尺寸已知、沒有危險名稱的普通檔案。文字擴充套件白名單為 txt、md、log、json、csv、tsv、toml、yaml、yml、ini、xml、rs、c、cpp、h、py；僅接受嚴格 UTF-8 或有 BOM 的 UTF-16。輸入及轉換後的 UTF-8 各最多 256 KiB，不允許 NUL 等二進位制控制位元組。內容透過 PlainText 控制元件顯示，標籤、網址、程式文字和宏不會執行。

| 圖片型別 | 三平臺範圍與實際語義 |
| --- | --- |
| PNG，JPEG（jpg、jpeg、jfif、jpe） | 完整讀取一張靜態圖片，按可用的變換後設資料處理朝向 |
| GIF，WebP | 靜態圖片或動畫首幀，不播放動畫 |
| BMP，ICO／CUR | 普通圖片或解碼器的預設影象，CUR 不啟用系統游標 |
| ICNS | PNG 或可用系統解碼器支援的 JPEG2000 內嵌影象，最多 256 塊；未知內嵌型別、舊式裸點陣圖／RLE 圖示明確拒絕 |
| TGA | 無色表／無影象 ID、左側起始的未壓縮真彩 16／24／32 位；補齊同佈局舊版空頁尾，不支援 RLE／索引色 |
| TIFF（tif、tiff） | 第一頁，不自動遍歷頁面 |
| SVG | UTF-8 靜態向量，在受限解析後柵格化，具體子集見下節 |
| HEIC／HEIF | 僅 macOS，Qt 官方外掛呼叫系統 ImageIO；其他平臺明確拒絕 |

不接入 AVIF、RAW、PSD、EXR、PDF、Office 或獨立第三方解碼庫。檔案擴充套件、Rust 簽名檢查及固定 Qt 解碼器共同決定準入，不把系統安裝了額外外掛當作產品能力，也不自動探測其他解碼器。

圖片編碼內容最多 16 MiB，Rust 事件佇列與 Qt mailbox 各限 32 MiB，命令預算仍為 8 MiB，原圖長寬分別最多 16384，總畫素最多 33554432。原圖准入與輸出縮圖獨立計量：最終輸出寬高均不超過 512，保持比例，RGBA8 最多 1 MiB。12MP 等照片可以在預算內縮略讀取；部分解碼器先讀取原圖再縮放，不能據縮圖尺寸聲稱內部只使用 1 MiB。可用色彩描述轉換為 sRGB，未知色彩描述保留解碼器結果，不承諾專業色彩校樣。

Qt 非同步圖片提供器只接收隨機令牌，不接收系統路徑或網路 URL。全域性保留的編碼內容最多 32 MiB，最多兩個並行解碼任務；已取消但尚在回收的任務各自最多持有一份 16 MiB 輸入。每次任務啟動固定的相鄰私有工作程序 `xdzip-image-preview`，不向它傳遞迴檔路徑、密碼、目標控制代碼或應用憑據。程序輸出只允許定長頭和嚴格寬高／長度一致的 RGBA8，不允許額外輸出。失敗、崩潰、非法幀、超時和晚到結果均不能顯示。

宿主從啟動開始施加 5 秒總時限，每 50ms 檢查請求是否仍有效；關閉、取消或更換條目會終止並回收該程序。工作程序對 QImage 分配設定 128 MiB 上限。Windows 使用 512 MiB 程序提交記憶體和 3 秒使用者 CPU 的 Job；Unix 使用 3 秒 CPU、禁用 core 及有界描述符。Linux 地址空間限 512 MiB，常規檔案大小額度為零。macOS 在已有 dyld 虛擬保留之外增加 512 MiB 地址空間額度，不將此數值當作 RSS 硬上限；系統 ImageIO 可能使用檔案支撐的執行時資源，因此每個常規檔案限 16 MiB，超額仍終止解碼。應用不匯出歸檔條目副本，系統執行時資源與條目輸出分別管理。這是私有解碼器的崩潰與資源隔離，不是任意第三方程式的核心許可權沙箱。

每次歸檔內容讀取累計來源最多 256 MiB，解碼與跳過工作最多 64 MiB，輔助演算法工作最多 256 MiB。格式字典、工作程序及方法圖仍受[格式後端契約](native-codecs.md)的獨立預算約束。固實包或順序壓縮流可能因前置解碼工作超過預算而拒絕小檔案預覽。

<a name="xdzip-svg-静态子集"></a>

## SVG 靜態子集

SVG 在三個桌面平臺使用同一 Qt Svg 渲染路徑。進入渲染器前，以 XML 流式解析器重建受支援的靜態圖形、文字、樣式、內部定義、漸變、裁剪、蒙版和限定濾鏡；最多 8192 元素、64 層、每元素 64 屬性，單屬性最多 1 MiB，總輸出仍限 16 MiB。metadata 內容不參與渲染。樣式元素只接受文字，合併 XML 文字分段及 CDATA 後按完整 CSS 檢查，不能透過分段繞過外部引用限制。

禁止 DTD、實體、處理指令、指令碼、事件、動畫、foreignObject、image 元素、字型檔案、外部樣式和外部資源引用。href 及 CSS url 只接受目前文件的簡單片段身份，禁止 xml:base、src、CSS import 和轉義形式。內嵌點陣圖與 SVGZ 不在本子集內。未知繪製元素或被禁止內容使整次預覽失敗，不靜默丟棄後冒充完整顯示。此範圍支援普通靜態 SVG，不聲稱覆蓋全部 SVG／瀏覽器能力。

<a name="xdzip-完整性密码与生命周期"></a>

## 完整性、密碼與生命週期

預覽複用已凍結的物理身份、源版本、負載定位及現有解碼器。必須完整解碼到 EOF，並完成格式提供的完整性及認證檢查後，才能將文字或編碼圖片交付到預覽階段。TAR 等沒有逐檔案內容校驗和的格式仍只具有其原有的結構與可讀性保證。磁碟大索引使用受限的所選負載讀取，不下載整份後設資料到 Qt。

密碼只繫結目前請求，沿用零化密碼容器；錯誤、認證歧義與取消按原有類別處理，最多十次嘗試。關閉密碼視窗只取消預覽，保留可用目錄。開啟、瀏覽及其他前景讀取命令優先於仍在進行的預覽讀取。關閉預覽、更換條目、隱藏歸檔頁面或關閉會話清空內容，失效請求和解碼結果不得恢復舊內容。失敗和取消丟棄未驗證部分，不寫出條目副本，也不啟動系統應用；雙擊的臨時開啟沿用[獨立流程](archive-opening.md)。

<a name="xdzip-工具链与验收"></a>

## 工具鏈與驗收

`desktop.py prepare --install-qt` 為新安裝或既有 SDK 補齊固定 Qt 6.8.2 的 qtimageformats；doctor 在構建前檢查 Svg 與必需外掛。官方原始碼、摘要、通知和 SDK 對應關係納入統一配置，Qt 自帶 libwebp／libtiff 與獨立新增格式庫分別管理。`check-image-preview.py` 核對實際工作程序、外掛和最小解碼，在預設測試、Windows／Linux 部署驗證及獲授權的 Mac 打包中執行；Mac 顯式補齊 offscreen 並在自檢前清除 SDK 搜尋覆蓋，不能以開發 SDK 的外掛目錄代替實際執行包驗證。

迴歸使用自有圖片覆蓋各型別、動畫首幀、TIFF 首頁、透明度、12MP 照片、macOS HEIC 及其他平臺拒絕、SVG 內部定義和外部資源拒絕、損壞輸入、畫素超限、異常幀、超時和取消。真實歸檔鏈路繼續覆蓋密碼、完整性、來源身份及 UI 失效清理。佈局沿用[視覺規範](../visual/design-standard.md#xdzip-%E4%B8%BB%E5%8A%A8%E5%86%85%E5%AE%B9%E9%A2%84%E8%A7%88)，按[驗證方法](../../../developers/qa/README.md)複用未改變的佈局證據，並觀察新增圖片的實際顯示。
