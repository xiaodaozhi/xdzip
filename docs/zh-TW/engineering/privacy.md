# 資料生命週期與診斷

[English](../../engineering/privacy.md) | [简体中文](../../zh-CN/engineering/privacy.md) | 繁體中文（台灣） | [日本語](../../ja-JP/engineering/privacy.md) | [한국어](../../ko-KR/engineering/privacy.md) | [Français](../../fr-FR/engineering/privacy.md) | [Deutsch](../../de-DE/engineering/privacy.md) | [Español](../../es-ES/engineering/privacy.md) | [Português (Brasil)](../../pt-BR/engineering/privacy.md) | [Русский](../../ru-RU/engineering/privacy.md)

[隱私政策](../../../PRIVACY.zh-CN.md)說明 xdzip 處理哪些資料，以及使用者可以作出哪些選擇。下表說明實現將資料存在哪裡、何時釋放。瀏覽、壓縮與解壓可離線使用。xdzip 不會自動向維護者傳送遙測或歸檔內容。

| 資料 | 生命週期 | 存放與清理 |
| --- | --- | --- |
| 設定與主題 | 跨啟動，使用版本化結構 | 透過原子替換儲存。設定更新失敗時保留上一次的設定，介面報告失敗。 |
| macOS 原預設應用 | 本地儲存，可跨啟動 | 將 xdzip 設為預設後，獨立的設定檔案按內容型別記錄原應用的包標識。恢復原應用或改用替代應用後，清除該型別的記錄。 |
| 最近檔案 | 可關閉，僅在本地儲存 | 私有 `recent.json` 檔案最多儲存 20 條去重記錄，讀取上限為 64 KiB。關閉後停止新增。清空只刪除歷史記錄，不影響原檔案。 |
| 歸檔索引 | 歸檔會話開啟期間 | 小索引駐留記憶體。大型 ZIP 用私有磁碟檔案儲存後設資料和查詢順序。正常關閉、替換查詢、失敗及取消會清理已知檔案。後續建立索引時可按身份和租約規則回收未使用的崩潰殘留。索引不會跨啟動複用。詳見[大型歸檔索引](large-index.md)。 |
| 暫存輸出與恢復狀態 | 任務執行及恢復期間 | 恢復只處理受控後設資料，只清理能夠確認歸屬的項，不執行歸檔內容或恢復任意路徑的寫入。 |
| 應用內預覽 | 使用者觸發，有資源上限 | 更換預覽目標或結束會話時清除當前結果，遲到的結果不能恢復已經失效的內容。 |
| 密碼 | 僅在操作需要期間 | 應用不會將密碼儲存到設定或日誌。作業系統可能持有應用無法控制的額外記憶體副本。 |
| 獨立更新檢查與下載 | 適用版本中由使用者觸發 | 請求訪問 GitHub 的公開發行和下載服務。已配置的代理可以轉發請求，可選的 HTTPS 映象會收到原始下載地址。服務端可見連線資訊及請求中的應用版本。Windows MSIX 禁用獨立更新。 |
| 更新事務回執 | 本地儲存，可跨安裝重啟 | 設定旁的獨立 `update-state.ini` 儲存事務和目標身份。失敗的下載可能留在私有更新快取中。更新器只讀取固定回執檔案，不執行回執內容。 |
| 狀態與診斷 | 按功能出現在介面、終端或本地記錄 | 應用不會自動上傳診斷。複製版本或檔案資訊會寫入系統剪貼簿。分享錯誤、日誌或截圖前，請檢查檔名、路徑等私人資訊。 |

更新網路、簽名、安裝交接與恢復流程見[主動更新契約](software-update.md)。
