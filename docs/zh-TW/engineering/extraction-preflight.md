# 解壓預檢：後設資料階段

[English](../../engineering/extraction-preflight.md) | [简体中文](../../zh-CN/engineering/extraction-preflight.md) | 繁體中文（台灣）

本模組提供後設資料預檢規則。沒有授權目標、解碼、寫入、暫存或提交能力。

<a name="xdzip-实现与边界"></a>

## 實現與邊界

`xdzip-extract-plan` 只依賴領域與後設資料介面，無 Qt、格式解析器或額外第三方依賴。輸入是會話快照、物理 EntryId 集合和取消訊號，輸出僅為有界報告；不返回可供寫入的路徑或“安全批准”標記。`xdzip-runtime` 持有快照，Qt 透過工作執行緒橋接呼叫它。

選擇上限 128 個物理 ID，必須非空並且全部屬於目前快照。選擇目錄時按原始名稱的斜槓邊界展開所有後代，不受搜尋、分頁或目前目錄範圍影響；目錄和子項同時選中只計一次。同名物理記錄不按路徑合併。統計中的目錄只計顯式記錄，不合成目錄物件。

預檢透過命令與事件服務執行，採用有界准入和獨立取消。執行時在檢查前後均複核已開啟來源的身份。對於使用磁碟索引的 ZIP，執行時從索引取出所選物理記錄及所需後代。選擇、查詢或會話變化後清空報告。結果是依據已記錄後設資料得出的估計，預檢不解碼條目負載、不佔用目標路徑，也不授予寫入許可權。

<a name="xdzip-已执行规则"></a>

## 已執行規則

- 名稱必須可解析為 UTF-8，最多 4 KiB、64 個元件、每個元件最多 255 位元組；不修復或改寫原始名稱。
- 拒絕絕對路徑、空元件、`.`、`..`、反斜槓、冒號、控制/雙向控制字元、Windows 非法字元及元件尾隨空格/點。
- 拒絕 Windows 常見裝置名（含副檔名形式及 COM/LPT 上標數字），保守應用跨平臺可移植名稱子集。
- 報告已有後設資料警告，並根據記錄的負載與密碼能力標誌判斷。加密記錄可提示需要受支援的密碼，或報告不支援該加密方式。大小已知且負載不受支援的記錄另報方法問題。預檢使用讀取器提供的後設資料和能力標誌，不解密、認證或解碼負載。
- 檢查精確重名、Unicode 小寫比較產生的碰撞、大小寫不同的父目錄別名，以及兩種插入順序下的檔案/目錄衝突。隱式父目錄可被同名顯式目錄補充；重複顯式目錄記錄仍報衝突。
- 報告宣告大小超過 8 GiB 的檔案、總計超過 20 GiB 的選擇及整數溢位。ZIP 條目的宣告壓縮比超過 1000:1 時提示覆核。目錄大小不計入輸出位元組。

Unicode 小寫比較不是完整大小寫摺疊或 NFC/NFD 檔案系統等價規則。任何非 ASCII 元件都使報告標記“需要目標檔案系統複核”。沒有問題的報告也不能授權輸出。

<a name="xdzip-资源与失败"></a>

## 資源與失敗

最多檢查 100,000 條快照記錄，選中/展開名稱累計不超過 4 MiB；碰撞索引儲存的比較鍵與原拼寫累計不超過 8 MiB（不包含容器開銷）。元件遍歷深度固定有界，外層逐記錄檢查取消。報告完整統計問題數量，但跨橋接最多傳 64 條代表問題，內容只有物理記錄 ID 和穩定原因，無任意歸檔錯誤文字。

空選擇、外來 ID、索引限額或取消返回錯誤，不返回部分成功報告。總量溢位顯示“無法計算”，不截斷成零。基礎問題只報告，不自動覆蓋、改名、忽略或跳過。

未知原始大小報告穩定原因 `unknown_size`，`declared_bytes=None` 表示總量不可知，和已知空檔案的 `Some(0)` 分開。未知本身不產生偽造的超總量或未知壓縮方法問題；實際整數溢位仍產生總量限額問題。輸出任務另行拒絕未知尺寸記錄，不進入解碼、暫存或密碼互動。

<a name="xdzip-桌面入口"></a>

## 桌面入口

選中條目後點選“解壓預檢”。結果使用 `OperationWindow` 獨立非模態頂層視窗，繫結主視窗為 transient owner，保留原生標題欄；不繪製 macOS 紅綠燈。關閉結果只關閉該視窗；主視窗關閉時複用協作取消，不在 GUI 執行緒等待工作執行緒。

<a name="xdzip-与真实解压的边界"></a>

## 與真實解壓的邊界

[真實安全解壓](zip-safe-extraction.md)已獨立實現輸出計量、CRC／結構驗證、目標授權、平臺路徑複核、衝突、暫存與檔案提交，不限於預檢的 128 條選擇，支援十萬條物理記錄的計劃及虛擬目錄選擇。預檢報告不復用為寫入許可；啟動任務仍須按[檔案安全規範](../design/file-security.md)重新獲得目標授權、複核來源並校驗實際內容。原生失敗行為與目前已知缺陷按對應契約及 issue 跟蹤。
