# 解壓預檢：後設資料階段

[English](../../engineering/extraction-preflight.md) | [简体中文](../../zh-CN/engineering/extraction-preflight.md) | 繁體中文（台灣）

本模組提供中繼資料預檢規則，不具備目標授權、解碼、寫入、暫存或提交能力。

<a name="xdzip-实现与边界"></a>

## 實現與邊界

`xdzip-extract-plan` 只依賴領域與中繼資料介面，不依賴 Qt、格式解析器或額外第三方套件。輸入是工作階段快照、一組實體 EntryId 和取消訊號；輸出僅為受限報告，不包含可寫入路徑或「安全核准」旗標。`xdzip-runtime` 持有快照，Qt 透過工作執行緒橋接呼叫它。

選取範圍必須非空，最多 128 個實體 ID，且全部屬於目前快照。選取目錄時，依原始名稱的斜線邊界展開所有後代，不受搜尋、分頁或目前目錄範圍影響；同時選取目錄和子項時，子項只計算一次。同名實體記錄不依路徑合併。目錄統計只計明確記錄，不虛構目錄物件。

預檢透過命令與事件服務執行，具有限制的准入及獨立取消。執行階段在檢查前後都會複核已開啟來源的識別。使用磁碟索引的 ZIP 會從索引載入所選實體記錄及所需後代。選取範圍、查詢或工作階段變更時會清除報告。結果是根據已記錄中繼資料的估計；預檢不解碼項目內容、不保留目標路徑，也不授予寫入權限。

<a name="xdzip-已执行规则"></a>

## 已執行規則

- 名稱須能解析為 UTF-8，最多 4 KiB、64 個路徑元件，每個元件最多 255 位元組；不修復或改寫原始名稱。
- 拒絕絕對路徑、空元件、`.`、`..`、反斜線、冒號、控制與雙向控制字元、Windows 無效字元，以及元件結尾的空格或句點。
- 拒絕常見 Windows 裝置名稱，包括帶副檔名的形式及 COM/LPT 上標數字；保守套用跨平台可攜名稱子集。
- 回報現有中繼資料警告，並使用記錄的內容與密碼能力旗標。加密記錄可能回報受支援的密碼需求，或回報不支援的加密方式。大小已知但內容不受支援的記錄也會回報方法問題。預檢使用讀取器提供的中繼資料與能力，不解密、驗證或解碼內容。
- 檢查完全相同的名稱、Unicode 小寫比較產生的衝突、大小寫不同的父目錄別名，以及兩種插入順序下的檔案與目錄衝突。隱含父目錄可由同名明確目錄補充；重複的明確目錄記錄仍會衝突。
- 回報宣告大小超過 8 GiB 的檔案、超過 20 GiB 的總量及整數溢位。ZIP 記錄宣告壓縮比超過 1000:1 時提示審查。目錄大小不計入輸出位元組。

Unicode 小寫比較不是完整大小寫折疊，也不是檔案系統的 NFC/NFD 等價判斷。任何非 ASCII 元件都會提示仍須在目標檔案系統檢查名稱等價與衝突。即使報告沒有問題，也不能授權輸出。

<a name="xdzip-资源与失败"></a>

## 資源與失敗

最多檢查 100,000 筆快照記錄；選取及展開名稱累計最多 4 MiB。衝突索引儲存的比較鍵與原始拼寫合計最多 8 MiB，不含容器額外負擔。元件遍歷深度受限，外層逐筆記錄檢查取消。報告計算所有問題，但最多只將 64 筆代表性問題傳過橋接，內容只有實體記錄 ID 和穩定原因，不含任意壓縮檔錯誤文字。

空選取、外來 ID、索引超限或取消會回傳錯誤，不回傳部分成功的報告。總量溢位時顯示「無法計算」，不截斷為零。基本問題僅供回報，不會自動覆寫、重新命名、忽略或略過。

未壓縮大小未知時回報穩定原因 `unknown_size`。`declared_bytes=None` 表示總量未知，與已知空檔案的 `Some(0)` 不同。未知值不會憑空產生總大小超限或未知方法問題；實際整數溢位仍會產生總量限制問題。輸出工作會另行拒絕未知大小的記錄，且在解碼、暫存或密碼互動之前拒絕。

<a name="xdzip-桌面入口"></a>

## 桌面入口

選取項目後點選「解壓後設資料預檢…」。結果使用獨立、非強制回應的頂層 `OperationWindow`，以主視窗為暫時擁有者並保留原生標題列；應用程式不自行繪製 macOS 紅綠燈按鈕。關閉結果只會關閉該視窗；關閉主視窗時採協作式取消，不在 GUI 執行緒等待工作程序。

<a name="xdzip-与真实解压的边界"></a>

## 與真實解壓的邊界

[實際安全解壓縮](zip-safe-extraction.md)獨立實作輸出計量、CRC／結構驗證、目標授權、平台路徑複核、衝突、暫存和檔案提交，不受預檢 128 個選取項目的限制，支援 100,000 筆實體記錄的計畫與虛擬目錄選取。預檢報告不能當作寫入許可；啟動工作時仍須依[檔案安全規範](../design/file-security.md)重新取得目標授權、驗證來源並檢查實際內容。原生失敗行為及目前已知缺陷由相關契約與 issue 追蹤。

<a name="xdzip-窗口与结果呈现"></a>

## 視窗與結果呈現

預檢使用寬 491 邏輯像素的共用操作視窗，內容區依內容調整，客戶區高度最多 600，長問題清單可捲動，固定頁尾可供無障礙操作。資料與中繼資料階段的授權邊界不變。參數與設計原稿見[預檢參數](../../../specs/visual/preflight-reference.json)。

2026-10-15 修訂預檢說明位置：將「此報告僅檢查後設資料……」移至可捲動內容末尾，使用 12 點說明文字。頁尾不再放置此說明，只保留返回動作，其高度與相同字級的共用純動作頁尾一致，不隨報告長度變化。
