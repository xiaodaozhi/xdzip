# 檔案列表開啟、雙向拖放與歸檔修改

[English](../../engineering/archive-transfers.md) | [简体中文](../../zh-CN/engineering/archive-transfers.md) | 繁體中文（台灣）

右鍵“開啟”作用於右擊條目，保留多選，複用雙擊和 Enter 的入口。目錄進入，普通檔案使用[臨時開啟](archive-opening.md)的私有快取、密碼和關聯程式規則。會話、查詢變化關閉選單，執行時仍核對穩定條目身份。

<a name="xdzip-外部拖出"></a>

## 外部拖出

列表和網格達到系統拖動閾值後凍結選擇與包內目錄。拖動未選項先單選，拖動已選項保留選擇。目錄展開後代，父子重複選擇去重，保留目前目錄以下的相對層級及空目錄，不刪除歸檔內容。連結不經拖出入口釋出。清單最多十萬項，名稱及結構預算為 4 MiB，仍受安全解壓的位元組、路徑、密碼及配額約束。

生成拖出清單隻準備傳輸後設資料，不屬於目錄讀取。準備及原生交接期間保留已提交的列表／網格、選擇和目錄，不顯示主頁面的“正在讀取”遮罩；請求仍保持忙碌與取消語義。真正的開啟、目錄查詢以及歸檔修改繼續使用各自的等待意見回饋。

Windows 透過 OLE `IDataObject` 的 FILEDESCRIPTOR/FILECONTENTS 和非同步能力提供內容。目標接受後啟動背景準備，私有副本完整校驗後才交給消費者讀取；同步消費者不能使 GUI 等待任務，未支援的目標明確失敗。Explorer 決定最終位置和重名。FILEDESCRIPTORW 的路徑須短於 260 個 UTF-16 單元。內容流只讀，取消後停止提供後續資料。非同步消費者結束前，退出仍等待本機傳輸結束。

macOS 透過 NSFilePromiseProvider 向 Finder 提供頂層檔案或目錄承諾。私有副本準備完成後，Finder 提供的本地檔案 URL 經 Rust 的獨立 PublishExport 任務授權，逐檔案暫存並校驗來源後釋出，不覆蓋既有普通檔案。POSIX 普通檔案沿用安全解壓的 0600 | (mode & 0155) 許可權策略，保留可執行位並剝離特權和外部寫位。目錄合併及部分完成遵循安全解壓的輸出邊界，不承諾傳輸整體回滾。檔案承諾回撥在背景等待，檔案寫入始終進入有界任務佇列與退出屏障。

Linux 的已支援基線為 Ubuntu 24.04 x86_64、X11。先準備私有副本，準備完成且滑鼠仍按下時開始檔案 URL 拖放；提前釋放時提示再次拖動並複用副本。檔案管理器決定最終複製與重名，應用不推斷最終目標和儲存成功。Wayland 不在本次支援承諾中。

匯出快取與臨時開啟快取分別存放。使用隨機目錄、身份標記及活動鎖，準備失敗不釋出 URL。保持七天保留與有界後續清理，不在拖動返回時刪除消費者可能仍需讀取的檔案。頁面關閉保留任務所屬控制器，明確退出取消準備並等待 Rust 工作執行緒與原生消費者結束。

拖出到系統目標位置後，匯出和複製任務均不自動開啟 Explorer、Finder 或目標目錄。普通解壓的“完成後開啟目錄”只屬於該次明確的解壓請求，不能被後續匯出或臨時開啟繼承。使用者主動點選結果視窗的開啟入口仍按原行為處理。

<a name="xdzip-外部拖入和确认"></a>

## 外部拖入和確認

現有 CAB、ISO、UDF 和 RAR 歸檔不支援新增、替換或包內移動，介面和 Rust 執行入口均執行這項限制。可輸出條目仍可透過統一的受保護讀取路徑拖出、臨時開啟或解壓。[建立新的 ISO 映像](iso-creation.md)是獨立操作。

已開啟歸檔的檔案列表正文接收真實本地檔案與目錄，僅接受複製。拖入其他壓縮檔檔案時按普通輸入新增，歡迎頁仍執行拖入開啟。遠端 URL、虛擬附件、連結和特殊物件拒絕接納。拖入時凍結會話、目前目錄及輸入，搜尋頁要求先進入目錄。

新增前由 Rust 按[建立輸入過濾](zip-creation.md#xdzip-macos-%E5%85%83%E6%95%B0%E6%8D%AE%E8%BE%93%E5%85%A5%E8%BF%87%E6%BB%A4)排除各層級 `.DS_Store` 檔案和 `__MACOSX`／`_MACOSX` 目錄。過濾後沒有有效條目時，結果視窗顯示明確失敗原因，原包位元組保持不變；不刪除主機原檔案或原歸檔既有後設資料。

UpdateWindow 按建立原稿呈現圖示標題與新增檔案、新增位置、新增選項三塊卡片，檔案區與 CreateWindow 共用 ArchiveInputPanel。使用者可繼續選擇檔案或目錄、去重及透過滑鼠、鍵盤和輔助功能移除；普通檔案大小複用最多 256 項的背景摘要，目錄總量未知。摘要是預覽，不替代任務輸入凍結。視窗草稿互相獨立，隱藏視窗不接管後設資料請求。目標歸檔與包內目錄只讀，接收原拖入時凍結的會話及目錄，確認仍復驗穩定身份。提供詢問、跳過、改名、替換策略。預設詢問。同名目錄合併並沿用原有拼寫，檔案/目錄衝突拒絕。替換作用於包內普通檔案，不授予覆蓋主機輸入檔案的許可權。確認前不修改歸檔。視覺使用建立視窗的 491 邏輯寬度、三卡片和共享控制元件，見[獨立稿](../../../design/hifi/sources/archive-add.html)。

新增或包內移動被接納後，主頁面的取消入口按原會話的真實任務身份傳送任務取消，包括重名提示已關閉、任務仍在等待決定的情況。不能只取消已經結束的任務登記請求。取消後繼續等待任務終態、清理與原歸檔重開完成，再恢復目錄查詢與選擇；不提前解除舊條目身份的凍結。

修改期間保留已提交檔案頁用於顯示，舊查詢和選擇身份仍不可操作。頁面等待層按真實命令保留新增或移動名稱，直到重新整理結束。任務取消被執行時接納後立即標記取消請求，重名和密碼提示失去決策資格，進度視窗顯示取消中並繼續跟隨真實終態。重名視窗繫結任務及提示令牌；使用者關閉後的同一提示不因其他任務更新自動重開，可由任務入口明確重開。任務切換、提示令牌更換、終態和退出均關閉舊提示，按鈕不得把舊決定提交到新任務。

<a name="xdzip-包内拖放移动"></a>

## 包內拖放移動

檔案列表和網格達到系統拖動閾值後，先以包內移動處理，凍結目前會話、查詢代次、選擇版本、包內源目錄與穩定條目 ID。拖動未選項先單選，拖動已選項保留多選。源項保持原位繪製，目標資料夾在列表、網格及目錄樹使用既有選擇色高亮。操作說明覆用提示的字號、最大寬度和內距，最多四行，邊界受目前客戶區約束；這是拖放中的即時狀態，不沿用普通懸停提示計時。

同目錄的資料夾及左側目錄樹中的任意已索引目錄可接收，包括從子目錄移到根目錄。只接受本會話的私有拖動身份，不把外部 URL 或其他會話的條目解釋為移動。列表、網格與左側目錄樹使用同一目標限制。目標不能是任一選中的資料夾、其任意深度後代或源目錄；混選時仍拒絕整次移動，不只跳過目標資料夾。搜尋頁、過期選擇和目前不可修改的歸檔同樣拒絕。拒絕目標保留即時說明和禁止投放狀態，鬆手不啟動任務；加密、分卷及兩者組合各有明確說明。外部新增的拒絕說明也在懸停時展示，實際 drop 仍拒絕。

有效目標鬆手後直接進入獨立 move 任務，複用既有進度、重名與結果視窗。普通檔案重名預設詢問，支援跳過、使用新名稱及替換，並可應用到後續衝突。資料夾合併，檔案與資料夾的型別衝突失敗。跳過的原始檔仍在原位置，保留所需的顯式源目錄；完全移動的源條目消失，空目錄與隱式目錄均可移動。移空目前隱式源目錄時補充空目錄記錄，保持瀏覽位置。成功或失敗後重新開啟原歸檔，保留源目錄及排序，清除舊物理 ID 的選擇。編輯接納、執行和重開期間保留列表快照並凍結目錄查詢，不允許舊身份再發起瀏覽。

MoveOptions 只傳遞有界的源目錄、目標目錄與選擇身份，不接納主機路徑。核心再次解析直屬源條目並拒絕迴圈、原位置及過期身份。移動與新增共用名稱空間、重名決策、完整內容校驗及同卷原子替換。ZIP 原樣複製壓縮載荷並改寫名稱；TAR 保留普通記錄頭和除 path 外的受支援 PAX 屬性，路徑以 UTF-8 PAX 改寫，GNU 長名稱轉為 PAX，TAR.GZ 重建外層 GZIP。無法安全保留的擴充套件明確失敗，提交前失敗和取消保持原包位元組。

滑鼠離開源視窗客戶區或源視窗失活後，凍結選擇交給原有平臺外部複製流程，包內拖動結束。晉升為系統拖出後，不將返回應用的匯出資料當作包內移動或新增輸入。該邊界防止私有暫存內容被再次新增，平臺外部拖出規則保持不變。

`Move` 和 `Update` 命令使用有界任務佇列，並校驗目前會話。任務准入後，命令執行緒釋放歸檔快照，控制器可繼續顯示最後一次渲染的頁面，等待任務終態後重新開啟歸檔。Page 的 `edit_restriction` 位 0 表示加密，位 1 表示分卷，位 2 表示其他限制，包括格式不支援改寫、ZIP 使用磁碟索引、記錄不安全或方法不受支援。所有位為零時 `update_allowed` 才為真。執行時依據整個來源快照計算資格，任務寫入前仍須校驗輸入。

<a name="xdzip-普通归档修改事务"></a>

## 普通歸檔修改事務

Update 支援普通單檔案 ZIP、TAR、TAR.GZ 和 7z，不改寫加密、分卷、連結、特殊記錄或無法安全保留的名稱。能力由整個源快照決定，不能僅檢查目前頁面。任務接納後釋放後設資料會話，舊條目 ID 不再接受新操作；任務保留源控制代碼與身份。

名稱使用[編碼契約](filename-encoding.md)的凍結結果，已解析的舊名稱在改寫時明確寫為 UTF-8，並重新檢查包內名稱空間與 Unicode/大小寫碰撞。源版本和 no-follow InputTree 凍結後，在原歸檔同卷的私有工作區生成完整新歸檔。ZIP 由獨立記錄層複製原壓縮載荷並保留已准入後設資料，新增項使用 Deflate 6；7z 使用獨立 Rust 後端重建並以 LZMA2 正常級別加入內容；TAR 保留原始記錄組，TAR.GZ 重新編碼外層 GZIP 流。保留的 ZIP、TAR 和受支援 7z 記錄按原物理順序處理，新項追加；7z 的可保留屬性和重建邊界見[自研規格](independent-rust-codecs.md#xdzip-7z%E8%AF%BB%E5%86%99%E8%A7%84%E6%A0%BC)。新包仍須核對預期條目的型別、大小和完整負載，不能遺漏、重複或混入記錄。重複或歧義記錄、ZIP 自解壓字首、無法改寫的擴充套件明確失敗，不能靜默丟棄。TAR 全域性 PAX 記錄暫不改寫。

包內名稱空間包含隱式父目錄，上限十萬節點，名稱及規範化索引共用 16 MiB 預算，避免透過深層路徑生成無界索引。新歸檔重新掃描並逐檔案解碼到有界校驗接收端，再複核輸入、原歸檔及目標身份。只有繫結原檔案版本的 ArchiveUpdate 能力可以整體替換它，普通建立和解壓的源保護不變。原歸檔作為新增輸入明確拒絕。檔案系統缺少所需原子原語時失敗，不先刪除、截斷或以複製/刪除模擬替換。版本複核是盡力檢測，不承諾同賬戶惡意併發寫入的內容 CAS 或斷電持久化。

提交前取消或失敗保留原歸檔位元組。提交許可獲得後成功釋出勝出，清理失敗單獨記錄。成功或失敗後重新開啟同一源，清除失效的物理條目選擇。任務使用獨立 update、move、export 和 export-copy 型別，不把私有準備完成當作系統複製成功。

7z 修改保持同一名稱空間、衝突、來源複核及原子替換契約，固實內容需要解碼重建。重建輸入使用顯式有界緩衝，總原內容及新增內容不超過原生介面卡的 512 MiB 快取上限，另受後端 1 GiB 程序記憶體預算約束，超限明確返回資源限制。該上限不擴大為磁碟快取許可權，原包仍不變。修改成功後的輸出可能採用正常級別和非固實佈局，不承諾保留原始壓縮流、演算法組合、固實分塊或最終物理記錄順序。驗證時逐項檢查負載，並確保凍結的唯一名稱集合恰好各出現一次。檔名加密、內容加密或任何分卷 7z 均拒絕修改，空的加密目錄也不能繞過。

RAR 使用獨立 Rust 只讀後端，不提供新增、替換或包內移動。整包 edit_restriction 的其他不支援位始終開啟，不能透過目前頁沒有不支援條目繞過。7z／RAR 連結及特殊物件不寫出，外部複製、臨時開啟仍經過既有預檢和安全輸出任務。

<a name="xdzip-验收边界"></a>

## 驗收邊界

列表與網格的完整名稱提示在內部移動、原生複製準備和實際原生拖動期間統一抑制，取消舊靜止計時。內外拖動交接不能短暫重新開啟源提示；Windows以OLE返回、macOS以原生拖動結束回撥、Qt準備後拖動以exec返回解除手勢狀態，非同步複製可繼續，不能把複製任務結束當作滑鼠手勢結束。結束後須先獲得新的指標位置，再重新完整靜止等待1200ms，避免快取的源hover使提示覆活。

拖動預覽只表達凍結的源名稱、圖示和選中數量，不讀取或解壓內容，不授予目標寫入許可權。內部預覽從有效拖動令牌取值，跨出視窗後清除內部覆蓋層並交給原生複製意見回饋。Windows IDataObject 為 Shell 影象保留有界、執行緒安全的私有 HGLOBAL 格式，並單獨持有唯一 DragContext 流的 COM 引用而不讀取或複製其內容，GetData 返回獨立引用；禁止覆蓋檔案描述符、內容流和首選動作。失敗不改變原有安全輸出與取消語義。原生影象使用非預乘 BGRA 交給 Shell，點陣圖所有權在初始化呼叫時移交，COM／GDI 準備失敗沿用系統游標。具體樣式見 [拖動規範](../../../specs/visual/drag-preview.json)。

核心覆蓋三格式、目前目錄、原內容和空目錄、重名策略、來源變化、受保護輸入及取消；Qt 覆蓋真實右鍵開啟與新增確認，中英文、淺深色、多字號和凍結會話。Windows 原生協議測試驗證非同步資料物件和實際內容流。移動迴歸覆蓋列表/網格、目錄樹、拒絕目標、混選、目錄合併、後設資料保留及邊界交接，三格式由獨立 Python 讀取器複核。真實 Explorer、Finder、Ubuntu Files 及桌面投放按需檢查，執行時分別登記；離屏與協議接收器不冒充未執行的桌面操作。階段證據記錄於對應 issue 和本地/CI 工件。
