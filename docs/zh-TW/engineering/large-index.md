# 大歸檔索引與按需瀏覽

[English](../../engineering/large-index.md) | [简体中文](../../zh-CN/engineering/large-index.md) | 繁體中文（台灣）

普通單檔案 ZIP/ZIP64 的原始碼能力上限為一百萬條物理記錄。其他格式和分卷路徑保持各自現有的十萬條准入；格式名稱不表示所有組合都已擴大上限。目錄、重複名稱和待檢查記錄均計入物理數量，隱式導航目錄只增加展示行。

<a name="xdzip-扫描与存储"></a>

## 掃描與儲存

ZIP 逐條掃描複用普通 ZIP 解析器，先完成有界的整包舊編碼名稱取樣，再以同一編碼決定執行第二遍。兩遍合計讀取最多 512 MiB，中央目錄最多 256 MiB，原始名稱累計最多 128 MiB，解碼和顯示名稱合計最多 128 MiB，每個原始或解碼名稱仍限 4 KiB。損壞尾部、取消或來源變化使整次結果失敗，不釋出區域性索引。

熱後設資料到達 64 MiB 或超過十萬條後，逐條遷入私有磁碟儲存，釋放已有名稱和記錄，不同時保留兩份完整索引。物理位置表最多一百萬個 u64 偏移。磁碟後設資料最多 512 MiB，檔名稱與內容均不進入診斷字串。目錄樹仍受 32768 節點、64 層和 4 MiB 名稱預算限制，超過時整棵樹不釋出，根目錄和物理搜尋仍可用。

臨時檔案位於宿主臨時目錄下隨機命名、僅目前使用者可讀寫的 `xdzip-index-*` 目錄，透過持有的目錄和普通檔案控制代碼操作。正常關閉、查詢替換、失敗和取消清理已知檔案及核對身份後的空目錄。崩潰遺留使用與目錄隨機身份一致的 16 位元組標記及排他租約識別；後續建立時有界掃描，七天以上且未使用的已知檔案才可清理。連結、身份失配或未知物件保留，不遞迴刪除陌生內容，不恢復或跨啟動複用索引。

Windows 新建目錄須先透過普通的所有者和修改許可權檢查，再保護 DACL 以存放私有資料。繼承給無關主體的修改許可權會在寫入租約或後設資料檔案前被拒絕，執行時不會靜默換用保護更弱的位置。隔離驗證時，僅將測試程序的 `TMP` 和 `TEMP` 指向新建的自有目錄，其 ACL 只允許目前使用者、SYSTEM 和 Administrators 修改。不要改寫真實使用者目錄 ACL 或放寬許可權檢查。分別核對初始化、實際磁碟查詢和歸併、活動租約、已知檔案清理，以及無關主體修改許可權的拒絕。

<a name="xdzip-查询与选择"></a>

## 查詢與選擇

搜尋與排序生成一個不可變的完整行序，按每段最多 8 MiB 的排序鍵寫入私有歸併段，最多 128 段，臨時排序儲存最多 512 MiB。終態查詢只存行令牌，不保留整套名稱副本。比較仍使用原始整數、現有名稱／型別規則和穩定物理身份；所有排序均固定將顯式和隱式目錄放在檔案前，升降序只作用於各組內部；未知大小在所屬組內排在已知項後，不因降序改變重複項身份順序。取消檢查覆蓋掃描、排序段前後和歸併，不在比較器內改變順序關係。

橋接每批最多 128 行、64 KiB 名稱。最多 1024 行的查詢保留原有完整提交方式，更大的 Qt 模型保留全部邏輯行數，僅按可見位置載入，駐留快取最多 1024 行。未載入行不能提交條目動作。每個延遲頁繫結會話、查詢、代際、修訂及請求偏移，舊頁不能進入新結果。

跨頁選擇以目前不可變查詢中的有界區間表達，最多 4096 段；全選覆蓋整個目前查詢。離開快取不改變選擇。解壓確認前由 Rust 將區間凍結為物理／導航身份，查詢變化後仍使用已凍結的身份。超過任務十萬條上限的選擇明確拒絕，不自動縮小範圍。未駐留選擇的總大小暫不顯示；超出駐留內容的整批剪貼簿複製給出資源限制，不隱式複製不完整清單。

<a name="xdzip-任务边界"></a>

## 任務邊界

磁碟索引中的普通檔案選擇可經完整源複核、安全計劃、整條目校驗和既有授權提交解壓。單次凍結計劃仍限十萬條及 64 MiB 後設資料，檔案和實際解碼位元組沿用[解壓契約](zip-safe-extraction.md)。目錄擴充套件不能跳過未解析名稱；所選連結在此索引配置中拒絕。ZIP 讀取器重新檢查全部中央目錄物理偏移，只保留所選負載定位，保留重疊、區域性頭、尺寸、CRC、認證及取消檢查。

進入磁碟索引的歸檔暫不支援整體修改或整包測試，不能把空的記憶體投影當成完整歸檔。建立、其他格式、分卷與歸檔重寫的原有上限不變。預覽另見[內容預覽](content-preview.md)。CLI 的物理列舉與選擇複用同一索引，使用[顯式分頁引數](command-line.md#xdzip-%E5%BD%92%E6%A1%A3%E8%A1%8C%E4%B8%BA)取得大包的完整物理範圍；不分頁的響應保留十萬條及 16MiB 序列化資料／文字預算，超限整體失敗。

<a name="xdzip-验证"></a>

## 驗證

`scripts/probe-large-index.py` 在 `build/` 生成含中文、重複名和巢狀目錄的真實 ZIP64，再呼叫實際 `xdzip-m2-probe`。探針讀完所有查詢批次，並單獨記錄掃描、排序、檢索、磁碟位元組與平臺可用的記憶體指標。樣本生成器不在記憶體構造百萬條檔名陣列。範圍、失敗、取消、清理、過期頁和實際所選檔案輸出按[驗收要求](../../../developers/qa/acceptance.md)執行，結果保留在 issue／本地或 CI 工件。
