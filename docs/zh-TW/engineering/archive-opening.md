# 分卷讀取與臨時開啟

[English](../../engineering/archive-opening.md) | [简体中文](../../zh-CN/engineering/archive-opening.md) | 繁體中文 | [日本語](../../ja-JP/engineering/archive-opening.md) | [한국어](../../ko-KR/engineering/archive-opening.md) | [Français](../../fr-FR/engineering/archive-opening.md) | [Deutsch](../../de-DE/engineering/archive-opening.md) | [Español](../../es-ES/engineering/archive-opening.md) | [Português (Brasil)](../../pt-BR/engineering/archive-opening.md) | [Русский](../../ru-RU/engineering/archive-opening.md)

桌面檔案選擇、系統選單請求和 CLI 共用 Rust 的來源開啟規則。宿主解析允許的分卷組，記錄來源身份並探測已授權的位元組。選定的格式實現提供[瀏覽後設資料](readonly-browser.md)，部分格式經[隔離的格式工作程序](native-codecs.md)讀取。主動開啟條目時，應用會生成經過校驗的臨時副本，再交給系統關聯程式。驗證整包應單獨執行[完整性檢查](archive-checking.md)。

<a name="xdzip-分卷-zip"></a>

## 分卷 ZIP

讀取層支援編號連續位元組流 `name.zip.001`、`.002` 等，以及 PKZIP 的
`name.z01`、`.z02`、最終 `name.zip`。任意一卷均可作為開啟入口。
卷必須在同一目錄，名稱連續，最多 1024 卷；拒絕缺卷、連結及特殊檔案。
檔案字尾只用於發現相鄰卷組，真實容器仍由來源位元組探測並由對應後端完整掃描。
ZIP64 的經典磁碟號為 0xFFFF 時，先以相鄰 locator 的有界總卷數發現真實卷組，
不把佔位值誤當成缺少 65,535 個卷；該發現結果不替代完整尾記錄與目錄校驗。

Rust 主機持有各卷的身份、長度和修改時間。邏輯輸入按需跨卷讀取，不合併
整個歸檔。PKZIP 的磁碟相對偏移轉換為有界的單卷中央目錄檢視；原有編解碼器
繼續檢查目錄、本地頭、CRC、密碼認證和解壓配額。每次使用及提交前重新核驗
所有源卷，任何變化均停止任務。所有源卷身份均受輸出覆蓋保護。

PKZIP 歸一化僅處理已准入的中央記錄，不支援中央目錄數字簽名尾記錄；
不能把這種拒絕解釋為簽名驗證失敗。普通單卷可以有界讀取該記錄，但不驗證
其密碼學簽名，且拒絕修改，避免重定位後丟棄或破壞未知後設資料。

驗收覆蓋編號卷、PKZIP、ZIP64、跨卷頭與負載、缺卷、非連續卷、源替換、
非法磁碟編號、中文名稱，以及普通單捲回歸。

<a name="xdzip-7z-与-rar-分卷"></a>

## 7z 與 RAR 分卷

7z 編號卷使用 name.7z.001、.002 等連續位元組流。RAR 使用 name.partN.rar 或 name.rar、name.r00 等舊式卷名，將各卷交給隔離的 Rust RAR 讀取器時，保留每個 RAR 實體分卷的邊界。兩者均可從任意現存捲開始定位同目錄卷組；上限 1024 卷，目錄發現上限十萬項，缺卷、名稱編號衝突、連結和重解析點均明確拒絕。

Rust 儲存每卷控制代碼身份、長度和時間，並透過 ReadSource::volume_lengths() 向原生介面卡宣告授權邊界。原生程序只能請求宿主讀取已授權範圍；換卷不接納任意歸檔提供的主機路徑。所有卷參與來源複核和輸出覆蓋保護，第一卷或任何後續卷發生變化均停止任務。

7z 和 RAR 檔名加密可能在開啟階段要求密碼。普通 Open 返回 password_required 時不釋出索引，Qt 複用密碼視窗，以 OpenWithPassword 重新提交原選中檔案與受限秘密；錯誤驗證值返回 wrong_password。成功後密碼只由會話及其已准入任務持有，關閉會話釋放會話副本，不寫設定和恢復記錄。

<a name="xdzip-cab-分卷"></a>

## CAB 分卷

CAB 的卷名來自包頭，允許任意合法檔名，不能套用編號卷的位元組拼接規則。下一卷按卷序逐個連線；邏輯前卷可以指向持續檔案最初出現的較早卷，而不一定緊鄰目前卷，既有樣例也可能使用緊鄰前卷。Rust 從使用者選擇的任意卷沿邏輯前捲回溯，再沿下一卷完整發現同目錄卷組，核對集合標識、連續卷序及身份後凍結每卷長度和原始卷名。解碼器核對所有檔案片段；非緊鄰的前卷必須是實際持續檔案的起始卷。最多 1024 卷，同目錄發現最多十萬項。拒絕缺卷、錯卷、迴圈、重複身份、絕對路徑、目錄分隔符、父目錄逃逸、連結及重解析點，不將已開啟子集作為完整歸檔釋出。

工作程序的換捲回撥只能選擇該授權集合中的名稱，每卷提供獨立有界流。所有卷參與任務前和檔案提交前來源複核及輸出覆蓋保護，原生處理器的警告或缺卷結果不能轉為成功索引。CAB 單卷與分卷均只讀。

<a name="xdzip-双击普通文件"></a>

## 雙擊普通檔案

目錄雙擊仍進入目錄。普通檔案雙擊提交僅包含該物理條目的背景解壓任務，
輸出到使用者私有快取中的隨機目錄。連結和特殊物件不能透過此入口開啟。
沿用密碼、CRC、認證、取消和應用級重任務序列准入；無需使用者選擇解壓目標。

成功完成輸出後，透過本地檔案 URL 呼叫系統關聯，不經過命令直譯器。
只有系統接受開啟請求時才自動隱藏對應任務進度視窗。解壓失敗、取消或系統
拒絕開啟時不自動隱藏，並保留可讀錯誤。系統接受請求不等於外部程式已讀完
檔案，臨時檔案不能在發出請求時刪除。

臨時目錄使用不可猜測的 128 位隨機名稱，載荷與身份標記分開。輸出載荷目錄採用僅目前使用者及可信系統主體可訪問的許可權。Windows 僅對本次獨佔建立的空目錄，透過持有控制代碼設定受保護 DACL，寫出明文前重新檢查；不修改使用者所選目錄的共享許可權。POSIX 使用 0700，並檢查 macOS 繼承 ACL。許可權無法保證時拒絕寫出，見 [Win32 DACL 介面](https://learn.microsoft.com/en-us/windows/win32/api/aclapi/nf-aclapi-setsecurityinfo)。

持有鎖期間不清理，完成後至少保留七天，在後續臨時開啟時清理過期且未鎖定的目錄。快取最多保留 256 項，達到上限明確拒絕；每次掃描上限 4096 項。清理校驗私有許可權、標記與名稱，不遍歷連結。臨時副本修改不寫回歸檔。

臨時檔案的清理限定於應用建立的私有快取，不掃描或刪除使用者解壓目錄。
驗收覆蓋成功自動隱藏、失敗保留、取消、密碼重試、重複檔名、Unicode 和
特殊字元、關閉頁面後任務路由、臨時目錄安全和退出清理策略。

只讀 [Brotli/TAR.BR](brotli-streams.md) 在釋出條目前完整驗證無標頭候選，Brotli/LZMA 共用候選讀取預算，保留強源簽名及合法 TAR/ZIP 識別優先順序，解碼後損壞的 TAR 不能降級為普通流。

[LHA/LZH](lha-containers.md) 候選須在釋出前完整驗證有界頭部與名稱，包括單零位元組空歸檔。LHA、Brotli 和 LZMA 弱候選共享實際讀取帳本。有效強容器識別仍優先，完整 LHA 准入可消歧無效原始 TAR 標記；尚不準入密碼、分卷和修復配置。

[PMA](pma-streams.md) 共用弱探測帳本，完整驗證後設資料、準確零終止和可選有界 CP/M 填充。0 級頭部 PM0/PM1/PM2 內容受支援，未知方法可見但不支援。帶填充的空 CP/M 容器識別為 PMA，無法區分的單個零終止仍沿用先前 LZH 選擇。建立、密碼、分卷、修改和修復配置未准入。
