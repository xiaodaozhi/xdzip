本文規定瀏覽階段的資料、資源及互動邊界，補充[領域與資料](../design/domain-data.md)、[Qt/Rust 橋接](../design/qt-rust-bridge.md)和[格式擴充套件設計](../design/codec-extension-sdk.md)，不凍結第三方協議或完整格式 SDK。ZIP 的具體後設資料規則如下；TAR/TAR.GZ 複用瀏覽與查詢模型，格式差異見 [TAR/GZIP 契約](tar-gzip.md)。

<a name="xdzip-数据与依赖方向"></a>

## 資料與依賴方向

xdzip-codec-api 定義借用只讀輸入、取消訊號、限額、條目和錯誤。xdzip-codec-zip 實現內建 ZIP 後設資料適配，不獲取路徑或寫入能力。xdzip-runtime 開啟並持有隻讀檔案，掃描成功後釋出不可變快照。xdzip-qt-bridge 透過 cxx 暴露工作執行緒入口；薄 C++ 控制器將有界頁面轉換為 Qt 模型，QML 負責顯示和操作意圖。

已遷移到 [命令與事件執行時](product-runtime.md)：GUI 提交短命令，Rust 工作執行緒持有歸檔，獨立 Qt 接收執行緒透過有界 mailbox 投遞結果。QtConcurrent 同步橋接已移除。每個瀏覽控制器最多一個 pending 請求；這仍不是完整多工排程器、動態外掛 ABI 或第三方程序協議。

<a name="xdzip-行为与数据"></a>

## 行為與資料

開啟歸檔後列出根目錄的直屬項，搜尋可以覆蓋所有後代物理記錄。同名記錄各自保留 `EntryId`，會話 ID 不復用。介面以字串傳輸 ID 和位元組數，避免丟失精度。領域層的 `PageRequest` 最多可表示 256 行，產品執行時實際從同一個已排序的查詢結果切頁，每頁最多傳輸 128 行，名稱合計不超過 64 KiB。Qt 對 1,024 行以內的結果一次性更新。更大的結果保留邏輯行數、按需取行，最多快取 1,024 行。介面沒有分頁控制元件。內容預覽見[內嵌預覽](content-preview.md)，用系統關聯應用開啟條目見[歸檔開啟契約](archive-opening.md)。

識別 ZIP／ZIP64，校驗 ZIP64 locator、尾記錄及中央目錄起始磁碟。[分卷主機](archive-opening.md)統一邏輯輸入，編解碼器仍拒絕未經轉換的多磁碟後設資料。ZIP64 的大小與偏移保持 64 位，不根據宣告大小分配內容緩衝。中央目錄數量必須與 EOCD 一致，錯誤、取消或超限不釋出半成品列表。名稱按[編碼契約](filename-encoding.md)統一解析，優先 Unicode 宣告，再檢測未宣告的舊編碼；未解析位元組轉義。控制字元和雙向文字控制符轉義；絕對路徑、上級路徑、特殊檔案等標為“需檢查”。原始名稱位元組始終保留，輸出僅使用經過獨立路徑驗證及授權的有效名稱。

瀏覽器顯示的大小、壓縮方法和加密位來自歸檔後設資料。ZIP 瀏覽讀取中央目錄，不逐條校驗本地頭或負載。部分格式需要解碼外層才能讀取記錄，例如壓縮 TAR。開啟歸檔不會寫出解壓後的歸檔條目，但執行時可為大型普通 ZIP 建立私有的[磁碟後設資料索引](large-index.md)。需要驗證內容時，請執行獨立的[完整性檢查](archive-checking.md)或[安全解壓](zip-safe-extraction.md)。

<a name="xdzip-跨平台文件名编码边界"></a>

## 跨平臺檔名編碼邊界

格式層保留原始名稱位元組和物理身份，優先 ZIP UTF-8 標誌及經 CRC 校驗的 Unicode Path，再對整組未宣告名稱進行 UTF-8 檢查及有界歸檔級統計檢測。GBK/GB18030、Big5、Shift-JIS 等舊名稱可直接用於瀏覽、導航、解壓、臨時開啟、拖出及普通包修改。所有路徑消費者共享凍結的解碼結果，重新執行路徑、Unicode/大小寫及重名檢查。

檢測不依賴系統內碼表或介面語言，也不能保證任意短名稱、多個未宣告編碼或已經儲存成 Unicode 的亂碼均可恢復。目前無手動編碼選擇器。宣告損壞、嚴格解碼失敗或異常路徑繼續標記需檢查並拒絕輸出。完整優先順序、TAR/PAX、預算、載荷繫結和儲存規則見[檔名編碼自適應契約](filename-encoding.md)。新建和新增名稱保持 UTF-8，修改時對已解析的舊名稱補充明確 UTF-8 宣告。


<a name="xdzip-资源与生命周期"></a>

## 資源與生命週期

主視窗校準後顯示名稱、原始大小、壓縮大小、型別、修改日期五列。型別僅由顯示名稱字尾推斷，JPG 統一為 JPEG。修改日期來自 ZIP 中央目錄的有效 DOS 本地日期／時間，不推斷時區，無效值留白。五列均支援排序；日期按完整 DOS 時間排序，表格顯示日期。屬性欄和獨立屬性視窗顯示包含秒的 24 小時制時間，簡體中文示例為 `2026/10/15 12:34:56`。壓縮方法仍在詳情中可用，橋接保留方法排序程式碼。加密／需檢查狀態保留於行提示、可訪問描述和詳情；需注意條目在名稱旁顯示標記，不能被視覺精簡隱藏。

正常產品由應用會話管理器處理標籤關閉，保留背景任務和結果；無任務頁面非同步關閉連線後回收。加號按儲存的開啟模式建立空白標籤頁或主視窗，檔案開啟統一優先複用歡迎頁並去重，詳見[應用會話契約](application-sessions.md)。獨立控制器和診斷測試仍保留 `CloseSession` 命令，用於清空單個連線中的歸檔狀態。標題欄全選核取方塊為三態；狀態列大小隻彙總目前查詢已選後設資料，不冒充歸檔總量。按[驗證方法](../../../developers/qa/README.md)保留行為及實際幾何證據。

| 專案 | 目前上限 |
| --- | --- |
| 物理記錄 | 100,000 |
| 單個原始名稱 | 4 KiB |
| 累計原始名稱 | 16 MiB |
| 轉義顯示名 | 16 MiB |
| 累計讀取位元組（含重複讀取） | 64 MiB |
| 掃描緩衝區 | 256 KiB |
| 橋接傳輸批次 | 128 條 |
| Qt 目前查詢模型 | 邏輯行數受索引准入限制，最多駐留 1024 行，虛擬化委託 |
| 獨立目錄索引 | 32,768 節點、64 層 |
| 目錄名稱與完整字首合計 | 4 MiB |

顯示轉義和橋接複製另佔空間；上述不是程序 RSS 或耗時保證。普通記憶體快照的後設資料駐留 Rust 記憶體；直屬索引保留行身份，查詢結果快取只存排序後的索引。十萬條測量按[驗證方法](../../../developers/qa/README.md)繫結提交、平臺與負載記錄，不能單獨證明百萬條場景的結果。掃描前後檢查長度和修改時間，只能盡力檢測變動，不能替代原子快照。

取消在讀取和遍歷邊界檢查，不能打斷作業系統阻塞讀取。關閉忙碌主視窗先請求停止，收到完成通知後關閉，不在 GUI 執行緒 join。控制器意外銷燬也不使背景任務引用懸空。正常視窗關閉和應用 Quit 已統一經過 M1 shutdown 屏障；建立與解壓共用該退出屏障；寫失敗和暫存清理按各寫入契約處理。強制終止後只報告可疑暫存，不自動恢復、覆蓋或刪除未知內容，不承諾全目錄事務或裝置掉電安全。

原始檔要求普通檔案。首次開啟、來源複核和任務來源副本統一使用 `xdzip_io::open_regular_readonly`，在開啟所得的同一控制代碼上覆核型別；Unix 以非阻塞方式開啟後分類，避免路徑被換成 FIFO 等特殊物件時等待其 I/O。普通檔案和指向普通檔案的源符號連結保持可用，來源版本仍繫結實際檔案身份。首次無法開啟或型別不符返回 `Io`，後續來源複核與副本開啟失敗返回 `SourceChanged`。這不是原子內容快照、沙箱或普通檔案 I/O 的強制時間限制。

橋接源路徑暫限可無損表示的 UTF-8。檔案選擇器採用原生獨立對話方塊，macOS 不繪製交通燈；實際系統焦點、模態歸屬與視窗裝飾須在桌面驗收。

<a name="xdzip-验收与后续"></a>

## 驗收與後續

實際測試與截圖按[驗證方法](../../../developers/qa/README.md)在 issue 和工件登記。瀏覽實現包含真實開啟、列表、內部批次查詢、目錄樹、目前查詢選擇與命令/事件生命週期，並提供三平臺開發構建。十萬條 ZIP64 索引與查詢代際按 [ZIP 瀏覽契約](zip-readonly-browsing.md)驗證；寫入行為由[安全解壓契約](zip-safe-extraction.md)獨立規定。內容預覽遵循獨立的內容和解碼配額，正式發行仍按[發行許可複核](../../../developers/qa/release-review.md)處理；不由本文記錄階段驗收結論。

<a name="xdzip-浏览交互增量"></a>

## 瀏覽互動增量

- 歸檔中的安全顯式目錄可雙擊進入，或聚焦核取方塊按 Enter；“根目錄”返回根範圍。普通目錄只顯示直屬檔案與目錄，不遞迴列出後代；搜尋遞迴目前範圍並顯示完整歸檔路徑。列表的普通名稱只顯示末級名稱，不影響內部完整路徑、複製與導航。危險名稱不可成為導航節點，仍保留在歸檔快照中供搜尋和後設資料檢查。
- 名稱搜尋回車提交，Unicode 小寫後作字面子串匹配，不支援正則或區域排序；搜尋框最多 256 個 UTF-16 程式碼單元，Rust 入口最多 1,024 UTF-8 位元組。搜尋作用於目前目錄範圍；返回根目錄保留搜尋詞，開啟新會話清空搜尋。
- 普通記憶體查詢過濾遍歷已載入且最多 100,000 條的快照，再按指定順序排序並返回至多 128 條；過濾每條記錄、排序前後檢查取消。目錄引數傳物理 EntryId 或 `d` 字首的虛擬目錄 ID，由 Rust 校驗目前會話資格，不接受 GUI 拼接的檔案路徑。
- 這是單工作執行緒、有界的版本化查詢。頁面攜帶完整 QueryKey，Qt 合併最新意圖並取消舊工作；過期請求或不匹配的會話、查詢、代際、修訂和偏移均不能替換目前檢視。偏移越界返回錯誤，空結果屬於 Ready。目錄跳轉與搜尋從第一頁開始。
- 已有快照時，目錄、排序或搜尋查詢期間保持該快照的列表／網格或空狀態，直到新結果提交；不因 busy 短暫切換整塊遮罩。初次開啟未就緒歸檔仍顯示載入狀態，控制器繼續執行原有序列准入、取消和源變化檢查。
- 單擊行或核取方塊切換目前查詢多選，以物理 ID 區分同名記錄，隱式目錄使用獨立的 dN 行鍵。查詢成功或新會話替換模型後清空選擇及詳情；內部傳輸批次不影響已合成列表，介面不分頁。詳情顯示最近啟用條目的後設資料，和核取方塊集合分別表達焦點與選擇。全選以目前完整列表最後一行作為詳情焦點，與逐項選中到最後一行的行為一致；取消全部選擇清空詳情。沒有選擇時隱藏原始大小、壓縮大小、修改日期、壓縮方法與解壓焦點條目的動作，不展示誤導的空屬性。
- 列表大小以 B/KiB/MiB/GiB 顯示，數值轉換僅用於近似顯示；模型和 Rust 保留原始整數。檔案圖示表示型別，詳情卡片顯示屬性，卡片可見時會依照[預覽契約](content-preview.md)自動預覽單一支援的檔案。
- 未知原始大小攜帶獨立 `size_known=false`，列表中的原始大小留白，狀態說明尺寸未知；已知空檔案仍顯示 0。選中彙總大小未知時，底欄只顯示已選數量，不顯示分隔符或佔位符，控制器仍保留未知狀態；彙總大小已知時繼續顯示大小。大小升降序均將未知項置於已知項之後，同組保持身份順序。物理未知項可請求後設資料預檢以檢視拒絕原因，含虛擬目錄的選擇仍不能預檢。未知尺寸不會變成輸出授權或解碼預算。


所選條目現可發起 [解壓後設資料預檢](extraction-preflight.md)，使用獨立原生結果視窗；該功能不寫出檔案，不改變只讀階段邊界。

<a name="xdzip-完整目录索引与排序"></a>

## 完整目錄索引與排序

- Rust 從完整不可變快照建立顯式/隱式目錄，Qt 不從目前頁推斷樹。每個虛擬節點有目前會話內唯一的 `dN` ID、父節點 ID、顯示名稱、歸檔內完整字首及後代物理記錄數。沒有顯式記錄的直屬目錄以導航行顯示，物理 id 為 0，橋接額外攜帶 navigation_id、physical=false，Qt 使用 dN 展示鍵；它不能作為物理解壓選擇，也不會增加物理記錄數。顯式重複記錄不去重；導航行只補沒有顯式記錄的目錄。導航行可選中、複製路徑和進入目錄，但大小、方法、日期留白；預檢只允許實際物理記錄，含導航行的選擇集合禁用預檢。
- 目錄先於子節點發布，按歸檔中首次出現的順序排列。同名物理條目保持獨立；節點計數包含該字首下全部後代（包括待檢查條目），不包含與目錄字首完全相同的記錄。計數不隨名稱搜尋改變。
- 帶警告、未解析名稱、反斜槓、空元件、`.` 或 `..` 的記錄不用於生成節點；它們仍留在物理快照和遞迴搜尋中供檢查。索引是導航能力，不是路徑安全或解壓授權。
- 超出任何目錄預算時丟棄整個目錄索引，介面明確提示，繼續提供根目錄、搜尋及符合條件的顯式目錄瀏覽；未獲得索引的隱式目錄不能推測生成，根目錄可能為空，搜尋仍覆蓋完整物理快照。絕不展示看似完整的截斷樹。目錄空間另受名稱預算限制，不改變對應格式的獨立掃描准入。
- 點選“名稱、原始大小、壓縮大小、型別、修改日期”列頭切換升/降序；Enter/Space 可啟用。列表右上角排序選單可恢復目錄組和檔案組各自的歸檔順序。先過濾和排序整個結果，再分頁，因此跨頁順序一致。名稱使用 Unicode 標量字典序、區分大小寫，不宣稱自然排序或區域規則；數值按 Rust 原始整數比較。所有相等值以行型別（物理先於導航）及對應身份升序決定先後，不因降序翻轉同名記錄。所有排序均先依據記錄的 directory 標記分組，顯式與隱式目錄始終先於檔案；升降序只作用於各組內部，未知原始大小在所屬組內排在已知大小後。型別升序／降序只改變檔案類別順序。檔案類別由規範化副檔名確定，JPG 與 JPEG 屬同組，無字尾檔案保留獨立的檔案組，不用本地化顯示文案作為目錄身份。
- 瀏覽命令排序碼：0 為各組內部的歸檔順序（物理目錄在前，補充的隱式目錄隨後按索引順序），1/2 名稱升/降序，3/4 原始大小，5/6 壓縮大小，7/8 ZIP 方法編號，9/10 型別，11/12 修改時間；其餘拒絕。切換列、目錄或搜尋回到第一頁，成功替換頁面時清空目前查詢選擇和詳情。未獲准入的操作恢復上一次已顯示的查詢引數。
- 樹支援展開/收起、鍵盤導航及 Enter 進入目錄；深層級透過橫向滾動訪問。基礎行高 32、層級縮排 12.8、資料夾槽 16、圖文間距 6.4，文字和圖示與行中心對齊。大字號可增長行高與列寬。

目錄導航與排序按[通用方法](../../../developers/qa/README.md)複驗。完整查詢身份、來源版本檢查與十萬條驗證見 [ZIP 瀏覽契約](zip-readonly-browsing.md)；介面選擇覆蓋完整目前查詢，內部批次和快取回收不清空選擇。大查詢的區間選擇在確認前凍結為穩定身份。

<a name="xdzip-共享控件与上下文命令"></a>

## 共享控制元件與上下文命令

選單、按鈕和快捷鍵複用只讀控制器動作。右擊已選條目保留目前查詢多選，右擊未選條目先單選；Shift 範圍使用穩定條目 ID 作為錨點，查詢或排序成功替換時清空。全選覆蓋目前完整目錄查詢（含導航行），受其格式與索引准入上限約束；預檢獨立限制為至多 128 個真實物理記錄，含導航行或超限的集合禁用預檢。名稱 / 歸檔內路徑複製到系統剪貼簿，目錄名稱去掉末尾分隔符，路徑保留原始展示形式。

列表與網格共享同一個受限模型與選中 ID；不為網格建立第二份索引。目錄指南、末尾兄弟標記、祖先鏈和麵包屑由已釋出的完整目錄模型派生，不新增格式查詢。歸檔摘要快取 Open 的物理總數，不隨目前目錄或搜尋變化；麵包屑右側計數顯示目前列表行數（含必要導航行）。

選單在讀取、查詢或會話變化時關閉，執行操作時控制器重新核對資格。每個 `BrowserController` 管理一個歸檔會話，應用可同時承載多個歸檔標籤頁或視窗。[解壓](zip-safe-extraction.md)獲取明確的輸出意圖和目標授權，[建立](zip-creation.md)單獨凍結輸入樹及儲存目標，[完整性檢查](archive-checking.md)作為獨立只讀任務執行。[預檢](extraction-preflight.md)分析目前來源的後設資料。

<a name="xdzip-查询身份与资源限制"></a>

## 查詢身份與資源限制

同一查詢先生成一次完整排序，再從快取的行索引切取傳輸批次。每批最多 128 行、名稱合計 64 KiB，命令佇列維持 8 MiB，Rust 資料事件與 Qt mailbox 各有 32 MiB 內容背壓，以容納完整有界圖片。搜尋或目錄意圖改變時，只保留最新待執行意圖；舊響應不寫入新查詢。普通查詢取消或超限保留最近成功列表；源版本變化清空失效資料並要求重新開啟。

掃描前後、查詢與預檢邊界檢查來源控制代碼及目前路徑的長度、修改時間和可用建立時間；Unix 另檢查裝置／inode，Windows 透過已鎖定 winapi-util 的安全封裝檢查卷號／檔案索引，以檢測保留時間戳的路徑替換。檢查不是檔案系統原子快照。選擇彙總按模型選擇修訂快取，使用 Rust u128 精確求和，避免重複遍歷及 64 位溢位。

介面語言由 Qt 設定介面卡載入。型別、狀態、錯誤及使用者可見日期使用語言目錄和 locale 展示；位元組數、條目身份、路徑、原始時間和排序引數的橋接值不隨語言改變。不能從翻譯後的文案反推格式能力、身份或安全判斷。語言變更成功後即時更新介面文字，不改變執行中任務，詳見[設定與國際化](../ux/settings-localization.md)。

成功開啟歸檔時，橋接層僅發出 archiveOpened(path) 給本地介面設定介面卡；最近路徑獨立儲存，不參與領域查詢、排序或任務授權。未成功開啟的路徑不寫入最近記錄。
