# 데이터 보관 및 진단

[English](../../engineering/privacy.md) | [简体中文](../../zh-CN/engineering/privacy.md) | [繁體中文](../../zh-TW/engineering/privacy.md) | [日本語](../../ja-JP/engineering/privacy.md) | 한국어 | [Français](../../fr-FR/engineering/privacy.md) | [Deutsch](../../de-DE/engineering/privacy.md) | [Español](../../es-ES/engineering/privacy.md) | [Português (Brasil)](../../pt-BR/engineering/privacy.md) | [Русский](../../ru-RU/engineering/privacy.md)

[개인정보 처리방침](../../../PRIVACY.md)은 xdzip이 처리하는 데이터와 사용자가 이용할 수 있는 선택 사항을 설명합니다. 아래 표에서 데이터를 저장하는 위치와 정리 시기를 확인할 수 있습니다. 탐색, 압축, 압축 풀기는 오프라인에서 동작합니다. xdzip은 원격 측정 데이터나 압축 파일 내용을 유지보수 담당자에게 자동으로 보내지 않습니다.

| 데이터 | 보관 기간 | 저장과 정리 |
| --- | --- | --- |
| 설정 및 테마 | 버전이 있는 스키마로 실행 간 유지 | 변경 사항을 원자적으로 교체합니다. 저장에 실패하면 이전 설정을 보존하고 화면에 오류를 표시합니다. |
| macOS의 이전 기본 앱 | 로컬에서 실행 간 유지 | xdzip을 기본값으로 설정할 때 해당 콘텐츠 유형의 이전 앱 번들 ID를 별도 설정 파일에 기록합니다. 복원하거나 다른 앱을 선택하면 해당 유형의 기록을 지웁니다. |
| 최근 파일 | 선택 사항, 로컬에만 저장 | 비공개 `recent.json`에는 중복 없이 최대 20개 항목을 저장하며 읽기 한도는 64 KiB입니다. 끄면 새 항목이 추가되지 않습니다. 기록을 지워도 원본 파일은 건드리지 않습니다. |
| 압축 파일 색인 | 열린 세션 동안 | 작은 색인은 메모리에, 대형 ZIP 색인의 메타데이터와 쿼리 순서는 비공개 디스크 파일에 저장합니다. 정상 종료, 쿼리 교체, 실패 또는 취소 시 알려진 파일을 정리합니다. 이후 색인을 만들 때 식별 정보와 사용권 규칙에 따라 충돌 후 남은 미사용 파일을 회수할 수 있습니다. 실행이 끝나면 색인을 재사용하지 않습니다. [대용량 압축 파일 색인](large-index.md)을 참조하세요. |
| 임시 출력과 복구 상태 | 작업과 복구 중 | 복구는 관리되는 메타데이터만 사용하며 소유권을 확인할 수 있는 항목만 정리합니다. 압축 파일 속 내용을 실행하거나 임의 경로에 쓰기를 복원하지 않습니다. |
| 앱 내 미리보기 | 사용자가 시작하며 범위가 제한됨 | 미리보기의 대상이 바뀌거나 세션이 끝나면 현재 결과가 지워집니다. 늦은 결과로 무효화된 내용을 되살릴 수 없습니다. |
| 암호 | 필요한 작업 동안 | 앱은 암호를 설정이나 로그에 저장하지 않습니다. 운영체제는 앱이 제어할 수 없는 별도의 메모리 복사본을 보유할 수 있습니다. |
| 독립 업데이트 확인 및 다운로드 | 해당 버전에서 사용자가 시작 | 요청은 GitHub의 공개 릴리스 및 다운로드 서비스를 사용합니다. 설정된 프록시에서 요청을 처리할 수 있으며 선택한 HTTPS 미러에는 원래 다운로드 URL이 전달됩니다. 제공자는 연결 정보와 요청에 포함된 앱 버전을 알 수 있습니다. Windows MSIX는 독립 업데이트 프로그램을 비활성화합니다. |
| 업데이트 작업 기록 | 로컬에서 설치 재시작 후에도 유지 | 설정 옆의 별도 파일 `update-state.ini`에 작업과 대상 식별 정보가 저장됩니다. 다운로드가 실패하면 비공개 업데이트 캐시에 남을 수 있습니다. 업데이트 프로그램은 정해진 작업 기록 파일만 읽으며 내용을 실행하지 않습니다. |
| 상태 및 진단 | 기능에 따라 화면, 터미널 또는 로컬 기록 | 앱은 진단을 자동으로 업로드하지 않습니다. 버전 또는 파일 정보를 복사하면 시스템 클립보드에 씁니다. 오류, 로그 또는 스크린샷을 공유하기 전에 파일 이름, 경로 및 기타 개인정보를 확인하세요. |

네트워크, 서명, 설치 전달 및 복구는 [업데이트 규칙](software-update.md)을 참조하세요.
