# 콘텐츠 미리 보기

[English](../../engineering/content-preview.md) | [简体中文](../../zh-CN/engineering/content-preview.md) | [繁體中文](../../zh-TW/engineering/content-preview.md) | [日本語](../../ja-JP/engineering/content-preview.md) | 한국어 | [Français](../../fr-FR/engineering/content-preview.md) | [Deutsch](../../de-DE/engineering/content-preview.md) | [Español](../../es-ES/engineering/content-preview.md) | [Português (Brasil)](../../pt-BR/engineering/content-preview.md) | [Русский](../../ru-RU/engineering/content-preview.md)

속성 카드가 보일 때 지원되는 파일 하나를 선택하면 선택이 안정된 후 미리 보기가 시작됩니다. 포인터가 미리 보기 위에 있거나 버튼이 키보드 포커스를 받으면 오른쪽 위에 새로 고침 아이콘이 나타나며 선택한 파일을 다시 불러옵니다. 카드는 읽기나 디코딩 실패를 알리고 여러 항목 선택 시 선택 메시지를 표시합니다. 기본 창과 독립 속성 뷰어는 이 동작과 기존 암호 창을 공유합니다. 파일 메타데이터는 별도로 계속 사용할 수 있습니다.

<a name="xdzip-capabilities-and-budgets"></a>

## 기능과 예산

읽을 수 있고 크기를 알며 위험한 이름이 없는 일반 파일만 지원합니다. 허용된 텍스트 확장자는 txt, md, log, json, csv, tsv, toml, yaml, yml, ini, xml, rs, c, cpp, h, py입니다. 엄격한 UTF-8 또는 BOM이 있는 UTF-16만 허용합니다. 입력과 변환된 UTF-8은 각각 256 KiB로 제한되며 NUL 같은 바이너리 제어 바이트는 금지됩니다. 내용은 PlainText 컨트롤에 표시하며 태그, URL, 프로그램 텍스트와 매크로는 실행하지 않습니다.

| 이미지 유형 | 세 플랫폼의 범위와 실제 동작 |
| --- | --- |
| PNG, JPEG (jpg, jpeg, jfif, jpe) | 정적 이미지 하나를 완전히 읽고 방향에 사용 가능한 변환 메타데이터 적용 |
| GIF, WebP | 정적 이미지 또는 애니메이션 첫 프레임. 애니메이션은 재생하지 않음 |
| BMP, ICO/CUR | 일반 이미지 또는 디코더 기본 이미지. CUR은 시스템 커서를 활성화하지 않음 |
| ICNS | 사용 가능한 시스템 디코더가 지원하는 내장 PNG 또는 JPEG2000 이미지, 최대 256블록. 알 수 없는 내장 유형과 오래된 원시 비트맵/RLE 아이콘은 명시적으로 거부 |
| TGA | 색상 맵과 이미지 ID가 없고 왼쪽이 원점인 비압축 16/24/32비트 트루컬러 이미지. 같은 배치에서 오래된 푸터가 없으면 채움. RLE와 인덱스 색상은 지원하지 않음 |
| TIFF (tif, tiff) | 첫 페이지만. 페이지를 자동으로 순회하지 않음 |
| SVG | 제한된 파싱 후 래스터화하는 UTF-8 정적 벡터. 아래 부분 집합 참조 |
| HEIC/HEIF | 시스템 ImageIO와 공식 Qt 플러그인을 사용하는 macOS만 지원. 다른 곳에서는 명시적으로 거부 |

AVIF, RAW, PSD, EXR, PDF, Office와 독립적인 제3자 디코더 라이브러리는 추가하지 않습니다. 파일 확장자, Rust 형식 시그니처 검사와 고정된 Qt 디코더가 함께 허용을 결정합니다. 시스템에 추가로 설치된 플러그인은 제품 기능이 되지 않으며 다른 디코더를 자동으로 조사하지 않습니다.

인코딩된 이미지 내용은 16 MiB로 제한됩니다. Rust 이벤트 대기열과 Qt 메일박스는 각각 32 MiB 한도를 가지며 명령 예산은 8 MiB로 유지됩니다. 원본 너비와 높이는 각각 최대 16,384이고 전체 픽셀은 최대 33,554,432입니다. 소스 허용과 출력 썸네일은 별도로 계산합니다. 최종 너비와 높이는 각각 최대 512이고 종횡비를 유지하며 RGBA8은 최대 1 MiB입니다. 12 MP 사진 같은 이미지를 예산 내에서 썸네일로 읽을 수 있습니다. 일부 디코더는 축소 전에 원본을 읽으므로 썸네일 크기만으로 내부 사용량이 1 MiB뿐이라고 입증할 수 없습니다. 사용 가능한 색상 프로파일은 sRGB로 변환하고 알 수 없는 프로파일은 디코더 결과를 유지합니다. 전문 색상 교정은 보장하지 않습니다.

Qt 비동기 이미지 제공자는 임의 토큰만 받고 시스템 경로나 네트워크 URL은 받지 않습니다. 인코딩 내용은 전역적으로 최대 32 MiB 유지하며 디코딩 작업은 최대 두 개 병렬 실행합니다. 취소되었지만 아직 회수 중인 작업은 각각 최대 한 개의 16 MiB 입력을 유지할 수 있습니다. 각 작업은 고정된 인접 비공개 워커 `xdzip-image-preview`를 시작하며 압축 파일 경로, 암호, 대상 핸들이나 애플리케이션 자격 증명을 전달하지 않습니다. 워커 출력은 고정 크기 헤더와 너비, 높이, 길이가 엄격히 일치하는 RGBA8만 허용하고 추가 출력을 허용하지 않습니다. 실패, 충돌, 유효하지 않은 프레임, 시간 초과와 늦은 결과는 표시할 수 없습니다.

호스트는 시작부터 총 5초의 기한을 적용하고 50 ms마다 요청 유효성을 확인합니다. 닫기, 취소 또는 항목 변경 시 워커를 종료하고 회수합니다. 워커는 QImage 할당을 128 MiB로 제한합니다. Windows는 프로세스 커밋 메모리 512 MiB와 사용자 CPU 3초의 Job을 사용합니다. Unix는 CPU 3초, 코어 덤프 비활성화와 파일 디스크립터 제한을 사용합니다. Linux는 주소 공간을 512 MiB, 일반 파일 크기를 0으로 제한합니다. macOS는 기존 dyld 가상 예약 외에 512 MiB 주소 공간을 추가하며 이는 RSS의 엄격한 한도가 아닙니다. 시스템 ImageIO는 파일 기반 런타임 리소스를 사용할 수 있으므로 일반 파일 각각을 16 MiB로 제한하며 초과 시 디코딩을 종료합니다. 애플리케이션은 압축 파일 항목의 복사본을 내보내지 않으며 시스템 런타임 리소스와 항목 출력은 별도로 관리합니다. 이는 비공개 디코더의 충돌 및 리소스 격리이지 임의의 제3자 프로그램에 대한 커널 권한 샌드박스가 아닙니다.

압축 파일 내용의 각 읽기는 누적 소스 읽기 256 MiB, 디코딩과 건너뛰기 작업 64 MiB, 보조 알고리즘 작업 256 MiB로 제한됩니다. 형식 사전, 워커와 메서드 그래프는 [형식 백엔드 계약](native-codecs.md)의 별도 예산을 계속 따릅니다. 솔리드 압축 파일이나 순차 압축 스트림은 앞선 디코딩이 작업 예산을 초과하면 작은 파일의 미리 보기도 거부할 수 있습니다.

<a name="xdzip-static-svg-subset"></a>

## 정적 SVG 부분 집합

SVG는 세 데스크톱 플랫폼 모두에서 같은 Qt Svg 렌더링 경로를 사용합니다. 렌더링 전에 스트리밍 XML 파서가 지원되는 정적 그래픽, 텍스트, 스타일, 내부 정의, 그라디언트, 클리핑, 마스크와 제한된 필터를 재구성합니다. 한도는 요소 8,192개, 64개 깊이, 요소당 속성 64개, 속성당 1 MiB, 전체 출력 16 MiB입니다. 메타데이터는 렌더링에 참여하지 않습니다. 스타일 요소는 텍스트만 허용하며 XML 텍스트 조각과 CDATA를 합친 후 전체 CSS를 검사하여 분할로 외부 참조 제한을 우회하지 못하게 합니다.

DTD, 엔터티, 처리 지시, 스크립트, 이벤트, 애니메이션, foreignObject, image 요소, 글꼴 파일, 외부 스타일과 외부 리소스 참조를 거부합니다. href와 CSS url은 현재 문서의 단순한 프래그먼트 신원만 허용합니다. xml:base, src, CSS import와 이스케이프 형식은 금지합니다. 내장 비트맵과 SVGZ는 부분 집합 밖입니다. 알 수 없는 그리기 요소나 금지된 내용은 조용히 버리고 완전한 것처럼 표시하는 대신 전체 미리 보기를 실패시킵니다. 일반적인 정적 SVG를 지원하지만 모든 SVG 또는 브라우저 기능을 주장하지 않습니다.

<a name="xdzip-integrity-passwords-and-lifecycle"></a>

## 무결성, 암호와 수명 주기

미리 보기는 고정된 물리 신원, 소스 버전, 데이터 위치와 기존 디코더를 재사용합니다. 텍스트나 인코딩 이미지를 미리 보기에 전달하기 전에 내용을 EOF까지 완전히 디코딩하고 해당 형식의 사용 가능한 무결성 및 인증 검사를 완료해야 합니다. 파일별 내용 체크섬이 없는 TAR 같은 형식은 기존 구조와 읽기 가능성 보장만 유지합니다. 디스크 기반 대형 인덱스는 모든 메타데이터를 Qt로 가져오지 않고 선택된 데이터만 제한적으로 읽습니다.

암호는 현재 요청에만 연결하고 기존 제로화 컨테이너를 사용합니다. 오류, 인증 모호성과 취소는 기존 범주를 따르며 최대 열 번 시도합니다. 암호 창을 닫으면 미리 보기만 취소하고 사용 가능한 디렉터리를 유지합니다. 열기, 탐색과 다른 전경 읽기 명령은 대기 중인 미리 보기 읽기보다 우선합니다. 미리 보기를 닫거나 항목을 바꾸거나 압축 파일 페이지를 숨기거나 세션을 닫으면 내용을 지우며 무효화된 요청과 디코딩 결과가 이전 내용을 복원할 수 없습니다. 실패와 취소는 검증되지 않은 부분 내용을 버리고 항목 복사본을 쓰거나 시스템 애플리케이션을 시작하지 않습니다. 두 번 클릭의 임시 열기는 [별도 흐름](archive-opening.md)을 따릅니다.

<a name="xdzip-toolchain-and-acceptance"></a>

## 도구 체인과 승인

`desktop.py prepare --install-qt`는 신규 또는 기존 SDK에 고정된 Qt 6.8.2 qtimageformats를 추가하며 doctor는 빌드 전에 Svg와 필요한 플러그인을 검사합니다. 공식 소스, 다이제스트, 고지와 SDK 대응 관계는 공통 구성에 포함됩니다. Qt에 포함된 libwebp/libtiff와 별도로 추가한 형식 라이브러리는 독립적으로 관리합니다. `check-image-preview.py`는 기본 테스트, Windows/Linux 배포 검증과 승인된 Mac 패키징에서 실제 워커, 플러그인과 최소 디코딩을 검증합니다. Mac은 offscreen을 명시적으로 포함하고 자체 검사 전에 SDK 검색 재정의를 지웁니다. 개발 SDK의 플러그인 디렉터리는 실제 런타임 패키지 테스트를 대체할 수 없습니다.

회귀 검사는 각 유형, 애니메이션 첫 프레임, TIFF 첫 페이지, 투명도, 12 MP 사진, macOS HEIC와 다른 플랫폼에서의 거부, SVG 내부 정의와 외부 리소스 거부, 손상된 입력, 픽셀 초과, 유효하지 않은 프레임, 시간 초과와 취소를 포함하는 자체 이미지를 사용합니다. 실제 압축 파일 경로는 계속 암호, 무결성, 소스 신원과 UI 무효화 정리를 다룹니다. 배치는 [시각 표준](../../visual/design-standard.md#content-preview)을 따르며 [검증](../../../developers/qa/README.md)에 따라 변경되지 않은 배치 증거를 재사용하고 새 이미지의 실제 표시를 관찰합니다.
