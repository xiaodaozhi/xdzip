# XDZip 제품 요구 사항

[English](../../design/product-requirements.md) | [简体中文](../../zh-CN/design/product-requirements.md) | [繁體中文](../../zh-TW/design/product-requirements.md) | [日本語](../../ja-JP/design/product-requirements.md) | 한국어 | [Français](../../fr-FR/design/product-requirements.md) | [Deutsch](../../de-DE/design/product-requirements.md) | [Español](../../es-ES/design/product-requirements.md) | [Português (Brasil)](../../pt-BR/design/product-requirements.md) | [Русский](../../ru-RU/design/product-requirements.md)

XDZip은 압축 파일을 폴더처럼 살펴보고 선택한 내용을 다루며 형식이 지원하면 압축 파일을 만들거나 수정할 수 있게 합니다. 데스크톱과 [독립 CLI](../engineering/command-line.md)는 같은 압축 파일 런타임을 사용합니다. [프로젝트 README](../../../README.ko-KR.md)에서 현재 기능과 배포 방식을 설명합니다. 아래 요구 사항은 유지하고 검증할 동작을 정의합니다.

<a name="xdzip-requirements-and-implementation"></a>

## 요구 사항과 구현

| ID | 요구 사항 | 현재 동작 또는 범위 |
| --- | --- | --- |
| P01 | 풀지 않고 탐색 | 열 때 원본을 판별하고 한도가 있는 검색을 끝낸 뒤 첫 페이지를 게시합니다. 항목의 내용을 디코딩하려면 별도 동작이 필요합니다. |
| P02 | 탐색, 검색, 정렬 및 선택 | 안정적인 물리 ID, 별도 탐색 ID, 페이지별 쿼리와 한도가 있는 선택이 구현되어 있습니다. 일반 단일 파일 ZIP/ZIP64는 더 큰 메타데이터 인덱스를 사용하며 작업 한도는 별도입니다. |
| P03 | 지정한 범위 압축 풀기 | 런타임은 범위를 고정하고 이름을 검증한 뒤 대상을 승인합니다. 충돌 결정을 처리하고 실제 확정, 건너뜀, 오류와 취소를 보고합니다. |
| P04 | 파일과 폴더로 압축 파일 만들기 | 만들기 레지스트리로 옵션을 검증하고 임시 영역에 인코딩한 뒤 검증하여 확정합니다. 지원 형식과 옵션은 레지스트리를 따릅니다. |
| P05 | 형식별 기능 준수 | UI는 형식 설명과 현재 세션 상태를 결합합니다. 런타임도 모든 요청을 검증합니다. 읽기, 미리 보기, 검사, 만들기, 암호 및 볼륨 프로필은 각각 한도가 있습니다. |
| P06 | 작업 제한과 취소 | 메타데이터와 무거운 작업은 별도 대기열을 사용합니다. 데스크톱의 무거운 작업은 한 번에 하나씩 실행하며 수락된 작업은 탭을 닫은 뒤에도 계속될 수 있습니다. |
| P07 | 검증된 권한과 한도 내에서 쓰기 | 호스트는 이름, 링크, 파일 식별, 임시 준비, 실제 출력과 확정을 관리합니다. 형식 검사는 해당 구조와 무결성을 검증합니다. |
| P08 | 일관되고 접근 가능한 데스크톱 컨트롤 제공 | QML과 C++는 공통 컨트롤, 키보드 탐색, 포커스 및 접근성을 제공합니다. 네이티브 IME, 화면 판독기와 표시 동작은 별도로 검증해야 합니다. |
| P09 | 리소스 제한 및 측정 | 코드는 독립적인 예산을 적용합니다. 성능 목표와 측정 결과는 별도로 관리합니다. |
| P10 | 형식 로직에서 Qt 분리 | Rust 트레이트, 명시적인 레지스트리 경로와 전용 프로세스 인터페이스로 내장 구현을 지원합니다. 데스크톱과 CLI는 같은 코어를 사용합니다. |
| P11 | 비밀 정보와 데이터 보호 | 압축 파일 작업은 오프라인으로 작동합니다. 암호는 사용 범위가 제한되고 0으로 지울 수 있는 저장소에 보관합니다. 개인정보, 진단과 명시적 업데이트 접근에는 각각의 계약이 있습니다. |
| P12 | 배포 감사 | 정해진 패키지 채널, 고정 입력, 매니페스트, 체크섬, 라이선스 자료와 플랫폼 검사를 사용합니다. 결과는 실제 검증한 빌드와 배포본에 적용합니다. |
| P13 | 신뢰와 권한이 검증된 타사 확장만 허용 | 읽기 전용 XDP1 실험은 별도로 구현되어 있습니다. 제품 내 확장 설치와 활성화는 설계 단계입니다. |
| P14 | 미리 보기와 열기 제한 | 속성 패널이 보일 때 지원되는 파일 하나를 선택하면 한도가 있는 텍스트 또는 이미지 미리 보기가 시작됩니다. 조건에 맞는 일반 파일을 명시적으로 열면 검증된 비공개 복사본을 시스템 연결 앱에 전달합니다. |
| P15 | 실패와 불확실한 결과를 정확히 보고 | 안정적인 오류와 한도가 있는 결과로 원본 변경, 디스크 실패, 건너뛴 항목과 정리를 보고합니다. 재시작 후 자동 복구는 설계 옵션입니다. |

## 작업 흐름과 범위

- **열고 확인.** 파일 열기 요청은 데스크톱 세션 조정기로 전달됩니다. 검색이 성공하면 세션을 게시하고 검색과 정렬은 새 쿼리를 만듭니다. 두 번 클릭하면 폴더에 들어가거나 적합한 파일을 임시 복사본으로 엽니다. 속성 패널이 보일 때 지원 파일 하나를 선택하면 미리 보기가 시작됩니다. [탐색과 미리 보기](../user-guide/browse.md), [임시 열기](../engineering/archive-opening.md)
- **압축 풀기.** 「모두 풀기」는 전체 압축 파일에 적용됩니다. 검색 결과만 풀려면 쿼리에서 선택하고 범위를 확인하세요. 메타데이터 사전 검사는 쓰기 승인 전에 결과를 제공합니다. 파일별 확정으로 이후 실패나 취소에도 완료된 파일을 보존합니다. [압축 풀기](../../engineering/zip-safe-extraction.md), [작업 예약](task-scheduling.md)
- **만들기, 수정 또는 검사.** 만들기와 지원되는 수정은 임시 출력을 검증한 뒤 확정합니다. 검사 동작은 지원되는 압축 파일을 형식에 따라 검사하며 출력 권한을 얻지 않습니다. 가능한 동작은 형식, 항목과 원본 프로필에 따라 다릅니다. [형식 레지스트리](../engineering/format-registry.md), [압축 파일 전송](../../engineering/archive-transfers.md), [압축 파일 검사](../engineering/archive-checking.md)

## 계획된 범위와 검증

외부 확장 관리, 지속적인 작업 복구와 추가 형식 프로필에는 별도 설계, 구현과 검증이 필요합니다. 버전 번호만으로 형식이나 플랫폼 지원 범위를 입증할 수 없습니다. 클라우드 압축 파일 동기화, 디스크 이미지 마운트와 악성코드 검사 서비스는 제품 범위 밖입니다. [추적 표](requirements-traceability.md)는 요구 사항과 검증을 연결합니다. [지원 정책](../engineering/support-policy.md)과 릴리스 노트에서 배포 빌드를 설명합니다.
