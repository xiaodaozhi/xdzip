## 압축 파일 창에서

1. 압축 파일을 엽니다. 도구 모음의 기본 버튼은 선택한 항목이 있으면 해당 항목의 압축을 풀고, 선택한 항목이 없으면 전체 압축을 풉니다. 버튼 옆의 화살표에서 **모두 풀기** 또는 **선택 항목 풀기**를 직접 선택할 수 있습니다.
2. 풀 항목의 범위를 확인하고 쓸 수 있는 대상 폴더를 선택합니다. 옵션을 사용할 수 있다면 압축 파일 이름과 같은 폴더를 만들 수 있습니다.
3. 파일명 충돌을 처리하는 방법을 결정합니다. **어떻게 할지 묻기**는 결정을 기다리는 동안 작업을 일시 중지합니다. **기존 파일 건너뛰기**는 기존 파일을 유지합니다. **이름을 바꾸고 두 버전 모두 유지**는 새 파일을 따로 저장합니다. **기존 파일 덮어쓰기**는 검증을 마친 후 바꿀 수 있는 파일을 바꿉니다.
4. 압축을 풀고 작업 결과를 확인합니다. 실패하거나 취소해도 먼저 풀린 파일이 남을 수 있습니다. 다시 시도하기 전에 결과 상세 내용에서 남은 항목을 확인하세요. [검사, 작업 및 결과](checks-and-tasks.md)

압축 풀기 메뉴에 **압축 풀기 전 메타데이터 검사** 항목도 있습니다. 실제 압축 파일 레코드를 최대 128개까지 직접 선택하면 안전하지 않은 이름, 지원되지 않는 방식, 선언된 제한 등을 보고합니다. 탐색용으로만 표시되는 암시적 폴더도 해당 기능을 지원하는 경우 압축을 풀 수 있습니다. 사전 확인은 실제 데이터를 읽거나 쓰기 권한을 부여하지 않습니다. [사전 확인 및 압축 풀기 제한](../engineering/extraction-preflight.md)

디스크에 인덱스를 저장하는 큰 ZIP 파일에서는 작업 제한 안에서 선택한 일반 파일의 압축을 풀 수 있습니다. 전체 압축 파일이 제한을 초과하면 더 적은 항목을 선택하세요. 원본이 변경되거나 교체되면 압축 파일을 다시 열고 항목을 새로 선택하세요. [큰 압축 파일의 제한](../engineering/large-index.md)

## 파일 관리자에서

Windows 11에서는 **더 많은 옵션 표시**를 통해 클래식 메뉴를 엽니다. Microsoft Store 버전은 새 메뉴에도 작업을 표시할 수 있습니다. Ubuntu에서는 Nautilus 확장을 사용합니다. macOS에서는 시스템 설정에서 Finder 확장을 켜거나 등록된 Finder 서비스를 사용합니다. 메뉴를 사용할 수 없으면 xdzip에서 압축 파일을 연 다음 해당 창에서 압축을 푸세요.

파일 관리자 메뉴에서 각 압축 파일이 있는 디렉터리에 풀거나, 압축 파일마다 별도의 폴더에 풀거나, 자동 풀기를 사용하거나, 대상 폴더를 직접 선택할 수 있습니다. 자동 풀기는 검증된 결과의 최상위가 정확히 폴더 하나일 때만 그 바깥에 추가 폴더를 만들지 않습니다. 일괄 작업에서는 압축 파일별 결과를 표시하며 특정 파일에서 실패하더라도 나머지를 계속 처리합니다. 취소하면 후속 항목을 시작하지 않고 진행 중인 작업의 중단을 요청합니다. [파일 관리자 작업 및 설정](../../engineering/shell-actions.md)
