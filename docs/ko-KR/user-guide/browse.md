# 파일 탐색, 선택 및 미리 보기

[English](../../user-guide/browse.md) | [简体中文](../../zh-CN/user-guide/browse.md) | [繁體中文](../../zh-TW/user-guide/browse.md) | [日本語](../../ja-JP/user-guide/browse.md) | 한국어 | [Français](../../fr-FR/user-guide/browse.md) | [Deutsch](../../de-DE/user-guide/browse.md) | [Español](../../es-ES/user-guide/browse.md) | [Português (Brasil)](../../pt-BR/user-guide/browse.md) | [Русский](../../ru-RU/user-guide/browse.md)

1. 압축 파일을 열고 디렉터리 트리에서 폴더를 선택하거나 해당 행을 두 번 클릭합니다. 경로 표시줄에서 상위 폴더로 돌아갈 수 있습니다.
2. 파일 이름의 일부를 입력하고 Enter 키를 누릅니다. 현재 폴더와 하위 폴더를 검색합니다. 목록 보기 또는 격자 보기를 선택하고 정렬 순서를 정하세요. 어느 방향으로 정렬해도 폴더가 파일보다 먼저 표시됩니다.
3. 체크 상자나 시스템의 선택 키로 항목을 선택합니다. **모두 선택**은 현재 검색 결과의 모든 항목을 선택하며 화면 밖의 행도 포함합니다. 압축을 풀기 전에 선택한 항목 수를 확인하세요.
4. 파일 속성이 표시된 상태에서 파일 하나를 선택하면 미리보기가 표시됩니다. 미리보기에 마우스를 올리고 오른쪽 위의 새로고침 아이콘을 누르면 다시 불러옵니다. 여러 항목을 선택하면 속성 카드에 그에 해당하는 안내가 표시됩니다. 텍스트는 UTF-8 또는 BOM이 있는 UTF-16이어야 하며 256 KiB 이하여야 합니다. 이미지에는 별도의 크기 제한이 있습니다. 정적 SVG는 지원하는 기능만 표시하며 macOS에서는 HEIC/HEIF를 사용할 수 있습니다. 미리 볼 수 없어도 해당 항목이 압축 풀기를 지원하면 파일을 풀 수 있습니다. [미리 보기 형식과 제한](../engineering/content-preview.md)

일반 파일을 두 번 클릭하면 임시 복사본의 압축을 풀고 운영체제에 열기를 요청합니다. 복사본을 편집해도 압축 파일에는 반영되지 않습니다. 보관할 복사본이 필요하면 원하는 위치에 파일을 푸세요. [임시 파일 열기](../engineering/archive-opening.md)

압축 파일은 기본적으로 탭에서 열립니다. 설정에서 별도의 창으로 열도록 바꿀 수 있습니다. 일반적인 단일 ZIP/ZIP64 파일은 실제 레코드를 최대 100만 개까지 인덱싱할 수 있습니다. 큰 인덱스는 필요한 행만 읽습니다. 디스크 인덱스를 사용하는 ZIP에서도 선택 파일을 풀 수 있는 경우가 있습니다. 전체 압축 파일 검사와 수정은 비활성화됩니다. [큰 압축 파일의 제한](../engineering/large-index.md)

## 압축 파일 주석 보기

ZIP 또는 RAR을 연 다음 도구 모음에서 **더 보기 → 압축 파일 주석**을 선택합니다. 텍스트를 선택하고 복사할 수 있습니다. 쓰기 가능한 일반 ZIP, ZIP64 또는 ZIPX에서는 편집 후 **저장**을 선택합니다. 내용을 지우고 저장하면 주석이 삭제됩니다. UTF-8 기준 한도는 65,535바이트입니다. 분할, 자체 압축 풀기, 암호화, 디스크 인덱스를 사용하는 대형 ZIP, 서명된 ZIP과 파생 패키지, RAR의 주석은 읽기 전용입니다.
