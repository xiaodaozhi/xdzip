# 중국어 간체 UI 용어

[English](../../ux/chinese-terminology.md) | [简体中文](../../zh-CN/ux/chinese-terminology.md) | [繁體中文](../../zh-TW/ux/chinese-terminology.md) | [日本語](../../ja-JP/ux/chinese-terminology.md) | 한국어 | [Français](../../fr-FR/ux/chinese-terminology.md) | [Deutsch](../../de-DE/ux/chinese-terminology.md) | [Español](../../es-ES/ux/chinese-terminology.md) | [Português (Brasil)](../../pt-BR/ux/chinese-terminology.md) | [Русский](../../ru-RU/ux/chinese-terminology.md)

사용자에게 표시되는 중국어 간체 문구는 [용어 설정](../../../specs/ux/chinese-terminology.json)을 따릅니다. Qt 정적 문구는 resources/i18n/zh-CN.json의 안정적인 ID를 유지합니다. 현재의 상세 설계 시안 및 사용자 안내서는 아래 표의 용어를 사용합니다. 기술 사양과 형식 문서에서는 전문 용어를 사용할 수 있습니다. 구성 요소 크기, 기본 창 0.8 및 메뉴 1의 밀도, DPR과 배율 설정은 기존 값을 따릅니다.

| 의미 | 표준 중국어 간체 문구 | 사용 예 |
| --- | --- | --- |
| ZIP, TAR 같은 컨테이너 파일 | 压缩包 | 压缩包名称, 空压缩包, 压缩包信息 |
| 전체 작업 이름 | 打开压缩包, 创建压缩包, 解压 | 도구 모음의 문맥이 분명하면 “打开”와 “新建”으로 줄일 수 있습니다 |
| 압축 파일 안의 항목 | 文件, 文件夹, 内容 | 所选文件和文件夹, 全部内容 |
| 파일 속성 | 原始大小, 压缩大小 | 열 머리글, 미리 보기 속성 및 정렬 메뉴에 같은 명칭을 씁니다 |
| 실제 항목 순서 복원 | 按原始顺序排列 | 이름이나 크기 기준 정렬과 구분합니다 |

“档案文件”는 제품 용어에서 제외합니다. “归档”, “归档文件” 및 “归档格式”는 기술 사양, 형식 설명 및 공개 API에서만 사용합니다. TAR가 파일을 묶기만 해도 UI는 “压缩包”를 사용합니다. 실제 압축 기능은 형식과 압축 수준으로 표시합니다.

“压缩文件”는 “正在压缩文件”처럼 작업을 가리킬 때만 사용할 수 있습니다. 속성 이름은 “压缩大小”를 쓰고 “压缩后”는 사용을 중단합니다. 만들기 창은 기본 이름으로 “新建压缩包.zip”을 제시하며 기존 파일의 이름은 유지합니다.

사용자가 제공한 이름과 경로, 압축 파일 내부 파일 이름, 프로토콜 필드, 코드 식별자 및 이전 상세 설계 이미지는 그대로 유지합니다. 영어는 자체 문법에 따라 “archive”를 사용하며 “全部内容”는 “All contents”라고 표기합니다. 좁은 열 머리글의 “Compressed”는 “compressed size”를 뜻합니다. 영어 코드 식별자는 그대로 사용합니다.

현재 용어 상태 설계를 참고하세요. 원본 이미지, 해시 및 글자 그리기 영역 측정값은 이전 검증의 근거로 남습니다. 본문 측정 스크립트는 이전 라벨과 명시적으로 대응시켜 새 문구를 검사하고 기존 치수 목표와 허용 오차를 적용합니다. 기본 창, 열 머리글, 미리 보기와 메뉴에서 긴 라벨이 끝까지 표시되는지 확인하세요.

`python3 scripts/check-ui-i18n.py`를 실행하여 모든 제품 언어 리소스와 중국어 간체 용어를 검사하세요. 용어 검사는 정적 제품 문구에만 적용합니다. 명시적으로 허용한 “压缩文件”의 동사 용법을 허용하며 사용자 콘텐츠나 전문 용어를 제한하지 않습니다.

시스템 파일 관리자는 [#270](https://github.com/xiaodaozhi/xdzip/issues/270)에서 확인한 “添加到压缩文件...” 및 “解压每个压缩文件到单独的文件夹”를 유지합니다. 예외는 두 안정 ID의 전체 문구에만 적용됩니다. 나머지 위치에서는 정해진 컨테이너 이름을 사용합니다.
