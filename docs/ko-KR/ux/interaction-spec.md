# 상호 작용과 문구의 추가 사양

[English](../../ux/interaction-spec.md) | [简体中文](../../zh-CN/ux/interaction-spec.md) | [繁體中文（台灣）](../../zh-TW/ux/interaction-spec.md) | [日本語](../../ja-JP/ux/interaction-spec.md) | 한국어 | [Français](../../fr-FR/ux/interaction-spec.md) | [Deutsch](../../de-DE/ux/interaction-spec.md) | [Español](../../es-ES/ux/interaction-spec.md) | [Português (Brasil)](../../pt-BR/ux/interaction-spec.md) | [Русский](../../ru-RU/ux/interaction-spec.md)

기본 창과 압축 풀기 확인의 시각 기준을 [작업 상태 사양](hifi-state-spec.md)이 보완합니다. 생성, 충돌, 작업, 결과, 설정과 플랫폼 비교를 다룹니다. 시작 페이지와 열기 진행은 [시작 페이지 계약](welcome-opening.md)을 참조하세요. 현재 시안과 레이아웃 참조는 [창 레지스트리](../../../specs/visual/window-registry.json)를 따릅니다. 실제 구현과 네이티브 표시의 검사 범위는 해당 기술 및 상호 작용 계약에서 설명합니다.

| 상황 | 표시 및 동작 | 후속 동작 |
| --- | --- | --- |
| 처음 실행 | 압축 파일을 열거나 만듭니다. 로컬 파일을 끌어올 수 있습니다. | 모든 디스크를 스캔하거나 모든 형식을 자동 연결하지 않습니다. |
| 디렉터리 읽기 | 읽은 수와 전체를 알 수 없는 진행률을 표시합니다. | 세션을 닫을 수 있습니다. 일부 결과를 완료로 표시하지 않습니다. |
| 빈 압축 파일 | “이 압축 파일은 비어 있습니다”를 표시하고 파일 속성을 유지합니다. | 다른 압축 파일을 엽니다. 압축 풀기를 비활성화하고 이유를 표시합니다. |
| 검색 결과 없음 | 검색어와 검색 범위를 표시합니다. | 검색을 지울 수 있습니다. 압축 파일이 비었다고 표시하지 않습니다. |
| 지원하지 않는 기능 | 해당 형식, 알고리즘 또는 암호화 이유를 표시합니다. | 읽을 수 있는 메타데이터를 유지하고 안전하지 않은 부분 출력을 중단합니다. |
| 압축 파일 만들기 | 입력 목록, 형식, 대상 위치, 수준 및 사전 검사를 표시합니다. | 오류를 관련 필드 근처에 표시합니다. 기본적으로 기존 파일을 보존합니다. |
| 이름 충돌 | 양쪽 항목, 건너뛰기, 이름 바꾸기, 덮어쓰기 및 이후에 적용할 범위를 표시합니다. | 안내를 닫으면 작업은 대기합니다. 작업에서 안내를 다시 열거나 취소할 수 있습니다. |
| 작업 완료 | 성공, 건너뜀, 실패, 최종 저장 건수를 표시합니다. | 압축을 푼 위치는 사용자가 요청하면 엽니다. 생성 후에는 지원하는 단일 압축 파일 또는 첫 볼륨을 앱에서 열 수 있습니다. 다시 시도하려면 새로 계획해야 합니다. |
| 일부 실패 | 이미 저장한 파일을 유지하고 실패를 설명합니다. | 작업 전체를 되돌린 것처럼 보이도록 사용자 파일을 삭제하지 않습니다. |
| 앱 종료 | 활성 작업 수를 표시합니다. 완료를 기다리거나 취소한 뒤 종료할 수 있습니다. | 코어가 정리를 확인합니다. GUI는 종료를 기다리며 무기한 차단되지 않습니다. |
| 설정 | 시스템, 밝은, 어두운 테마와 목록 간격, 글자 크기, 언어, 최근 기록, 알림 영역을 제공합니다. | 저장 후 즉시 적용하고 실패하면 기존 값을 유지합니다. 현재 설정에서는 한도를 편집할 수 없습니다. |
| 형식 확장 | 제품은 내장 형식을 사용합니다. [외부 SDK 시험](../engineering/sdk-trial.md)은 읽기 전용 실행을 별도로 확인합니다. | 지원 작업은 [형식 레지스트리](../engineering/format-registry.md)를 확인하세요. |

압축 풀기 버튼은 선택 범위를 따릅니다. 현재 조건에 따라 메뉴에서 두 범위를 제공합니다. 검색은 현재 디렉터리와 그 하위 항목을 포함합니다. 지원하는 파일 하나를 선택하면 보이는 속성 패널에 [텍스트 또는 이미지 미리보기](../engineering/content-preview.md)가 자동으로 표시됩니다. 패널의 너비가 부족하면 별도 창에서 열 수 있습니다. 큰 글자 크기에서는 콘텐츠가 늘어나며 스크롤로 확인 버튼에 닿을 수 있습니다.

오류 문구에는 문제와 사용자가 할 수 있는 동작을 설명합니다. 오류 코드는 세부 정보에 표시합니다. 일반 화면에는 호출 스택이나 IPC 용어를 표시하지 않습니다. 위험한 파일 이름은 안전한 텍스트로 표시하고 플러그인 메시지를 HTML로 해석하지 않습니다. 바로 가기 키, IME, 포커스 및 화면 읽기 프로그램은 [Qt Quick 설계](../design/qt-quick-ui.md)를 따릅니다.
