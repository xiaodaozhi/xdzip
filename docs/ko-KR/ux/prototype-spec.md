# v0.1 상호작용 프로토타입과 기능 매핑

<a name="xdzip-interaction-decisions"></a>

## 상호작용 결정

<a name="xdzip-selection-and-search"></a>

### 선택과 검색

- 각 선택은 정렬된 행 번호가 아니라 안정적인 항목 ID에 대응합니다. 숨은 선택으로 인한 오해를 피하려고 쿼리나 디렉터리를 바꾸면 선택을 지웁니다.
- 현재 목록의 전체 선택과 압축 파일 전체 추출은 별개입니다. 폴더를 체크하면 중복을 제거한 하위 파일로 확장합니다.
- IME 조합 중에는 쿼리를 제출하지 않고 compositionend 이후 갱신합니다. 브라우저의 모의 이벤트 검사는 macOS/Windows/Linux의 네이티브 IME 검수를 대체하지 않습니다.
- 일반 파일에서 Enter 또는 두 번 클릭하면 임시 사본을 추출해 시스템 연결 프로그램으로 열고 디렉터리에서는 그 안으로 들어갑니다. 속성 진입점은 유지됩니다. HTML은 진행과 자동 숨김만 시연하며 파일을 쓰거나 시스템을 호출하지 않습니다. Qt의 자동 콘텐츠 미리 보기는 [미리 보기 계약](../engineering/content-preview.md)을 참고하세요.

<a name="xdzip-extraction-and-conflicts"></a>

### 추출과 충돌

- 최종 경로를 실시간 표시하고 같은 이름의 디렉터리는 한 번만 추가합니다. 비어 있거나 쓸 수 없음이 명백한 예제 경로는 시작을 막고 대상을 바꾼 뒤 사전 검사를 다시 합니다.
- 충돌 시 기본적으로 확인하며 건너뛰기, 자동 이름 변경과 덮어쓰기를 선택할 수 있습니다. 인접한 설명에 덮어쓰기의 영향을 표시합니다.
- 충돌 패널의 초기 포커스는 건너뛰기이며 덮어쓰기는 기본 Enter 동작이 아닙니다. 이후 충돌에 적용은 이 작업에만 제한하며 예제 데이터는 충돌 하나만 만듭니다.
- 이름 변경은 완료 요약과 파일 세부 정보에 표시합니다. 건너뛰기는 실패가 아니며 기존 예제 파일은 완료된 쓰기로 계산하지 않습니다.

<a name="xdzip-tasks-and-results"></a>

### 작업과 결과

- 탐색으로 돌아가도 작업은 취소되지 않으며 상태 표시줄에서 다시 열 수 있습니다.
- 취소 요청 → 중지 중, 반복 취소 비활성화 → 취소 요약. 추출은 게시된 항목을 유지하고 압축 파일 생성은 중간 결과를 게시하지 않습니다.
- 디스크가 가득 차면 작업을 중지하고 성공한 항목을 유지합니다. 재시도는 실패하거나 미완료된 범위만 선택하고 계획 확인으로 돌아갑니다.
- 원본이 변경되면 이전 인덱스를 조용히 재사용하지 않고 압축 파일을 다시 열어야 합니다.
- 생성 작업은 최종 압축 파일 하나를 계산하며 취소 시 생성 수 0을 표시하고 이전 압축 파일을 명확히 보존합니다.

<a name="xdzip-archive-creation-and-capabilities"></a>

### 압축 파일 생성과 지원 범위

프로토타입은 ZIP 수준, TAR 묶음과 GZIP 압축 옵션을 시연합니다. 기본 입력, 파일 이름과 대상 필드를 검사하고 형식에 따라 확장자를 바꿉니다. 현재 제품 선택지는 [내장 형식 레지스트리](../engineering/format-registry.md)를 사용하며 [ISO](../engineering/iso-creation.md)와 [Windows SFX](../engineering/sfx-creation.md) 생성 프로필도 포함합니다. 허용 옵션은 [암호 상호작용](password-extraction.md)과 [볼륨 계약](../engineering/archive-opening.md)을 참고하세요.

<a name="xdzip-visuals-and-adaptation"></a>

### 시각과 적응

따뜻한 회색, 코발트 파랑과 흑연 테마를 유지합니다. 일반 행 높이는 40, 압축형은 32입니다. 어두운 테마의 텍스트 강조는 버튼 채우기와 독립적이어서 작은 글자의 가독성을 유지합니다. 좁은 데스크톱 너비에서는 세부 정보가 닫을 수 있는 오버레이가 됩니다. 모바일 검토는 사이드바와 보조 표 열을 접으며 작업 패널은 좁은 화면에 맞춰 스크롤합니다.

작업 인터페이스는 [플랫폼 창 사양](platform-windows.md)에 따른 독립 창입니다. HTML은 dialog로 시뮬레이션하며 결정 창은 포커스를 제한하고 진행, 결과와 설정은 모달이 아니며 닫을 때 포커스 복원을 시도합니다. 충돌 창을 닫으면 조용히 건너뛰지 않고 작업을 취소하며 진행 창을 닫으면 세부 정보만 숨깁니다. Qt는 실제 독립 최상위 창을 사용합니다.

<a name="xdzip-theme-selection"></a>

### 테마 선택

설정 페이지는 `fieldset#setting-theme`과 ‘Appearance theme’ 범례를 사용해 시스템, 밝게, 어둡게 세 개의 네이티브 라디오 입력을 구성합니다. 각 테마 카드는 공유 자산 `theme-system`, `theme-light`, `theme-dark` 중 하나를 사용하고 텍스트 레이블과 입력을 연결합니다. 실제 라디오 컨트롤은 카드 클릭, 키보드 전환과 포커스에 참여합니다. 선택은 공유 라디오 표시를 사용하고 카드 테두리와 미리 보기 모양을 동기화하며 상호작용할 수 없는 스크린샷으로 대체하지 않습니다.

이는 HTML 디자인 검증 동작을 설명합니다. 현재 설정은 메모리에 있으며 시스템 따라가기는 선택 시에만 결정합니다. 실행 중 시스템 테마 변경, 실행 간 영속성 및 제품 Qt 설정의 즉시 저장과 실패 처리는 별도 검증이 필요합니다.

<a name="xdzip-verification-and-remaining-boundaries"></a>

## 검증과 남은 경계

브라우저 검증 스크립트는 scripts/check-html-design.py이며 실제 클릭 흐름, 통계, 비활성 조건, 형식 연동, 복구, 모바일 오버플로와 오프라인 단일 파일 동작을 검사합니다. 보고서는 내보낸 프로토타입 패키지에 포함되며 브라우저 검사는 Chromium만 사용합니다.

현재 기본 창 전달에는 서로 독립된 두 예제 압축 파일 세션, 목록/격자, 필드 정렬, 재귀 디렉터리 트리, 계층 경로, 컨텍스트/드롭다운/하위 메뉴와 버튼 상태가 포함됩니다. [구성 요소 및 상호작용 계약](../../ux/main-window-components.md)과 [검증 방법](../../../developers/qa/README.md)을 참고하세요. `scripts/check-html-controls.py`는 실제 브라우저 입력으로 이를 검사하며 [구성 요소 검토 페이지](../../../design/html/components.html)는 기본 UI와 같은 구현을 사용합니다.

HTML은 예제 상태만 검증하며 실제 작업 스케줄링, 권한, 경로 경쟁, CRC나 플랫폼 접근성을 입증하지 않습니다. Qt는 실제 생성/추출, 끌어서 놓기, 시스템 선택기, 영속 설정과 선택적 탭 또는 여러 창의 독립 압축 파일 세션을 통합합니다. 여러 형식, 일반 단일 파일 ZIP의 백만 항목 인덱싱과 제한된 미리 보기의 실제 범위는 각각 [형식 백엔드](../engineering/native-codecs.md), [대형 인덱싱](../engineering/large-index.md), [콘텐츠 미리 보기](../engineering/content-preview.md)에 있으며 검수는 해당 issue에 기록합니다. HTML 설정은 데모 상태를 페이지 안에서만 유지하고 실행 간에는 유지하지 않으며 네이티브 시스템 테마 추종이나 접근성 검수를 입증하지 않습니다.

이 제한은 소프트웨어 디자인의 목표 기능을 바꾸지 않습니다. 프로토타입의 ‘완료’는 데모 작업 상태만 나타내며 실제 압축이나 추출의 전달을 입증하지 않습니다.

<a name="xdzip-current-directory-queries-and-card-revisions"></a>

## 현재 디렉터리 쿼리와 카드 개정

루트 항목은 ‘Root’이며 직접 파일과 폴더만 나열합니다. 검색은 현재 범위의 하위 항목을 찾아 압축 파일 내부 전체 경로를 표시합니다. 일반 목록/격자는 마지막 이름만 표시하고 복사와 탐색은 전체 경로를 유지합니다. 경로 오른쪽은 현재 목록 행 수를 표시합니다. 디렉터리 트리 제목은 ‘Archive’이며 경로와 세로로 가운데 정렬되고 트리를 가리켜도 떠 있는 도움말이 나타나지 않습니다.

목록 호버는 전체 행을 덮습니다. 격자는 가로 안쪽 여백이 약 16 논리 픽셀이며 왼쪽 위 8픽셀 체크박스는 호버 시 나타나고 선택 시 계속 보입니다. 버튼으로 여는 메뉴는 버튼에서 4단위 떨어지고 부드러운 그림자를 사용합니다. 미리 보기 다시 열기 버튼은 한 변이 28로 고정됩니다. 매개변수는 layout-scale.json, directory-tree.json, controls.json에 있으며 실제 검증은 [일반 방법](../../../developers/qa/README.md)을 따릅니다.

<a name="xdzip-settings-window"></a>

## 설정 창

설정은 원본 아이콘 제목, 테마 미리 보기 카드, 밀도, 최근 기록과 개인정보 설명을 유지하고 텍스트 크기와 UI 언어를 추가합니다. 테마와 글꼴 미리 보기를 취소할 수 있으며 저장과 기본값 복원은 초안을 사용합니다. HTML은 데모 상태를 현재 페이지 안에서만 유지합니다. HTML 데모의 언어 선택은 다음 Qt 시작에 적용되는 구성을 보여 주며 디자인 검토 페이지나 예제 압축 파일 내용은 제품 번역 범위의 증거가 아닙니다. 현재 Qt의 언어 전환, 포함된 리소스와 영속성은 [설정과 지역화](settings-localization.md)를 참고하세요.
