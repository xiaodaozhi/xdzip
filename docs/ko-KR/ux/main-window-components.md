# 메인 창 기능, 구성 요소와 상호 작용 계약

[English](../../ux/main-window-components.md) | [简体中文](../../zh-CN/ux/main-window-components.md) | [繁體中文](../../zh-TW/ux/main-window-components.md) | [日本語](../../ja-JP/ux/main-window-components.md) | 한국어 | [Français](../../fr-FR/ux/main-window-components.md) | [Español](../../es-ES/ux/main-window-components.md)

메인 창 컨트롤은 모양과 동작을 함께 제공하며 기본, 호버, 눌림, 키보드 포커스, 비활성, 선택, 처리 중과 오류 상태를 명시합니다. HTML은 샘플 아카이브로 상호 작용을 검증하고 Qt는 실제 탐색, 만들기, 압축 풀기, [무결성 검사](../engineering/archive-checking.md)와 [자동 콘텐츠 미리 보기](../engineering/content-preview.md) 기능에 따라 동작을 활성화합니다. HTML 예제는 실제 백그라운드 결과가 아닙니다.

파일 이름, 디렉터리 이름, 아카이브 이름과 경로는 시작 시 시스템 기본 글꼴을 우선 사용하고 글리프가 없으면 플랫폼 폴백을 사용합니다. 고정 UI 문구는 계속 번들 하위 집합을 사용합니다. 디렉터리 트리와 드래그 미리 보기는 각 텍스트 글꼴로 측정합니다. [시각 표준](../../visual/design-standard.md#界面字体与用户数据)을 참조하세요.

## 기능과 구성 요소

| 영역 | 공유 / 합성 구성 요소 | 상호 작용과 기능 |
| --- | --- | --- |
| 시스템 제목 표시줄 | `Browser`, `ArchiveTabs`, 플랫폼 프레임 | macOS는 네이티브 신호등 버튼 사용. Windows는 통합 버튼, 네이티브 크기 조절과 DWM 장식 사용. Ubuntu X11에서는 통합 버튼과 일반 상태의 둥근 모서리가 X11 디자인을 따름. [플랫폼 창](platform-windows.md) 참조 |
| 아카이브 탭 | ArchiveTabs, ArchiveTab, 아이콘 버튼 | 기본은 새 탭, 선택적으로 새 창. 비활성 탭은 일반 굵기이며 축소 후 가로 스크롤하고 스크롤 및 탭 목록 진입점을 제공. 창 안 드래그와 Ctrl+Shift+Page Up/Down으로 순서 변경. 닫아도 백그라운드 작업 유지 |
| 도구 모음 | `ArchiveToolbar`, `ArchiveAction`, `CommandMenu` | 열기, 새로 만들기, 검사, 더 보기와 분할 압축 풀기 버튼은 메뉴 및 키보드와 같은 명령을 실행. 적격 선택의 사전 검사는 압축 풀기 메뉴에서 사용 가능 |
| 검색 | SearchField, 지우기 동작, 범위 힌트 | IME 조합 중에는 제출하지 않음. 현재 디렉터리 범위를 검색하고 지워도 디렉터리는 바뀌지 않음. 단축키로 포커스 |
| 아카이브 요약 | ArchiveSummary, 형식 배지, 통계 표시줄 | 준비 완료, 읽는 중, 비어 있음과 읽기 실패를 구분. 알 수 없는 값을 0으로 표시하지 않음 |
| 디렉터리 탐색 | DirectoryTree, DirectoryRow, Disclosure, 연결선 | 다단계 확장, 리프의 빈 화살표 슬롯, 독립적인 현재 위치와 포커스, 접근 가능한 전체 경로, 접힌 조상 표시와 디렉터리 컨텍스트 동작 |
| 파일 영역 머리글 | PaneHeader, Breadcrumb, ViewToggle | 계층 경로 탐색, 목록/격자 전환과 정렬 메뉴. 높이와 세로 중심 공유 |
| 목록과 격자 | EntryView, SelectableEntry, 체크박스, SortHeader | 단일/다중/범위 선택, 모두 선택, 해제, 반전과 화살표 키. 두 번 클릭/Enter는 디렉터리에 들어가거나 일반 파일을 임시로 풀어 시스템 연결로 엶. 속성은 컨텍스트 메뉴나 세부 정보에서 계속 사용 가능 |
| 파일 컨텍스트 메뉴 | ContextMenu, CommandMenuItem, Submenu | 열기는 두 번 클릭과 같이 오른쪽 클릭한 항목에만 적용하고 기존 다중 선택을 유지. 선택되지 않은 항목을 오른쪽 클릭하면 먼저 그 항목만 선택. 선택에 따라 압축 풀기, 속성, 이름/경로 복사와 디렉터리 탐색 활성화 |
| 빈 영역 컨텍스트 메뉴 | ContextMenu, RadioMenuItem, CheckboxMenuItem | 현재 목록의 선택, 보기, 정렬과 세부 정보 패널. 임의로 선택을 지우지 않음 |
| 머리글 컨텍스트 메뉴 | 정렬 메뉴 | 정렬 필드와 방향, 아카이브 순서 복원. 보이는 항목만이 아니라 전체 조회 결과 정렬 |
| 속성 / 미리 보기 | 페이지의 `InspectorPanel` 또는 독립 세부 정보 창 | 파일, 선택 또는 아카이브 상태를 표시. 콘텐츠는 요청 시 읽음. 논리 너비 928 미만에서는 내장 패널을 접고 세부 정보 동작으로 별도 창을 엶 |
| 상태와 작업 | 상태 표시줄, 작업 버튼과 `CommandMenu` | 선택 개수와 알려진 크기 표시. 작업 메뉴는 앱 전체 기록 사용. 활성 작업은 별도 개수를 가지며 진행 창을 닫아도 유지 |
| 힌트와 작업 창 | Tooltip, Notice, Toast, 독립 플랫폼 창 | 전체 이름과 비활성 이유 제공. Escape, 포커스 복귀, 취소와 닫기는 각 동작의 의미를 따름 |

목록과 격자는 빈 상태를 공유합니다. 제출된 검색에 결과가 없으면 다른 검색어를 제안합니다. 검색이 없을 때 레코드가 없는 아카이브는 비어 있다고 표시하고, 그렇지 않으면 현재 폴더에서 보이는 내용만 설명하며 제한된 디렉터리 인덱스의 완전성을 추론하지 않습니다. 읽는 중과 오류는 실제 상태를 유지하고 제출하지 않은 검색 텍스트는 현재 결과 메시지를 바꾸지 않습니다. 파일을 열기 전 안내에는 오래된 형식 목록을 나열하지 않습니다.

## 통합 명령과 메뉴

버튼, 단축키, 컨텍스트 메뉴와 드롭다운은 같은 명령을 호출하고 실행 전에 현재 기능을 다시 확인합니다. 메뉴를 열 때 대상과 선택 범위를 고정합니다. 아카이브나 조회가 바뀌거나 대상이 사라지면 메뉴를 닫아 이전 항목의 명령이 새 아카이브에 적용되지 않게 합니다.

메뉴는 아이콘/체크 슬롯, 이름, 단축키와 하위 메뉴 화살표의 네 열을 공유하고 동작 그룹 사이에 구분선을 둡니다. 해당 맥락에 필요한 동작만 포함합니다. 디렉터리는 진입과 확장을 제공하고 파일은 세부 정보를 제공하며 다중 선택은 일괄 범위를 유지합니다. 현재 실행할 수 없는 동작은 비활성으로 유지하고 이유는 접근성 설명에서만 제공합니다. 설명 보조 줄이나 도구 설명을 표시하지 않고 비활성 대신 클릭 시 “출시 예정”을 표시하지 않습니다.

글꼴 크기가 바뀌면 메뉴 레이블 높이는 실제 글꼴 메트릭을 따르고 행의 세로 중심을 유지합니다. 첫 표시부터 논리 픽셀 0.5 이내의 중심 오차를 만족해야 하며 나중의 레이아웃 단계가 오래된 텍스트 슬롯을 고치는 데 의존하지 않습니다.

일반, 체크박스, 라디오와 하위 메뉴 행 및 구분선은 공유 구성 요소입니다. 정렬과 보기는 현재 상태에 라디오 항목을 사용하고 세부 정보 패널은 체크박스 항목을 사용합니다. 위험한 동작은 기본적으로 자동 실행하지 않습니다. 오른쪽 클릭과 메뉴 열기만으로는 어떤 동작도 실행하지 않습니다.

## 메뉴 입력과 수명 주기

- 아래/위로 사용 가능한 항목 사이를 이동하고 Home/End로 처음/끝에 갑니다. Enter/Space는 활성화하고 오른쪽은 하위 메뉴에 들어가며 왼쪽은 부모로 돌아갑니다.
- Escape는 한 단계씩 닫습니다. 루트를 닫으면 트리거한 컨트롤이나 원래 항목에 포커스를 돌려줍니다. Tab은 메뉴를 닫고 일반 페이지 포커스 순서를 계속합니다. 이름의 첫 글자 검색을 지원하며 IME 조합은 메뉴 문자 검색을 실행하지 않습니다.
- 호버는 실행 없이 강조합니다. 하위 메뉴는 지연 후 열리고 들어가는 동안 부모 항목을 유지합니다. 마우스와 키보드를 이어서 사용해도 여러 강조 상태나 루트 메뉴가 남지 않습니다.
- 바깥 클릭은 바깥 대상의 포커스를 빼앗지 않고 메뉴를 닫습니다. 메인 영역 스크롤, 창 크기 조절, 작업 창 진입이나 아카이브 전환은 메뉴를 닫지만 메뉴 자체 스크롤은 닫지 않습니다. HTML 공유 컨트롤은 열 때 기존 컨테이너의 실제 스크롤 위치를 기록합니다. 열기 전에 완료되었으나 늦게 전달된 이벤트는 메뉴를 닫지 않고 이후 위치 변경은 닫습니다.
- 뷰포트의 아래쪽과 오른쪽 가장자리를 피하고 필요하면 왼쪽이나 위쪽으로 엽니다. 호스트 좌표에 배치하되 논리 치수, 원본 소스 픽셀, DPR과 검토 배율을 구분합니다.
- Shift+F10/Menu 키는 현재 항목의 컨텍스트 메뉴를 엽니다. 터치 길게 누르기와 마우스 오른쪽 클릭은 같은 맥락을 사용하며 단일 클릭처럼 다중 선택을 없애지 않습니다.

## 컨트롤 상태와 접근성

| 상태 | 모양 | 동작 |
| --- | --- | --- |
| 기본 | 승인된 원본 테두리, 반경, 아이콘과 기준선 유지 | 상태가 바뀌어도 컨트롤 치수는 바뀌지 않음 |
| 호버 | 연한 채움. 주 버튼은 더 진한 주 색상 | 지연 힌트가 대상을 가리지 않고 터치 후 호버가 고착되지 않음 |
| 눌림 | 호버보다 뚜렷한 채움 | 텍스트/아이콘 이동 없음. 취소된 누름은 실행하지 않음 |
| 포커스 | 추가 외곽선, 두꺼운 테두리나 광채 없음 | Tab 순서와 키보드 활성화 유지. 바깥 클릭, Escape와 Enter로 컨트롤 포커스를 벗어남 |
| 비활성 | 외곽선을 유지하면서 명시적 비활성 텍스트/그래픽 색상 | 클릭이나 단축키에 응답하지 않고 접근성 설명으로 이유 제공 |
| 선택 | 배경이나 체크 표시로 상태를 명확히 표시 | `aria-selected` / `aria-checked` / Qt Accessible 동기화 |
| 처리 중 | 상태와 비활성 범위는 작업에 따름 | 중복 제출 방지. 백그라운드 작업 중 탐색 허용 |
| 오류 | 인접 문구로 문제와 복구 설명 | 색상만으로 정보를 전달하지 않고 성공을 조작하지 않음 |

공유 아이콘은 `design/assets`에서 가져옵니다. 컨트롤은 텍스트, 체크, 배경, 연결선과 메뉴 위치를 구현하며 원본 픽셀 슬라이스는 비교용입니다. HTML은 메인 디자인의 소스 좌표를 유지하고 새 컨트롤 매개변수를 먼저 논리 픽셀에서 변환합니다. Qt는 같은 논리 명세를 사용합니다.

## 검수

파일 영역 오른쪽의 개수와 동작 버튼은 고정 너비 그룹을 이룹니다. 목록, 격자, 정렬과 표시된 세부 정보 진입점은 논리 픽셀 28×28과 간격 6.4를 유지하며 창을 넓히면 이동 경로에만 공간이 늘어납니다. 도구 모음의 더 보기 메뉴에는 설정만 포함하고 원래 순서, 압축 풀기 메타데이터 사전 검사, 모두 선택과 세부 정보는 기존 전용 진입점을 사용합니다.

시작 페이지와 아카이브 페이지는 layout-scale.json의 statusbarHeight에 따라 최소 논리 픽셀 32의 상태 표시줄을 공유합니다. 접근성 글꼴이 커지면 실제 작업 버튼 높이와 같은 위아래 여백을 사용하고 페이지를 전환해도 높이를 바꾸지 않습니다. 두 작업 버튼은 main.interaction.taskIconSize의 중앙 정렬된 논리 16×16 아이콘 슬롯에 task-list를 사용하며 페이지나 글꼴 배율에 따라 바뀌지 않습니다.

아카이브 상태 표시줄은 선택 개수를 표시합니다. 선택이 비어 있지 않고 전체 크기를 알 때만 구분자와 크기를 덧붙입니다. 가상 디렉터리나 크기 미상 파일 때문에 전체 크기를 모르면 추가 구분자나 `—` 없이 개수만 표시합니다. 크기가 알려진 0바이트도 표시하며 시작 페이지 문구는 바꾸지 않습니다.

파일 목록 체크박스의 오른쪽 끝은 파일 아이콘 슬롯에서 논리 픽셀 12를 유지하고 아이콘, 파일 이름과 이름 머리글을 함께 정렬합니다. 접근성 글꼴 크기는 실제 텍스트 메트릭을 바꾸지만 이 간격을 넓히지 않습니다. 행 체크박스와 머리글의 모두 선택은 기존 선택 모델을 유지합니다.

다섯 열은 모두 오른쪽 경계를 드래그하여 크기를 조절할 수 있으며 히트 영역은 논리 픽셀 8입니다. 두 번 클릭하면 해당 열의 기본 너비를 복원합니다. 이름 열은 기본적으로 남은 공간을 채우고 다른 열은 원본 디자인 값에서 시작합니다. 두 크기 열은 측정된 레이블과 정렬 화살표가 잘리지 않도록 기본적으로 확장합니다. 사용자가 지정한 너비는 실행 중 탭과 창 사이에서 공유하고 종료 시 초기화합니다. 논리 너비는 메모리에만 보관하고 설정이나 DPR에 저장하지 않습니다. 이름의 최소 너비는 160, 다른 열은 64이며 접근성 글꼴에 따라 비례해 증가하고 넘치면 가로 스크롤합니다. 머리글과 내용은 하나의 너비 출처를 공유하며 드래그는 정렬을 실행하지 않습니다. 오름차순/내림차순 표시는 오른쪽 정렬된 원래 크기와 압축 크기 레이블 앞, 다른 레이블 뒤에 두고 표시된 텍스트에서 항상 논리 픽셀 6을 띄웁니다. 활성 정렬 열은 알맞은 쪽에 화살표 공간을 예약합니다. 수동으로 좁히면 먼저 레이블을 생략하고 화살표가 텍스트나 인접 열과 겹치지 않게 합니다. 숫자 머리글은 내용과 함께 오른쪽 정렬을 유지합니다.

파일 유형 아이콘은 [확장자 힌트 표](../../../specs/visual/file-types.json)에서 Qt와 HTML 선택기용으로 생성하며 사무 문서, 스프레드시트, 프레젠테이션, 오디오, 비디오, 아카이브, 설치 프로그램, 글꼴과 디스크 이미지를 다룹니다. 확장자는 대소문자를 구분하지 않고 알 수 없는 유형은 일반 문서 아이콘을 사용합니다. 이는 모양만 설명하며 신뢰할 수 있는 콘텐츠나 아카이브 형식의 탐색, 만들기 또는 압축 풀기 지원을 뜻하지 않습니다.

실제 마우스와 키보드로 항목, 메뉴 가장자리 회피, 하위 메뉴 왕복, 선택 유지, 포커스 복원, 비활성 보호, 탭 격리, 보기 전환과 디렉터리 계층을 확인합니다. 밝은/어두운 테마, 세 플랫폼 장식, 일반/큰 글꼴과 배율에서 실제 컨트롤을 캡처합니다. 메뉴 작업 때문에 기존 초기 메인 창 제목, 도구 모음, 파일 목록과 미리 보기 정렬이 퇴행해서는 안 됩니다.

[일반 검증 방법](../../../developers/qa/README.md)에 따라 기능 범위, 실제 스크린샷과 미통합 기능을 기록하고 결론은 해당 이슈에, 증거는 build/ 또는 CI 아티팩트에 둡니다. 정적 보드, 브라우저 동작과 Qt 런타임 검증은 별도로 설명하며 서로 대체할 수 없습니다.

Qt 메뉴는 `Popup.Item`과 공유 델리게이트를 명시적으로 사용하여 AppKit이 사용자 정의 스타일을 무시하지 않도록 합니다. 작업 창은 독립 최상위 창으로 유지합니다. `CommandTooltip`은 공유 힌트 매개변수와 일반 텍스트를 사용해 아카이브 이름을 서식 있는 텍스트로 해석하지 않으며 메뉴가 포커스를 얻으면 힌트를 숨깁니다. 공유 JSON의 8자리 색상은 CSS RGBA이고 QML 생성기가 QColor ARGB로 변환합니다. 색상과 불투명도를 함께 검증합니다.

디렉터리 트리와 메인 도구 모음의 열기, 새로 만들기, 검사, 더 보기와 압축 풀기 호버 상태에는 떠 있는 도구 설명이 없습니다. 비활성 메뉴 동작도 화면상 힌트나 도구 설명이 없으며 다른 버튼은 공유 지연 힌트를 사용합니다. 루트와 일반 하위 디렉터리는 직속 파일과 폴더만 나열하고 검색은 현재 범위를 재귀적으로 탐색합니다. 일반 이름은 마지막 구성 요소, 검색은 전체 경로를 표시합니다. 목록 호버는 행 전체를 덮고 격자는 고정 가로 여백과 호버/선택 체크박스를 유지합니다. 메뉴는 모든 방향에 부드러운 그림자를 사용하고 호출 버튼에서 논리 픽셀 4만큼 떨어집니다. 상호 작용과 배율 증거는 [일반 방법](../../../developers/qa/README.md)에 따라 별도로 보존합니다.

모든 정렬 모드에서 디렉터리는 파일 앞에 둡니다. 오름차순과 내림차순은 각 그룹 안에 적용합니다. 파일 유형 정렬은 확장자가 없는 파일을 디렉터리와 별도로 묶고 같은 유형은 안정적인 ID 순서를 유지합니다. 내부 전송 배치로 나누기 전에 전체 조회를 정렬합니다. HTML에서 folder가 설정되지 않은 파일은 false로 처리하며 비교를 위해 undefined를 NaN으로 변환하지 않습니다.

## 선택, 작업과 힌트

모두 선택은 현재 목록의 마지막 항목에 세부 정보 포커스를 유지하고 메타데이터는 개별 선택과 일치합니다. 선택을 지우면 네 가지 속성과 “이 파일 압축 풀기”를 숨기고 해당 버튼은 공유 호버/눌림/포커스 상태를 사용합니다. 모두 선택은 디렉터리나 물리 ID 계약을 바꾸지 않고 현재 조회 전체에 적용됩니다.

하단의 “작업 N”은 보존된 기록 개수를 표시하며 활성 개수는 힌트와 종료 로직에만 사용합니다. 각 작업 메뉴 항목은 왼쪽에 만들기/압축 풀기와 번호, 오른쪽에 상태 색상을 표시하고 마우스나 키보드로 활성화하면 같은 작업을 다시 엽니다. 작업 메뉴는 다른 메뉴와 밀도, 글꼴 크기와 스크롤 경계를 공유합니다. 선택이 없으면 압축 풀기 범위 메뉴의 선택 범위와 사전 검사 동작을 비활성화하고 추가 힌트 줄을 표시하지 않습니다.

떠 있는 힌트는 포인터가 같은 컨트롤 안에서 1200 ms 동안 계속 정지한 뒤에만 표시합니다. 이동, 벗어남, 누름 또는 메뉴 열기는 표시와 오래된 타이머를 취소합니다. 다른 컨트롤로 이동하면 이전 힌트에서 빠르게 깨어나지 않고 전체 시간을 다시 기다립니다. 컨트롤 위쪽을 우선하고 위에 공간이 부족하면 아래쪽을 사용하여 가장자리 제약이 도구 설명을 컨트롤 위로 밀어 호버가 진동하는 것을 방지합니다. Qt 공유 CommandTooltip은 명시적인 정지 타이머를 사용하고 HTML data-tooltip과 동기화합니다. 목록의 전체 이름은 이 정책을 우회하는 네이티브 브라우저 title을 사용하지 않습니다. 시스템 네이티브 메뉴와 트레이 힌트 시간은 시스템이 제어하며 QML로 제어할 수 있다고 주장하지 않습니다. 시간은 글꼴 크기, DPR 또는 밀도에 따라 확대하지 않고 시각적 지오메트리도 유지합니다.

아카이브 탭도 공유 정지 지연 도구 설명에 전체 파일 이름을 일반 텍스트로 표시합니다. 누르기, 순서 변경, 탭 메뉴나 탭 목록 열기 시 숨깁니다. 전역 작업 항목은 먼저 메뉴를 닫고 작업 창만 열며 아카이브 탭을 전환하거나 닫힌 아카이브 페이지를 다시 열지 않습니다.

시작 페이지는 위쪽에 고정되고 가로로 중앙 정렬된 스크롤 본문을 사용합니다. 오류와 경고는 형식 힌트 아래에 빨간 텍스트와 의미 아이콘으로 표시하고 위 콘텐츠를 밀지 않습니다. 트레이에 상주하는 메인 창을 닫으면 탭이 지워지고 일반 복원에는 시작 페이지만 표시됩니다. 최소화하면 탭을 유지하며 백그라운드 작업은 전역에서 계속 접근할 수 있습니다.

파일 목록의 양방향 드롭, 현재 디렉터리에 추가 확인과 세 플랫폼 외부 복사는 [파일 드래그 앤 드롭과 수정](../../engineering/archive-transfers.md)을 참조하세요.

아카이브 내부 이동은 내부 드래그를 사용합니다. 목록/격자와 디렉터리 트리의 폴더 대상은 기존 선택 채움을 사용하며 즉각적 피드백은 도구 설명 지오메트리를 재사용하고 최대 네 줄로 현재 클라이언트 영역에 제한합니다. 선택된 디렉터리, 그 하위 항목, 원래 위치, 검색과 암호화/분할 대상에는 새 확인 창 없이 명시적인 거부 이유를 표시합니다. 이름 충돌은 파일 충돌 창을 사용하고 이동 작업에는 별도 이름을 사용합니다. 트랜잭션과 경계는 [아카이브 내 이동 디자인](../../../design/hifi/sources/archive-move.html)과 [드래그 앤 드롭 계약](../../engineering/archive-transfers.md)을 참조하세요.
