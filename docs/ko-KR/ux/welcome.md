고충실도 디자인은 확인되었습니다. Qt는 실제 열기와 생성을 구현하며 데스크톱 수동 검수는 별도 기록합니다. 환영 페이지 상태 디자인과 [welcome-reference.json](../../../specs/visual/welcome-reference.json)을 참고하세요. 색상과 기본 창 밀도는 기존 토큰과 layout-scale을 유지하며 전역 표준을 바꾸지 않습니다. PNG 네 개는 코드로 그린 디자인 원본의 내보내기이며 실행 중인 제품 스크린샷이 아닙니다.

<a name="xdzip-information-and-layout"></a>

## 정보와 레이아웃

시작 페이지 제목은 중국어로 ‘打包与解压，都简单一点。’, 영어로 ‘Pack and unpack, a little simpler’, 한국어 카탈로그에서는 ‘압축하고 풀기를 더 간편하게’입니다. 보조 문구는 먼저 탐색하고 필요한 파일을 추출하며 공유를 위해 압축하는 내용을 설명합니다.

기본 클라이언트 영역은 1024×622, 최소는 832×544이며 제목 영역 48, 캡슐 32, 하단 표시줄 32입니다. 너비 608의 콘텐츠 그룹은 가로로만 가운데 정렬하고 사용 가능한 본문 위쪽에서 고정된 28 논리 픽셀 아래에 시작하며 세로 가운데 정렬하지 않습니다. 제목 크기는 30, 좁은 창에서는 28이며 설명 13, 동작 제목 16, 카드 설명 12입니다. 두 동작 카드는 너비 296, 높이 124, 간격 16, 안쪽 여백 20, 반경 8입니다. 이는 환영 페이지 진입 카드이며 공유 작업 창 버튼을 대체하지 않습니다.

제목 표시줄은 기본 창의 기존 구성 요소를 완전히 재사용해 브랜드, 시작 탭, 탭 추가와 모양 설정을 유지하며 환영 페이지는 레이아웃, 치수, 글꼴이나 아이콘을 바꾸지 않습니다. 본문에는 빈 파일 트리, 표 머리글, 검색 상자 또는 추출 도구 모음을 표시하지 않으며 압축 파일을 연 뒤 탐색 레이아웃이 나타납니다. 주 동작은 ‘압축 파일 열기’, 보조 동작은 ‘압축 파일 만들기’이며 놓기 영역 뒤에 지원 파일 형식이 나옵니다. 각 범주는 등록된 확장자 수를 표시하고 처음에는 ‘압축 파일’이 열립니다. 다른 범주를 활성화하면 미리 보기가 바뀌고 같은 범주를 다시 활성화하면 접힙니다. 강조 글자와 굵기로 활성 범주를 표시합니다. 미리 보기는 일반 UI 글꼴의 옅은 채우기와 테두리가 있는 태그를 한 줄에 표시합니다. 말줄임표는 넘침을 나타내며 행에 마우스를 올리면 선택 범주의 확장자를 보여 줍니다. ‘파일 연결’은 설정의 기존 연결 컨트롤을 엽니다. 하단 표시줄의 로컬 처리 문구는 처리 장소를 설명하며 안전을 보장하지 않습니다. 작업 수는 실제 기록을 사용하고 디자인의 0은 첫 사용 시 빈 기록을 나타냅니다.

예제 최근 파일, 임의의 크기 또는 제품에 없는 형식 기능을 표시하지 않습니다. 제목 영역의 신호등은 macOS 장식 위치만 나타내며 구현은 플랫폼 창 기능을 사용합니다. Windows와 Linux는 신호등을 복사하지 않고 플랫폼 장식을 유지합니다.

<a name="xdzip-interaction-design"></a>

## 상호작용 디자인

- 환영 페이지는 첫 시작, 마지막 압축 파일 탭을 닫은 뒤 또는 탐색 가능한 압축 파일 없이 열기가 실패한 뒤 나타날 수 있습니다. 백그라운드 작업은 계속되며 초기화되지 않습니다.
- 열기는 시스템 파일 선택기를 호출하고 취소하면 환영 페이지에 남습니다. 성공하면 실제 압축 파일 탭으로 전환하며 실패하면 복구 가능한 오류를 표시하고 성공 목록을 꾸며 내지 않습니다.
- 만들기는 기존 생성 창을 열고 취소하면 환영 페이지를 유지합니다. 후보 단축키는 macOS에서 ⌘O/⌘N, Windows/Linux에서 Ctrl+O/Ctrl+N입니다. 구현 전에 실제 바인딩을 확인하며 이 디자인은 통합되었다고 주장하지 않습니다.
- 허용되는 선택 항목을 끌면 2 논리 픽셀 강조 테두리와 선택 채우기로 놓기 영역을 강조하며 벗어나면 일반 상태로 돌아갑니다. 실제 파일 열기는 [실제 Qt 통합](#xdzip-real-qt-integration)을 참고하세요.
- 카드 전체를 클릭할 수 있습니다. 제목 표시줄 뒤 키보드 순서는 열기, 만들기, 작업입니다. 키보드 포커스는 추가 윤곽선을 그리지 않고 창 전체의 포커스 상실 규칙을 따릅니다. 호버와 누름은 불투명도만이 아니라 공유 accentHover와 accentPressed를 사용합니다.
- 여는 동안 열기 카드는 제목 대신 바쁨 표시와 ‘여는 중…’을 보여 주고 반복 열기와 놓기를 일시적으로 막습니다. 비활성 모양은 accentDisabled와 accentDisabledText를 사용합니다. 생성 창의 동시 실행 가능 여부는 호스트 규칙을 따르며 환영 페이지는 작업 의미를 바꾸지 않습니다. 바쁨, 비활성, 오류는 네 정적 원본에 그려지지 않은 구현 계약입니다.
- 설정 및 작업 팝업은 너비 240, 글꼴 13, 최소 행 높이 32를 유지해 본문 글꼴 13과 1:1 비율을 이루며 별도 메뉴 스타일을 도입하지 않습니다. 카드 글꼴 16은 진입 제목이지 메뉴 밀도 비교 기준이 아닙니다.

<a name="xdzip-verification-and-boundaries"></a>

## 검증과 경계

밝은/어두운 테마, 최소 창, 끌기 상태와 메뉴/제목 표시줄 비율을 다루고 DPR 1, 1.25, 2 및 실제 브라우저 페이지 확대율을 검사합니다. 축소 스크린샷으로 레이아웃을 대체하거나 CSS 크기 조정으로 브라우저 페이지 확대율을 대체하지 않습니다. 결과, 이미지와 형상 보고서는 로컬/CI 산출물에만 보관하고 상태는 해당 issue에 기록합니다.

Qt 환영 페이지와 브라우저 회귀 검사를 사용하며 실제 제품 진입점으로 파일을 엽니다. 자동 검사는 네이티브 끌어서 놓기, 화면 판독기 또는 IME 검증을 대체하지 않습니다.

<a name="xdzip-real-qt-integration"></a>

## 실제 Qt 통합

WelcomePage와 WelcomeAction은 레이아웃과 의도만 표현합니다. 환영 페이지는 시작 시와 압축 파일을 닫은 뒤 나타나며 성공적으로 열면 해당 세션으로 들어갑니다. 빈 압축 파일도 유효한 탐색 상태입니다. 초기 로딩은 반복 열기와 생성을 비활성화하고 ‘여는 중…’을 표시하며 로딩 취소를 허용합니다. 실패하면 환영 페이지와 실제 오류를 유지해 다시 선택할 수 있습니다. 생성 초안을 닫아도 작업은 만들어지지 않습니다. 백그라운드 작업 목록은 초기화되지 않습니다.

열기와 시스템 단축키는 chooseArchive를 재사용하고 생성은 CreateWindow를 재사용합니다. 네이티브 파일 선택기는 시스템 창이며 취소해도 세션을 만들지 않습니다. Qt는 저장된 탭/창 모드로 라우팅하고 빈 시작 페이지를 우선 재사용하며 중복 압축 파일에는 기존 세션을 활성화합니다.

데스크톱 세션 관리자를 사용할 때 한 번의 놓기에서 최대 128개 로컬 파일을 열 수 있습니다. 각 항목은 생성된 끌어서 놓기 확장자 또는 지원되는 분할 볼륨 이름 패턴과 일치해야 합니다. 단일 세션 개발 진입점은 한 항목을 받습니다. 디렉터리와 비로컬 URL은 거부합니다. 이 검사는 열기 경로를 선택하며 Rust 런타임은 실제 형식을 식별하고 원본을 검증합니다. 명시적 열기 진입점만 있는 형식에는 **압축 파일 열기**를 사용합니다. [형식 레지스트리](../engineering/format-registry.md)를 참고하세요.

치수는 welcome-reference.json에서 generate-qml-theme.py를 통해 Theme으로 들어갑니다. 더 큰 텍스트는 카드와 본문을 키우며 본문은 스크롤하고 키보드 포커스 항목을 자동으로 보이는 곳에 가져옵니다. 상태와 제목 영역은 Item.scale 없이 독립적으로 커집니다. Qt는 공유 PNG 아이콘과 주 동작의 기존 어두운/밝은 잉크 그림을 사용하며 런타임 자산을 원본에서 잘라내지 않습니다.

자동화 진입점은 tst_welcome.qml, browser_test.cpp의 welcomeOpensRealArchivesAndReturns, scripts/check-qt-welcome.py입니다. 필요 시 세 플랫폼 Qt 워크플로는 실제 열기, 닫기, 실패 복구와 DPR 1, 1.25, 2에서 36개 형상 항목을 검사하고 메뉴 너비 240과 글꼴 13도 검사합니다. 네이티브 놓기, 파일 선택기, 화면 판독기와 IME는 필요에 따라 확인하며 오프스크린 결과를 수행하지 않은 데스크톱 조작으로 제시하지 않습니다.

환영 페이지는 본문만 바꾸고 동일한 Qt ArchiveTabs 구성 요소를 재사용합니다. `screens/welcome-titlebar-*.png`는 제목 표시줄 디자인을 보존합니다. 회귀 검사는 압축 파일을 열기 전후 제목 표시줄, 탭과 모양 버튼의 형상을 비교합니다.

로딩 상태: 초기 열기 취소 진입점이 본문의 떠 있는 오버레이로 이동했습니다. 진행률을 모르면 모의 백분율 없이 활성 진행 표시줄을 사용합니다. [로딩 오버레이 계약](welcome-opening.md)을 참고하세요. 원본 환영 비트맵을 유지하며 동적 디자인은 `opening=1`을 제공합니다.

오류와 경고는 형식 안내 아래에 공유 위험 색상과 상태 경고 아이콘을 사용해 표시합니다. 오류를 표시, 줄 바꿈, 지우기 또는 교체해도 제목과 진입 카드의 위쪽 좌표는 바뀌지 않으며 긴 콘텐츠는 본문에서 스크롤합니다. 트레이로 닫은 뒤 기본 창을 다시 열면 시작 페이지 하나만 표시하고 백그라운드 작업을 취소하지 않습니다. 이전 환영 PNG는 과거 바이트를 유지하며 이전의 중앙 정렬 레이아웃으로 상단 위치 계약을 대체해서는 안 됩니다.
