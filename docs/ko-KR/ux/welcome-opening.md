# 홈 화면 불러오기 표시와 압축 파일 만들기 완료

[English](../../ux/welcome-opening.md) | [简体中文](../../zh-CN/ux/welcome-opening.md) | [繁體中文](../../zh-TW/ux/welcome-opening.md) | [日本語](../../ja-JP/ux/welcome-opening.md) | 한국어 | [Français](../../fr-FR/ux/welcome-opening.md) | [Deutsch](../../de-DE/ux/welcome-opening.md) | [Español](../../es-ES/ux/welcome-opening.md) | [Português (Brasil)](../../pt-BR/ux/welcome-opening.md) | [Русский](../../ru-RU/ux/welcome-opening.md)

2026-10-16 개정. 매개변수는 [welcome-reference.json](../../../specs/visual/welcome-reference.json)을 따릅니다. 동적 상세 설계 진입점은 홈 화면의 불러오기 상태입니다. 기본 창, 메뉴 및 홈 화면의 논리 단위와 제목 표시줄을 유지합니다.

홈 화면에서 실제 압축 파일을 열면 본문 가운데에 떠 있는 카드와 반투명 덮개가 표시됩니다. 논리 단위 기준으로 일반 카드의 너비는 360, 안쪽 여백은 24, 간격은 12, 모서리 반경은 8, 제목 크기는 16입니다. 창이 좁으면 카드를 사용 가능한 너비에 맞춥니다. 파일 이름은 가운데를 줄일 수 있고 상태 문구는 줄을 바꿀 수 있으며 취소 버튼은 계속 사용할 수 있습니다. 밝은 테마와 어두운 테마는 공통 디자인 값을 사용합니다. 접근성 글자 크기는 전체 설정을 따릅니다.

열린 압축 파일에 파일을 추가하거나 내부 항목을 옮길 때 BrowserBusyOverlay 카드와 치수를 재사용합니다. 배경은 완전히 투명해 기존 파일 목록이 보이며 아래쪽 동작을 차단합니다. 제목, 설명, 진행 표시의 접근 가능한 이름과 취소 버튼은 실제 작업을 표시합니다. 작업 정리와 디렉터리 새로 고침 중에도 작업 이름을 유지합니다. 처음 열 때는 반투명 읽기 표시를 사용합니다.

현재 메타데이터를 읽는 동안 전체 바이트 수나 진행률을 알 수 없습니다. 진행률을 타이머로 꾸며내지 않고 진행률을 알 수 없는 막대와 “압축 파일 내용 읽는 중”을 표시합니다. 취소는 기존 취소 요청을 호출하며 압축 풀기 작업을 만들거나 파일을 쓰지 않습니다. 취소 확인, 실패 또는 성공 시 표시를 닫습니다. 실패 결과는 홈 화면에 남고 성공하면 파일 목록으로 이동합니다. 읽는 동안 본문에서 열기나 만들기를 반복하거나 파일을 놓을 수 없습니다. 제목 표시줄은 배치와 호스트 명령 규칙을 유지합니다.


만들기 창에서 “완료 후 대상 폴더 열기”를 제거합니다. 자동 완료 시 Finder나 Explorer를 열지 않습니다. 지원하는 암호화 압축 파일과 번호가 붙은 분할 압축 파일 등, 만든 결과는 계속 앱 안에서 자동으로 열립니다. 압축 풀기에 있는 같은 이름의 옵션과 사용자가 명시적으로 폴더를 여는 동작은 기존 의미를 유지합니다. 이미 확정됐거나 종료 알림이 먼저 도착한 경우 모두 예전의 만들기 후 폴더 자동 열기 인수를 무시합니다.

만들기 결과의 개수는 중국어에서 “已保存”, 영어에서 “Saved”로 표시하며 숫자의 의미는 유지합니다. 공통 작업 입력란의 자리 표시자는 textSecondary에 명시적으로 연결하여 어두운 테마의 암호란에 밝은 플랫폼 기본값이 적용되는 것을 막습니다. 비활성화 상태는 공통 컨트롤 정책을 따릅니다.

인수 검증은 실제 취소, 읽기 실패 후 복구, 제목 표시줄 치수, 밝은 테마와 어두운 테마 및 접근성 글자 크기를 확인합니다. 만들기가 성공했을 때 시스템 폴더를 열지 않고 앱에서 압축 파일을 여는지도 확인합니다. 테스트 화면과 측정값은 build/ 또는 CI 결과물에만 보관합니다.

명령줄, Windows의 연결 프로그램, Linux 데스크톱 항목 또는 macOS 파일 열기 이벤트로 특정 파일을 열면 기본 창을 처음 표시하기 전에 실제 읽기를 요청합니다. 읽기가 끝날 때까지 기다리지 않고 취소 가능한 진행 카드를 바로 표시하며 홈 화면 브랜드, 열기 및 만들기 카드와 놓기 영역을 숨깁니다. 성공하면 파일 목록을 표시하고 실패하거나 취소하면 실제 결과와 함께 홈 화면으로 돌아갑니다. 파일 없이 일반 실행하면 홈 화면이 표시되고 홈 화면에서 열 때는 기존 덮개를 사용합니다. 제목 표시줄, 기본 창과 메뉴의 비율을 유지하며 인위적인 지연이나 가짜 진행률을 사용하지 않습니다.

회귀 검사는 창 표시 전 읽기 요청, 첫화면에서 홈 콘텐츠 숨김, 실패 후 복구와 각 플랫폼의 실제 시스템 열기를 다룹니다. 연결 확인 도구는 실제 frameSwapped 횟수와 홈 화면 콘텐츠가 표시된 횟수를 기록합니다. 읽기 성공만으로는 시작 화면을 검증할 수 없습니다.
