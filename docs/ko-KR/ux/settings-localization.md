# 설정 창과 인터페이스 언어

[English](../../ux/settings-localization.md) | [简体中文](../../zh-CN/ux/settings-localization.md) | [繁體中文](../../zh-TW/ux/settings-localization.md) | [日本語](../../ja-JP/ux/settings-localization.md) | 한국어 | [Français](../../fr-FR/ux/settings-localization.md) | [Deutsch](../../de-DE/ux/settings-localization.md) | [Español](../../es-ES/ux/settings-localization.md) | [Português (Brasil)](../../pt-BR/ux/settings-localization.md) | [Русский](../../ru-RU/ux/settings-localization.md)

기본 창이 보이지 않을 때 알림 영역에서 소유자 없이 연 설정과 xdzip 정보 창은 포인터가 있는 화면의 작업 영역에 전체 네이티브 프레임을 중앙 배치합니다. OperationWindow의 화면 배치를 사용하고 네이티브 창 생성과 높이 결정이 끝난 뒤 다시 가운데로 맞춥니다. 높이 제한에는 선택한 QScreen의 실제 사용 가능 높이와 기존 여백을 사용합니다. 전체 가상 데스크톱 높이를 쓰거나 숨겨진 기본 창 또는 최소화된 기본 창을 복원하지 않습니다. 소유자가 있는 진입점은 호출한 창의 배치, 크기 및 밀도를 유지합니다.

설정은 독립적인 비모달 시스템 창입니다. 제목 표시줄, 앱 메뉴 및 알림 영역은 같은 설정 창을 엽니다. 사이드바는 모양, 일반, 개인정보 보호, 파일 연결, 네트워크, xdzip 정보 순서입니다. 모든 정보 진입점은 같은 설정 창의 정보 페이지를 엽니다. 논리 너비는 612, 클라이언트 높이는 532이며 화면 공간이 부족하면 제한됩니다. 사이드바와 본문은 독립적으로 스크롤하며 위쪽에 추가 간격 없이 맞닿습니다. 바닥글, 저장 단추 및 취소 단추가 없습니다. [설정 디자인](../../../design/hifi/sources/settings.html)과 [레이아웃 값](../../../specs/visual/layout-scale.json)을 참조하세요.

테마, 글자 크기, 목록 간격, 언어, 열기 방식, 알림 영역 아이콘 및 최근 기록 설정은 조작할 때 저장되고 적용됩니다. 창을 닫아도 성공적으로 저장된 변경은 유지됩니다. 언어를 바꾸면 실행 중인 작업에 영향을 주지 않고 제품의 텍스트, 앱 소유 네이티브 메뉴 및 알림 영역 메뉴를 즉시 갱신합니다. 시스템 메뉴 항목은 시스템 언어를 따릅니다. 열기 방식은 이후 파일을 열 때와 제목 표시줄의 더하기 단추에 적용합니다. 이미 열린 세션은 이동하지 않습니다. 최근 기록을 지우면 즉시 반영되고 원본 파일은 유지됩니다. 기록을 지우거나 설정을 쓰지 못하면 페이지에 표시하고 기존 데이터 및 적용된 설정을 유지합니다. 확인란은 IntentCheckBox를 사용하며 테마와 프록시의 라디오 단추는 IntentRadioButton을 사용합니다. 마우스와 키보드, 네이티브 접근성 press/toggle 동작은 같은 선택을 제출하고 모델 상태를 확인합니다. 드롭다운의 OperationSelect는 선택이 확정되면 한 번만 제출합니다.

설정은 스키마 1을 사용하며 알 수 없는 키를 보존하고 프록시 및 미러 주소를 저장합니다. 암호는 저장하지 않습니다. 저장할 때 별도 구성 잠금을 유지하고 같은 디렉터리에 완전한 INI를 임시 기록하며 백업과 주 파일을 원자적으로 갱신합니다. 읽기 오류, 1 MiB 초과, 잘못되거나 새 버전의 스키마, 심볼릭 링크, 백업 또는 커밋 실패 시 원본을 덮어쓰지 않습니다. 적용에 실패하면 실행 중 상태를 복원합니다. 최근 경로는 같은 디렉터리의 recent.json에 따로 저장합니다. 중복을 제거하고 최대 20개 및 읽기 64 KiB로 제한하며 사용자만 읽고 쓸 수 있습니다. 기록을 끄면 더 추가하지 않습니다. 지우기를 실행하면 기존 기록이 삭제됩니다.

준비 과정에서는 원본 바이트를 변경할 수 없는 스냅숏으로 보존합니다. 모든 키를 새로운 후보 INI에 복사하고 그 파일에 변경을 적용합니다. 방금 만든 스냅숏은 다시 쓰지 않습니다. 스키마를 계속 검증하고 알 수 없는 키를 보존하며 백업에는 원본 바이트가 남습니다.

Windows에서는 삭제 공유를 지원하지 않는 읽기 핸들과 같은 일시적 경합으로 원자적 교체의 이름 바꾸기가 실패하면 최대 네 번 재시도합니다. 총 대기 시간은 입출력을 제외하고 75 ms입니다. 구성 잠금을 유지합니다. 시도할 때마다 같은 바이트를 새 임시 파일에 기록하고 GUI 이벤트를 처리하거나 원본에 직접 덮어쓰지 않습니다. 경합이 계속되거나 다른 오류가 나면 원본과 적용된 설정을 유지하고 실패를 표시합니다.

파일 연결 페이지는 생성된 형식 데이터로 등록된 확장자를 묶어 보여 줍니다. 일반 설치의 스위치는 시스템에서 조회한 기본 앱을 표시합니다. Windows에서는 기본 앱을 열고, macOS는 Launch Services, Ubuntu는 데스크톱 MIME 기본값을 사용합니다. macOS 또는 Ubuntu에서 연결을 끌 때 다른 앱을 선택해야 할 수 있습니다. 여러 확장자가 시스템 유형 하나를 공유할 수 있습니다. Windows는 `.tar.gz`의 마지막 확장자를 사용합니다. MSIX는 연결할 수 있는 유형을 비활성화된 스위치로 보여 줍니다. **Windows 기본 앱 열기**를 선택하면 실제 기본값을 표시하는 시스템 설정으로 이동합니다. [파일 연결 계약](../engineering/installers-associations.md)과 [패키지 설정 디자인](../../../design/hifi/sources/settings.html?tab=associations&channel=msix)을 참조하세요.

Windows에 설치된 형식 설명은 언어 변경이 성공하면 선택한 언어로 표시됩니다. 설치 프로그램은 설치나 업그레이드 시 저장된 언어를 읽습니다. 앱은 현재 설치의 것으로 확인한 ProgID 설명 아홉 개만 갱신하고 기본 앱은 바꾸지 않습니다. 시스템이나 다른 앱의 유형 설명과 캐시 및 다른 플랫폼의 표시 내용은 각자 관리합니다. 조건과 오류 처리는 [설치와 파일 연결](../engineering/installers-associations.md)을 참조하세요.

네트워크에서는 직접 연결, 시스템 프록시, 사용자 지정 HTTP 또는 SOCKS5 프록시, 선택 사항인 HTTPS GitHub 미러를 제공합니다. 사용자 지정 프록시는 호스트와 포트가 필요하며 인증 정보는 받지 않습니다. 입력한 주소를 검증한 뒤 저장합니다. 미러가 비어 있으면 공식 주소를 사용합니다. 미러를 지정해도 업데이트 전송 주소만 바뀌며 체크섬 및 서명 검사 조건은 유지됩니다. 진행 중인 업데이트는 기존 네트워크 설정을 계속 사용하고 다음 작업부터 새 설정을 사용합니다. macOS의 Sparkle은 시스템 설정, 직접 연결, 인증 정보가 없는 HTTP CONNECT 또는 SOCKS5 프록시를 지원합니다. 사용자 지정 프록시가 실패하면 직접 연결로 전환하지 않습니다. 신뢰와 리디렉션 정책은 [소프트웨어 업데이트](../engineering/software-update.md)를 참조하세요.

여섯 페이지는 사이드바의 제목을 반복하지 않습니다. 일반 빌드의 정보 페이지는 업데이트 상태와 동작을 위한 스크롤 영역을 확보합니다. 기본 동작은 업데이트 상태에 따라 확인, 취소, 다운로드, 설치 또는 릴리스 페이지 열기로 바뀝니다. 키보드 포커스로 화면 밖의 동작까지 스크롤할 수 있습니다. MSIX 패키지 ID가 있으면 빌드 정보와 고지를 유지하고 앱 내 업데이트 영역을 숨깁니다. Microsoft Store 에디션의 업데이트는 스토어에서 관리합니다. [MSIX 정보 디자인](../../../design/hifi/sources/settings.html?tab=about&channel=msix)과 [업데이트 계약](../engineering/software-update.md)을 참조하세요.

정보 페이지는 업데이트 상태 텍스트를 네이티브 접근성 이름으로 제공합니다. 확인, 다운로드, 설치, 성공 또는 실패 상태 및 언어를 표시 내용과 동기화합니다.

macOS 수동 업데이트 안내는 충족하지 못한 첫 설치 조건을 보여 주고 릴리스 페이지 및 다운로드 위치를 열 수 있게 합니다. 누락된 조건이 여러 개일 수 있으며 ID 확인 실패만으로 원인을 특정할 수 없습니다. 해당 DMG와 app.zip을 사용한 수동 교체를 안내하고, 다운로드만으로 설치되지는 않음을 표시합니다.

본문 세로 스크롤 막대는 표시 영역 오른쪽 끝을 따라 전체 높이에 놓입니다. 손잡이는 스크롤을 따라가며 끌어서 이동할 수 있습니다. 정보 페이지의 버전 정보 표에서 라벨 열 너비는 실제 문구와 글자 크기에 맞춥니다. 값은 남은 너비를 사용하며 줄바꿈할 수 있습니다. 새 필드에도 같은 배치를 적용합니다.

제품 텍스트는 `resources/i18n/` 카탈로그의 안정적인 ID를 사용합니다. QML은 `qsTrId`, C++는 `qtTrId`를 사용합니다. 프로토콜 코드, 파일 이름, 경로 및 사용자 콘텐츠 값은 유지합니다. 메뉴는 자동 감지 뒤에 포함된 언어를 각 언어의 이름으로 표시합니다. 자동 감지는 실행할 때마다 숫자 형식과 독립적으로 시스템의 첫 인터페이스 언어 환경설정을 읽습니다. 중국어는 명시된 문자 체계를 지역보다 우선합니다. 중국어 번체 문자 체계와 zh-TW, zh-HK, zh-MO 지역은 번체 중국어 번역을 사용합니다. 다른 언어는 같은 언어의 제공 버전이 있으면 사용합니다. 비어 있거나 지원하지 않는 언어는 영어(미국)를 사용합니다. 언어 태그의 국가(지역) 코드는 언어의 지역별 변형을 구분하며, 언어 수가 국가(지역) 수를 뜻하지 않습니다.

언어 전환은 즉시 적용됩니다. 저장하지 못하면 직전 선택과 표시 언어로 돌아갑니다. 영어와 중국어 간체 이후에 추가된 언어를 수동으로 선택하면 `locale/extendedLanguage`에 실제 선택과 `locale/language`에 이전 버전에서 읽을 수 있는 대체값을 기록합니다. 이전 버전은 번체를 간체로, 나머지 추가 언어는 영어로 표시하면서 다른 설정을 계속 읽습니다. 현재 버전은 저장된 대체값과 맞을 때 확장 값을 사용합니다. 자동 감지, 중국어 간체 또는 영어를 선택하면 확장 값을 지웁니다.

글자 크기는 100%, 125%, 150%입니다. 예전의 200% 설정은 150%로 읽습니다. 시스템 파일 선택기와 기본 Qt 컨트롤은 시스템 언어를 사용합니다. macOS 번들은 포함된 언어를 선언하고 여러 현지화의 혼용을 허용합니다.

여섯 탭과 공용 설정 및 정보 진입점, 즉시 저장과 실패 복원, 각 언어의 테마와 글자 크기, 해당하는 프록시, 업데이트 및 파일 연결 상태를 확인합니다. 일반 Windows 설치에서는 필요한 경우 핵심 ProgID 아홉 개의 즉시 동기화를 검사합니다. MSIX에서는 비활성화된 연결 스위치, 시스템 설정 링크와 앱 내 업데이트 영역이 표시되지 않는지 확인합니다. `QAccessibleActionInterface`로 라디오 단추와 스위치를 조작하고 모델 및 이벤트를 검사합니다. 네이티브 검사 및 증거는 [검증 안내](../../../developers/qa/README.md)를 참조하세요.
