# 시스템 메뉴와 트레이

[English](../../ux/desktop-integration.md) | [简体中文](../../zh-CN/ux/desktop-integration.md) | [繁體中文（台灣）](../../zh-TW/ux/desktop-integration.md) | [日本語](../../ja-JP/ux/desktop-integration.md) | 한국어 | [Français](../../fr-FR/ux/desktop-integration.md) | [Deutsch](../../de-DE/ux/desktop-integration.md) | [Español](../../es-ES/ux/desktop-integration.md) | [Português (Brasil)](../../pt-BR/ux/desktop-integration.md) | [Русский](../../ru-RU/ux/desktop-integration.md)

다중 세션, 단일 인스턴스, 창 상태와 전체 종료는 [애플리케이션 세션 계약](../engineering/application-sessions.md)을 따릅니다. 마지막이 아닌 기본 창을 닫아도 작업은 유지되며 마지막 창은 트레이 설정을 따릅니다. 종료 확인은 모든 세션을 포함합니다.

작업 암호나 충돌 확인이 표시된 상태에서도 시스템, 메뉴 또는 트레이의 명시적 종료로 전체 확인 창을 열 수 있습니다. macOS에서는 애플리케이션 메뉴의 종료와 Command-Q를 계속 사용할 수 있습니다. 돌아가기를 선택하면 작업과 확인 창이 유지됩니다. 네이티브 파일 선택기나 다른 차단 모달 창은 먼저 완료하거나 닫아야 합니다. 애플리케이션은 그 모달 창에 의해 차단된 종료 시도를 버립니다.

macOS 메뉴 막대와 세 플랫폼의 트레이는 운영체제 네이티브 메뉴를 사용하면서 기존 기본 창 제목 표시줄을 유지합니다. [데스크톱 통합 매개변수](../../../specs/visual/desktop-integration.json), [상호작용 디자인](../../../design/html/desktop-integration.html), [고충실도 디자인](../../../design/hifi/sources/desktop-integration.html)을 참조하세요. 네이티브 글꼴, 행 높이, 메뉴 너비와 시스템 강조 표시는 앱 내부 CommandMenu 밀도 매개변수를 사용하지 않습니다. HTML은 상호작용을 설명하며 네이티브 픽셀 승인이 아닙니다.

macOS 메뉴는 xdzip, 파일, 편집, 보기, 작업, 창, 도움말입니다. 도움말의 “사용자 가이드”와 “문제 신고”는 기본 브라우저에서 프로젝트 README와 Issues를 열며 피드백을 전송하지 않습니다. 구분선 뒤의 “xdzip 정보”는 앱과 트레이 메뉴에서 사용하는 동일한 설정 창의 정보 페이지를 엽니다. 도움말의 정보 항목은 NoRole을 사용해 제자리에 남고 앱 메뉴는 AboutRole, PreferencesRole, QuitRole을 사용하며 서비스, 가리기, 모두 표시는 시스템이 제공합니다. 파일에는 열기, 새로 만들기, 최근 항목, 압축 파일 닫기, 창 닫기가 있습니다. 편집은 텍스트 포커스에 따라 실행 취소, 다시 실행, 잘라내기, 복사, 붙여넣기, 모두 선택, 찾기를 제공합니다. 보기는 목록, 격자, 미리 보기, 작업은 모두 추출, 선택 추출, 메타데이터 사전 확인, 창은 최소화, 확대, 기본 창, 작업과 보이는 제품 창을 포함합니다.

메뉴와 기존 UI는 공통 명령 진입점을 사용하고 열 때와 활성화 전에 기능을 다시 확인합니다. ⌘W는 현재 창을, ⇧⌘W는 압축 파일을 닫습니다. 텍스트 편집이 실수로 파일 선택에 영향을 주어서는 안 됩니다. 모달 창은 기본 창 명령을 차단하며 비활성 항목에 설명 줄을 추가하지 않습니다. 최근 파일은 기록이 허용된 경우에만 표시하고 경로를 추가로 복사하거나 업로드하지 않습니다. 애플리케이션 소유 텍스트는 활성 언어 카탈로그를 사용하고 시스템 항목은 시스템 언어를 따릅니다.

언어 저장이 성공하면 기존 메뉴 막대, 애플리케이션 소유 정보, 설정, 종료 항목, 트레이 메뉴, 작업 하위 메뉴와 트레이 도구 설명이 즉시 전환됩니다. 저장 실패 시 이전 언어가 유지됩니다. 명령, 단축키, 작업 신원과 실행 중인 작업은 바뀌지 않습니다. macOS 서비스와 가리기 등 시스템 소유 항목과 네이티브 파일 선택기는 계속 시스템 언어를 따릅니다.

트레이 상주는 기본적으로 켜져 있으며 저장 성공 후 적용됩니다. 메뉴는 기본 창 표시, 열기, 새로 만들기, 작업, 설정, 정보, 종료를 제공합니다. macOS에서는 트레이 아이콘으로 메뉴를 엽니다. Windows와 Linux에서는 트레이 활성화나 두 번 클릭으로 창을 복원하고 시스템 컨텍스트 활성화로 메뉴를 엽니다. Windows는 트레이를 다시 활성화할 때 네이티브 메뉴를 다시 바인딩합니다. 작업 완료는 포커스를 빼앗지 않고 작업 항목을 갱신합니다.

트레이를 사용할 수 있을 때 마지막 기본 창을 닫으면 그 창의 탐색 탭과 초안을 지운 뒤 숨깁니다. 기본 창을 복원하면 시작 페이지로 돌아갑니다. 최소화는 탭을 유지합니다. 활성 작업과 원래 신원은 전체 작업 항목에서 계속 접근할 수 있습니다. 관리 세션이 트레이를 잃고 보이는 작업 항목이 없으면 작업 창을 통해 활성 작업에 접근합니다. 트레이, 보이는 창, 활성 작업이 모두 없으면 애플리케이션이 종료됩니다. 명시적 종료와 재시작은 여전히 작업 확인과 비동기 종료 절차를 따릅니다. macOS Dock과 시스템의 파일 열기로도 애플리케이션을 복원할 수 있습니다.

macOS는 기존 브랜드 마크에서 파생한 템플릿 트레이 아이콘을 사용합니다. Windows와 Linux를 포함한 다른 플랫폼은 앱 아이콘을 재사용하고 표시 크기는 시스템이 선택합니다. 앱 아이콘은 앱 또는 시스템 테마에 따라 바뀌지 않으며 레지스트리 테마 읽기에도 의존하지 않습니다. 아이콘은 깜박이거나 계속 애니메이션되지 않습니다.

보기 메뉴는 “파일 미리 보기 및 속성” 뒤에 접히지 않는 구분선을 유지해 AppKit이 자동 추가한 전체 화면 명령을 분리합니다. 그러면 시스템 전체 화면 아이콘이 미리 보기에 추가 아이콘 열을 예약하지 않습니다. 미리 보기 텍스트는 목록과 격자에 맞추고 체크 표시는 시스템이 계속 그립니다. 공백, 고정 너비 또는 사용자 지정 메뉴로 보정하지 않습니다. HTML과 고충실도 디자인은 앱 명령만 표현하며 시스템이 추가한 항목은 네이티브 데스크톱에서 검증합니다.

## 검증

애플리케이션 소유 Qt Quick 창을 숨기거나 최소화할 때 포인터 호버를 동기적으로 끝내고 버튼, MouseArea, HoverHandler, 도구 설명의 이전 위치를 지웁니다. 복원된 첫 프레임을 동기화하기 전에 이전 호버 색이나 좌표를 재사용하지 않고 실제 시스템 포인터 위치와 조정합니다. 늦게 들어온 네이티브 진입 이벤트도 실제 마우스 이동이나 누르기가 현재 좌표를 제공할 때까지 실제 위치를 기준으로 정규화합니다. 기본 창과 작업 창에 적용하며 포커스, 버튼 바인딩, 네이티브 파일 선택기는 변경하지 않습니다.

Windows에서 트레이로 숨기면 네이티브 창, 상태, QML 객체, 컨트롤러와 백그라운드 작업을 유지합니다. 숨겨진 동안 불투명도를 마스킹하고 복원 후 새로 제출된 첫 프레임까지 유지하여 DWM이 이전 프레임을 잠시 노출하지 않게 합니다. hovered만 지워서는 방지할 수 없습니다. 다시 숨기면 이전 프레임 콜백은 무효화됩니다. 이 정책은 트레이 숨김에만 적용하고 최소화나 보이는 창에는 적용하지 않으며 스크린샷 읽기, 고정 지연, 시스템 애니메이션 변경을 사용하지 않습니다.

전역 시스템 포인터가 없는 백엔드는 물리 커서 조회로 덮어쓰지 않고 주입된 이벤트를 기준으로 삼습니다. offscreen/minimal 구성 요소 검사는 실제 네이티브 DWM, Cocoa, X11 창 승인과 별개입니다.

자동화는 메뉴 구조와 역할, 상태 동기화, 명령 및 편집 라우팅, 설정 호환성과 취소, 상주 및 종료 정책, 트레이 없는 대체, 작업 메뉴, 모달 차단과 재시작을 다룹니다. 네이티브 데스크톱 검사는 macOS 메뉴 막대와 Dock 복원, Windows 알림 영역과 Linux StatusNotifier/XEmbed, 밝고 어두운 외관, 높은 DPR, 키보드와 화면 읽기 프로그램을 별도로 확인합니다. 오프스크린 검증은 네이티브 데스크톱 승인이 아니며 스크린샷과 보고서는 build/ 또는 dist/에만 저장합니다.

네이티브 편집 역할이 앱 언어 카탈로그를 사용하는 곳은 `QCocoaMenuItem`의 Cut, Copy, Paste, Select All 번역 컨텍스트뿐입니다. `QCocoaMenuBar/Edit`도 같은 제목을 사용하여 Qt 텍스트 역할 감지와 편집 메뉴 인식이 시스템 언어에 의존하지 않게 합니다. 시스템 파일 선택기와 다른 Qt 컨트롤은 계속 시스템 로캘의 qtbase 번역을 사용합니다. 사용자의 전역 AppleLanguages를 수정하지 않고 중국어 앱과 영어 시스템, 영어 앱과 중국어 시스템을 모두 검증합니다.

한국어 트레이 도구 설명은 `xdzip(실행 중인 작업: %1개)`, 작업 메뉴는 `작업(실행 중: %1개)`입니다. 영어는 각각 `xdzip (Active tasks: %1)`와 `Tasks (Active tasks: %1)`입니다. 개수는 탐색 페이지가 닫힌 후에도 실행 중인 작업을 포함해 앱 전체의 실제 활성 작업에서 가져오며 완료된 결과는 활성으로 세지 않습니다.
