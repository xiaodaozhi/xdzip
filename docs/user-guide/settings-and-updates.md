# Settings and updates

English | [简体中文](../zh-CN/user-guide/settings-and-updates.md)

## Set up your workspace

Open **Settings** from the application menu or toolbar. Choose the language, theme, font size and interface density in their respective settings. The automatic language option follows the system where supported. Choose whether archives open in tabs or windows, and configure recent files and tray behavior if the setting is available for your platform. Changes apply as you make them. If a setting cannot be saved, use the error shown on that page. [Settings behavior](../ux/settings-localization.md)

Change file associations through the operating system. Configure context-menu actions separately. On macOS, Finder extension enablement is managed by the system, with Finder Services available where registered. [File-manager actions](../engineering/shell-actions.md)

## Update the app

- **Microsoft Store edition.** Check for updates in Microsoft Store. The app's About panel does not offer the GitHub updater in a packaged MSIX build.
- **GitHub edition.** Open **About xdzip** and choose to check for updates. Eligible installations can download and install a verified update. Keep the app open while it waits for active tasks, or cancel the wait if you want to update later.
- **Portable or experimental builds.** Download the appropriate package and use the platform's manual installation steps. On macOS, quit the old app before replacing it in Applications.

The app uses network settings for GitHub updates, including the configured proxy mode where supported. Check the error message and the release page if the network check or verification fails. The Store and GitHub publish independently. [Update behavior and recovery](../engineering/software-update.md)
