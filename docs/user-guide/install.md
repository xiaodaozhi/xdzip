# Install XDZip and open an archive

English | [简体中文](../zh-CN/user-guide/install.md)

Choose your platform on the [download page](../../README.md#download-and-install). Verify direct downloads against the checksums on the release page. For supported system versions, see the [support policy](../engineering/support-policy.md).

1. **Windows 11 x64.** Search for XDZip in Microsoft Store, run the GitHub per-user installer, or extract the entire portable ZIP and run the executable from its folder. Keep the bundled files with it. The GitHub installer uses the current user by default.
2. **macOS on Apple Silicon.** Open the DMG and move XDZip to Applications. If you downloaded the app ZIP, extract it first and move the application there. Start the new copy from Applications. The GitHub release uses ad-hoc integrity signing. If macOS shows a warning, check the download's source and checksum before proceeding.
3. **Ubuntu 24.04 x64 under X11.** Install the DEB using your package manager, or extract the entire runtime TAR.GZ and use the launcher in that directory. Keep the runtime files together.

In XDZip, use **Open archive** or drag a supported archive onto the window. To use XDZip from the file manager, choose it in the system's **Open with** menu. To make it the default, select it in the operating system's default-app settings. The Windows Store edition provides **Open default apps settings** in the file associations page. Changing default apps and enabling archive actions in the context menu are separate settings. [Installation and associations](../engineering/installers-associations.md)
