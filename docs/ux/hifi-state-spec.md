对应 [操作状态原稿](../../design/hifi/README.md) 和 [统一素材库](../../design/assets/README.md)。状态编号延续原型映射，补充 C02、T02、R02、R03，不另造业务协议。需求 P03/P04/P05/P06/P07/P08/P11/P15；验收仍对照 AC-03/04/05/06/07/08/11/14。

## 画面与任务语义

| 状态 / 图板 | 进入条件 | 默认焦点与操作 | 关闭与恢复 |
| --- | --- | --- | --- |
| C01 / 01 | 新建，尚无执行任务 | 首个输入按钮或文件名；创建前校验输入、名称、目标、能力 | 放弃本窗口草稿；不产生写入 |
| E02 / 02 | 当前 TaskId/PromptId 需要重名决定 | 默认跳过；改名保留扩展名；覆盖须明确按下；“应用后续”默认不勾选 | 关闭请求取消任务，经过 T02，再进入结果；不默认覆盖或跳过 |
| T01 / 03、08 | 已接受计划并收到运行事件 | 返回浏览与取消均为普通按钮；没有虚构的暂停能力 | 仅隐藏视图；任务入口可重开；后台完成不抢焦点 |
| R01 / 04 | 本次任务有已发布项和未完成项 | 重试仅选未完成项，重新进入计划确认 | 关闭视图不删除已提交文件 |
| S01 / 05 | 打开设置，拷贝当前配置为草稿 | 所有编辑可用键盘访问；保存前校验数值 | 取消/关闭丢弃草稿，恢复预览前外观 |
| R02 / 06 上 | 收到唯一成功终态 | 打开目标文件夹；零失败计数用中性状态 | 关闭详情，不重复通知完成 |
| T02 / 06 中 | 已接受取消，清理尚未完成 | 重复取消禁用；仍可返回浏览 | 可隐藏；不能提前显示“已取消” |
| R03 / 06 下 | 收到取消终态 | 保留已发布项；若允许重试，重新规划未完成范围 | 关闭不回滚已发布项 |
| C02 / 07 | 新建目标已有同名归档 | 默认返回修改；使用新名称回到 C01 并建议未占用名；替换非默认 | 返回 C01 保留输入、格式、路径草稿；不隐式开始覆盖 |

“使用新名称”只提出建议名，真正开始时仍验证目标是否已存在；不能把文件名检查当作最终写入授权。替换创建必须先完整生成并验证临时归档，发布前再检查目标条件。取消在线性化提交点之后到达时按核心结果显示已完成，不把成功改写为取消。

## 新建能力与字段错误

- ZIP 的四档级别映射 Store／Deflate 1／6／9，默认 2-正常压缩。TAR／TAR.GZ 暂不可创建。修改格式同步扩展名，但不能静默覆盖既有目标。
- 无输入、空名称、目标无效或无权限时，创建按钮禁用，原因显示在相邻字段。错误文本参与读屏，不只改变边框颜色。
- 同一输入去重与目录展开由核心处理；UI 只展示选择摘要。创建页的图像图标是类型标志，不进行图片预览。
- ZIP 密码和分卷按 WP-10 宿主契约实际创建；RAR、7z 创建仍禁用。

## 任务数据与异常

样例 A 为 3 个文件：8.4 + 6.2 + 12.8 = 27.4 MB。成功 2 个时已保存 14.6 MB，剩余 PDF 为 12.8 MB；成功、跳过、未完成的计数不可混淆。样例 B 为整个归档：30 个文件、77.5 MB；46.5 MB 对应 60%，不是样例 A 的同一个时刻。

百分比来源于已知总字节与真实计量；未知总量显示不定进度、不编造剩余时间。阶段变化后重新估算速率；图中 6.2 MB/s、约 5 秒仅为稳定阶段示例。文件计数标明已完成还是正在处理，不以当前条目序号当成功数。

磁盘满：停止并保留已发布项，释放空间或修改目标后重新规划。源变化：重试入口改为重新打开归档，不能沿用旧索引。单纯取消：未完成用琥珀/中性色，不显示归档损坏。错误码位于详情，普通画面不出现调用栈或内部桥接术语。

## 设置草稿契约

外观在草稿期间可即时预览；保存设置后持久化，取消或窗口关闭恢复原主题/密度。恢复默认仅修改草稿。清空最近记录先在草稿中标记待清空并显示“保存后清空”；只有保存时删除记录，不删除归档本身。

8 GiB / 20 GiB 沿用既定单文件/任务输出默认限额。输入须为有效正数，转换为字节使用检查过的运算；单文件上限不得大于单次任务上限。无效输入不保存并聚焦字段。限额修改只用于后续新计划，不能更改运行中任务的不可变授权。提高限额仍须重新规划并检查空间，不代表无限放行。

原型旧设置为即时内存修改；本稿定义正式设置窗口的保存/取消行为，旧 HTML 不作为此项验收依据。

## 窗口、布局与素材映射

全部操作窗遵循 [平台窗口规范](platform-windows.md)。macOS 原生标题栏不采用切图交通灯；Windows/Linux 标题栏按钮位置、禁用、系统菜单和移动行为由平台层验证。平台对照图中的 Linux 右侧控件不是对所有桌面环境的硬编码承诺。

逻辑尺寸建议：新建与设置 640×820，冲突 820×560，进度 760×560，部分结果 820×640。可用屏幕小于建议高度时滚动内容，标题栏和底部主操作保持可见。正文 14、标题 20、标准行高 40、按钮高 36，间距沿用 4/8/12/16/24/32；系统字体或 200% 字号可增高，不以原稿像素固定组件尺寸。

| 使用位置 | 新增素材 | 共享 / 动态部分 |
| --- | --- | --- |
| 新建标题、添加输入 | archive-add、image-file、remove | folder、file-pdf、new |
| 冲突、部分失败 | document-warning、status-warning、info | file-pdf；比较卡与文本由 QML 绘制 |
| 运行进度 | document-download、image-file、info | 进度条与数字动态绘制 |
| 成功、跳过、取消、停止 | status-success、status-skipped、status-stopped、spinner、clock | spinner 旋转由 Qt 控件处理 |
| 设置 | settings-tile、theme-system | 主题预览、开关、数字输入为组件；settings 用于小图标 |

素材统一位于 `design/assets/`。`reference/` 保留原像素切片，用于外观对照；`svg/` 和 `png/` 为透明运行素材，不能混称原稿图层。全部 SVG 使用 24×24 画布，PNG 导出 24×24、48×48、72×72；各倍率保持相同逻辑显示尺寸。HTML 文件列表采用 48×48 源空间槽位，Qt 文件列表采用 18×18 逻辑像素槽位。PDF、文本、代码与 Markdown 图标共用中心与 22 像素可见高度，保留不同的轮廓宽度；文件夹在相同画布内居中。深色 SVG 是素材适配，完整深色行为仍需 Qt 实机与对比度检查。
