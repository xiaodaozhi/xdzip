# 密码解压交互

AES ZIP（含受支持分卷）的任务在遇到需要密码的条目时进入 `waiting_password`。运行时发布带任务 ID 和请求 ID 的密码请求；QML 只表达输入与取消意图，不负责解密、认证或文件提交。密码请求与重名冲突是不同状态，不能把密码请求交给重名窗口。格式、认证、重试次数及输出边界以[工程契约](../engineering/password-extraction.md)为准。

PasswordWindow 使用应用模态和现有系统标题栏，客户区宽 491，最高 600，并受当前屏幕可用高度约束。标题 20、正文 13、说明 12，正文随内容增长或独立滚动，footer 固定可达。尺寸来自 [password-reference.json](../visual/password-reference.json)，高保真依据为 [P02 独立状态稿](../../design/hifi/sources/password-extraction.html)。中英文、浅深色、100%／125%／150% 字号使用同一几何政策。

窗口显示当前加密条目的名称、密码输入框、显示／隐藏密码动作与当前任务范围说明。显示动作使用明确文字和可读名称，不增加包含密码的提示。输入默认为掩码；提交后、取消、窗口关闭或请求 ID 改变时，清空输入并恢复掩码。密码不写入设置、剪贴板、日志、任务快照或报告。UI 的字符串清理不宣称可擦除 Qt 内存中的所有历史副本，底层秘密容器的生命周期由运行时契约约束。

外来压缩包的密码可以为空，可以包含控制字符，不做 trim，不套用创建密码的 1–128 字节限制。解压密码上限为 1,024 个 UTF-8 字节，输入框限制最多 1,024 个 UTF-16 单元，并在提交前检查 UTF-8 字节数；后端再次检查边界。超限显示真实错误并保留当前输入，允许修改。错误密码请求使用新的请求 ID，清空旧输入并显示“密码不正确，请重试”。

继续解压向控制器提交精确的任务 ID、请求 ID 和原始密码。提交获接收后立即清空字段、恢复掩码并禁止重复提交，窗口等待任务快照确认离开该请求后关闭。过期、取消或重复请求不能提交到其他任务；立即拒绝时保留当前有效请求和输入，允许重试。并行任务的请求由控制器依次呈现，不能用后来的请求静默覆盖尚未处理的任务。

点击“取消任务”或关闭原生窗口取消窗口对应的当前任务，不把任务留在不可发现的等待状态。Escape 遵循应用共享焦点策略，第一次退出当前控件焦点，之后关闭窗口并取消任务。Return／Enter 在密码字段中提交当前密码，仍受同一请求身份、长度和 pending 检查；按钮保留既有键盘激活语义。任务窗口的“等待输入密码”状态保留真实进度并提供重开请求动作；终止任务清除相关密码请求。

设计演示只使用空字段和自有示例文件名，不读取真实压缩包，不验证密码。自动化必须核对输入掩码、空密码、非 ASCII 字节边界、拒绝和重复提交、请求替换、取消与关闭，以及小屏滚动与固定 footer；功能通过与原生视觉验收分别记录。
