高保真设计已确认，现已接入[正式 HTML 审阅入口](../../design/html/index.html?view=welcome&zoom=1)。Qt 已接入真实打开与新建，桌面人工验收另行登记。设计入口见[欢迎页状态稿](../../design/hifi/sources/welcome.html)，参数见 [welcome-reference.json](../visual/welcome-reference.json)。颜色、主窗口密度沿用现有 tokens 和 layout-scale，不调整全局规范。四张 PNG 为代码绘制的设计原稿导出，不是产品运行截图。

## 信息与布局

默认客户区 1024×622，最小 832×544；标题区 48，胶囊 32，底栏 32。中央内容组宽 608，在可用正文中垂直居中。标题 30，窄窗口 28，说明 13，操作标题 16，卡片说明 12。两张操作卡宽 296、高 124，间隔 16、内距 20、圆角 8。它们是欢迎页入口卡片，不替代操作窗口共享按钮。

标题栏完整复用主窗口原有组件，保留品牌、起始标签、添加标签与外观设置；欢迎页不改变标题栏的布局、尺寸、字体或图标。正文不展示空文件树、空表头、搜索框或解压工具栏；打开归档后再进入浏览布局。主操作为“打开压缩文件”，次操作为“新建压缩文件”；下方单独显示拖入区和 ZIP、TAR、TAR.GZ。底栏“文件在本机处理”表达处理位置，不暗示已经通过独立安全审查。任务数字取真实历史数据，稿中 0 仅为首次进入的空历史状态。

不放示例最近文件、样例容量或产品尚未具备的格式能力。标题区交通灯只表示 macOS 装饰位置，正式实现使用平台窗口能力；Windows、Linux 沿用平台装饰，不复制交通灯。

## 交互设计

- 首次启动、最后一个归档标签关闭、打开失败后没有可浏览归档时可进入欢迎页；后台任务继续运行，不因欢迎页重置。
- 打开入口调用系统文件选择器，取消停留欢迎页。打开成功后切换真实归档标签，失败显示可恢复错误，不能伪造成功列表。
- 新建入口打开既有创建窗口，取消保留欢迎页。快捷键候选 macOS 为 ⌘O、⌘N，Windows/Linux 为 Ctrl+O、Ctrl+N；实施前核对应用快捷键绑定，本稿不表示已接入。
- 拖入单个受支持归档时，虚线边框改为 2 像素主题强调色，填充 selection，文案“松开即可打开压缩文件”。移出恢复默认。目录、多个文件或不支持格式不得显示可打开态，落下时给出明确反馈；不隐式创建归档。
- 卡片完整区域可点击，标题栏之后的键盘顺序为打开、新建、任务。键盘焦点不增加外框，遵循全窗口统一失焦规则。Hover、pressed 使用共享 accentHover、accentPressed，不能只改变透明度。
- 打开请求进行中时，打开卡片以忙碌标记和“正在打开…”替代标题，临时禁止重复打开和拖入；禁用使用 accentDisabled、accentDisabledText。新建窗口是否可并行沿用宿主规则，不借欢迎页改变任务语义。忙碌、禁用与错误为实施契约，四张静态原稿未展示这些状态。
- 设置和任务弹出菜单沿用 240 宽、13 字号、32 最小行高，与正文 13 字号比例为 1；欢迎页不另造菜单样式。卡片 16 字号是入口标题，不能作为菜单密度比较基准。

## Qt 真实接入

WelcomePage、WelcomeAction 仅表达布局和意图。启动及关闭归档后显示欢迎页，成功打开后进入现有单归档浏览；空归档仍是有效浏览状态。首次读取期间禁用重复打开及新建，显示“正在打开…”与取消读取；失败保留欢迎页和真实错误消息，可重新选择文件。创建草稿关闭后不产生任务。后台任务列表不随欢迎页重置。

打开按钮和系统快捷键复用 chooseArchive，新建复用 CreateWindow。原生文件选择器保持系统窗口，取消不创建会话。Qt 当前只有单归档会话，HTML 的多标签示例不是本次新增的产品能力。

拖入适配仅接受一个本地普通文件，文件名为 ZIP、TAR、TAR.GZ 或 TGZ。QFileInfo 只检查输入形态，不读取归档内容；openDroppedUrls 复用 openPath，格式、预算、错误和源变化仍由现有 Rust 核心检查。拖入扩展名不表示内容有效，目录、多个条目及网络 URL 明确拒绝，不隐式创建。

尺寸取 welcome-reference.json，经 generate-qml-theme.py 进入 Theme；字号放大增长卡片与正文，正文可滚动，键盘聚焦入口时自动滚到可见范围。状态栏和标题区独立增长，不使用 Item.scale。Qt 使用共享 PNG 图标，主按钮为既有深色浅墨图形；不从原稿裁切运行素材。

自动化入口为 tst_welcome.qml、browser_test.cpp 的 welcomeOpensRealArchivesAndReturns 与 scripts/check-qt-welcome.py。三平台 CI 在 DPR 1、1.25、2 检查真实打开、关闭、失败恢复及 36 项几何，菜单同时检查 240 宽、13 字号。离屏结果不代替原生拖放、文件选择器、读屏和输入法人工验收。

标题栏修订：初版欢迎页中对标题栏的专属样式已撤销。Qt ArchiveTabs 恢复接入前的组件原样，HTML 复用主窗口原有源画布及相同比例；欢迎页只替换正文。旧 PNG 与哈希保持历史记录，新修订为 screens/welcome-titlebar-*.png，源为 design/hifi/sources/welcome.html。回归比较欢迎页与打开归档后的标题栏、标签及外观按钮几何，防止空态再次改变应用框架。
