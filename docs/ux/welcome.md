# W01 主窗口欢迎页，高保真候选

本次只交付设计，不改变 Qt 或正式 HTML 界面。设计入口见[欢迎页状态稿](../../design/hifi/sources/welcome.html)，参数见 [welcome-reference.json](../visual/welcome-reference.json)。颜色、主窗口密度沿用现有 tokens 和 layout-scale，不调整全局规范。四张 PNG 为代码绘制的设计原稿导出，不是产品运行截图。

## 信息与布局

默认客户区 1024×622，最小 832×544；标题区 48，胶囊 32，底栏 32。中央内容组宽 608，在可用正文中垂直居中。标题 30，窄窗口 28，说明 13，操作标题 16，卡片说明 12。两张操作卡宽 296、高 124，间隔 16、内距 20、圆角 8。它们是欢迎页入口卡片，不替代操作窗口共享按钮。

保留品牌、欢迎标签、添加标签与设置。正文不展示空文件树、空表头、搜索框或解压工具栏；打开归档后再进入浏览布局。主操作为“打开压缩文件”，次操作为“新建压缩文件”；下方单独显示拖入区和 ZIP、TAR、TAR.GZ。底栏“文件在本机处理”表达处理位置，不暗示已经通过独立安全审查。任务数字取真实历史数据，稿中 0 仅为首次进入的空历史状态。

不放示例最近文件、样例容量或产品尚未具备的格式能力。标题区交通灯只表示 macOS 装饰位置，正式实现使用平台窗口能力；Windows、Linux 沿用平台装饰，不复制交通灯。

## 交互设计

- 首次启动、最后一个归档标签关闭、打开失败后没有可浏览归档时可进入欢迎页；后台任务继续运行，不因欢迎页重置。
- 打开入口调用系统文件选择器，取消停留欢迎页。打开成功后切换真实归档标签，失败显示可恢复错误，不能伪造成功列表。
- 新建入口打开既有创建窗口，取消保留欢迎页。快捷键候选 macOS 为 ⌘O、⌘N，Windows/Linux 为 Ctrl+O、Ctrl+N；实施前核对应用快捷键绑定，本稿不表示已接入。
- 拖入单个受支持归档时，虚线边框改为 2 像素主题强调色，填充 selection，文案“松开即可打开压缩文件”。移出恢复默认。目录、多个文件或不支持格式不得显示可打开态，落下时给出明确反馈；不隐式创建归档。
- 卡片完整区域可点击，键盘顺序为打开、新建以及保留的窗口入口。键盘焦点为外侧 2 像素描边、3 像素间隔。Hover、pressed 使用共享 accentHover、accentPressed，不能只改变透明度。
- 打开请求进行中时，打开卡片以忙碌标记和“正在打开…”替代标题，临时禁止重复打开和拖入；禁用使用 accentDisabled、accentDisabledText。新建窗口是否可并行沿用宿主规则，不借欢迎页改变任务语义。忙碌、禁用与错误为实施契约，四张静态原稿未展示这些状态。
- 设置和任务弹出菜单沿用 240 宽、13 字号、32 最小行高，与正文 13 字号比例为 1；欢迎页不另造菜单样式。卡片 16 字号是入口标题，不能作为菜单密度比较基准。

## 本次验证与边界

已导出并目视复核浅色、深色、最小窗口、拖入四种设计状态，资源完整、无横向溢出；正常视口标题区 48、底栏 32。导出使用 macOS ARM64 无头 Chromium，DPR 1、浏览器缩放 100%，PNG 像素与逻辑尺寸相同；没有通过截图缩小实现布局。辅助报告位于忽略的 build/review/welcome/。

本轮未实施 Qt 或正式 HTML 交互，未执行桌面人工验收，也不声称通过 125% 页面缩放、高 DPR、200% 字号和平台菜单验收。这些在后续接入时按统一设计流程验证。欢迎页完整深色稿不代表归档浏览页已有完整深色原稿。
