# 设置窗口与界面语言

设置使用独立非模态系统窗口，主标题栏和更多菜单均进入同一窗口，支持平台标准设置快捷键。使用既有 OperationWindow、OperationFrame、OperationSelect、主题卡片和共享 footer 按钮；逻辑宽度 612，正文按内容增长，最高为可用屏幕高度减 80，超出时滚动。正文 13、说明 12、标题 20，辅助字号可增高。

保留原 HTML 设置的图标标题、三张带插画的主题单选卡片、列表密度、最近记录与隐私区域，在原布局中增加文字大小和语言行。本次实际支持主题（跟随系统、浅色、深色）、文字大小（100%、125%、150%、200%）和语言（中文 (简体)、English (US)）。列表密度提供标准和紧凑两档，仅改变归档表格行高，不缩小字号。最近记录仅在本机保存，可关闭；清空操作先标记“保存后清空”，点击“完成”才执行，不删除归档。外观、字号和密度即时预览；点击“完成”后持久化，取消或系统关闭恢复保存值，恢复默认仅修改草稿。语言保存后下次启动生效，运行中的任务保持同一界面语言。

配置通过 Qt 设置适配器写入应用配置目录，schema 为 1，不包含归档内容、路径或密码。最近路径独立保存在同目录 recent.json，最多 20 条、去重并限制读取为 64 KiB，仅成功打开时记录，文件仅用户可读写。关闭记录开关停止新增，已有记录由清空入口删除。无效值恢复默认，读取或写入失败有非阻塞说明；保存失败保留窗口及草稿。设置保存与记录清理是两个本地文件操作；若设置已保存但记录清理失败，保留窗口并提示写入错误，允许重试。首次默认简体中文，未知语言回退简体中文。文件备份仅用于迁移或恢复，不改变核心任务策略。

所有产品可见静态文案从 QML/C++ 逻辑提取到 resources/i18n/zh-CN.json 和 en-US.json，以稳定 ID 引用。Qt 翻译适配器读取资源，QML 使用 qsTrId，薄 C++ 使用 qtTrId；协议码、归档文件名、路径和用户内容不翻译。占位参数及复数形式保持语言资源一致，数字、时间和字节按界面 locale 格式化。HTML 同步设置设计与语言选择，演示边界仍需明确。

验收包括两份目录的 ID/占位符完整性、无散落的产品静态中文、真实设置入口、预览回滚、保存和跨进程重启恢复、英文主界面及操作窗口、200% 字号、焦点规则和 macOS 标题栏。自动化证据只存 build/ 或 dist/，桌面人工与辅助功能验收另行登记。
