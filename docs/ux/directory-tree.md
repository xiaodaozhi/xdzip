# 目录树 B：设计、素材与接入规格

状态：**核心目录交互已接入 HTML 示例和 Qt 只读浏览，边界状态资源仍待接入**。范围对应 B01 浏览、P01/P02/P08 和 WP-05/06，沿用[只读浏览契约](../engineering/readonly-browser.md)，不改变归档记录、搜索范围或输出授权。

三张正式图板位于 [多级展开](../../design/hifi/screens/directory-tree.png)、[节点与交互状态](../../design/hifi/screens/directory-tree-states.png)、[空态与导航边界](../../design/hifi/screens/directory-tree-boundaries.png)。[统一画廊](../../design/hifi/index.html#components)展示整幅图板，[素材库](../../design/assets/index.html#directory-tree)提供逐项切图。原有主窗口图片保持原样，B 作为其目录树组件修订；图板中的顶部和中央列表仅提供上下文，不重新定义标题栏、工具栏或文件表格。

图板采用放大展示，每张卡片的局部比例不完全相同。图片中的文字、圆角和像素尺寸不能直接当作控件尺寸；[组件参数](../visual/directory-tree.json)明确记录落地的逻辑尺寸，资产清单单独记录原图裁剪的物理坐标。实现采用 1280 逻辑宽度及统一源画布变换，不能把这一组新组件再整体放大。

Qt 直接使用下表的逻辑值。现有 HTML 主稿采用 1548 源像素窗口映射到 1280 逻辑像素，转换遵循 [display-spec.js](../../design/html/display-spec.js)：`source CSS = logical / (1280/1548)`。因此 40 行高对应 48.375 源 CSS 像素，14 字号对应 16.93125，20 图标槽对应 24.1875，16 缩进对应 19.35。预览缩放在换算之后统一作用于整个窗口；DPR 只决定采样密度和线条对齐，不参与逻辑尺寸换算。

## 树结构与计数

完整索引同时提供显式和隐式目录。叶子仅表示**没有子目录**，不表示没有文件；冰川湖若含子目录，就有自己的展开箭头，与其父目录的箭头互不替代。

```text
全部文件                         30  ← 当前目录
▼ 01 照片                       12
  ▼ 冰川湖                       6
    ▸ 湖岸步道                   3  ← 有更深目录，尚未展开
      雪山远景                   3  ← 只有文件，保留空箭头槽
  ▸ 山间日出                     4
    其他照片                     2  ← 无子目录
▸ 02 文档                        8
  03 地图                        4  ← 无子目录
```

示例全部文件由照片 12、文档 8、地图 4 和根目录文件 6 构成。未展开分支的后代也完整列入参数文件，避免用假箭头装饰叶子节点。另一张图板中的显式空目录是独立状态样例，不追加到这个 30 条样例中。

目录数字表示该前缀下全部后代**物理归档记录数**，包含重复名称，不包含与该目录前缀完全相同的目录记录；它不是子目录数量，也不随名称搜索变化。“全部文件”显示归档完整物理记录数，不必等于顶层目录数字之和，因为根目录文件和显式目录记录可能另占物理记录。

箭头只由已知子目录决定：有子目录且折叠时向右，展开时向下；只有文件或为空时不显示，但同层级的箭头槽、图标槽和文字起点保持相同。读取完整索引期间不猜测逐节点箭头、计数或结构，也不增加逐节点异步加载状态。

## 布局、字体与动态几何

| 项目 | 正常逻辑尺寸 / 行为 |
| --- | --- |
| 侧栏默认宽度 | 220；沿用已有可伸缩布局约束 |
| 行高 | 最小 40；字体放大时按参数文件公式增高 |
| 每层缩进 | 16；不随节点类型变化 |
| 箭头命中区 / 图形槽 | 至少 24×24 / 18×18；叶子保留相同槽位 |
| 文件夹图标槽 | 20×20；共享 24 单位 SVG 等比显示，替代当前树的 18 槽位 |
| 图标到文字 / 文字到计数 | 8 / 至少 8 |
| 正文 / 数字 | 14 / 12；系统字体，数字采用等宽数字特性 |
| 数字列 | 靠右；至少 32 宽，按实际数字测量增宽，完整显示不省略 |
| 当前目录 | 淡蓝背景、8 圆角与 3 宽左侧标记 |
| 键盘焦点 | 2 宽内侧描边，不改变行占位 |
| 层级连接线 | 1 宽；颜色与背景保持克制的层级关系 |
| 隐藏当前目录标记 | 24 单位透明槽中的 6 单位圆点，与数字共享行中心 |

连接线根据可见祖先链与最后同级节点标志动态绘制。父层竖线经过已展开子树，直至最后兄弟节点中心；该层的最后连接以 L 形终止，不向下一组顶层目录延伸。内层线独立终止，不能把一张通用直线图片贯穿全部行。线段按目标 DPR 对齐；文字、箭头、文件夹与计数共用行垂直中心。

层级区可横向滚动；数字与隐藏当前目录圆点固定在右侧预留列，不能随深层路径滚出视口。名称单行右侧省略，不挤占数字列；悬停或键盘聚焦截断名称时提供原显示名称和完整归档路径。提示内容使用纯文本，长路径按屏幕预算换行、滚动并可复制。垂直滚动只发生在目录视口，滚动条不包住主窗口边框。

所有目录使用同一个文件夹资源。分支圆点、实心信息 / 警告、分段转轮有浅深色 SVG 和 1×/2×/3× PNG；连接线、焦点框、背景、骨架、文字与提示属于动态组件。深色参数沿用全局主题并补充线条和标记颜色；**完整深色目录树图板仍待绘制与实测**，不能以深色图标导出标记整个深色组件已验收。

## 交互与独立状态

展开、当前目录、悬停和键盘焦点分别保存，可以同时发生。目录当前态与右侧文件复选框的选择状态也是两回事。

| 操作 | 结果 |
| --- | --- |
| 点击箭头 | 仅展开 / 收起该节点，目录查询、文件选择和详情保持原状 |
| 点击名称区或 Enter | 通过当前会话的目录 ID 进入目录；成功替换查询后按既有契约重置分页、文件选择和详情 |
| 上 / 下 | 在可见目录行中移动焦点，不自动切换文件列表 |
| 右 | 折叠父节点先展开；已展开则移到首个子目录；叶子保持原位 |
| 左 | 展开父节点先收起；其余节点移到父目录；顶层保持原位 |
| 收起当前目录的祖先 | 保持当前目录和文件列表；隐藏焦点回到最近可见祖先 |
| 新归档会话 | 清除旧节点 ID、展开、焦点与分支圆点，不串用另一归档状态 |

例如当前路径为 `01 照片 / 冰川湖`，收起 `01 照片` 后，右侧仍显示冰川湖。照片行只显示焦点轮廓及数字前的蓝点，不获得冰川湖的当前目录填充；全部文件也不能变为当前态。蓝点落在**最近的可见折叠祖先**，一个隐藏当前目录只有一个分支标记；展开恢复后，冰川湖重新显示当前背景。

树本身为一个键盘导航入口，节点保留稳定 ID、名称、层级、展开状态、位置和记录数的可访问语义。叶子不声明可展开；装饰性文件夹、连接线和圆点不重复读出。隐藏当前路径通过可访问描述提供，不能只依赖蓝色。方向键和箭头点击均不得穿透到行激活。

## 状态覆盖与恢复

| 状态 | 目录树 | 文件列表 / 恢复 |
| --- | --- | --- |
| 正在读取 | 未知计数 `—`，骨架与读取提示；导航禁用 | 遵循全局读取状态；完整索引发布后一次替换树 |
| 空归档 | 全部文件 0，“此压缩文件没有内容” | 空列表；仍可打开另一个归档 |
| 只有根文件 | 全部文件 6，“没有子目录” | 正常显示六条文件，不能把整页改成空态 |
| 目录索引超限 | 不发布半棵树；显示“目录超过显示限额” | 全部文件、搜索及合格显式目录浏览继续按现有能力工作 |
| 读取失败 | 未知计数 `—`，灰化导航，明确错误 | 重新打开归档；不能把失败解释为 0 或空目录 |
| 有子目录的节点 | 每一级都有独立箭头 | 展开并不等于进入该目录 |
| 非空 / 空叶子 | 计数分别可以大于 0 / 等于 0；都没有箭头 | 名称仍可激活，空目录可浏览 |
| 长名称 / 深层级 | 省略、全文提示、横向滚动与固定数字列 | 路径筛选保持一致 |
| 字号 200% | 槽位和行高增长，线条重新取行中心 | 名称、计数、箭头和焦点不裁切 |
| 隐藏当前目录 | 最近可见祖先显示分支圆点 | 列表保持当前路径；重新展开恢复当前行 |

导航超限与全局读取失败是不同状态，原因、可用操作和计数来源不能共用一个“空目录”模板。现有 2,048 节点、64 层和 1 MiB 目录名称预算来自只读契约；设计不提升或绕过这些资源预算。

| 部分 | 资源 / 绘制方式 | 当前接入情况 |
| --- | --- | --- |
| 文件夹、左右 / 向下箭头 | `folder`、`chevron-right`、`chevron-down`，复用统一素材库 | 既有共享资源可用；B 共享图标与 B 尺寸已用于递归 HTML 行和 Qt 委托 |

HTML 与 Qt 已接入连接线、固定计数栏、分支圆点、20 文件夹槽和目录右键；HTML 示例采用完整递归层级，Qt 使用真实受限索引。收起当前祖先不提交查询。加载骨架、专用信息 / 错误图标仍为设计资源；深色完整图板、逐平台读屏与 HiDPI 人工验收没有据此宣称通过。

## 接入后的验收标准

1. 在同一 1280 逻辑宽度、字体配置、DPR 和状态数据下截取实际目录区域，与已确认图板的对应区域及规格对照；记录两者缩放关系。视觉判断与结构断言分别保留。
2. 同层箭头、图标、名称起点及右侧数字边缘一致；图标、文字、圆点、箭头共用行中心。目标几何偏差不超过 1 个物理像素，字体差异注明平台和实际回退。
3. 至少三层展开，含一个更深但折叠的分支和非空叶子；验收连接线在最后兄弟与展开子树中的连续 / 终止规则。
4. 单独及组合检查当前、悬停、焦点；箭头点击不提交目录查询、不清除文件选择，Enter 激活遵循成功查询重置规则。
5. 冰川湖为当前目录时收起照片：列表路径不变、全部文件不选中、照片只显示分支圆点；展开后恢复当前行。焦点隐藏后始终可继续键盘导航。
6. 从真实受限索引核对空归档、根文件、显式空目录、读取失败与目录超限；分别检查计数、禁用和恢复操作。
7. 长名称、200% 字号、最小窗口和索引最大允许深度下，数字完整可见、横向滚动只作用于层级区，提示全文可访问；树滚动不移动归档摘要和底部统计。
8. 完成浅深色实际渲染、正常 / Retina / Windows 高 DPI、键盘与读屏验收。图片检查或素材生成通过不能代替这些运行验证。

[设计素材检查](../qa/directory-tree.md)验证原稿、切片与资源；[组件交互复核](../qa/main-window-components.md)另记实时鼠标、键盘、菜单和树行为，未测的辅助功能与平台差异保持明确标记。
