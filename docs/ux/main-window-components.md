# 主窗口功能、组件与交互契约

主窗口的控件同时交付外观和行为：普通、悬停、按下、键盘焦点、禁用、选中、忙碌与错误均有明确状态。HTML 使用示例归档验证完整交互，Qt 根据真实只读能力启用动作；压缩、解压与 CRC 业务能力继续由各里程碑实现，菜单不能报告虚假的完成结果。

## 功能与组件清单

| 区域 | 通用组件 / 组合组件 | 交互与能力 |
| --- | --- | --- |
| 系统标题栏 | 平台窗口装饰、窗口拖动区域 | macOS 原生红绿灯；Windows / Linux 遵循平台窗口约束，按钮区域不触发拖动 |
| 归档标签 | ArchiveTabs、ArchiveTab、图标按钮 | 激活、关闭、关闭其他 / 右侧、恢复关闭标签、键盘切换；每个归档独立保存目录、搜索、排序、选择与展开状态 |
| 工具栏 | CommandButton、IconButton、SplitButton | 打开、新建、测试、更多、解压主动作与范围菜单；鼠标 / 键盘使用同一命令入口 |
| 搜索 | SearchField、清除动作、范围提示 | 输入法组合期间不提交；当前目录范围搜索，清空不改变目录；快捷键聚焦 |
| 归档摘要 | ArchiveSummary、格式徽章、统计条 | 就绪、读取、空内容、读取失败分别显示，不用未知值冒充零 |
| 目录导航 | DirectoryTree、DirectoryRow、Disclosure、连接线 | 多级展开、叶子空箭头槽、当前 / 焦点独立、可访问完整路径、祖先收起标记、目录右键动作 |
| 文件区域标题 | PaneHeader、Breadcrumb、ViewToggle | 路径分级返回、列表 / 网格切换、排序菜单；共享行高和垂直中心 |
| 列表与网格 | EntryView、SelectableEntry、复选框、SortHeader | 单选、多选、范围选择、全选、清除、反选、方向键；文件夹进入，文件查看属性 |
| 文件右键 | ContextMenu、CommandMenuItem、Submenu | 保留已有多选；右击未选中项先单选该项；按当前选择启用解压、属性、复制名称 / 路径、目录导航 |
| 空白右键 | ContextMenu、RadioMenuItem、CheckboxMenuItem | 当前列表选择、视图、排序、详情栏；不擅自取消已有选择 |
| 表头右键 | 排序菜单 | 排序字段、方向、恢复归档顺序；全部查询结果先排序，不只排序当前可见条目 |
| 属性 / 预览 | InspectorPanel、PropertyRow、详情动作 | 文件、多选、归档与未就绪；关闭 / 重开、单文件操作、预览图边缘与表头对齐 |
| 状态与任务 | StatusBar、StatusAction、任务入口 | 选择统计、索引状态、后台任务；隐藏任务窗口不取消任务 |
| 提示与操作窗 | Tooltip、Notice、Toast、平台独立窗口 | 提示完整名称 / 禁用理由；Esc、焦点返回、取消和关闭遵循各动作语义 |

## 统一命令与菜单

按钮、快捷键、右键与下拉调用同一个命令，动作执行前重新检查当前能力。菜单打开时固定对象和选择范围；归档切换、查询变化或对象消失时关闭，不能把旧条目的命令应用到新归档。

菜单统一使用图标 / 勾选槽、名称、快捷键、子菜单箭头四列；分隔线按动作组划分。只包含当前上下文相关动作：目录提供进入与展开，文件提供详情，多选保留批量范围。尚不可执行的动作保留禁用状态并提供理由，不使用“点击后提示待开发”代替禁用。

普通菜单行、复选项、单选项、子菜单入口与分隔线是共享组件。排序和视图以单选项标明当前状态；详情面板以复选项表示开关。危险动作没有默认自动激活行为，右键和打开菜单均不执行动作。

## 菜单输入与生命周期

- 向下 / 向上在可用项间移动，Home / End 到首尾；Enter / Space 激活，右键盘箭头进入子菜单，左箭头返回父菜单。
- Esc 逐级关闭，根菜单关闭后恢复触发控件或原条目焦点；Tab 关闭菜单并继续页面正常焦点顺序。支持按名称首字符定位，输入法组合不触发菜单类型搜索。
- 鼠标悬停高亮但不执行；子菜单延迟展开，移动到子菜单时保持父项。鼠标与键盘操作可以互相接续，不残留多个高亮或多个根菜单。
- 点击外部关闭，不抢走外部目标焦点。滚动主区域、窗口尺寸变化、进入操作窗或切换归档关闭菜单；菜单自身滚动不关闭。
- 根据实际视口避让底边与右边，必要时向左或向上展开。定位使用宿主坐标，逻辑尺寸、原稿源像素、DPR 和审阅缩放分别处理。
- 键盘通过 Shift+F10 / 菜单键打开当前条目菜单；长按触屏与鼠标右击使用相同上下文，不以单击方式破坏多选。

## 控件状态与可访问性

| 状态 | 表现 | 行为 |
| --- | --- | --- |
| 普通 | 保留已确认原稿的边框、圆角、图标和基线 | 不因状态变化改变控件尺寸 |
| 悬停 | 淡色填充；主按钮使用加深主色 | 提示延迟出现，不遮挡目标；触屏不保留粘滞悬停 |
| 按下 | 比悬停更明确的填充 | 不通过位移造成文字 / 图标跳动；取消按下不执行动作 |
| 焦点 | 可见描边，与悬停 / 选中并存 | 焦点与激活独立；关闭菜单 / 窗口后恢复可访问位置 |
| 禁用 | 文字与图形采用明确禁用色，保留轮廓 | 不响应点击或快捷键；可访问描述说明原因 |
| 选中 | 背景或勾选标志明确当前状态 | `aria-selected` / `aria-checked` / Qt Accessible 同步 |
| 忙碌 | 状态与禁用范围按任务确定 | 阻止重复提交；后台任务允许继续浏览 |
| 错误 | 邻近文案说明问题与恢复动作 | 不用颜色作为唯一信息，不报告假成功 |

共享图标来自 `design/assets`。文字、勾选、背景、焦点框、连接线与菜单定位由控件实现，原像素切片用于对照。HTML 沿用主稿源坐标，新增控件参数先从逻辑像素换算；Qt 使用相同逻辑规范。

## 验收

实际鼠标与键盘驱动检查各入口、菜单避让、子菜单往返、选择保持、焦点恢复、禁用保护、标签隔离、视图切换与目录层级。浅深色、三种平台装饰、正常 / 大字号和缩放下截取真实控件画面；初始主窗口的标题栏、工具栏、文件列表与预览既有对齐不以菜单改造为由回退。

功能覆盖、实际截图和仍未接入的后端能力记录在[实际复核文档](../qa/main-window-components.md)。静态图板、浏览器行为验证、Qt 运行验证分别说明，不能相互替代。

Qt 菜单明确使用 `Popup.Item` 消费共享委托，保证 AppKit 不忽略自定义样式；操作窗口继续采用独立顶层窗口。`CommandTooltip` 使用同一提示参数与纯文本，避免把归档名称解释为富文本；菜单获得焦点时隐藏提示。共享 JSON 的八位颜色采用 CSS RGBA，QML 生成器转换为 QColor ARGB，颜色与透明度一起验证。

目录树悬停没有浮动 tooltip，其他按钮与禁用操作仍按共享延时提供提示。根目录和普通子目录只列直属文件与文件夹，搜索递归当前范围；普通名称显示末级名称，搜索显示完整路径。列表悬停覆盖整行，网格有固定左右留白及悬停／选中复选框，菜单使用四周柔和阴影并与调用按钮留 4 逻辑像素。[本次同步验收](../qa/root-directory-interactions.md)记录真实交互及缩放。

文件类型排序的升序与降序都保持目录在前，以数据中的目录标记分组；无后缀文件不能与文件夹共用分组键。相同类型保留稳定身份顺序，排序作用于完整查询后再拆分内部传输批次。HTML 中未设置 folder 的文件按 false 处理，不能将 undefined 转成 NaN 参与比较。
