## 交互决定

### 选择与搜索

- 每项选择对应稳定条目 ID，不依赖排序后的行号。切换查询/目录清空选择，避免隐藏选择误解。
- 当前列表全选与整个归档解压是两个独立概念。文件夹勾选展开为去重后代文件。
- 输入法组合期间不提交查询，compositionend 后更新。浏览器模拟事件检查不替代 macOS/Windows/Linux 原生 IME 验收。
- 文件 Enter 显示属性；文件夹 Enter/双击进入。首版不解码图像预览或自动执行内容。

### 解压与冲突

- 最终路径实时显示，同名目录只追加一次。空路径或演示不可写路径阻止启动，更改目标后重新预检。
- 默认询问重名；可选择跳过、自动改名或覆盖。覆盖后果用邻近文案解释。
- 冲突面板初始焦点是“跳过”，覆盖不是默认 Enter。应用到后续冲突的选项限定本次任务；演示数据仅产生一个冲突。
- 改名同时体现在完成摘要和文件明细中。跳过不计为失败；示例已有文件不在完成写入计数内。

### 任务与结果

- 返回浏览不取消任务；状态栏可以再次打开任务。
- 请求取消 → 正在停止（重复取消禁用）→ 已取消摘要。解压保留已发布项；创建归档没有中间发布。
- 磁盘满停止任务并保留成功项。重试只取失败/未完成范围，重新进入计划确认。
- 源变化要求重新打开归档，不静默复用旧索引。
- 创建任务以一个最终归档计数；取消时“已创建归档”为 0，明确旧归档不变。

### 新建归档与能力

ZIP 显示 Store/Deflate，Store 隐藏级别；TAR 隐藏算法和级别；TAR.GZ 显示 GZIP 级别。格式变化更新扩展名。空输入/空名称/空保存位置禁用创建。首版没有密码、分卷、RAR 或 7z 创建选项。

### 视觉与适配

沿用暖灰、钴蓝和石墨主题。标准行高 40、紧凑 32；深色文本强调色独立于按钮填色，以提高小字辨识度。桌面宽度不足时详情作为可关闭浮层。手机审阅布局收起侧栏和次要表格列，操作面板适配窄屏并可滚动。

所有模态面板使用浏览器原生 dialog，限制焦点在当前操作；关闭后尽力恢复到触发控件。危险冲突不能通过 Esc 静默跳过。正式 Qt 界面需实现等价的焦点和读屏行为。

## 验证与剩余边界

浏览器验证脚本为 scripts/check-prototype.py，检查实际点击流程、统计、禁用条件、格式联动、异常恢复、手机溢出以及单文件离线运行。报告随导出的原型包提供；浏览器验证仅使用 Chromium。

仍需后续设计/实现验证：多归档标签、多任务调度、拖放、逐平台系统选择器与菜单、完整读屏、200% 字体缩放、更多文件类型与数量、正式后端授权/路径竞态/配额/CRC/持久化。当前设置只保存在内存，不跨启动持久化；主题跟随系统在选择时解析，尚未演示运行中的系统主题变化。

这些限制不改变软件设计中的目标能力。原型中的“已完成”仅描述演示任务状态，不代表真实压缩解压功能已交付。
