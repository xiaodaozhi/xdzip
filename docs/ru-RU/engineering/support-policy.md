# Политика поддержки и сопровождения

[English](../../engineering/support-policy.md) | [简体中文](../../zh-CN/engineering/support-policy.md) | [繁體中文](../../zh-TW/engineering/support-policy.md) | [日本語](../../ja-JP/engineering/support-policy.md) | [한국어](../../ko-KR/engineering/support-policy.md) | [Français](../../fr-FR/engineering/support-policy.md) | [Deutsch](../../de-DE/engineering/support-policy.md) | [Español](../../es-ES/engineering/support-policy.md) | [Português (Brasil)](../../pt-BR/engineering/support-policy.md) | Русский

Владелец проекта утвердил первоначальную политику 2026-10-19. Версия `v0.1.0` была опубликована 2026-11-06. Текущие версии и файлы доступны на [странице выпусков](https://github.com/xiaodaozhi/xdzip/releases). Эта политика определяет объём поддержки. Проверки минимальных версий продолжают действовать. Результаты CI и приёмки пользователем относятся к проверенным средам. Ручная проверка завершена по решению пользователя.

<a name="xdzip-initial-support-scope"></a>
## Первоначальный объём поддержки

| Платформа | Первоначальная поддержка | Проверки и ограничения |
| --- | --- | --- |
| macOS | macOS 14 или новее, Apple Silicon arm64 | Целевая версия развёртывания 14.0, нативный CI и локальный DMG для разработки. Пакетов для Intel и Universal нет. Поддержка всех будущих версий системы не гарантируется. |
| Windows | Версии Windows 11 x86_64, которые Microsoft продолжает сопровождать | Сборка MSVC, установка для текущего пользователя, реальные сценарии установки, обновления, отката и удаления в CI. Проверки на Windows Server не покрывают все версии Windows 11. Пакета ARM64 нет. |
| Linux | Ubuntu 24.04 LTS x86_64, X11, glibc 2.39 или новее | Проверка текущего пакета .deb и запуска в изолированной среде без Qt SDK. Другие дистрибутивы, более ранние версии glibc, Wayland и ARM64 выходят за рамки поддержки. |

Минимальная версия macOS соответствует текущей цели развёртывания. Версия 13, упоминавшаяся в старых проектах, не проверялась. Стандартная поддержка Windows 10 закончилась 2025-10-14. Windows 10 не входит в первоначальный объём поддержки. Это также относится к LTSC и ESU, если для них не предусмотрено отдельное решение. См. [сообщение Microsoft о жизненном цикле](https://learn.microsoft.com/en-us/lifecycle/announcements/windows-10-end-of-support). Список [платформ, поддерживаемых Qt 6.8](https://doc.qt.io/qt-6.8/supported-platforms.html), описывает возможности зависимости. Совместимость xdzip проверяется отдельно.

<a name="xdzip-maintenance"></a>
## Сопровождение

Этот личный проект сопровождается по мере наличия ресурсов. Платные услуги, фиксированный срок ответа и обязательства по безопасности сверх выполненных работ не предусмотрены. Приоритет имеет последний общедоступный стабильный выпуск. Предварительные сборки могут менять совместимость. В примечаниях к выпускам описаны известные проблемы и способы отката. При обнаружении проблемы безопасности затронутые файлы могут быть сняты с публикации. В окне «О xdzip» пользователь может проверить наличие обновления и начать его установку. Фоновой проверки и скрытой установки нет. Текущий исходный код также содержит команду обновления для CLI. Поддерживаемые типы установки и различия с уже опубликованными файлами указаны в [спецификации командной строки](command-line.md).

В кандидатах используются Qt 6.8.2 и уже зафиксированные версии Rust и Cargo, чтобы проверки были воспроизводимы. Это не гарантирует отсутствие уязвимостей в старых исправлениях или постоянную доступность бесплатных обновлений LTS. Перед публикацией сопровождающий проверяет официальные бюллетени безопасности Qt и доступные обновления с открытым исходным кодом. В первую очередь оцениваются публичные версии, которые продолжают сопровождаться. Если неисправленная проблема безопасности в зависимости затрагивает xdzip, соответствующий выпуск откладывается. После обновления Qt требуется заново проверить исходный код, лицензии модулей, закрытые интерфейсы Windows, динамическую замену, сборку на трёх платформах и работу настоящих меню и окон. Коммерческое сопровождение остаётся необязательным.

<a name="xdzip-approved-scope-and-changes"></a>
## Утверждённый объём и изменения

Утверждены первоначальные платформы, сопровождение только последнего публичного выпуска по мере наличия ресурсов, отсутствие фиксированного срока ответа и обозначение сборок для разработки как экспериментальных. Итоги `v0.1.0` записаны в публикации и в соответствующих задачах приёмки. Эти результаты не гарантируют производительность на всех версиях систем. Новую архитектуру, систему или канал распространения следует реализовать и проверить до изменения политики. См. [ADR-011](../design/architecture-decisions.md#xdzip-adr-011-initial-support-scope-and-personal-project-maintenance-policy).

Официальная подпись, нотариальное заверение и платные учётные записи больше не требуются. Об уязвимостях сообщайте в соответствии с [политикой безопасности](../../../SECURITY.md).
