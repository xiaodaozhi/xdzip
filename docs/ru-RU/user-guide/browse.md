# Просмотр, выбор и предпросмотр файлов

[English](../../user-guide/browse.md) | [简体中文](../../zh-CN/user-guide/browse.md) | [繁體中文](../../zh-TW/user-guide/browse.md) | [日本語](../../ja-JP/user-guide/browse.md) | [한국어](../../ko-KR/user-guide/browse.md) | [Français](../../fr-FR/user-guide/browse.md) | [Deutsch](../../de-DE/user-guide/browse.md) | [Español](../../es-ES/user-guide/browse.md) | [Português (Brasil)](../../pt-BR/user-guide/browse.md) | Русский

1. Откройте архив. Чтобы перейти в папку, выберите её в дереве или дважды нажмите на её строку. Строка пути позволяет вернуться в родительскую папку.
2. Введите часть имени файла и нажмите Enter. Поиск выполняется в текущей папке и во вложенных папках. Выберите список или сетку и порядок сортировки. При любом порядке папки отображаются перед файлами.
3. Отметьте записи флажками или используйте клавиши выбора вашей системы. **Выбрать всё** охватывает результаты текущего запроса, включая строки вне области просмотра. Перед распаковкой проверьте количество выбранных элементов.
4. Откройте свойства и выберите один файл, чтобы увидеть его предпросмотр. Наведите указатель на область предпросмотра и нажмите значок обновления в правом верхнем углу, чтобы загрузить его заново. Если выбрано несколько элементов, в карточке появится соответствующее сообщение. Поддерживается текст в UTF-8 или UTF-16 с BOM размером до 256 KiB. Для изображений есть отдельные ограничения. Поддерживается только часть функций статического SVG. Формат HEIC/HEIF доступен в macOS. Если предпросмотр недоступен, файл можно распаковать, когда его запись поддерживает распаковку. [Форматы и ограничения предпросмотра](../engineering/content-preview.md)

При двойном нажатии на обычный файл программа распаковывает временную копию и передаёт её системе для открытия. Изменения этой копии не записываются в архив. Чтобы сохранить постоянную копию, распакуйте файл в выбранное место. [Временное открытие](../engineering/archive-opening.md)

По умолчанию архивы открываются во вкладках. В настройках можно выбрать отдельные окна. Обычный однофайловый ZIP/ZIP64 позволяет индексировать до миллиона фактических записей. Строки большого индекса загружаются по мере необходимости. ZIP с дисковым индексом может поддерживать распаковку выбранных файлов. Проверка всего архива и внесение изменений отключены. [Ограничения для больших архивов](../engineering/large-index.md)

## Просмотр комментария к архиву

Откройте ZIP или RAR и выберите **Ещё → Комментарий к архиву** на панели инструментов. Текст можно выделить и скопировать. В обычном доступном для записи ZIP, ZIP64 или ZIPX измените текст и нажмите **Сохранить**. Чтобы удалить комментарий, очистите поле и сохраните изменения. Ограничение составляет 65 535 байт в UTF-8. Комментарии к многотомным, самораспаковывающимся, зашифрованным ZIP, ZIP с дисковым индексом, подписанным и производным пакетам, а также к RAR доступны только для чтения.
