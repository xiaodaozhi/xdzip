# Установка XDZip и открытие архива

[English](../../user-guide/install.md) | [简体中文](../../zh-CN/user-guide/install.md) | [繁體中文](../../zh-TW/user-guide/install.md) | [日本語](../../ja-JP/user-guide/install.md) | [한국어](../../ko-KR/user-guide/install.md) | [Français](../../fr-FR/user-guide/install.md) | [Deutsch](../../de-DE/user-guide/install.md) | [Español](../../es-ES/user-guide/install.md) | [Português (Brasil)](../../pt-BR/user-guide/install.md) | Русский

Скачайте пакет для своей системы со страницы [последнего стабильного выпуска на GitHub](https://github.com/xiaodaozhi/xdzip/releases/latest) или воспользуйтесь Microsoft Store в Windows. На странице GitHub указаны название и версия файла, а также опубликован файл `SHA256SUMS` для проверки прямых загрузок. Требования к системе приведены в [правилах поддержки](../engineering/support-policy.md).

| Настольная система | Установка или запуск |
| --- | --- |
| Windows 11 x64 | Найдите **XDZip** в Microsoft Store или запустите файл `-setup.exe` с GitHub для установки только для текущего пользователя. Установщик с GitHub не подписан. Для портативной ZIP-версии распакуйте весь пакет и запустите `xdzip.exe` из полученной папки. |
| macOS 14 и новее, Apple Silicon | Откройте DMG и перетащите `xdzip.app` в папку **Программы**. Если скачан файл `.app.zip`, сначала распакуйте его, затем перенесите приложение в папку «Программы». Запустите копию из папки «Программы». Сборки GitHub используют подпись целостности ad hoc и не прошли нотариализацию. Если macOS показывает предупреждение, проверьте источник загрузки и контрольную сумму. |
| Ubuntu 24.04 LTS x64, X11, glibc 2.39 или новее | Установите `.deb` через менеджер пакетов. Для портативного пакета `.tar.gz` распакуйте все файлы и запустите `./xdzip` из полученного каталога. Оставьте файл запуска рядом с остальными рабочими файлами. |

Настольное приложение не поддерживает Windows ARM64, компьютеры Mac с процессором Intel, Linux ARM64 и Wayland. Автономная программа командной строки для Linux работает без X11 и требует системных OpenSSL 3 и сертификатов. Выберите файл с именем, начинающимся на `xdzip-cli-`, и следуйте [краткому руководству по командной строке](../integration/README.md).

## Открытие архива

Выберите **Открыть архив** в XDZip или перетащите архив на начальную страницу. В файловом менеджере выберите **Открыть с помощью**, если установленный пакет зарегистрирован. Чтобы открывать файлы определённого типа через XDZip по умолчанию, укажите приложение в настройках системы. В версии из Microsoft Store на странице ассоциаций файлов есть команда **Открыть настройки приложений по умолчанию Windows**. Приложения по умолчанию и действия сжатия из контекстного меню настраиваются отдельно. См. [распаковку из файлового менеджера](extract.md#xdzip-from-the-file-manager) и [установку и ассоциации файлов](../../engineering/installers-associations.md).

Далее [узнайте, как просматривать файлы и их содержимое](browse.md).
