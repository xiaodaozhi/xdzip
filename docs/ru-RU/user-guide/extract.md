## Из окна архива

1. Откройте архив. Основная кнопка на панели инструментов распаковывает выбранные элементы, а если ничего не выбрано, то весь архив. Нажмите стрелку рядом с кнопкой, чтобы явно выбрать **Распаковать всё** или **Распаковать выбранное**.
2. Проверьте, что именно будет распаковано, и выберите папку назначения с правом на запись. Если доступна соответствующая настройка, можно создать папку с именем архива.
3. Выберите способ разрешения конфликтов. **Спрашивать, что делать** приостанавливает операцию до принятия решения. **Пропустить существующие файлы** сохраняет существующий файл. **Переименовать и сохранить обе версии** сохраняет новый файл отдельно. **Перезаписать существующие файлы** заменяет существующий файл после проверки, если его можно заменить.
4. Запустите распаковку и проверьте результат задачи. При ошибке или отмене ранее распакованные файлы могут остаться в папке назначения. Перед повторной попыткой проверьте в подробностях результата, что осталось распаковать. [Проверки, задачи и результаты](checks-and-tasks.md)

В меню также есть команда **Проверить метаданные**. Выберите не более 128 фактических записей архива. В отчёте отмечаются, например, небезопасные имена, неподдерживаемые методы и заявленные ограничения. Неявную папку, отображаемую для навигации, можно распаковать, если формат это позволяет. Предварительная проверка не читает данные файлов и не предоставляет разрешения на запись. [Предварительная проверка и ограничения распаковки](../engineering/extraction-preflight.md)

В больших архивах ZIP с дисковым индексом можно распаковать выбранные обычные файлы в пределах ограничений задачи. Если архив целиком превышает лимит, выберите меньше элементов. Если исходный файл изменён или заменён, откройте его заново и повторите выбор. [Ограничения для больших архивов](../engineering/large-index.md)

## Из файлового менеджера

В Windows 11 классическое меню открывается командой **Показать дополнительные параметры**. Версия из Microsoft Store может показывать действия и в новом меню. В Ubuntu используется расширение Nautilus. В macOS включите расширение Finder в системных настройках или воспользуйтесь зарегистрированной службой Finder. Если меню недоступно, откройте архив в xdzip и распакуйте его из окна архива.

Из меню файлового менеджера можно распаковать архив в его текущую папку, создать отдельную папку для каждого архива, определить папку автоматически или выбрать её вручную. Автоматический режим не создаёт дополнительную внешнюю папку только в том случае, если проверенный результат уже содержит ровно одну папку верхнего уровня. Пакетная обработка показывает результат для каждого архива и продолжается после отдельной ошибки. Отмена останавливает последующие операции и запрашивает остановку текущей. [Действия и настройки файлового менеджера](../engineering/shell-actions.md)
