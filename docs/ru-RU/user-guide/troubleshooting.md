# Устранение неполадок XDZip

[English](../../user-guide/troubleshooting.md) | [简体中文](../../zh-CN/user-guide/troubleshooting.md) | [繁體中文（台灣）](../../zh-TW/user-guide/troubleshooting.md) | [日本語](../../ja-JP/user-guide/troubleshooting.md) | [한국어](../../ko-KR/user-guide/troubleshooting.md) | [Français](../../fr-FR/user-guide/troubleshooting.md) | [Deutsch](../../de-DE/user-guide/troubleshooting.md) | [Español](../../es-ES/user-guide/troubleshooting.md) | [Português (Brasil)](../../pt-BR/user-guide/troubleshooting.md) | Русский

| Проблема | Что попробовать |
| --- | --- |
| Архив не открывается | Проверьте [поддержку формата](../../../README.ru-RU.md#xdzip-format-support), метод сжатия или шифрования и наличие всех томов. Если источник недоступен, скопируйте архив со всеми томами в доступную локальную папку, сохраните имена и откройте снова. |
| Имена файлов выглядят неправильно или их нельзя записать | Проверьте, можно ли пересоздать архив с именами UTF-8. XDZip определяет некоторые старые кодировки, с ограничениями для коротких и смешанных имён. Распаковывайте записи, для которых можно безопасно определить путь. [Обработка имён файлов](../engineering/filename-encoding.md) |
| Свойства файла видны, а предпросмотра нет | Проверьте формат, размер, систему и кодировку. Предпросмотр ограничен отдельно от распаковки. [Ограничения предпросмотра](../engineering/content-preview.md) |
| Место назначения отклонено или результат неполный | Выберите закрытую папку с правом на запись. Проверьте конфликты имён и неподдерживаемые записи, изучите результат перед повторной попыткой. [Распаковка файлов](extract.md) |
| Файл был заменён во время работы XDZip | Откройте новую копию и повторно выберите записи. Перед записью XDZip ещё раз проверяет исходный файл. |
| В Проводнике, Finder или «Файлах» нет нужной команды | Проверьте канал установки и включено ли расширение. В Windows 11 классическое меню доступно через **Показать дополнительные параметры**. В macOS включите расширение Finder в настройках или воспользуйтесь зарегистрированной службой. Вы всегда можете сначала открыть архив в XDZip. [Распаковка из файлового менеджера](extract.md#xdzip-from-the-file-manager) |
| Проверка или изменение большого ZIP отключены | При использовании дискового индекса выберите только нужные обычные файлы и распакуйте их в пределах ограничений задачи. [Ограничения для больших архивов](../engineering/large-index.md) |
| Не удаётся обновить или установить программу | Проверьте версию и канал. Сверьте контрольные суммы загруженных вручную пакетов и следуйте соответствующей инструкции. [Восстановление после обновления](settings-and-updates.md) |

Сообщая о проблеме, укажите версию и сборку из окна **О программе xdzip**, ОС и архитектуру, формат, операцию, шаги и ожидаемый и фактический результаты. По возможности используйте небольшой собственный пример. Перед отправкой удалите пароли и личные пути. [Сообщить о проблеме](https://github.com/xiaodaozhi/xdzip/issues/new/choose)
