## Настройка рабочего пространства

Откройте **Настройки** через меню приложения или панель инструментов. Выберите язык, цветовую схему, размер текста и плотность интерфейса в соответствующих разделах. Автоматический выбор использует язык системы, если он поддерживается. Укажите, открывать ли архивы во вкладках или в окнах. На поддерживаемых платформах можно настроить список недавних файлов и значок в области уведомлений. Изменения применяются сразу. Если настройку не удалось сохранить, прочитайте сообщение об ошибке на странице. [Работа настроек](../ux/settings-localization.md)

Изменяйте ассоциации файлов через операционную систему. Действия в контекстном меню настраиваются отдельно. В macOS расширение Finder включается в системных настройках. Службы Finder доступны после регистрации. [Действия файлового менеджера](../engineering/shell-actions.md)

<a name="xdzip-update-the-app"></a>

## Обновление приложения

- **Версия из Microsoft Store.** Для обновления используйте Microsoft Store. Если приложение работает как пакет MSIX, на странице «О программе» нет команды обновления через GitHub.
- **Установки из GitHub.** Откройте **О программе xdzip** и запустите проверку обновлений. Для установки из приложения требуется поддерживаемая установка Windows для текущего пользователя, поддерживаемая копия macOS в папке «Программы» или установка из DEB в Ubuntu. Также нужен проверенный пакет выпуска. Windows может запросить подтверждение установки. Ubuntu использует системную авторизацию. Если установку задерживают активные задачи, дождитесь завершения или отмените ожидание обновления.
- **Портативные версии и сборки для разработки.** Скачайте подходящий пакет. В Windows и Linux распакуйте весь новый пакет ZIP или TAR.GZ в отдельную папку. В macOS закройте старое приложение перед заменой в папке «Программы». См. [порядок установки](install.md).

Проверку обновлений через GitHub запускает пользователь. При этом используется поддерживаемая настройка прокси. Если предлагается только ручное скачивание, перейдите по ссылке на выпуск и проверьте пакет. Скачанный пакет нужно установить. После обновления снова откройте **О программе xdzip**, чтобы проверить текущую версию. Microsoft Store и GitHub публикуют выпуски независимо.
