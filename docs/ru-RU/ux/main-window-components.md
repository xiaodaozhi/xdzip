# Функции, компоненты и контракт взаимодействия главного окна

[English](../../ux/main-window-components.md) | [简体中文](../../zh-CN/ux/main-window-components.md) | [繁體中文](../../zh-TW/ux/main-window-components.md) | [日本語](../../ja-JP/ux/main-window-components.md) | [한국어](../../ko-KR/ux/main-window-components.md) | [Français](../../fr-FR/ux/main-window-components.md) | [Deutsch](../../de-DE/ux/main-window-components.md) | [Español](../../es-ES/ux/main-window-components.md) | [Português (Brasil)](../../pt-BR/ux/main-window-components.md) | Русский

Элементы главного окна обеспечивают внешний вид и поведение с явными состояниями обычного вида, наведения, нажатия, клавиатурного фокуса, отключения, выбора, занятости и ошибки. HTML использует примеры архивов для проверки взаимодействия; Qt включает действия согласно фактическим возможностям просмотра, создания, извлечения, [проверки целостности](../engineering/archive-checking.md) и [автоматического предпросмотра содержимого](../engineering/content-preview.md). Примеры HTML не представляют реальные фоновые результаты.

Имена файлов, каталогов и архивов, а также пути преимущественно используют системный шрифт по умолчанию при запуске с резервным шрифтом платформы для отсутствующих глифов. Постоянные тексты интерфейса продолжают использовать включённое подмножество. Дерево каталогов и предпросмотры перетаскивания измеряются с соответствующими шрифтами текста; см. [визуальный стандарт](../visual/design-standard.md#界面字体与用户数据).

## Функции и компоненты

| Область | Общие / составные компоненты | Взаимодействие и возможности |
| --- | --- | --- |
| Системная строка заголовка | `Browser`, `ArchiveTabs`, рамка платформы | macOS использует системные кнопки-светофоры. Windows использует встроенные кнопки, системное изменение размера и оформление DWM. В Ubuntu X11 встроенные кнопки и скруглённые углы обычного состояния следуют дизайну X11. См. [окна платформы](platform-windows.md) |
| Вкладки архивов | ArchiveTabs, ArchiveTab, кнопки со значками | По умолчанию новые вкладки, по выбору новые окна; неактивные вкладки обычной насыщенности сначала сжимаются, затем прокручиваются горизонтально с доступом к прокрутке и списку вкладок. Перетаскивание в окне и Ctrl+Shift+Page Up/Down меняют порядок; закрытие сохраняет фоновые задачи |
| Панель инструментов | `ArchiveToolbar`, `ArchiveAction`, `CommandMenu` | Открыть, Создать, Проверить, Дополнительно и разделённая кнопка извлечения используют ту же отправку команд, что меню и клавиатура. Предварительная проверка доступна в меню извлечения для допустимого выбора |
| Поиск | SearchField, действие очистки, подсказка области | Не отправлять во время композиции IME; искать в текущем каталоге; очистка не меняет каталог; сочетание клавиш устанавливает фокус |
| Сводка архива | ArchiveSummary, значок формата, строка статистики | Различать готовность, чтение, пустое состояние и ошибку чтения; неизвестные значения не равны нулю |
| Навигация по каталогам | DirectoryTree, DirectoryRow, Disclosure, соединительные линии | Многоуровневое раскрытие, пустые места стрелок у листьев, независимые текущий каталог и фокус, доступные полные пути, маркер свёрнутого предка, контекстные действия каталога |
| Заголовок области файлов | PaneHeader, Breadcrumb, ViewToggle | Иерархическая навигация по пути, переключение списка/сетки и меню сортировки; общие высота и вертикальный центр |
| Список и сетка | EntryView, SelectableEntry, флажок, SortHeader | Одиночный/множественный/диапазонный выбор, выбрать всё, очистить, инвертировать и клавиши-стрелки. Двойной щелчок/Enter входит в каталог или временно извлекает обычный файл и открывает через системную ассоциацию; свойства остаются доступны из контекстного меню или подробностей |
| Контекстное меню файла | ContextMenu, CommandMenuItem, Submenu | Открыть применяется только к элементу, нажатому правой кнопкой, как при двойном щелчке; существующий множественный выбор сохраняется. Правый щелчок по невыбранному элементу сначала выбирает только его. Извлечение, свойства, копирование имени/пути и навигация каталогов включаются по выбору |
| Контекстное меню пустой области | ContextMenu, RadioMenuItem, CheckboxMenuItem | Выбор, вид и сортировка текущего списка и панель подробностей; не очищать выбор произвольно |
| Контекстное меню заголовка | Меню сортировки | Поле, направление и восстановление порядка архива; сортировать все результаты запроса, а не только видимые записи |
| Свойства / предпросмотр | `InspectorPanel` на странице или отдельное окно подробностей | Показывает состояние файла, выбора или архива. Содержимое читается по запросу. При ширине менее 928 логических пикселей встроенная панель сворачивается, а действие подробностей открывает отдельное окно |
| Состояние и задачи | Строка состояния, кнопка задач и `CommandMenu` | Показывает количество выбранных элементов и известные размеры. Меню задач использует общую историю приложения. Активные задачи имеют отдельное количество и продолжаются после закрытия окна прогресса |
| Подсказки и окна операций | Tooltip, Notice, Toast, отдельные окна платформы | Полные имена и причины отключения; Escape, возврат фокуса, отмена и закрытие следуют смыслу каждого действия |

Список и сетка используют общее пустое состояние. Если отправленный поиск не дал результатов, предлагается другой термин. Без поиска архив без записей обозначается пустым; иначе сообщение описывает только видимое содержимое текущей папки и не предполагает полноту ограниченного индекса каталогов. Чтение и ошибки сохраняют фактические состояния; неотправленный поисковый текст не меняет сообщения текущего результата. Подсказка перед открытием файла не перечисляет устаревший список форматов.

## Единые команды и меню

Кнопки, сочетания клавиш, контекстные и выпадающие меню вызывают одни и те же команды и повторно проверяют текущую возможность перед выполнением. Меню фиксируют объект и область выбора при открытии; закрывайте их при изменении архива или запроса либо исчезновении объекта, чтобы команда старой записи не применилась к новому архиву.

Меню используют четыре общих столбца для места значка/отметки, имени, сочетания клавиш и стрелки подменю, с разделителями между группами действий. Включайте только действия, относящиеся к контексту: каталоги предлагают вход и раскрытие, файлы — подробности, а множественный выбор сохраняет пакетную область. Недоступные для выполнения действия остаются отключёнными, причины доступны только в описаниях доступности; не показывайте поясняющие подстроки или всплывающие подсказки и не заменяйте отключение сообщением «скоро» при нажатии.

При изменении размера шрифта высота подписи меню следует фактическим метрикам и остаётся вертикально по центру строки. Уже первое отображение должно отвечать пределу ошибки центрирования в половину логического пикселя без зависимости от последующего прохода компоновки для исправления старого места текста.

Обычные строки, строки с флажком, переключателем и подменю, а также разделители являются общими компонентами. Сортировка и вид используют переключатели для текущего состояния; панель подробностей — пункт с флажком. Опасные действия никогда не выполняются автоматически по умолчанию; правый щелчок и открытие меню не выполняют действия.

## Ввод и жизненный цикл меню

- Вниз/вверх перемещают между доступными пунктами; Home/End переходят к первому/последнему; Enter/пробел активируют, вправо входит в подменю, влево возвращает к родителю.
- Escape закрывает по одному уровню; закрытие корня возвращает фокус вызывающему элементу или исходной записи. Tab закрывает меню и продолжает обычный порядок фокуса страницы. Поддерживается поиск по первой букве имени; композиция IME не запускает поиск по символам меню.
- Наведение выделяет без выполнения. Подменю открывается с задержкой и сохраняет родительский пункт при входе. Мышь и клавиатура могут использоваться последовательно без нескольких оставшихся выделений или корневых меню.
- Щелчок снаружи закрывает меню, не отнимая фокус у внешней цели. Прокрутка главной области, изменение размера окна, вход в окно операции или переключение архива закрывают меню; прокрутка самого меню не закрывает. Общие элементы HTML записывают фактические позиции прокрутки существующих контейнеров при открытии; события, завершённые до открытия, но доставленные позднее, не закрывают меню, а последующее изменение позиции закрывает.
- Избегайте нижнего и правого краёв области просмотра, при необходимости открывая влево или вверх. Позиционируйте в координатах хоста, различая логические размеры, исходные пиксели, DPR и масштаб проверки.
- Shift+F10/клавиша Menu открывает контекстное меню текущей записи. Долгое касание и правый щелчок используют общий контекст и не уничтожают множественный выбор, как одиночный щелчок.

## Состояния элементов и доступность

| Состояние | Внешний вид | Поведение |
| --- | --- | --- |
| Обычное | Сохранять утверждённые исходные границу, радиус, значок и базовую линию | Смена состояния не меняет размеры элемента |
| Наведение | Бледная заливка; основная кнопка использует более насыщенный основной цвет | Отложенные подсказки не закрывают цели; касание не оставляет залипшего наведения |
| Нажатие | Заливка заметнее, чем при наведении | Текст и значок не перемещаются; отменённое нажатие не выполняется |
| Фокус | Без дополнительного контура, толстой рамки или свечения | Сохранять порядок Tab и клавиатурную активацию; внешний щелчок, Escape и Enter выводят фокус из элемента |
| Отключено | Явные цвета отключённого текста и графики при сохранении контуров | Нет реакции на щелчок или сочетание клавиш; описание доступности объясняет причину |
| Выбрано | Фон или отметка ясно показывает состояние | Синхронизировать `aria-selected` / `aria-checked` / Qt Accessible |
| Занято | Состояние и область отключения следуют задаче | Предотвращать повторную отправку; разрешать просмотр во время фоновой работы |
| Ошибка | Соседний текст объясняет проблему и восстановление | Цвет не является единственным источником информации, успех не имитируется |

Общие значки берутся из `design/assets`. Элементы реализуют текст, отметки, фон, соединительные линии и позиционирование меню; фрагменты в исходных пикселях служат для сравнения. HTML сохраняет исходные координаты основного дизайна, сначала преобразуя параметры новых элементов из логических пикселей; Qt использует ту же логическую спецификацию.

## Приёмка

Количество и кнопки действий справа в области файлов образуют группу фиксированной ширины. Элементы списка, сетки, сортировки и видимых подробностей остаются размером 28×28 логических пикселей с промежутком 6.4; увеличение окна даёт больше места только навигационной цепочке. Меню «Дополнительно» панели инструментов содержит только настройки; исходный порядок, предварительная проверка метаданных извлечения, выбор всего и подробности используют существующие отдельные точки входа.

Стартовая страница и страница архива используют общую строку состояния высотой не менее 32 логических пикселей по statusbarHeight в layout-scale.json. Увеличение шрифта доступности использует фактическую высоту кнопки задач и равные вертикальные отступы без изменения высоты при смене страниц. Обе кнопки используют task-list в центрированном месте значка 16×16 логических пикселей из main.interaction.taskIconSize, неизменном при смене страницы или масштаба шрифта.

Строка состояния архива показывает количество выбранных записей; для непустого выбора разделитель и размер добавляются только при известном итоге. Если виртуальный каталог или файл неизвестного размера делает итог неизвестным, показывается только количество без дополнительного разделителя или `—`. Известный размер ноль байтов по-прежнему показывается; текст стартовой страницы не меняется.

Правая кромка флажка списка файлов остаётся на расстоянии 12 логических пикселей от места значка; значок, имя файла и заголовок имени выровнены. Шрифты доступности меняют фактические метрики текста, не увеличивая этот промежуток. Флажки строк и «Выбрать всё» в заголовке сохраняют существующую модель выбора.

Размер всех пяти столбцов можно менять перетаскиванием правой границы с областью захвата 8 логических пикселей; двойной щелчок восстанавливает стандартную ширину столбца. Имя по умолчанию заполняет оставшееся пространство; другие столбцы начинают с исходных значений дизайна. Оба столбца размера по умолчанию расширяются, чтобы измеренные подписи и стрелки сортировки помещались без обрезки. Пользовательские ширины общие для вкладок и окон во время работы и сбрасываются при выходе; логические ширины хранятся в памяти, а не в настройках или DPR. Минимум имени — 160, других столбцов — 64, с пропорциональным увеличением для шрифтов доступности; переполнение прокручивается горизонтально. Заголовки и содержимое используют единый источник ширины, перетаскивание не запускает сортировку. Маркеры возрастания/убывания стоят перед выровненными справа подписями исходного и сжатого размера и после других подписей, всегда на расстоянии 6 логических пикселей от видимого текста. Активные столбцы сортировки резервируют место стрелки с нужной стороны; при ручном сужении сначала сокращаются подписи, стрелки не перекрывают текст или соседние столбцы. Числовые заголовки остаются выровненными вправо вместе с содержимым.

Значки типов файлов генерируются для селекторов Qt из [таблицы подсказок расширений](../../../specs/visual/file-types.json), охватывающей офисные документы, таблицы, презентации, аудио, видео, архивы, установщики, шрифты и образы дисков. Расширения не зависят от регистра, неизвестные типы используют общий значок документа. Это описывает только внешний вид, а не достоверность содержимого или поддержку просмотра, создания и извлечения формата архива.

Фактическими мышью и клавиатурой проверяйте записи, обход краёв меню, переходы в подменю и обратно, сохранение выбора, возврат фокуса, защиту отключённых действий, изоляцию вкладок, переключение вида и иерархию каталогов. Снимайте реальные элементы в светлой/тёмной темах, с оформлениями трёх платформ, обычными/крупными шрифтами и масштабами. Работа над меню не должна ухудшать существующее начальное выравнивание заголовка, панели инструментов, списка файлов и предпросмотра главного окна.

Функциональное покрытие, реальные снимки и неинтегрированные возможности фиксируйте по [общему методу проверки](../../../developers/qa/README.md), с выводами в соответствующих issue и свидетельствами в build/ или артефактах CI. Статические макеты, поведение браузера и проверка Qt во время выполнения описываются отдельно и не заменяют друг друга.

Меню Qt явно используют `Popup.Item` с общими делегатами, чтобы AppKit не игнорировал пользовательское оформление; окна операций остаются отдельными окнами верхнего уровня. `CommandTooltip` использует общие параметры подсказок и обычный текст, чтобы имена архивов не интерпретировались как форматированный текст; скрывайте подсказки, когда меню получает фокус. Общие восьмизначные цвета JSON используют CSS RGBA; генератор QML преобразует их в QColor ARGB. Проверяйте цвет и непрозрачность вместе.

У дерева каталогов и состояний наведения «Открыть», «Создать», «Проверить», «Дополнительно» и «Извлечь» главной панели нет плавающих подсказок. У отключённых действий меню также нет видимой подсказки; другие кнопки используют общие отложенные подсказки. Корень и обычные подкаталоги перечисляют только непосредственные файлы и папки, а поиск рекурсивно охватывает текущую область. Обычные имена показывают последний компонент, поиск — полные пути. Наведение списка охватывает всю строку; сетки сохраняют фиксированные горизонтальные отступы и флажки при наведении/выборе. Меню используют мягкие тени со всех сторон и промежуток 4 логических пикселя от вызывающих кнопок. Отдельные свидетельства взаимодействия и масштабирования сохраняются по [общему методу](../../../developers/qa/README.md).

Во всех режимах сортировки каталоги остаются перед файлами. Возрастание и убывание применяются внутри каждой группы. Сортировка типов группирует файлы без расширения отдельно от каталогов и сохраняет стабильный порядок идентичности для одинаковых типов. Полный запрос сортируется до разделения на внутренние пакеты передачи. Файлы HTML без установленного folder трактуются как false; не преобразуйте undefined в NaN для сравнения.

## Выбор, задачи и подсказки

«Выбрать всё» сохраняет фокус подробностей на последнем элементе текущего списка, с метаданными как при индивидуальном выборе. Очистка выбора скрывает четыре свойства и «Извлечь этот файл»; эта кнопка использует общие состояния наведения, нажатия и фокуса. «Выбрать всё» по-прежнему применяется ко всему текущему запросу без изменения контрактов каталога или физической идентичности.

Нижний пункт «Задачи N» показывает количество сохранённой истории; число активных используется только для подсказок и логики выхода. Каждая запись меню задач показывает создание/извлечение и номер слева, цвет состояния справа; активация мышью или клавиатурой повторно открывает ту же задачу. Меню задач разделяют плотность, размер шрифта и границы прокрутки с другими меню. Без выбора действия выбранной области и предварительной проверки в меню области извлечения отключены без дополнительных строк подсказки.

Плавающие подсказки появляются только после того, как указатель непрерывно остаётся неподвижным внутри одного элемента 1200 ms. Движение, уход, нажатие или открытие меню отменяют показ и старые таймеры; переход между элементами требует полного нового ожидания, а не быстрого пробуждения от предыдущей подсказки. Предпочтительно размещение над элементом; при недостатке места сверху использовать низ, чтобы ограничения края не сдвинули подсказку на элемент и не вызвали колебание наведения. Общий CommandTooltip Qt использует явный таймер неподвижности, синхронизированный с HTML data-tooltip. Полные имена списка не используют системный browser title для обхода правила. Время подсказок системных нативных меню и трея контролируется системой и не объявляется управляемым через QML. Время не масштабируется с размером шрифта, DPR или плотностью; визуальная геометрия не меняется.

Вкладки архивов также показывают полные имена файлов обычным текстом в общей подсказке с задержкой неподвижности; нажатие, перестановка, открытие меню вкладки или списка вкладок скрывают её. Глобальные записи задач сначала закрывают своё меню, затем открывают только окно задачи, не переключая вкладки архивов и не открывая заново закрытые страницы архивов.

Стартовая страница использует прокручиваемое содержимое, закреплённое сверху и центрированное по горизонтали. Ошибки и предупреждения появляются под подсказками форматов красным текстом и семантическими значками, не сдвигая верхнее содержимое. Закрытие главного окна, остающегося в трее, очищает его вкладки; обычное восстановление показывает только стартовую страницу. При минимизации вкладки сохраняются; фоновые задачи остаются глобально доступны.

Двустороннее перетаскивание в список файлов, подтверждение добавления в текущий каталог и внешнее копирование на трёх платформах описаны в [перетаскивании и изменении файлов](../engineering/archive-transfers.md).

Перемещение внутри архива использует внутреннее перетаскивание. Целевые папки в списке/сетке и дереве каталогов используют существующую заливку выбора; мгновенная обратная связь повторно использует геометрию подсказки, занимает не более четырёх строк и ограничена текущей клиентской областью. Для выбранных каталогов, их потомков, исходных позиций, поиска и зашифрованных/разделённых целей показываются явные причины отказа без нового окна подтверждения. Конфликты имён используют окно конфликтов файлов, а задачи перемещения имеют отдельное имя. Транзакции и границы описаны в дизайне перемещения внутри архива и [контракте перетаскивания](../engineering/archive-transfers.md).
