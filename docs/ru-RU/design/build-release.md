## Входные данные сборки и упаковки

CMake собирает настольное приложение Qt, адаптеры C++ и нативные вспомогательные программы. Cargo собирает среду выполнения Rust и генерирует подключаемый мост CXX. У отдельной CLI своя точка входа для сборки, Qt ей не нужна. `scripts/desktop.py` и `scripts/cli.py` координируют сборку и тестирование. В исходном коде зафиксированы Rust 1.99.0 и SDK Qt 6.8.2. При сравнении результатов учитывайте идентификатор сборки, целевую архитектуру, файлы фиксации зависимостей и происхождение инструментов. [Инструменты](../engineering/toolchain.md), [Руководство по сборке](../../engineering/developer-build.md)

Пакет настольного приложения развёртывает необходимые библиотеки Qt, модули QML, ресурсы платформы и вспомогательные программы. Закрытый процесс обработки изображений использует Qt для декодирования и показа статических SVG. В дистрибутив CLI входит необходимый процесс обработки архивов. Профили сборки, списки разрешённых файлов и проверки развёртывания определены в сценариях и контрактах платформ. Состав установленных зависимостей и общий размер определяют по полному пакету. [Аудит развёртывания и зависимостей](../engineering/deployment-audit.md), [Распространение CLI](../../engineering/command-line.md)

## Текущие каналы распространения

| Целевая платформа | Пакет и границы доверия |
| --- | --- |
| macOS Apple Silicon | GitHub предоставляет DMG и ZIP с пакетом приложения. Минимальная версия — macOS 14. Пакет использует подпись ad hoc для проверки целостности. Порядок установки и обновления см. в инструкции для платформы. |
| Windows 11 x86_64 | GitHub предоставляет неподписанный установщик для текущего пользователя и переносимый ZIP. Microsoft Store управляет идентификатором MSIX, подписью и каналом обновления своей редакции. |
| Ubuntu 24.04 LTS x86_64 | GitHub предоставляет архив каталога среды выполнения и DEB. Поддерживаемая конфигурация включает X11 и glibc 2.39 или более позднюю версию. |
| Отдельная CLI | Имеет собственные идентификаторы пакета и обновления. CLI, устанавливаемая с настольным приложением, следует правилам интеграции и передачи управления его пакета. |

## Регулярные проверки, нативные сборки и выпуск

Регулярный [процесс CI](https://github.com/xiaodaozhi/xdzip/blob/main/.github/workflows/docs.yml) выполняет быстрые проверки. Нативные задачи Foundation и Qt выполняются в отдельных процессах с ручным запуском. Обычный CI для Apple Silicon собирает, тестирует и проверяет запуск, не развёртывая приложение для скачивания. Специальный процесс выпуска включает собственные разрешённые этапы развёртывания, подписания, упаковки и публикации. [Протокол выпуска](../engineering/release-protocol.md) и [политика CI](../../../developers/engineering/ci-policy.md) определяют условия перехода к выпуску и необходимые подтверждения.

Манифесты выпуска, контрольные суммы, списки компонентов, SBOM и лицензионные материалы описывают поставляемые артефакты. Процесс выпуска не создаёт и не загружает ZIP-архивы исходного кода проекта. GitHub предоставляет собственные снимки по тегам с помощью отдельного механизма. Обязательства определяются по фактически поставляемым компонентам, [реестру лицензий](../engineering/licensing.md) и [политике предоставления исходников](../../engineering/source-delivery.md).

## Обновления и дальнейшее распространение

Выбор и проверка обновлений выполняются независимо от операций с архивами. Поддерживаемые установленные сборки следуют контракту обновления для метаданных доверия, проверенных файлов, идентификации установки и передачи управления при активных задачах. Windows и Linux используют соответствующую вспомогательную программу, macOS использует Sparkle, а редакцию Store обслуживает Microsoft Store. Переносимые и отладочные конфигурации имеют собственные ограничения. [Обновления программы](../../engineering/software-update.md)

Новые архитектуры, минимальные версии ОС, форматы пакетов и магазины требуют отдельных подтверждений сборки и приёмки. История решений о распространении и условия их пересмотра зафиксированы в [журнале архитектурных решений](architecture-decisions.md).
