# xdzip 0.1.0-alpha.8 源码与许可补充材料

本补充材料对应已公开的 `0.1.0-alpha.8`、build 21、源码提交 `e1cd6a3e125d5fcabc85a9f4edb106d013709c89`。它补充原发行中的来源和通知，不改变原有发行附件、更新签名或校验和。原始版本及对应源码包仍可从 [alpha.8 发布页](https://github.com/xiaodaozhi/xdzip/releases/tag/v0.1.0-alpha.8)取得；`xdzip-0.1.0-alpha.8-corresponding-source.tar.gz` 的 SHA-256 为 `95d7e3eac9d457d3e20773fa9b3c71c520cc9e9893343815b3c8c4547020361e`。

## 原版的补充通知与源码

- 原源码包中的七个 Rust vendor 包缺少独立的常见名称通知文件。请同时取得[固定的补充通知目录](https://github.com/xiaodaozhi/xdzip/tree/7497058904fe29fe9728fdf02a72e68d6847d37a/third_party/rust-vendor-notices)和[逐包来源索引](https://github.com/xiaodaozhi/xdzip/blob/7497058904fe29fe9728fdf02a72e68d6847d37a/scripts/rust-vendor-notice-sources.json)。补充目录不改动原 vendor 文件。
- Qt Network 内嵌的 Public Suffix List 对应的[可编辑原始列表和 MPL-2.0 许可](https://github.com/xiaodaozhi/xdzip/tree/8ae6f6ff9a3d3a228256f10124ad2d802ef900e7/third_party/qt-public-suffix-list)随本补充提供。
- Qt Core MIME 数据所用的 [Apache Tika 原始文件、完整 NOTICE 和 OGL-UK-3.0 原文](https://github.com/xiaodaozhi/xdzip/tree/c9454ed8378935dbb15b63bdd044a4b674548b45/third_party/qt-tika-mimetypes)随本补充提供。相关归属包括 Apache Software Foundation 及英国国家档案馆的 PRONOM；完整 Tika NOTICE 包含上游发行的其他声明，不表示其他全部依赖均随 xdzip 分发。
- RAR 的有限参考映射继续保留原 UnRAR 许可，按保守做法在涉及的[旧版 LZ 映射源码](https://github.com/xiaodaozhi/xdzip/blob/b0b3d8f88c1a6a9065acd28f5aab04f5e02e51d2/crates/xdzip-codec-rar/src/legacy_lz15_codes.rs)和[旧版密码映射源码](https://github.com/xiaodaozhi/xdzip/blob/b0b3d8f88c1a6a9065acd28f5aab04f5e02e51d2/crates/xdzip-codec-rar/src/legacy_crypto/permutation.rs)中补充许可第 2 段。[原版源码注释补丁](0.1.0-alpha.8-rar-notice.patch)可下载到本地；在原版项目源码根目录先运行 `git -c core.autocrlf=false -c core.eol=lf apply --check --verbose <补丁路径>`，确认两个文件均显示正在检查而非跳过后，再运行 `git -c core.autocrlf=false -c core.eol=lf apply --verbose <补丁路径>`。补丁只增加源码注释，不改变原版可执行文件；[参考来源与原许可](https://github.com/xiaodaozhi/xdzip/tree/b0b3d8f88c1a6a9065acd28f5aab04f5e02e51d2/third_party/rar-wire-mappings)继续适用，未加入官方 RAR 引擎源码。
- 原包的 Qt 许可说明误称其为私有开发审阅包，且模块列表遗漏 Network。请参阅[更正后的 Qt 说明](https://github.com/xiaodaozhi/xdzip/blob/82e5db0cf1fc7d524be9a2051fa9e649810d0381/third_party/qt/README.md)。Qt 运行库采用 LGPL-3.0 分支，Qt 内嵌第三方组件可能有其他条款；原包中的 LGPL-3.0 和 GPL-3.0 原文仍保留。

## Qt 重建与替换

原源码包包含固定的 Qt 6.8.2 模块归档、应用源码和 Rust vendor。补充材料的[源码构建与替换说明](https://github.com/xiaodaozhi/xdzip/blob/758ef6fba66c50d4c97a46f76e48205d18ac9dbf/docs/engineering/wp12-automation.md#qt-源码与兼容替换)和[重建脚本](https://github.com/xiaodaozhi/xdzip/tree/758ef6fba66c50d4c97a46f76e48205d18ac9dbf/scripts)提供隔离构建、兼容 QtCore 替换及验证入口。Windows／Linux 使用原始便携包副本；Apple Silicon Mac 需在本机使用原始 app.zip，修改副本后可使用本地 ad-hoc 完整性签名。无需项目私有签名密钥。替换要求接口兼容，不能据此保证任意修改均可运行。

原版 Qt 翻译文件的上游 SPDX 根包没有声明具体许可，源码中的许可规则也不能单独确认为每个翻译文件的授权；这一问题仍在 #53 跟踪。

已公开原包的 macOS 上游 SPDX 中有 110 条文件摘要与 61 个实际 SDK 文件不同。官方 SDK 归档与原发行记录的 SDK 输入一致，但原摘要生成后的具体变化尚未证明；源自官方数据并不自动解决该差异。[#53](https://github.com/xiaodaozhi/xdzip/issues/53) 保留逐项证据、剩余平台验收与许可限制。本补充不宣称原版已完成全部许可审查或所有平台人工验收。

## English

This supplement applies to published `0.1.0-alpha.8`, build 21, source revision `e1cd6a3e125d5fcabc85a9f4edb106d013709c89`. It supplements the original release and corresponding-source archive without modifying their assets, signatures or checksums. The original source archive SHA-256 is recorded above.

The links above supply the missing pinned notices for seven Rust vendor packages, the editable Public Suffix List and MPL-2.0 text, and the Apache Tika MIME input, complete upstream NOTICE and OGL-UK-3.0 text. The Tika notice covers more than the components distributed with xdzip. The two RAR source links retain the original UnRAR license paragraph 2 as a conservative notice for limited reference mappings. The [patch for the original source](0.1.0-alpha.8-rar-notice.patch) can be checked and then applied from its project source root using `git -c core.autocrlf=false -c core.eol=lf apply --check --verbose <patch-path>` and `git -c core.autocrlf=false -c core.eol=lf apply --verbose <patch-path>`; verify that both files are checked rather than skipped. The patch changes comments, not the published executable, and does not incorporate the official RAR engine.

The corrected Qt notice identifies the actual release and includes Network. Distributed Qt runtime libraries use the LGPL-3.0 option; embedded third-party components may have different terms. The original release includes LGPL-3.0 and GPL-3.0 texts. The linked source-build and replacement instructions describe isolated, interface-compatible QtCore substitution; an Apple Silicon Mac can use a local ad-hoc integrity signature without the project signing key. Arbitrary ABI changes are not guaranteed to work.

The upstream SPDX package for Qt translations does not declare a specific license, and the source license rule alone does not establish a grant for each translation file; this remains tracked in #53.

The original macOS upstream SPDX records have 110 checksum differences covering 61 SDK files. Verified official SDK archives match the original release's recorded SDK inputs, but the exact transformation after those SPDX digests remains unresolved. Follow [#53](https://github.com/xiaodaozhi/xdzip/issues/53) for evidence and outstanding licensing and device acceptance; this supplement is not a claim of complete compliance or manual acceptance.
