# xdzip 0.1.0-alpha.8

xdzip **0.1.0-alpha.8，build 21** 是实验性跨平台预发布版本。具体候选、验证记录和未完成事项见 [#53](https://github.com/xiaodaozhi/xdzip/issues/53)。

## 本次能力与修复

- ZIP、TAR/GZIP、7z、RAR、CAB、ISO/UDF 使用项目独立 Rust 格式后端，并保留隔离工作进程和安全文件提交。7z 支持创建、密码与文件名加密；RAR、CAB、ISO 和 UDF 保持只读。
- 支持归档内文件打开、原生拖出、拖入添加和普通未加密单文件归档的受限修改。常见旧编码名称贯通浏览、解压和普通包修改；创建和添加排除 macOS 元数据。
- 用户的归档名、文件名、目录和路径优先使用系统字体及平台回退，固定界面文案保留产品字体。空文件夹、空压缩包和搜索无结果分别显示对应提示。
- 关于页提供用户主动检查更新；满足安装身份、版本及签名条件的安装版可进行更新。**已公开的 alpha.6 及更早版本没有现行更新组件，须先从本发布页手动下载并安装新版本。**便携版继续手动更新。

## 系统与已知限制

提供 Windows 11 x86_64 的安装器和便携包、macOS 14+ Apple Silicon 的 app.zip 和 DMG，以及 Ubuntu 24.04 x86_64／X11 的 tar.gz 和 DEB。当前不提供 Intel Mac、Windows／Linux ARM64 或 Wayland 支持。

Windows 安装器没有发行者签名；Mac 使用 ad-hoc 完整性签名，没有 Developer ID 或公证。更新清单和 Mac 更新材料使用的签名与系统发行者身份不同。文件内容预览、百万条磁盘索引和第三方扩展尚未实现；加密或分卷归档的修改、7z 重建工作集及其他格式限制见 README 和工程契约。

此前 a1a3940 的 Windows 真人界面结果及旧版本安装结果保留各自构建身份。Mac／Ubuntu 真人桌面、指定参考机性能以及实际候选的来源、许可与再分发复核仍按 #53 登记；SBOM 保留 incomplete 状态，未决材料不因自动检查通过而视为完成。

## English

**xdzip 0.1.0-alpha.8, build 21** is an experimental cross-platform prerelease. Candidate-specific validation and outstanding work are tracked in [#53](https://github.com/xiaodaozhi/xdzip/issues/53).

ZIP, TAR/GZIP, 7z, RAR, CAB and ISO/UDF use the project's independent Rust format backends with isolated workers and guarded file commits. 7z creation, content encryption and filename encryption are supported; RAR, CAB, ISO and UDF remain read-only. Archive browsing, native export, adding files, restricted rewriting, legacy filename decoding and macOS metadata filtering are available within the documented format limits.

Archive names, filenames, directories and paths prefer the system font and platform fallback; fixed interface text keeps the bundled font. Empty folders, empty archives and searches without results have distinct messages.

Updates are initiated by the user from About, and eligible installed builds can update after identity, version and signature checks. **Published alpha.6 and earlier clients lack the current updater and require one manual installation from this release page.** Portable builds continue to be updated manually.

Packages target Windows 11 x86_64, macOS 14+ Apple Silicon and Ubuntu 24.04 x86_64/X11. Windows installers have no publisher signature; Mac apps use ad-hoc integrity signing without Developer ID or notarization. Update signatures are distinct from platform publisher identity. Encrypted or split archives cannot be modified, and 7z rewriting has a 512 MiB working-set limit. Intel Mac, Windows/Linux ARM64, Wayland, content preview, million-entry disk indexing and third-party extensions are outside the current support scope.

Prior Windows human observations and earlier installation checks retain their original build identities. Mac/Ubuntu human desktop work, reference-host performance and candidate-specific provenance, licensing and redistribution review remain tracked in #53. SBOM completeness remains marked incomplete; passing automated checks does not close those open material questions.
