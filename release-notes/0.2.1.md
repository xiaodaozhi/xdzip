# xdzip 0.2.1

**应用版本 0.2.1，构建 30。** GitHub 提供 Windows x64、macOS Apple Silicon 和 Linux x64 的桌面包与独立 CLI。Microsoft Store 使用同一版本源码构建 MSIX 1.0.30.0。

- **归档格式**。新增多种归档与压缩流的浏览和提取能力，包括 LHA/LZH、ARJ、ARC、DEB、ASAR、Zstandard 和 LZ4 的受支持子集。新增 LZH 创建、ISO9660/Joliet 数据镜像创建及 Windows x64 ZIP 自解压文件。各格式限制见[格式支持表](https://github.com/xiaodaozhi/xdzip/blob/v0.2.1/README.zh-CN.md#格式支持)。
- **浏览与预览**。文件夹在各种排序中优先，普通 ZIP/ZIP64 支持百万条流式索引。属性缺失时留空，预览修改时间显示到秒。按需预览受限文本、常见图片和静态 SVG。macOS 另支持受限 HEIC/HEIF。
- **Windows 集成**。商店版文件关联页可打开 Windows 默认应用设置。Windows 11 商店版提供现代与传统 Explorer 菜单，归档显示对应格式的文件图标。修复重新启用托盘图标后托盘菜单无法打开的问题。
- **更新**。Microsoft Store 管理 MSIX 更新。GitHub 版的 Qt 更新客户端使用 HTTP/1.1 获取更新信息和程序包，避开固定 Qt 版本受影响的路径。macOS Sparkle 保留独立传输。[Qt 通告](https://www.qt.io/blog/security-advisory-cve-2026-96432)

旧版客户端无法自动升级时，可从本页手动安装新版。桌面与独立 CLI 各自提供受签名保护的更新清单，下载文件随附 SHA-256 校验清单。商店版在 Microsoft Store 中更新。

发布工作流分别执行三平台构建和自动化验收。商店旧版的默认应用入口、双菜单和图标实机验收分别见 [#325](https://github.com/xiaodaozhi/xdzip/issues/325)、[#326](https://github.com/xiaodaozhi/xdzip/issues/326) 和 [#342](https://github.com/xiaodaozhi/xdzip/issues/342)。本版发布与验收记录见 [#348](https://github.com/xiaodaozhi/xdzip/issues/348)。

## English

**Application version 0.2.1, build 30.** GitHub provides desktop and standalone CLI packages for Windows x64, macOS Apple Silicon and Linux x64. The Microsoft Store build uses the same versioned source and has MSIX version 1.0.30.0.

- **Archive formats.** Added browsing and extraction for more archive and stream profiles, including supported subsets of LHA/LZH, ARJ, ARC, DEB, ASAR, Zstandard and LZ4. Create LZH archives, ISO9660/Joliet data images and Windows x64 ZIP self-extracting files. See the [format support table](https://github.com/xiaodaozhi/xdzip/blob/v0.2.1/README.md#format-support) for limits.
- **Browsing and previews.** Folders appear first in all sort orders. Ordinary ZIP/ZIP64 archives support streaming indexes of up to one million records. Missing properties remain blank, and preview modification times include seconds. Preview supported text, common images and static SVG on demand. macOS also supports bounded HEIC/HEIF previews.
- **Windows integration.** The Store edition links to Windows default-app settings and provides both modern and classic Explorer menus on Windows 11. Associated archives display icons for their formats. The tray menu works again after the tray icon is re-enabled.
- **Updates.** Microsoft Store manages MSIX updates. The GitHub edition's Qt updater uses HTTP/1.1 for update metadata and package downloads to avoid the affected path in the pinned Qt version. macOS Sparkle uses its own transport. [Qt advisory](https://www.qt.io/blog/security-advisory-cve-2026-96432)

If an older client cannot update automatically, install the new package from this release. Desktop and standalone CLI downloads have separate signed update manifests. SHA-256 checksums accompany the downloads. Update the Store edition through Microsoft Store.

The release workflow builds and verifies each platform separately. The owner previously verified default-app settings, both Explorer menus and icons in Store builds, as recorded in [#325](https://github.com/xiaodaozhi/xdzip/issues/325), [#326](https://github.com/xiaodaozhi/xdzip/issues/326) and [#342](https://github.com/xiaodaozhi/xdzip/issues/342). See [#348](https://github.com/xiaodaozhi/xdzip/issues/348) for this release's verification and publication record.
