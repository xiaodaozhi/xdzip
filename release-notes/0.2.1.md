# xdzip 0.2.1

本版本修正 Windows MSIX 的系统集成。当前商店候选包版本为 `1.0.29.0`，与应用显示版本 `0.2.1` 分开管理。

- 文件关联页提供当前包的 Windows 默认应用设置入口，隐藏无法直接修改的逐扩展开关。默认应用仍由 Windows 和用户管理。
- 商店构建声明现代菜单和“显示更多选项”中的传统菜单。现代菜单要求已注册的商店构建具有微软 Store 签名；自行生成的侧载构建仅声明传统菜单。
- 菜单命令使用所属包的 AUMID 激活应用，执行前复核包注册，拒绝已升级或卸载的旧目标。
- 无法取得的文件属性留空，预览修改时间显示到秒。
- 构建 29 补齐多尺寸和明暗主题无底板图标资源，修复应用图标偏小及额外底板；文件关联复用已有逐格式归档图标的原始尺寸与位置。

构建 28 的默认应用入口及 Explorer 双菜单已通过所有者商店实机验收，见 [#325](https://github.com/xiaodaozhi/xdzip/issues/325) 和 [#326](https://github.com/xiaodaozhi/xdzip/issues/326)。构建 29 的图标修复及新商店交付后的显示验收见 [#342](https://github.com/xiaodaozhi/xdzip/issues/342)。生成候选包不代表已发布，现有商店安装不会自动获得尚未发布的代码。

## English

This version fixes Windows MSIX integration. The current Store candidate package version is `1.0.29.0`, separate from the application display version `0.2.1`.

- File associations now link to Windows default-app settings for the current package, replacing unavailable per-extension switches. Windows and the user retain control over default applications.
- Store builds declare both modern and classic menus under “Show more options.” Modern commands require a registered Store build with a Microsoft Store signature. Project-generated sideload builds declare only the classic menu.
- Menu commands activate their owning package by AUMID and recheck registration before invocation, rejecting superseded or uninstalled targets.
- Unavailable file properties remain blank, and preview modification times include seconds.
- Build 29 adds scale, target-size and both unplated theme variants to fix the undersized application icon and extra backplate. File associations reuse canonical per-format archive icons with their original size profiles and alignment.

The owner accepted build 28's default-app settings entry and both Explorer menus after Store delivery; see [#325](https://github.com/xiaodaozhi/xdzip/issues/325) and [#326](https://github.com/xiaodaozhi/xdzip/issues/326). Build 29's icon fix and display acceptance after the new Store delivery are tracked in [#342](https://github.com/xiaodaozhi/xdzip/issues/342). Preparing a candidate does not publish it or update existing Store installations.
