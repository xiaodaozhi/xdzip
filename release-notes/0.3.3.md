# xdzip 0.3.3

**应用版本 0.3.3，构建 35。** 提供 Windows x64、macOS Apple Silicon、macOS Intel 和 Linux x64 的桌面包与独立 CLI。

- **压缩包注释。** 支持查看整包注释，并在普通可写 ZIP、ZIP64 和 ZIPX 中新增、修改或清空注释。受限 ZIP 和支持的 RAR 注释为只读。文件预览也支持显示更多格式提供的条目注释和属性。
- **文件操作。** 改进创建、编辑和解压时的文件名及路径处理，保留受支持的原始名称，改善 Windows 共享目录下的解压和编辑。
- **界面。** 起始页和文件页增加最近打开入口，文件页增加快速解压及打开压缩包所在位置。更新应用图标和文档图标。

Windows 安装器未使用发布者证书签名。macOS 应用包采用 ad-hoc 完整性签名，未经过 Apple 公证。Microsoft Store 独立发布和更新。Ubuntu amd64 Snap 通过发行工作流同步到稳定渠道。

功能验收及其平台范围分别记录于 [#519](https://github.com/xiaodaozhi/xdzip/issues/519)、[#511](https://github.com/xiaodaozhi/xdzip/issues/511) 和相关议题。本版构建、依赖及发行核验记录见 [#526](https://github.com/xiaodaozhi/xdzip/issues/526)。

## English

**Application version 0.3.3, build 35.** Desktop and standalone CLI packages are available for Windows x64, macOS Apple Silicon, macOS Intel and Linux x64.

- **Archive comments.** View archive comments and add, edit or clear comments in ordinary writable ZIP, ZIP64 and ZIPX archives. Comments in restricted ZIP and supported RAR archives are read-only. The file preview also shows entry comments and attributes provided by more formats.
- **File operations.** Improve filename and path handling when creating, editing and extracting archives, preserve supported original names, and improve extraction and editing in shared Windows directories.
- **Interface.** Add recently opened archives to the start and file pages, and add quick extraction and an action to open the archive location on the file page. Update the application and document icons.

The Windows installer is unsigned. The macOS packages use ad-hoc integrity signing and are not notarized by Apple. Microsoft Store releases and updates are separate. The release workflow also publishes the Ubuntu amd64 Snap to stable.

Feature acceptance and its platform coverage are recorded in [#519](https://github.com/xiaodaozhi/xdzip/issues/519), [#511](https://github.com/xiaodaozhi/xdzip/issues/511) and related issues. See [#526](https://github.com/xiaodaozhi/xdzip/issues/526) for this version's build, dependencies and release verification.
