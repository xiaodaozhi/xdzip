# xdzip 0.1.0

xdzip **0.1.0，build 23** 是首个稳定版，提供 Windows、macOS 和 Linux 的原生安装或便携包。每个发行包、对应源码和通知材料均附带 SHA-256 校验信息。

## 功能

- 浏览、搜索、排序和检查 ZIP、TAR、TAR.GZ、7z、RAR、CAB、ISO 与 UDF 压缩包或映像。
- 解压受支持的文件和目录；创建 ZIP、TAR、TAR.GZ 与 7z，支持适用格式的 AES-256 加密、分卷和压缩级别。
- 使用多标签页或多窗口管理归档；按需拖放、添加或移动受支持的归档内容。
- 通过设置发起软件更新检查；安装版在发行签名、版本和安装身份均有效时可使用更新交接。

## 本版更新

- 改进设置窗口滚动布局和更新状态辅助功能，并修复设置窗口原生悬停回归。
- 更新检查使用系统代理路由，并补充 Windows 设置和安装包验证。
- 修复第三方通知收集，并规范源码 SBOM 中的 SPDX 许可表达式及 Rust 运行时候选依赖图。

## 系统支持与限制

- Windows 11（受维护版本），x86_64；macOS 14 或更新版本，Apple Silicon arm64；Ubuntu 24.04 LTS，x86_64、X11、glibc 2.39 或更新版本。
- Windows 安装器没有发行者签名；macOS 使用 ad-hoc 完整性签名，未使用 Developer ID 签名或公证。更新材料的签名不代表平台发行者身份。
- 不提供 Intel Mac、Windows 或 Linux ARM64、Wayland 支持。尚不支持文件内容预览、RAR／CAB／ISO／UDF 创建与修改、加密或分卷 7z 修改、稀疏 TAR、独立非 TAR 的 GZIP、第三方扩展和百万条磁盘索引；7z 修改有 512 MiB 工作集上限。
- Windows 包包含应用目录内 VC++ 运行库，不包含 Windows SDK 图形编译 DLL 或软件 OpenGL 回退库。

## English

**xdzip 0.1.0, build 23** is the first stable release, with native installer or portable packages for Windows, macOS and Linux. Each release package, corresponding source archive and notice materials include SHA-256 integrity information.

## Features

- Browse, search, sort and check ZIP, TAR, TAR.GZ, 7z, RAR, CAB, ISO and UDF archives or images.
- Extract supported files and directories; create ZIP, TAR, TAR.GZ and 7z archives with AES-256 encryption, volume splitting and compression levels where supported.
- Manage archives in multiple tabs or windows, and drag, add or move supported archive contents.
- Initiate update checks from Settings. Installed builds can use the update handoff when release signatures, version and installation identity are valid.

## Changes

- Improved Settings scrolling layout and accessibility for update status, and fixed a native hover regression in Settings.
- Routed update checks through the system proxy and expanded Windows Settings and installer verification.
- Fixed third-party notice collection and normalized SPDX license expressions and Rust runtime-candidate dependencies in source SBOMs.

## Supported systems and limitations

- Windows 11 (supported servicing versions), x86_64; macOS 14 or later, Apple Silicon arm64; Ubuntu 24.04 LTS, x86_64, X11 and glibc 2.39 or later.
- The Windows installer has no publisher signature. macOS uses ad-hoc integrity signing without Developer ID signing or notarization. Update-material signatures do not represent platform publisher identity.
- Intel Mac, Windows/Linux ARM64 and Wayland are unsupported. File-content preview, RAR/CAB/ISO/UDF creation or modification, encrypted or split-volume 7z modification, sparse TAR, standalone non-TAR GZIP, third-party extensions and million-entry disk indexes are not supported. 7z modifications have a 512 MiB working-set limit.
- Windows packages include the app-local VC++ runtime and do not include Windows SDK graphics compiler DLLs or the software OpenGL fallback library.
