# xdzip 0.1.0-alpha.6

xdzip **0.1.0-alpha.6，build 19**，实验性跨平台预发布。

本次基于已验收提交 `e7f49979ef036261880c0e2d86c4675b58c80758`，不替换历史公开版本的资产。

### 本次更新

- 修复托盘恢复窗口时关闭按钮短暂闪红，保留窗口边框、圆角及普通、最大化、全屏状态。
- 修复 Git 源码 TAR 的 GNU 长文件名兼容，优化起始页错误提示，关闭窗口时清空其标签，后台任务继续运行。
- 支持分卷 ZIP 浏览与解压，双击压缩包内普通文件后解压到私有临时目录并调用系统关联打开。
- 修复“打开压缩包”设置保存，改进胶囊标签的溢出滚动、拖动排序和加载取消操作。
- 保留单实例、共享托盘及按设置在新标签或新窗口打开的会话模式。

### 下载与系统要求

| 平台 | 安装或运行包 | 系统要求 |
| --- | --- | --- |
| Windows x86_64 | `windows-x86_64.zip`、`windows-x86_64-setup.exe` | 受维护的 Windows 11 |
| macOS arm64 | `macos-arm64.app.zip`、`macos-arm64.dmg` | macOS 14.0+，Apple Silicon |
| Linux x86_64 | `linux-x86_64.tar.gz`、`ubuntu24.04-x86_64.deb` | Ubuntu 24.04，glibc 2.39，X11 |

实际附件文件名均带完整版本。Windows 包携带应用目录内 VC++ 运行库和图形兼容库，安装器未作发行者签名。macOS ZIP 和 DMG 来自同一已部署、ad-hoc 完整性签名并验证的应用，未经 Developer ID 签名或 Apple 公证。系统可能显示来源或安全提示，请保留系统安全保护。

### 验证与发布协议

专用 Release 流水线在原生三平台执行构建、测试、部署审计、独立启动及包生命周期核验，六类包齐备且哈希一致后才公开；公开后重新下载所有附件复验。Windows 本版本人工视觉验收已由用户确认，托盘恢复关闭按钮不再闪红，记录见 [#24](https://github.com/xiaodaozhi/xdzip/issues/24)。本次发布记录见 [#25](https://github.com/xiaodaozhi/xdzip/issues/25)。

`release.json` 采用更新协议 `schema_version: 1`，绑定完整版本、渠道 `alpha`、构建号、标签和完整提交 SHA，记录六类资产的系统要求、字节数、SHA-256 和固定标签下载 URL。`SHA256SUMS` 覆盖清单及所有交付附件。对应源码包含 Rust vendor、Qt 源码和补丁及重建材料；各平台 materials 附件包含通知、许可、SBOM 和部署／验证回执。

未来更新客户端应分页获取 Releases 列表，按语义版本、允许渠道、平台、架构和包类型选择，并验证字节数和 SHA-256。预发布不能依赖 `/releases/latest`。当前尚未实现自动更新器。

### 已知边界

仍属实验性预发布。macOS 和 Linux 的本次完整人工视觉验收未执行，自动化验证不等于人工验收。许可来源复核仍由 [#4](https://github.com/xiaodaozhi/xdzip/issues/4) 跟踪，不因本次发布而视为通过。尚不支持 RAR／7z、Intel Mac、Windows／Linux ARM64 或 Wayland。重要文件请保留备份。
