# xdzip 0.3.1

**应用版本 0.3.1，构建 32。** GitHub 提供 Windows x64、macOS Apple Silicon 和 Linux x64 的桌面包与独立 CLI。

- **浏览体验。** 优化起始页格式分类和翻页，修复面包屑导航时工具栏抖动及操作窗口的布局问题。
- **归档处理。** 修复大型归档分页查询可能提前结束的问题，并改进 Windows 解压文件的来源信息保留。
- **语言和依赖。** 调整简体与繁体中文选项的位置和名称，更新部分归档与图像处理依赖。

Windows 安装程序未使用发布者证书签名；macOS 程序包使用 ad-hoc 完整性签名，未经过 Apple 公证，系统可能显示安全提示。Microsoft Store 的发布和更新独立进行；实验性 strict Snap 不属于本次 GitHub 发行，见 [#376](https://github.com/xiaodaozhi/xdzip/issues/376)。

本次发行的提交、自动检查、许可证复核及实际平台验收范围见 [#432](https://github.com/xiaodaozhi/xdzip/issues/432)。既有人工验收记录不代表本版已重新完成相同操作。

## English

**Application version 0.3.1, build 32.** GitHub provides desktop and standalone CLI packages for Windows x64, macOS Apple Silicon and Linux x64.

- **Browsing.** Improve format categories and paging on the start page, fix toolbar movement during breadcrumb navigation, and correct operation-window layout.
- **Archive handling.** Fix premature completion of paged queries for large archives and improve preservation of Windows origin information on extracted files.
- **Languages and dependencies.** Adjust the order and labels of Simplified and Traditional Chinese choices, and update some archive and image-processing dependencies.

The Windows installer is not signed with a publisher certificate. macOS packages use ad-hoc integrity signing and are not notarized by Apple; operating systems may show security warnings. Microsoft Store publication and updates are separate. The experimental strict Snap is outside this GitHub release; see [#376](https://github.com/xiaodaozhi/xdzip/issues/376).

See [#432](https://github.com/xiaodaozhi/xdzip/issues/432) for the release commit, automated checks, license review and actual platform acceptance scope. Earlier manual acceptance does not establish that the same operations were repeated for this version.
