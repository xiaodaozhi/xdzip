# xdzip 0.3.2

**应用版本 0.3.2，构建 34。** GitHub 提供 Windows x64、macOS Apple Silicon、macOS Intel 和 Linux x64 的桌面包与独立 CLI。

- **macOS Intel。** 首次提供原生 Intel 桌面和 CLI，支持 macOS 14 及以上。Intel Mac 请选择文件名含 `macos-x86_64` 的下载项，Apple Silicon 请选择 `macos-arm64`。两种架构分别提供认证更新。
- **界面。** 优化起始页格式后缀标签的对齐，修复 Windows 解压窗口的尺寸和下拉样式。

Windows 安装器未使用发布者证书签名。macOS 应用包采用 ad-hoc 完整性签名，未经过 Apple 公证。Microsoft Store 独立发布和更新。Ubuntu amd64 的 stable Snap 由专用发行工作流同步。

Intel 候选包和四平台生产更新的已有验收见 [#460](https://github.com/xiaodaozhi/xdzip/issues/460)。本版源码、依赖、实际交付工件和验收范围记录在 [#475](https://github.com/xiaodaozhi/xdzip/issues/475)。已记录的自动检查和人工桌面验收各自适用于其覆盖范围。

## English

**Application version 0.3.2, build 34.** GitHub provides desktop and standalone CLI packages for Windows x64, macOS Apple Silicon, macOS Intel and Linux x64.

- **macOS Intel.** Native Intel desktop and CLI packages are available for macOS 14 or later. Choose `macos-x86_64` on an Intel Mac and `macos-arm64` on Apple Silicon. Each architecture has its own authenticated update feed.
- **Interface.** Align the format suffix labels on the start page and correct the size and dropdown styling of the Windows extraction window.

The Windows installer is unsigned. The macOS packages use ad-hoc integrity signing and are not notarized by Apple. Microsoft Store releases and updates are separate. The dedicated release workflow also publishes the Ubuntu amd64 Snap to stable.

See [#460](https://github.com/xiaodaozhi/xdzip/issues/460) for the existing Intel candidate and four-platform production update evidence. See [#475](https://github.com/xiaodaozhi/xdzip/issues/475) for this version's source, dependencies, delivered artifacts and acceptance scope. Automated checks and manual desktop acceptance each apply to the scope recorded for them.
