# xdzip 0.3.0

**应用版本 0.3.0，构建 31。** GitHub 提供 Windows x64、macOS Apple Silicon 和 Linux x64 的桌面包与独立 CLI。

- **十语言界面与文档。** 桌面界面、系统菜单及用户文档支持十种语言，自动语言在支持时跟随系统，否则使用美式英语。可在设置中选择界面语言。
- **归档编辑。** 更多受支持的格式可以添加、替换、移动、重命名和删除条目；具体能力和限制见[格式支持表](https://github.com/xiaodaozhi/xdzip/blob/v0.3.0/README.zh-CN.md#格式支持)。
- **浏览和系统集成。** 文件预览可自动加载并按需刷新；改进了归档条目的操作入口、macOS 文件关联和 Ubuntu 窗口及文件交接。

Windows 安装程序未使用发布者证书签名，macOS 程序包使用 ad-hoc 完整性签名，未经过 Apple 公证，系统可能显示安全提示。Microsoft Store 的发布和更新独立进行；实验性 strict Snap 不属于本次 GitHub 发行，相关桌面验收见 [#376](https://github.com/xiaodaozhi/xdzip/issues/376) 和 [#398](https://github.com/xiaodaozhi/xdzip/issues/398)。

此前的 Finder、Windows 传统与现代菜单实机验收，以及 Ubuntu 十语言菜单实机操作的范围见 [#370](https://github.com/xiaodaozhi/xdzip/issues/370)。十语言的三平台原生自动检查针对提交 `3b225387`；这些证据不表示本发行候选的十种语言均已逐项在 Finder 和 Windows 菜单中实机操作。最终候选的提交、包校验和发行验证记录见 [#402](https://github.com/xiaodaozhi/xdzip/issues/402)。

## English

**Application version 0.3.0, build 31.** GitHub provides desktop and standalone CLI packages for Windows x64, macOS Apple Silicon and Linux x64.

- **Ten interface and documentation languages.** The desktop interface, system menus and user documentation support ten languages. Automatic language selection follows supported system languages and otherwise uses US English; the interface language can also be selected in settings.
- **Archive editing.** More supported formats can add, replace, move, rename and delete entries. See the [format support table](https://github.com/xiaodaozhi/xdzip/blob/v0.3.0/README.md#format-support) for capabilities and limits.
- **Browsing and system integration.** File previews can load automatically and refresh on demand. Archive entry actions, macOS file associations, and Ubuntu window and file handoff behavior have been improved.

The Windows installer is not signed with a publisher certificate. macOS packages use ad-hoc integrity signing and are not notarized by Apple; operating systems may show security warnings. Microsoft Store publication and updates are separate. The experimental strict Snap is outside this GitHub release; its desktop acceptance is tracked in [#376](https://github.com/xiaodaozhi/xdzip/issues/376) and [#398](https://github.com/xiaodaozhi/xdzip/issues/398).

Earlier Finder, Windows classic and modern menu desktop acceptance, and Ubuntu ten-language menu operation are documented with their actual scope in [#370](https://github.com/xiaodaozhi/xdzip/issues/370). The three-platform native automated checks for ten languages used commit `3b225387`; these records do not establish manual testing of every language in Finder and Windows menus for this release candidate. The final candidate commit, package checksums and release verification are tracked in [#402](https://github.com/xiaodaozhi/xdzip/issues/402).
