# xdzip 0.1.1

xdzip **0.1.1，build 24** 是稳定补丁版本，修复目录浏览、macOS 更新交接和发行 ZIP 兼容性问题。

## 本版更新

- 目录、搜索或排序查询期间保留已提交的列表、网格或空状态，减少工作区加载遮罩造成的闪烁。
- macOS 无法自动安装更新时，说明安装身份、更新源或代理等限制，并提供 DMG 和 app.zip 的手动安装指引。下载完成不代表安装完成。
- 修复 macOS ZIP 中安全的父相对符号链接解压，继续拒绝越界、循环及不完整链接；Windows 不恢复 POSIX 符号链接。

## 支持与限制

- Windows 11（受维护版本）x86_64，macOS 14 或更新版本 Apple Silicon，Ubuntu 24.04 LTS x86_64、X11、glibc 2.39 或更新版本。
- Windows 安装器未签署发行者证书；macOS 使用 ad-hoc 完整性签名，未使用 Developer ID 签名或公证。系统可能显示安全提示。
- macOS 的 Finder 和手动安装演练在 Apple Silicon 本机执行；更新故障恢复使用测试密钥及受控候选。Windows 11 对公开 Windows ZIP 的应用界面解压已验证；Windows 不恢复 macOS 包中的 POSIX 符号链接。
- 发行材料包含适用通知和 SBOM，不附单独的对应源码压缩包；该政策本身不代表所有适用许可义务已自动满足。

## English

**xdzip 0.1.1, build 24** is a stable maintenance release fixing directory browsing, macOS update handoff and release ZIP compatibility.

## Changes

- Keep the last committed list, grid or empty state during directory, search and sorting queries, reducing flashes caused by the workspace loading overlay.
- Explain installation identity, update feed or proxy restrictions when macOS automatic installation is unavailable, and provide manual DMG and app.zip instructions. A completed download is not an installation.
- Extract safe parent-relative symbolic links in macOS ZIP archives while continuing to reject escaping, cyclic and incomplete links. Windows does not restore POSIX symbolic links.

## Support and limitations

- Windows 11 (supported servicing versions) x86_64, macOS 14 or later on Apple Silicon, and Ubuntu 24.04 LTS x86_64 with X11 and glibc 2.39 or later.
- The Windows installer has no publisher signature. macOS uses ad-hoc integrity signing without Developer ID signing or notarization. System security prompts may appear.
- Finder and manual installation were exercised on an Apple Silicon Mac; update failure recovery used test keys and controlled candidates. Windows 11 application extraction of the public Windows ZIP was verified; Windows does not restore POSIX links from the macOS archive.
- Release materials include applicable notices and SBOMs without a separate corresponding-source archive. This policy does not itself establish that all applicable license obligations are satisfied.
