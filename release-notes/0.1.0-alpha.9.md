# xdzip 0.1.0-alpha.9

xdzip **0.1.0-alpha.9，build 22** 是实验性跨平台预发布候选。具体候选、验证记录及剩余事项见 [#216](https://github.com/xiaodaozhi/xdzip/issues/216) 和 [#53](https://github.com/xiaodaozhi/xdzip/issues/53)。

## 本次变更

- Windows 开发部署不再随包携带 `d3dcompiler_47.dll`、`dxcompiler.dll`、`dxil.dll` 三份 Windows SDK 图形 DLL，使用系统提供的图形运行时；正式候选包需按 #216 核对实际载荷和运行结果。
- 设置窗口、归档任务和文件关联包含 alpha.8 之后的修正。Windows 文件关联类型描述随应用语言更新；macOS 的 CAB、RAR 和 UDF 关联行为见[安装与关联说明](../docs/engineering/installers-associations.md)。不同平台的实际验证范围按 #53 分别记录。
- 原 alpha.8 的 Windows 附件仍包含上述 SDK 文件，其历史分发条件与处置见 [#135](https://github.com/xiaodaozhi/xdzip/issues/135)；新候选不追认历史接收者的协议选择。

## 系统与更新

候选面向 Windows 11 x86_64、macOS 14+ Apple Silicon、Ubuntu 24.04 x86_64／X11。Windows 安装器无发行者签名；macOS 使用 ad-hoc 完整性签名，没有 Developer ID 或公证。更新签名不等同平台发行者身份。当前不提供 Intel Mac、Windows／Linux ARM64 或 Wayland 支持。

已安装且满足身份、版本和签名条件的 alpha.8 可从设置中主动检查更新；alpha.6 及更早版本缺少现行更新组件，需要手动安装一次。便携版继续手动更新。实际新版本的发现、签名和安装升级须按 #216 的候选身份验证，不能以此说明代替结果。

Mac／Ubuntu 的未完成桌面验收、参考机性能与发行许可复核继续按 #53 登记。既有其他版本的人工结果保留原身份，SBOM 完整性及未决许可不能因自动测试通过而视为完成。

## English

**xdzip 0.1.0-alpha.9, build 22** is an experimental cross-platform prerelease candidate. Candidate-specific evidence and outstanding work are tracked in [#216](https://github.com/xiaodaozhi/xdzip/issues/216) and [#53](https://github.com/xiaodaozhi/xdzip/issues/53).

Windows development deployment no longer bundles the Windows SDK graphics DLLs `d3dcompiler_47.dll`, `dxcompiler.dll` and `dxil.dll`, relying on the system graphics runtime. Actual release-candidate payloads and operation remain subject to #216 verification. Settings, archive tasks and file associations include fixes since alpha.8; Windows association descriptions follow the app language, and macOS CAB, RAR and UDF behavior is described in the [association guide](../docs/engineering/installers-associations.md). Platform verification is tracked separately in #53. The original alpha.8 Windows assets still contain the SDK files; their historical conditions and disposition remain in [#135](https://github.com/xiaodaozhi/xdzip/issues/135).

Targets are Windows 11 x86_64, macOS 14+ Apple Silicon and Ubuntu 24.04 x86_64/X11. Windows installers have no publisher signature; macOS uses ad-hoc integrity signing without Developer ID or notarization. Update signatures are separate from publisher identity. Intel Mac, Windows/Linux ARM64 and Wayland are not currently supported.

Eligible installed alpha.8 builds can initiate update checks from Settings; published alpha.6 and earlier clients lack the current updater and need one manual installation. Portable builds are updated manually. Actual candidate discovery, signatures and installation upgrades must be verified under #216. Unfinished Mac/Ubuntu desktop checks, reference-host performance and licensing review remain in #53; historical human observations retain their own build identities and automated checks do not resolve incomplete SBOM or license items.
